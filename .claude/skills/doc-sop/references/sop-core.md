# Core Principles

## Quality First

**CRITICAL**: Every code example must be complete and runnable.

### Forbidden Patterns

❌ **NEVER** do these:
- Leave TODO or FIXME markers
- Use "// ... implementation omitted"
- Write code without imports
- Assume functions exist without defining them
- Write partial code examples
- Skip version number updates when editing

### Required Patterns

✅ **ALWAYS** do these:
- Write complete, runnable code
- Include all imports
- Define all referenced functions
- Use kebab-case for filenames
- Use .mdx extension
- Update version number on edits
- Update last modified date
- Verify code runs independently

## Consistency

- Unified document structure and format
- Unified naming convention (kebab-case)
- Unified code style (JavaScript)
- Unified comment standards

## Practicality

- Provide complete runnable code examples
- Include real application scenarios
- Provide learning checkpoints
- Give next learning path
