# Generator 模式

> **版本**：v1.0  
> **最后更新**：2026-04-20

## 📚 概念介绍

Effect.gen 基于 JavaScript 的 Generator 语法，理解 Generator 的工作原理有助于更好地使用 Effect.gen。

## 🎯 Generator 基础

### 什么是 Generator

```js
// 普通 Generator
function* simpleGenerator() {
  yield 1
  yield 2
  yield 3
  return 4
}

const gen = simpleGenerator()
console.log(gen.next())  // { value: 1, done: false }
console.log(gen.next())  // { value: 2, done: false }
console.log(gen.next())  // { value: 3, done: false }
console.log(gen.next())  // { value: 4, done: true }
```

### Generator 与 Effect.gen 的关系

```js
import { Effect } from 'effect'

// Effect.gen 内部使用 Generator
const effectGen = Effect.gen(function* () {
  const value1 = yield* Effect.succeed(1)
  const value2 = yield* Effect.succeed(2)
  return value1 + value2
})

// Effect.gen 将 yield* 的 Effect 转换为实际的执行
Effect.runSync(effectGen)  // 3
```

## 💡 yield* 的委托机制

### 委托给其他 Generator

```js
import { Effect } from 'effect'

// 子 Generator
function* fetchUserData(userId: string) {
  const user = yield* Effect.succeed({ id: userId, name: 'Alice' })
  const posts = yield* Effect.succeed([{ id: '1', userId, title: 'Post 1' }])
  return { user, posts }
}

// 主 Generator
const program = Effect.gen(function* () {
  const data = yield* fetchUserData('1')
  return data
})

Effect.runSync(program)
// { user: { id: '1', name: 'Alice' }, posts: [...] }
```

### 委托给 Effect

```js
import { Effect } from 'effect'

// Effect.gen 自动处理 Effect 的委托
const program = Effect.gen(function* () {
  // yield* 将控制权委托给 Effect
  const result1 = yield* Effect.succeed(1)
  const result2 = yield* Effect.succeed(2)
  const result3 = yield* Effect.succeed(3)
  
  return result1 + result2 + result3
})

Effect.runSync(program)  // 6
```

## 🚀 常见模式

### 顺序执行模式

```js
import { Effect } from 'effect'

// 顺序执行多个操作
const sequentialPattern = Effect.gen(function* () {
  const step1 = yield* initialize()
  const step2 = yield* process(step1)
  const step3 = yield* finalize(step2)
  
  return step3
})
```

### 并行执行模式

```js
import { Effect } from 'effect'

// 并行执行多个操作
const parallelPattern = Effect.gen(function* () {
  const [result1, result2, result3] = yield* Effect.all([
    operation1(),
    operation2(),
    operation3()
  ])
  
  return { result1, result2, result3 }
})
```

### 混合模式

```js
import { Effect } from 'effect'

// 混合顺序和并行执行
const mixedPattern = Effect.gen(function* () {
  // 顺序执行
  const config = yield* loadConfig()
  
  // 并行执行
  const [users, posts, comments] = yield* Effect.all([
    fetchUsers(config.userApi),
    fetchPosts(config.postApi),
    fetchComments(config.commentApi)
  ])
  
  // 顺序处理
  const enriched = yield* enrichData({ users, posts, comments })
  
  return enriched
})
```

## 📝 错误处理模式

### Try-Catch 模式

```js
import { Effect } from 'effect'

const tryCatchPattern = Effect.gen(function* () {
  try {
    const result = yield* riskyOperation()
    return { success: true, result }
  } catch (error) {
    console.error('Operation failed:', error)
    return { success: false, error }
  }
})
```

### 错误恢复模式

```js
import { Effect } from 'effect'

const recoveryPattern = Effect.gen(function* () {
  let result
  
  try {
    result = yield* primaryOperation()
  } catch (error) {
    console.log('Primary failed, using fallback')
    result = yield* fallbackOperation()
  }
  
  return result
})
```

### 错误聚合模式

```js
import { Effect } from 'effect'

const aggregationPattern = Effect.gen(function* () {
  const results = yield* Effect.all([
    operation1(),
    operation2(),
    operation3()
  ], { mode: 'all' })  // 收集所有结果，包括错误
  
  const successful = results.filter(r => !r._tag)
  const errors = results.filter(r => r._tag)
  
  return { successful, errors }
})
```
