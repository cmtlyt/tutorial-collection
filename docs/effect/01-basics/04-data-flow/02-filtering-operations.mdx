# 过滤操作

> **版本**：v1.0  
> **最后更新**：2026-04-20

## 📚 概念介绍

Effect 提供了多种过滤操作，用于选择和过滤 Effect 中的数据。这些操作让你能够以声明式的方式构建数据选择逻辑。

## 🎯 Effect.filter - 基本过滤

根据谓词函数过滤 Effect 的成功值。

### 基本用法

```js
import { Effect } from 'effect'

// 过滤数组
const numbersEffect = Effect.succeed([1, 2, 3, 4, 5])

const evenNumbersEffect = numbersEffect.pipe(
  Effect.filter(n => n % 2 === 0)
)

Effect.runSync(evenNumbersEffect)  // [2, 4]

// 过滤对象数组
const usersEffect = Effect.succeed([
  { id: '1', name: 'Alice', age: 25, active: true },
  { id: '2', name: 'Bob', age: 30, active: false },
  { id: '3', name: 'Charlie', age: 35, active: true }
])

const activeUsersEffect = usersEffect.pipe(
  Effect.filter(user => user.active)
)

Effect.runSync(activeUsersEffect)
// [
//   { id: '1', name: 'Alice', age: 25, active: true },
//   { id: '3', name: 'Charlie', age: 35, active: true }
// ]
```

### 复杂过滤条件

```js
import { Effect } from 'effect'

const productsEffect = Effect.succeed([
  { id: '1', name: 'Laptop', price: 1000, category: 'Electronics', inStock: true },
  { id: '2', name: 'Mouse', price: 20, category: 'Electronics', inStock: true },
  { id: '3', name: 'Desk', price: 500, category: 'Furniture', inStock: false },
  { id: '4', name: 'Chair', price: 200, category: 'Furniture', inStock: true }
])

// 多条件过滤
const affordableElectronics = productsEffect.pipe(
  Effect.filter(product => 
    product.category === 'Electronics' && 
    product.price < 500 && 
    product.inStock
  )
)

Effect.runSync(affordableElectronics)
// [
//   { id: '2', name: 'Mouse', price: 20, category: 'Electronics', inStock: true }
// ]
```

## 💡 Effect.filterMap - 过滤和转换

同时过滤和转换数据。

### 基本用法

```js
import { Effect } from 'effect'

// 过滤并转换
const numbersEffect = Effect.succeed([1, 2, 3, 4, 5])

const doubledEvens = numbersEffect.pipe(
  Effect.filterMap(n => 
    n % 2 === 0 ? Option.some(n * 2) : Option.none()
  )
)

Effect.runSync(doubledEvens)  // [4, 8]

// 提取有效值
const valuesEffect = Effect.succeed([
  { id: '1', value: 42 },
  { id: '2', value: null },
  { id: '3', value: 100 },
  { id: '4', value: undefined }
])

const validValues = valuesEffect.pipe(
  Effect.filterMap(item => 
    item.value !== null && item.value !== undefined 
      ? Option.some(item.value) 
      : Option.none()
  )
)

Effect.runSync(validValues)  // [42, 100]
```

### 复杂过滤和转换

```js
import { Effect, Option } from 'effect'

const usersEffect = Effect.succeed([
  { id: '1', name: 'Alice', email: 'alice@example.com', verified: true },
  { id: '2', name: 'Bob', email: 'bob@example.com', verified: false },
  { id: '3', name: 'Charlie', email: 'charlie@example.com', verified: true }
])

// 提取已验证用户的邮箱
const verifiedEmails = usersEffect.pipe(
  Effect.filterMap(user =>
    user.verified ? Option.some(user.email) : Option.none()
  )
)

Effect.runSync(verifiedEmails)
// ['alice@example.com', 'charlie@example.com']
```

## 🚀 Effect.find - 查找元素

查找满足条件的第一个元素。

### 基本用法

```js
import { Effect, Option } from 'effect'

const usersEffect = Effect.succeed([
  { id: '1', name: 'Alice', age: 25 },
  { id: '2', name: 'Bob', age: 30 },
  { id: '3', name: 'Charlie', age: 35 }
])

const foundUser = usersEffect.pipe(
  Effect.find(user => user.name === 'Bob')
)

Effect.runSync(foundUser)
// Option.some({ id: '2', name: 'Bob', age: 30 })

// 查找不存在的元素
const notFound = usersEffect.pipe(
  Effect.find(user => user.name === 'David')
)

Effect.runSync(notFound)  // Option.none()
```

### 条件查找

```js
import { Effect, Option } from 'effect'

const productsEffect = Effect.succeed([
  { id: '1', name: 'Laptop', price: 1000 },
  { id: '2', name: 'Mouse', price: 20 },
  { id: '3', name: 'Keyboard', price: 50 }
])

// 查找第一个价格低于 100 的产品
const cheapProduct = productsEffect.pipe(
  Effect.find(product => product.price < 100)
)

Effect.runSync(cheapProduct)
// Option.some({ id: '2', name: 'Mouse', price: 20 })
```

## 🎯 Effect.findFirst - 查找第一个元素

查找第一个元素，可以不提供条件。

### 基本用法

```js
import { Effect, Option } from 'effect'

const numbersEffect = Effect.succeed([1, 2, 3, 4, 5])

const firstNumber = numbersEffect.pipe(
  Effect.findFirst()
)

Effect.runSync(firstNumber)  // Option.some(1)

// 空数组
const emptyEffect = Effect.succeed([])

const firstOfEmpty = emptyEffect.pipe(
  Effect.findFirst()
)

Effect.runSync(firstOfEmpty)  // Option.none()
```

### 结合条件使用

```js
import { Effect, Option } from 'effect'

const usersEffect = Effect.succeed([
  { id: '1', name: 'Alice', age: 25 },
  { id: '2', name: 'Bob', age: 30 },
  { id: '3', name: 'Charlie', age: 35 }
])

const firstAdult = usersEffect.pipe(
  Effect.findFirst(user => user.age >= 18)
)

Effect.runSync(firstAdult)
// Option.some({ id: '1', name: 'Alice', age: 25 })
```

## 📝 实际应用示例

### 数据验证和过滤

```js
import { Effect, Option } from 'effect'

interface User {
  id: string
  name: string
  email: string
  age: number
}

// 验证用户数据
const validateUser = (user: unknown): Option.Option<User> => {
  if (typeof user !== 'object' || user === null) {
    return Option.none()
  }

  const u = user as any
  if (!u.id || !u.name || !u.email || typeof u.age !== 'number') {
    return Option.none()
  }

  if (u.age < 18) {
    return Option.none()
  }

  return Option.some({
    id: u.id,
    name: u.name,
    email: u.email,
    age: u.age
  })
}

// 过滤有效用户
const rawUsersEffect = Effect.succeed([
  { id: '1', name: 'Alice', email: 'alice@example.com', age: 25 },
  { id: '2', name: 'Bob', email: 'bob@example.com', age: 15 },
  { id: '3', name: 'Charlie', email: 'charlie@example.com', age: 30 },
  { invalid: 'data' }
])

const validUsers = rawUsersEffect.pipe(
  Effect.filterMap(validateUser)
)

Effect.runSync(validUsers)
// [
//   { id: '1', name: 'Alice', email: 'alice@example.com', age: 25 },
//   { id: '3', name: 'Charlie', email: 'charlie@example.com', age: 30 }
// ]
```

### 权限过滤

```js
import { Effect } from 'effect'

interface Resource {
  id: string
  name: string
  permissions: string[]
}

interface User {
  id: string
  roles: string[]
}

const resourcesEffect = Effect.succeed([
  { id: '1', name: 'Dashboard', permissions: ['read'] },
  { id: '2', name: 'Settings', permissions: ['read', 'write'] },
  { id: '3', name: 'Admin', permissions: ['read', 'write', 'delete'] }
])

const userEffect = Effect.succeed({
  id: '1',
  roles: ['user']
})

// 检查用户权限
const hasPermission = (user: User, permission: string) => {
  return user.roles.includes('admin') || user.roles.includes(permission)
}

// 过滤用户有权限的资源
const accessibleResources = Effect.gen(function* () {
  const user = yield* userEffect
  const resources = yield* resourcesEffect

  return resources.filter(resource =>
    resource.permissions.some(permission =>
      hasPermission(user, permission)
    )
  )
})

Effect.runSync(accessibleResources)
// [
//   { id: '1', name: 'Dashboard', permissions: ['read'] },
//   { id: '2', name: 'Settings', permissions: ['read', 'write'] }
// ]
```

### 搜索和匹配

```js
import { Effect, Option } from 'effect'

interface Product {
  id: string
  name: string
  category: string
  price: number
}

const productsEffect = Effect.succeed([
  { id: '1', name: 'Laptop', category: 'Electronics', price: 1000 },
  { id: '2', name: 'Mouse', category: 'Electronics', price: 20 },
  { id: '3', name: 'Desk', category: 'Furniture', price: 500 },
  { id: '4', name: 'Chair', category: 'Furniture', price: 200 }
])

// 搜索产品
const searchProducts = (query: string) =>
  productsEffect.pipe(
  Effect.filter(product =>
    product.name.toLowerCase().includes(query.toLowerCase()) ||
    product.category.toLowerCase().includes(query.toLowerCase())
  )
)

Effect.runSync(searchProducts('elec'))
// [
//   { id: '1', name: 'Laptop', category: 'Electronics', price: 1000 },
//   { id: '2', name: 'Mouse', category: 'Electronics', price: 20 }
// ]

// 查找特定产品
const findProduct = (id: string) =>
  productsEffect.pipe(
  Effect.find(product => product.id === id)
)

Effect.runSync(findProduct('3'))
// Option.some({ id: '3', name: 'Desk', category: 'Furniture', price: 500 })
```
