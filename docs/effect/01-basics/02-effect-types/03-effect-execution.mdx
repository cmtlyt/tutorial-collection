# Effect 执行

> **版本**：v1.0  
> **最后更新**：2026-04-20

## 📚 概念介绍

Effect 本身只是对计算的描述，需要通过执行器来真正运行。Effect 提供了多种执行方式，适用于不同的场景。

## 🎯 执行方式概览

```js
import { Effect } from 'effect'

// 创建一个简单的 Effect
const program = Effect.gen(function* () {
  console.log('Starting program')
  const value = yield* Effect.succeed(42)
  console.log('Computed value:', value)
  return value * 2
})
```

### 执行方式对比

| 执行方式 | 返回类型 | 适用场景 | 是否阻塞 |
|---------|---------|---------|---------|
| `runSync` | `A` | 同步、无失败的 Effect | 是 |
| `runPromise` | `Promise<A>` | 异步 Effect | 否 |
| `runFork` | `Fiber<A>` | 并发执行 | 否 |
| `runCallback` | `void` | 回调风格 | 否 |

## 🔍 Effect.runSync - 同步执行

同步执行 Effect，立即返回结果。只适用于不会失败的同步 Effect。

### 基本用法

```js
import { Effect } from 'effect'

// 简单的同步 Effect
const syncEffect = Effect.succeed(42)
const result = Effect.runSync(syncEffect)
console.log(result)  // 42

// 使用 sync 创建的 Effect
const computed = Effect.sync(() => {
  console.log('Computing...')
  return Math.random() * 100
})

const value = Effect.runSync(computed)
console.log(value)
```

### 使用限制

```js
import { Effect } from 'effect'

// ❌ 不能用于异步 Effect
const asyncEffect = Effect.async((resume) => {
  setTimeout(() => {
    resume(Effect.succeed('Async result'))
  }, 1000)
})

// Effect.runSync(asyncEffect)  // 运行时错误

// ❌ 不能用于可能失败的 Effect
const failingEffect = Effect.fail(new Error('Error'))

// Effect.runSync(failingEffect)  // 运行时错误

// ✅ 只能用于同步、无失败的 Effect
const safeEffect = Effect.succeed(42)
Effect.runSync(safeEffect)  // 42
```

### 实际应用

```js
import { Effect } from 'effect'

// 纯计算
const calculateTotal = (items: { price: number; quantity: number }[]) =>
  Effect.sync(() =>
    items.reduce((sum, item) => sum + item.price * item.quantity, 0)
  )

const items = [
  { price: 10, quantity: 2 },
  { price: 20, quantity: 1 }
]

const total = Effect.runSync(calculateTotal(items))
console.log(total)  // 40
```

## 💡 Effect.runPromise - 异步执行

异步执行 Effect，返回 Promise。这是最常用的执行方式。

### 基本用法

```js
import { Effect } from 'effect'

// 简单的异步 Effect
const asyncEffect = Effect.async((resume) => {
  setTimeout(() => {
    resume(Effect.succeed('Async result'))
  }, 1000)
})

Effect.runPromise(asyncEffect).then(result => {
  console.log(result)  // 'Async result'
})

// 使用 async/await
const main = async () => {
  const result = await Effect.runPromise(asyncEffect)
  console.log(result)  // 'Async result'
}
```

### 处理错误

```js
import { Effect } from 'effect'

// 可能失败的 Effect
const errorEffect = Effect.fail(new Error('Something went wrong'))

// 使用 catch
Effect.runPromise(errorEffect).catch(error => {
  console.log('Error:', error.message)  // 'Error: Something went wrong'
})

// 使用 try-catch
try {
  const result = await Effect.runPromise(errorEffect)
} catch (error) {
  console.log('Caught:', error)
}
```

### 实际应用

```js
import { Effect } from 'effect'

// API 请求
const fetchUser = (id: string) =>
  Effect.tryPromise(() =>
    fetch(`/api/users/${id}`).then(res => res.json())
  )

const main = async () => {
  try {
    const user = await Effect.runPromise(fetchUser('1'))
    console.log('User:', user)
  } catch (error) {
    console.error('Failed to fetch user:', error)
  }
}

main()
```

## 🚀 Effect.runFork - 并发执行

并发执行 Effect，返回 Fiber。用于需要并发控制的场景。

### 基本用法

```js
import { Effect } from 'effect'

// 创建并发的 Effect
const task1 = Effect.sync(() => {
  console.log('Task 1')
  return 1
})

const task2 = Effect.sync(() => {
  console.log('Task 2')
  return 2
})

// 并发执行
const fiber1 = Effect.runFork(task1)
const fiber2 = Effect.runFork(task2)

// 等待完成
const results = await Effect.runPromise(Effect.all([
  Effect.fromFiber(fiber1),
  Effect.fromFiber(fiber2)
]))

console.log(results)  // [1, 2]
```

### Fiber 操作

```js
import { Effect } from 'effect'

// 创建长时间运行的任务
const longTask = Effect.sleep(2000).pipe(
  Effect.andThen(Effect.succeed('Task completed'))
)

// Fork 执行
const fiber = Effect.runFork(longTask)

// 检查状态
const isDone = await Effect.runPromise(fiber.await)
console.log('Task done:', isDone)

// 获取结果
const result = await Effect.runPromise(fiber.join)
console.log('Result:', result)
```

### 实际应用

```js
import { Effect } from 'effect'

// 并发处理多个请求
const fetchUser = (id: string) =>
  Effect.tryPromise(() =>
    fetch(`/api/users/${id}`).then(res => res.json())
  )

const fetchPosts = (userId: string) =>
  Effect.tryPromise(() =>
    fetch(`/api/users/${userId}/posts`).then(res => res.json())
  )

const main = async () => {
  // 并发执行
  const userFiber = Effect.runFork(fetchUser('1'))
  
  // 等待用户数据
  const user = await Effect.runPromise(Effect.fromFiber(userFiber))
  
  // 并发获取用户的帖子
  const postsFiber = Effect.runFork(fetchPosts(user.id))
  
  // 等待帖子数据
  const posts = await Effect.runPromise(Effect.fromFiber(postsFiber))
  
  console.log({ user, posts })
}

main()
```

## 🎯 Effect.runCallback - 回调执行

通过回调执行 Effect，适用于需要回调风格的场景。

### 基本用法

```js
import { Effect } from 'effect'

// 简单的 Effect
const effect = Effect.succeed(42)

// 使用回调执行
Effect.runCallback(effect, {
  onSuccess: (result) => {
    console.log('Success:', result)  // Success: 42
  },
  onFailure: (error) => {
    console.log('Error:', error)
  }
})
```

### 处理错误

```js
import { Effect } from 'effect'

// 可能失败的 Effect
const errorEffect = Effect.fail(new Error('Error'))

Effect.runCallback(errorEffect, {
  onSuccess: (result) => {
    console.log('Success:', result)
  },
  onFailure: (error) => {
    console.log('Error:', error.message)  // Error: Error
  }
})
```

### 实际应用

```js
import { Effect } from 'effect'

// 在 Node.js 回调中使用
const fs = require('fs')

const readFile = (path: string) =>
  Effect.tryPromise(() =>
    new Promise((resolve, reject) => {
      fs.readFile(path, 'utf8', (err, data) => {
        if (err) reject(err)
        else resolve(data)
      })
    })
  )

Effect.runCallback(readFile('./data.txt'), {
  onSuccess: (data) => {
    console.log('File content:', data)
  },
  onFailure: (error) => {
    console.error('Failed to read file:', error)
  }
})
```

## 📝 执行模式比较

### 同步 vs 异步

```js
import { Effect } from 'effect'

// 同步执行 - 立即返回
const syncEffect = Effect.succeed(42)
const syncResult = Effect.runSync(syncEffect)
console.log('Sync result:', syncResult)

// 异步执行 - 返回 Promise
const asyncEffect = Effect.async((resume) => {
  setTimeout(() => {
    resume(Effect.succeed(42))
  }, 1000)
})

Effect.runPromise(asyncEffect).then(result => {
  console.log('Async result:', result)
})
```

### 串行 vs 并发

```js
import { Effect } from 'effect'

// 串行执行
const serial = Effect.gen(function* () {
  const result1 = yield* Effect.succeed(1)
  const result2 = yield* Effect.succeed(2)
  const result3 = yield* Effect.succeed(3)
  return [result1, result2, result3]
})

Effect.runSync(serial)  // [1, 2, 3]

// 并发执行
const parallel = Effect.all([
  Effect.succeed(1),
  Effect.succeed(2),
  Effect.succeed(3)
])

Effect.runSync(parallel)  // [1, 2, 3]

// 使用 Fiber 的并发控制
const task1 = Effect.sync(() => {
  console.log('Task 1')
  return 1
})

const task2 = Effect.sync(() => {
  console.log('Task 2')
  return 2
})

const fiber1 = Effect.runFork(task1)
const fiber2 = Effect.runFork(task2)

const results = await Effect.runPromise(Effect.all([
  Effect.fromFiber(fiber1),
  Effect.fromFiber(fiber2)
]))
```
