# 不可变性（Immutability）

> **版本**：v1.0  
> **最后更新**：2026-04-20

## 📚 概念介绍

不可变性是指数据一旦创建就不能被修改。在函数式编程中，不可变性是一个核心原则，它与纯函数和副作用管理密切相关。

## 🎯 核心概念

### 可变 vs 不可变

```js
// ❌ 可变操作 - 修改原数组
const numbers = [1, 2, 3]
numbers.push(4)
console.log(numbers) // [1, 2, 3, 4] - 原数组被修改

// ✅ 不可变操作 - 返回新数组
const numbers = [1, 2, 3]
const newNumbers = [...numbers, 4]
console.log(numbers)    // [1, 2, 3] - 原数组不变
console.log(newNumbers) // [1, 2, 3, 4] - 新数组
```

## 🔍 JavaScript 中的不可变操作

### 数组操作

```js
const arr = [1, 2, 3]

// 添加元素
const withAdd = [...arr, 4]              // [1, 2, 3, 4]
const withUnshift = [0, ...arr]          // [0, 1, 2, 3]

// 删除元素
const withoutLast = arr.slice(0, -1)     // [1, 2]
const withoutFirst = arr.slice(1)        // [2, 3]
const filtered = arr.filter(x => x !== 2) // [1, 3]

// 修改元素
const mapped = arr.map(x => x * 2)       // [2, 4, 6]
const withIndex = arr.with(1, 10)        // [1, 10, 3]

// 排序（不修改原数组）
const sorted = [...arr].sort((a, b) => b - a) // [3, 2, 1]
```

### 对象操作

```js
const user = {
  name: 'Alice',
  age: 25,
  address: {
    city: 'Beijing'
  }
}

// 添加属性
const withEmail = { ...user, email: 'alice@example.com' }

// 修改属性
const withNewAge = { ...user, age: 26 }

// 删除属性
const { address, ...withoutAddress } = user

// 深度修改
const withNewCity = {
  ...user,
  address: {
    ...user.address,
    city: 'Shanghai'
  }
}
```

### 使用 Immer 简化不可变操作

```js
import { produce } from 'immer'

const user = {
  name: 'Alice',
  todos: [
    { id: 1, text: 'Learn Effect', done: false }
  ]
}

// 使用 Immer 进行深度更新
const updatedUser = produce(user, draft => {
  draft.todos.push({ id: 2, text: 'Write docs', done: false })
  draft.todos[0].done = true
})

console.log(user)        // 原对象不变
console.log(updatedUser) // 新对象
```

## 💡 不可变性的优势

### 1. 可预测性

```js
// 可变 - 难以追踪变化
let state = { count: 0 }
function increment() {
  state.count += 1 // 谁修改了 state？
}

// 不可变 - 变化清晰可见
let state = { count: 0 }
function increment(state) {
  return { ...state, count: state.count + 1 } // 明确返回新状态
}
```

### 2. 时间旅行调试

```js
// 保存历史状态
const history = []
let currentState = { count: 0 }

function updateState(newState) {
  history.push(currentState)
  currentState = newState
}

// 可以回退到任何历史状态
function undo() {
  currentState = history.pop()
}
```

### 3. 并发安全

```js
// 不可变数据可以安全地在多个线程/协程间共享
const sharedData = { items: [1, 2, 3] }

// 多个协程同时读取，无需担心数据竞争
const task1 = Effect.sync(() => sharedData.items.map(x => x * 2))
const task2 = Effect.sync(() => sharedData.items.filter(x => x > 1))
```

### 4. 简化比较

```js
// 引用比较 - 高效
const state1 = { count: 0 }
const state2 = state1
console.log(state1 === state2) // true

// 深度比较 - 低效
const state3 = { count: 0 }
console.log(JSON.stringify(state1) === JSON.stringify(state3)) // true
```

## 🚀 Effect 中的不可变性

Effect 本身就是不可变的，Effect 操作总是返回新的 Effect：

```js
import { Effect } from 'effect'

// Effect 操作不会修改原 Effect
const effect1 = Effect.succeed(1)
const effect2 = effect1.pipe(Effect.map(x => x * 2))
const effect3 = effect1.pipe(Effect.map(x => x + 1))

console.log(effect1 !== effect2) // true - 不同的 Effect
console.log(effect1 !== effect3) // true - 不同的 Effect
```

### 使用 Ref 管理可变状态

虽然鼓励不可变性，但 Effect 也提供了 `Ref` 来管理必要的可变状态：

```js
import { Effect, Ref } from 'effect'

const program = Effect.gen(function* () {
  // 创建可变引用
  const counter = yield* Ref.make(0)
  
  // 读取状态
  const current = yield* Ref.get(counter)
  console.log(`Current: ${current}`)
  
  // 修改状态（返回新的 Effect）
  yield* Ref.set(counter, current + 1)
  
  // 原子修改
  yield* Ref.modify(counter, n => [n * 2, n + 1])
})
```

## 📝 实践建议

### 1. 优先使用不可变操作

```js
// ❌ 避免直接修改
function addItem(items, item) {
  items.push(item)
  return items
}

// ✅ 返回新数组
function addItem(items, item) {
  return [...items, item]
}
```

### 2. 使用展开运算符

```js
// 数组
const newArr = [...oldArr, newItem]

// 对象
const newObj = { ...oldObj, newProp: value }
```

### 3. 考虑使用不可变数据库

```js
// Immer
import { produce } from 'immer'

// Immutable.js
import { Map, List } from 'immutable'

const list = List([1, 2, 3])
const newList = list.push(4) // 返回新 List
```

### 4. 深拷贝时注意性能

```js
// ❌ 性能差 - 深拷贝整个对象
const deepCopy = JSON.parse(JSON.stringify(largeObject))

// ✅ 性能好 - 只复制需要修改的部分
const updated = {
  ...largeObject,
  nested: {
    ...largeObject.nested,
    prop: newValue
  }
}
```

## 🔗 相关概念

- **纯函数（Pure Functions）**：不可变性是纯函数的重要基础
- **副作用（Side Effects）**：不可变性有助于避免副作用
- **持久化数据结构（Persistent Data Structures）**：高效的不可变数据结构
