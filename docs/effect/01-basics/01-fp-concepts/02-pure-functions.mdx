# 纯函数（Pure Functions）

> **版本**：v1.0  
> **最后更新**：2026-04-20

## 📚 概念介绍

纯函数是函数式编程的核心概念之一。一个函数如果满足以下两个条件，就是纯函数：

1. **相同的输入总是产生相同的输出**
2. **没有副作用（Side Effects）**

## 🎯 核心特性

### 1. 确定性（Deterministic）

纯函数对于相同的输入，总是返回相同的输出：

```js
// 纯函数
function add(a, b) {
  return a + b
}

console.log(add(2, 3)) // 5
console.log(add(2, 3)) // 5
console.log(add(2, 3)) // 5
```

### 2. 无副作用（No Side Effects）

纯函数不会修改外部状态，也不依赖外部可变状态：

```js
// 非纯函数 - 依赖外部状态
let counter = 0
function increment() {
  counter += 1
  return counter
}

// 纯函数 - 不依赖外部状态
function incrementPure(counter) {
  return counter + 1
}
```

## 🔍 副作用示例

以下操作都会产生副作用，因此不是纯函数：

```js
// ❌ 修改外部变量
let globalVar = 0
function modifyGlobal() {
  globalVar = 1
}

// ❌ DOM 操作
function changeElement() {
  document.getElementById('app').innerHTML = 'Hello'
}

// ❌ 网络请求
function fetchData(url) {
  return fetch(url) // 每次调用结果可能不同
}

// ❌ 读写文件
function readFile(path) {
  return fs.readFileSync(path) // 文件内容可能变化
}

// ❌ 获取当前时间
function getCurrentTime() {
  return Date.now() // 每次调用结果都不同
}
```

## ✅ 纯函数示例

```js
// ✅ 数学运算
function square(x) {
  return x * x
}

// ✅ 数组操作（不修改原数组）
function doubleArray(arr) {
  return arr.map(x => x * 2)
}

// ✅ 对象操作（不修改原对象）
function updateName(user, newName) {
  return { ...user, name: newName }
}

// ✅ 字符串操作
function reverseString(str) {
  return str.split('').reverse().join('')
}
```

## 💡 纯函数的优势

### 1. 可测试性

纯函数易于测试，因为不需要设置复杂的环境：

```js
// 易于测试
function calculateDiscount(price, discountRate) {
  return price * (1 - discountRate)
}

// 测试用例
assert(calculateDiscount(100, 0.1) === 90)
assert(calculateDiscount(200, 0.2) === 160)
```

### 2. 可缓存性

由于输入输出关系确定，可以缓存结果：

```js
const cache = new Map()

function memoizedAdd(a, b) {
  const key = `${a},${b}`
  if (cache.has(key)) {
    return cache.get(key)
  }
  const result = a + b
  cache.set(key, result)
  return result
}
```

### 3. 并行执行

纯函数可以安全地并行执行，因为没有共享状态：

```js
// 可以并行执行
const numbers = [1, 2, 3, 4, 5]
const results = numbers.map(n => square(n)) // 并行安全
```

### 4. 可预测性

代码行为更容易理解和预测，便于调试和维护。

## 🚀 Effect 中的纯函数

Effect 鼓励将副作用隔离，保持核心逻辑的纯函数特性：

```js
// 纯函数 - 业务逻辑
function calculateTotal(items) {
  return items.reduce((sum, item) => sum + item.price * item.quantity, 0)
}

// Effect - 处理副作用
import { Effect } from 'effect'

const fetchItems = Effect.tryPromise(() => 
  fetch('/api/items').then(res => res.json())
)

const calculateOrderTotal = fetchItems.pipe(
  Effect.map(items => calculateTotal(items)) // 使用纯函数
)
```

## 📝 实践建议

1. **识别纯函数**：在编写函数时，思考它是否满足纯函数的两个条件
2. **隔离副作用**：将副作用操作（IO、网络、状态修改）与纯逻辑分离
3. **使用不可变数据**：避免修改传入的参数，返回新的数据结构
4. **函数组合**：通过组合小的纯函数构建复杂功能

## 🔗 相关概念

- **不可变性（Immutability）**：纯函数通常与不可变数据配合使用
- **函数组合（Function Composition）**：纯函数可以安全地组合
- **引用透明（Referential Transparency）**：纯函数调用可以被其返回值替换
