# 类基础

> **版本**: v1.0  
> **最后更新**: 2026-04-22

## 📚 概念介绍

TypeScript 在 JavaScript 类的基础上增加了类型注解和访问修饰符等特性，使得面向对象编程更加安全和规范。本节将介绍类的属性声明、构造函数、方法定义、访问修饰符和 `readonly` 修饰符等基础概念。

## 🎯 属性声明与初始化

### 基本属性声明

在 TypeScript 中，类的属性需要显式声明类型：

```ts
class User {
  name: string;
  age: number;
  email: string;

  constructor(name: string, age: number, email: string) {
    this.name = name;
    this.age = age;
    this.email = email;
  }
}

const user = new User("Alice", 28, "alice@example.com");
console.log(`${user.name}, ${user.age}, ${user.email}`);
// "Alice, 28, alice@example.com"
```

### 属性默认值

```ts
class Settings {
  theme: string = "light";
  fontSize: number = 14;
  language: string = "en";
  notifications: boolean = true;

  constructor(overrides?: Partial<Settings>) {
    if (overrides) {
      Object.assign(this, overrides);
    }
  }
}

const defaultSettings = new Settings();
console.log(defaultSettings.theme); // "light"

const customSettings = new Settings({ theme: "dark", fontSize: 16 });
console.log(customSettings.theme);    // "dark"
console.log(customSettings.fontSize); // 16
console.log(customSettings.language); // "en"（使用默认值）
```

### 可选属性

```ts
class Profile {
  name: string;
  bio?: string;
  avatarUrl?: string;

  constructor(name: string) {
    this.name = name;
  }

  getDisplayInfo(): string {
    let info = this.name;
    if (this.bio) {
      info += ` - ${this.bio}`;
    }
    return info;
  }
}

const profile = new Profile("Alice");
console.log(profile.getDisplayInfo()); // "Alice"

profile.bio = "TypeScript enthusiast";
console.log(profile.getDisplayInfo()); // "Alice - TypeScript enthusiast"
```

## 🏗️ 构造函数

### 基本构造函数

```ts
class Rectangle {
  width: number;
  height: number;

  constructor(width: number, height: number) {
    this.width = width;
    this.height = height;
  }

  getArea(): number {
    return this.width * this.height;
  }

  getPerimeter(): number {
    return 2 * (this.width + this.height);
  }
}

const rect = new Rectangle(10, 5);
console.log(rect.getArea());      // 50
console.log(rect.getPerimeter()); // 30
```

### 多种初始化方式（静态工厂方法）

TypeScript 的构造函数不支持多重重载（只能有一个实现），但可以通过可选参数或静态工厂方法实现类似效果：

```ts
class Color {
  readonly red: number;
  readonly green: number;
  readonly blue: number;

  constructor(red: number, green: number, blue: number) {
    this.red = Math.max(0, Math.min(255, red));
    this.green = Math.max(0, Math.min(255, green));
    this.blue = Math.max(0, Math.min(255, blue));
  }

  static fromHex(hex: string): Color {
    const matched = hex.replace("#", "").match(/.{2}/g);
    if (!matched || matched.length !== 3) {
      throw new Error(`Invalid hex color: ${hex}`);
    }
    return new Color(
      parseInt(matched[0], 16),
      parseInt(matched[1], 16),
      parseInt(matched[2], 16)
    );
  }

  static fromHSL(hue: number, saturation: number, lightness: number): Color {
    const chroma = (1 - Math.abs(2 * lightness - 1)) * saturation;
    const x = chroma * (1 - Math.abs(((hue / 60) % 2) - 1));
    const m = lightness - chroma / 2;
    let rawRed = 0;
    let rawGreen = 0;
    let rawBlue = 0;

    if (hue < 60) { rawRed = chroma; rawGreen = x; }
    else if (hue < 120) { rawRed = x; rawGreen = chroma; }
    else if (hue < 180) { rawGreen = chroma; rawBlue = x; }
    else if (hue < 240) { rawGreen = x; rawBlue = chroma; }
    else if (hue < 300) { rawRed = x; rawBlue = chroma; }
    else { rawRed = chroma; rawBlue = x; }

    return new Color(
      Math.round((rawRed + m) * 255),
      Math.round((rawGreen + m) * 255),
      Math.round((rawBlue + m) * 255)
    );
  }

  toString(): string {
    return `rgb(${this.red}, ${this.green}, ${this.blue})`;
  }
}

const red = new Color(255, 0, 0);
console.log(red.toString()); // "rgb(255, 0, 0)"

const blue = Color.fromHex("#0000FF");
console.log(blue.toString()); // "rgb(0, 0, 255)"

const green = Color.fromHSL(120, 1, 0.5);
console.log(green.toString()); // "rgb(0, 255, 0)"
```

## 📋 方法定义

```ts
class Calculator {
  private history: string[] = [];

  add(a: number, b: number): number {
    const result = a + b;
    this.history.push(`${a} + ${b} = ${result}`);
    return result;
  }

  subtract(a: number, b: number): number {
    const result = a - b;
    this.history.push(`${a} - ${b} = ${result}`);
    return result;
  }

  multiply(a: number, b: number): number {
    const result = a * b;
    this.history.push(`${a} × ${b} = ${result}`);
    return result;
  }

  divide(a: number, b: number): number {
    if (b === 0) {
      throw new Error("Cannot divide by zero");
    }
    const result = a / b;
    this.history.push(`${a} ÷ ${b} = ${result}`);
    return result;
  }

  getHistory(): string[] {
    return [...this.history];
  }

  clearHistory(): void {
    this.history = [];
  }
}

const calc = new Calculator();
console.log(calc.add(10, 5));      // 15
console.log(calc.multiply(3, 4));  // 12
console.log(calc.divide(20, 4));   // 5
console.log(calc.getHistory());
// ["10 + 5 = 15", "3 × 4 = 12", "20 ÷ 4 = 5"]
```

## 🔒 访问修饰符

TypeScript 提供三种访问修饰符来控制类成员的可见性：

### public（默认）

`public` 成员可以在任何地方访问，这是默认行为：

```ts
class Animal {
  public name: string;    // 显式声明 public
  species: string;        // 默认就是 public

  public constructor(name: string, species: string) {
    this.name = name;
    this.species = species;
  }

  public makeSound(): string {
    return `${this.name} makes a sound`;
  }
}

const dog = new Animal("Rex", "Dog");
console.log(dog.name);        // "Rex"（外部可访问）
console.log(dog.makeSound()); // "Rex makes a sound"
```

### private

`private` 成员只能在类的内部访问：

```ts
class BankAccount {
  private balance: number;
  private accountNumber: string;

  constructor(accountNumber: string, initialBalance: number) {
    this.accountNumber = accountNumber;
    this.balance = initialBalance;
  }

  deposit(amount: number): void {
    if (amount <= 0) {
      throw new Error("Deposit amount must be positive");
    }
    this.balance += amount;
    this.logTransaction("deposit", amount);
  }

  withdraw(amount: number): void {
    if (amount <= 0) {
      throw new Error("Withdrawal amount must be positive");
    }
    if (amount > this.balance) {
      throw new Error("Insufficient funds");
    }
    this.balance -= amount;
    this.logTransaction("withdrawal", amount);
  }

  getBalance(): number {
    return this.balance;
  }

  private logTransaction(type: string, amount: number): void {
    console.log(`[${this.accountNumber}] ${type}: ${amount.toFixed(2)}, balance: ${this.balance.toFixed(2)}`);
  }
}

const account = new BankAccount("ACC-001", 1000);
account.deposit(500);
// [ACC-001] deposit: $500.00, balance: $1500.00
account.withdraw(200);
// [ACC-001] withdrawal: $200.00, balance: $1300.00
console.log(account.getBalance()); // 1300

// account.balance;         // 编译错误：属性 "balance" 为私有属性
// account.logTransaction;  // 编译错误：属性 "logTransaction" 为私有属性
```

:::tip
TypeScript 还支持 JavaScript 原生的私有字段语法（使用 `#` 前缀），它在运行时也能保证私有性：

```ts
class SecureAccount {
  #balance: number; // JavaScript 原生私有字段

  constructor(balance: number) {
    this.#balance = balance;
  }

  getBalance(): number {
    return this.#balance;
  }
}
```
:::

### protected

`protected` 成员可以在类内部和子类中访问，但不能在外部访问：

```ts
class Vehicle {
  protected speed: number = 0;
  protected maxSpeed: number;

  constructor(maxSpeed: number) {
    this.maxSpeed = maxSpeed;
  }

  protected accelerate(amount: number): void {
    this.speed = Math.min(this.speed + amount, this.maxSpeed);
  }

  getSpeed(): number {
    return this.speed;
  }
}

class Car extends Vehicle {
  private gear: number = 1;

  constructor() {
    super(200); // 最高时速 200
  }

  drive(): void {
    // 可以访问 protected 成员
    this.accelerate(this.gear * 20);
    console.log(`Driving at ${this.speed} km/h in gear ${this.gear}`);
  }

  shiftUp(): void {
    if (this.gear < 6) {
      this.gear++;
    }
  }
}

const car = new Car();
car.drive();    // "Driving at 20 km/h in gear 1"
car.shiftUp();
car.drive();    // "Driving at 60 km/h in gear 2"

// car.speed;      // 编译错误：属性 "speed" 受保护
// car.accelerate; // 编译错误：属性 "accelerate" 受保护
console.log(car.getSpeed()); // 60（通过 public 方法访问）
```

### 修饰符对比

```
修饰符        类内部   子类   外部
──────────────────────────────
public        ✅      ✅     ✅
protected     ✅      ✅     ❌
private       ✅      ❌     ❌
```

## 📌 readonly 修饰符

`readonly` 修饰符使属性在初始化后不可修改：

```ts
class Configuration {
  readonly appName: string;
  readonly version: string;
  readonly maxRetries: number;

  constructor(appName: string, version: string, maxRetries: number = 3) {
    this.appName = appName;
    this.version = version;
    this.maxRetries = maxRetries;
  }

  getInfo(): string {
    return `${this.appName} v${this.version} (max retries: ${this.maxRetries})`;
  }
}

const config = new Configuration("MyApp", "1.0.0");
console.log(config.getInfo()); // "MyApp v1.0.0 (max retries: 3)"
console.log(config.appName);   // "MyApp"

// config.appName = "OtherApp";  // 编译错误：无法为 "appName" 赋值，因为它是只读属性

// readonly 可以和访问修饰符组合使用
class ImmutablePoint {
  constructor(
    public readonly x: number,
    public readonly y: number
  ) {}

  distanceTo(other: ImmutablePoint): number {
    return Math.sqrt((this.x - other.x) ** 2 + (this.y - other.y) ** 2);
  }

  toString(): string {
    return `(${this.x}, ${this.y})`;
  }
}

const pointA = new ImmutablePoint(3, 4);
const pointB = new ImmutablePoint(6, 8);
console.log(pointA.toString());              // "(3, 4)"
console.log(pointA.distanceTo(pointB));       // 5
// pointA.x = 10;  // 编译错误：只读属性
```

## 📝 实际应用示例

### 任务管理器

```ts
class Task {
  readonly id: string;
  title: string;
  private completed: boolean = false;
  private completedAt: Date | null = null;
  readonly createdAt: Date;

  constructor(id: string, title: string) {
    this.id = id;
    this.title = title;
    this.createdAt = new Date();
  }

  complete(): void {
    this.completed = true;
    this.completedAt = new Date();
  }

  isCompleted(): boolean {
    return this.completed;
  }

  getSummary(): string {
    const status = this.completed ? "✅" : "⬜";
    const completedInfo = this.completedAt
      ? ` (completed: ${this.completedAt.toLocaleDateString()})`
      : "";
    return `${status} [${this.id}] ${this.title}${completedInfo}`;
  }
}

class TaskManager {
  private tasks: Task[] = [];
  private nextId: number = 1;

  addTask(title: string): Task {
    const task = new Task(`TASK-${this.nextId++}`, title);
    this.tasks.push(task);
    return task;
  }

  completeTask(id: string): boolean {
    const task = this.tasks.find((t) => t.id === id);
    if (!task) {
      return false;
    }
    task.complete();
    return true;
  }

  getPendingTasks(): Task[] {
    return this.tasks.filter((t) => !t.isCompleted());
  }

  getCompletedTasks(): Task[] {
    return this.tasks.filter((t) => t.isCompleted());
  }

  printReport(): void {
    console.log("=== Task Report ===");
    this.tasks.forEach((task) => {
      console.log(task.getSummary());
    });
    console.log(`\nTotal: ${this.tasks.length} | Pending: ${this.getPendingTasks().length} | Completed: ${this.getCompletedTasks().length}`);
  }
}

const manager = new TaskManager();
manager.addTask("Learn TypeScript basics");
manager.addTask("Practice type narrowing");
manager.addTask("Build a sample project");

manager.completeTask("TASK-1");
manager.completeTask("TASK-2");

manager.printReport();
// === Task Report ===
// ✅ [TASK-1] Learn TypeScript basics (completed: ...)
// ✅ [TASK-2] Practice type narrowing (completed: ...)
// ⬜ [TASK-3] Build a sample project
//
// Total: 3 | Pending: 1 | Completed: 2
```
