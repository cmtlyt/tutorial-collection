# 开发环境搭建

> **版本**: v1.0  
> **最后更新**: 2026-04-22

## 📚 概念介绍

在开始学习 TypeScript 之前，我们需要搭建一个完整的开发环境。本节将带你完成从 Node.js 安装到 VS Code 配置的全流程，确保你拥有一个高效、舒适的 TypeScript 开发体验。

## 🎯 Node.js 与包管理器

### 安装 Node.js

TypeScript 编译器运行在 Node.js 环境上，因此首先需要安装 Node.js。推荐使用 [nvm](https://github.com/nvm-sh/nvm)（Node Version Manager）来管理 Node.js 版本：

```bash
# macOS / Linux：安装 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

# 安装最新 LTS 版本的 Node.js
nvm install --lts

# 验证安装
node -v   # 输出类似 v22.x.x
npm -v    # 输出类似 10.x.x
```

Windows 用户可以使用 [nvm-windows](https://github.com/coreybutler/nvm-windows) 或直接从 [Node.js 官网](https://nodejs.org/) 下载安装包。

### 选择包管理器

推荐使用 **pnpm** 作为包管理器，它比 npm 更快且节省磁盘空间：

```bash
# 使用 Node.js 内置的 corepack 启用 pnpm
corepack enable

# 验证 pnpm 安装
pnpm -v

# 或者通过 npm 全局安装
npm install -g pnpm
```

## 🔧 TypeScript 编译器（tsc）

### 安装 TypeScript

有两种常见的安装方式：

```bash
# 方式一：全局安装（适合快速体验）
pnpm add -g typescript

# 方式二：项目本地安装（推荐用于实际项目）
mkdir my-ts-project && cd my-ts-project
pnpm init
pnpm add -D typescript
```

验证安装：

```bash
# 全局安装时
tsc --version   # 输出类似 Version 5.8.x

# 本地安装时
npx tsc --version
```

### 第一个 TypeScript 文件

创建一个 `hello.ts` 文件来验证环境是否正常：

```ts
function greet(name: string): string {
  return `Hello, ${name}! Welcome to TypeScript.`;
}

const message = greet("World");
console.log(message);
```

编译并运行：

```bash
# 编译 TypeScript 为 JavaScript
npx tsc hello.ts

# 运行编译后的 JavaScript
node hello.js
# 输出: Hello, World! Welcome to TypeScript.
```

## ⚙️ tsconfig.json 核心配置

### 初始化配置文件

使用 `tsc --init` 生成默认配置：

```bash
npx tsc --init
```

这会在项目根目录生成一个 `tsconfig.json` 文件。以下是一份适合入门学习的精简配置：

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "outDir": "./dist",
    "rootDir": "./src",
    "declaration": true,
    "sourceMap": true
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

### 核心配置项说明

| 配置项 | 说明 | 推荐值 |
|--------|------|--------|
| `target` | 编译输出的 JavaScript 版本 | `ES2022` |
| `module` | 模块系统 | `NodeNext` |
| `moduleResolution` | 模块解析策略 | `NodeNext` |
| `strict` | 启用所有严格类型检查 | `true` |
| `esModuleInterop` | 允许 CommonJS 和 ES Module 互操作 | `true` |
| `outDir` | 编译输出目录 | `./dist` |
| `rootDir` | 源代码根目录 | `./src` |
| `declaration` | 生成 `.d.ts` 声明文件 | `true` |
| `sourceMap` | 生成 source map 便于调试 | `true` |

### 项目目录结构

配置完成后，推荐的项目结构如下：

```
my-ts-project/
├── src/
│   └── index.ts
├── dist/           # 编译输出（自动生成）
├── node_modules/
├── package.json
└── tsconfig.json
```

创建 `src/index.ts` 并编译整个项目：

```bash
mkdir src
echo 'console.log("TypeScript project is ready!")' > src/index.ts

# 编译整个项目
npx tsc

# 运行
node dist/index.js
# 输出: TypeScript project is ready!
```

## 🛠️ VS Code 插件与开发体验优化

### 必装插件

VS Code 对 TypeScript 有原生支持，但以下插件可以进一步提升开发体验：

| 插件名称 | 作用 |
|----------|------|
| **TypeScript Importer** | 自动补全和管理 import 语句 |
| **Error Lens** | 在代码行内直接显示错误和警告 |
| **Pretty TypeScript Errors** | 美化 TypeScript 错误信息，更易阅读 |
| **ESLint** | 代码规范检查 |
| **Prettier** | 代码格式化 |

### VS Code 配置优化

在项目根目录创建 `.vscode/settings.json`：

```json
{
  "typescript.preferences.importModuleSpecifier": "relative",
  "typescript.suggest.autoImports": true,
  "typescript.updateImportsOnFileMove.enabled": "always",
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.codeActionsOnSave": {
    "source.organizeImports": "explicit"
  }
}
```

### 使用 tsx 快速运行 TypeScript

在开发阶段，每次手动编译再运行很繁琐。可以使用 [tsx](https://github.com/privatenumber/tsx) 直接运行 TypeScript 文件：

```bash
# 安装 tsx
pnpm add -D tsx

# 直接运行 TypeScript 文件，无需手动编译
npx tsx src/index.ts

# 监听文件变化自动重新运行
npx tsx watch src/index.ts
```

在 `package.json` 中添加便捷脚本：

```json
{
  "scripts": {
    "dev": "tsx watch src/index.ts",
    "build": "tsc",
    "start": "node dist/index.js"
  }
}
```

## 📝 实际应用示例

### 完整的项目初始化流程

以下是从零开始创建一个 TypeScript 项目的完整步骤：

```bash
# 1. 创建项目目录
mkdir ts-demo && cd ts-demo

# 2. 初始化 package.json
pnpm init

# 3. 安装 TypeScript 和 tsx
pnpm add -D typescript tsx

# 4. 初始化 tsconfig.json
npx tsc --init

# 5. 创建源码目录和入口文件
mkdir src
```

创建 `src/index.ts`：

```ts
interface User {
  name: string;
  age: number;
  email: string;
}

function createUser(name: string, age: number, email: string): User {
  return { name, age, email };
}

function formatUser(user: User): string {
  return `${user.name} (${user.age}) - ${user.email}`;
}

const user = createUser("Alice", 28, "alice@example.com");
console.log(formatUser(user));
// 输出: Alice (28) - alice@example.com
```

运行验证：

```bash
npx tsx src/index.ts
# 输出: Alice (28) - alice@example.com
```
