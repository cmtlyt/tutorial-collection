# 类型体操练习平台

> **版本**: v1.0  
> **最后更新**: 2026-04-22

## 📚 概念介绍

学习类型体操最有效的方式就是**动手实践**。TypeScript 社区提供了多个优秀的练习平台和项目，它们按难度分级、即时反馈，是提升类型编程能力的最佳途径。

本节将介绍三个主流的类型体操练习平台，并提供推荐的练习路径。

## 🎯 type-challenges

[type-challenges](https://github.com/type-challenges/type-challenges) 是 TypeScript 类型体操领域最知名的开源项目，由 Anthony Fu（Vue / Vite 核心团队成员）创建。

### 项目特点

- **难度分级**：从 warm-up（热身）、easy（简单）、medium（中等）、hard（困难）到 extreme（地狱级）
- **题目丰富**：超过 170+ 道类型挑战题
- **即时验证**：通过 TypeScript Playground 在线验证答案
- **社区活跃**：每道题都有社区提交的多种解法

### 推荐练习顺序

从 easy 难度开始，按以下顺序练习效果最佳：

```ts
// === Easy 级别推荐顺序 ===

// 1. Pick —— 理解映射类型的基础
type MyPick<T, K extends keyof T> = {
  [P in K]: T[P];
};

// 2. Readonly —— 理解修饰符
type MyReadonly<T> = {
  readonly [P in keyof T]: T[P];
};

// 3. Tuple to Object —— 理解 T[number] 索引
type TupleToObject<T extends readonly PropertyKey[]> = {
  [K in T[number]]: K;
};

// 4. First of Array —— 理解条件类型和 infer
type First<T extends unknown[]> = T extends [infer F, ...unknown[]] ? F : never;

// 5. Length of Tuple —— 理解元组的 length 属性
type Length<T extends readonly unknown[]> = T["length"];

// 6. Exclude —— 理解分布式条件类型
type MyExclude<T, U> = T extends U ? never : T;

// 7. Awaited —— 理解递归条件类型
type MyAwaited<T> = T extends Promise<infer U> ? MyAwaited<U> : T;

// 8. If —— 条件类型的直接应用
type If<Condition extends boolean, True, False> = Condition extends true ? True : False;

// 9. Concat —— 理解元组展开
type Concat<A extends unknown[], B extends unknown[]> = [...A, ...B];

// 10. Includes —— 综合挑战
type Includes<T extends readonly unknown[], U> =
  T extends [infer First, ...infer Rest]
    ? Equal<First, U> extends true
      ? true
      : Includes<Rest, U>
    : false;

// Equal 辅助类型（用于精确类型比较）
type Equal<X, Y> =
  (<T>() => T extends X ? 1 : 2) extends
  (<T>() => T extends Y ? 1 : 2) ? true : false;
```

### 如何开始

1. 访问 [type-challenges GitHub 仓库](https://github.com/type-challenges/type-challenges)
2. 点击题目标题旁的 Playground 链接，进入在线编辑器
3. 在 `/* _____________ Your Code Here _____________ */` 处填写你的答案
4. 如果 `/* _____________ Test Cases _____________ */` 部分没有报错，说明答案正确

### Medium 级别精选

当你完成 Easy 级别后，以下 Medium 题目值得重点练习：

```ts
// 1. Get Return Type —— 理解 infer 在函数中的应用
type MyReturnType<T extends (...args: unknown[]) => unknown> =
  T extends (...args: unknown[]) => infer R ? R : never;

// 2. Omit —— Pick 的反操作
type MyOmit<T, K extends keyof T> = {
  [P in keyof T as P extends K ? never : P]: T[P];
};

// 3. Deep Readonly —— 递归映射类型
type DeepReadonly<T> = T extends Function
  ? T
  : { readonly [K in keyof T]: DeepReadonly<T[K]> };

// 4. Trim —— 模板字面量 + 递归
type Trim<S extends string> =
  S extends `${" " | "\t" | "\n"}${infer Rest}`
    ? Trim<Rest>
    : S extends `${infer Rest}${" " | "\t" | "\n"}`
    ? Trim<Rest>
    : S;

// 5. Capitalize —— 字符串操作基础
type MyCapitalize<S extends string> =
  S extends `${infer First}${infer Rest}`
    ? `${Uppercase<First>}${Rest}`
    : S;
```

## 🎯 TypeHero

[TypeHero](https://typehero.dev/) 是一个交互式的 TypeScript 类型练习平台，提供了浏览器内的完整编辑体验。

### 平台特点

- **浏览器内编辑器**：内置 Monaco Editor，体验接近 VS Code
- **即时类型检查**：实时显示类型错误和推断结果
- **社区解答**：可以查看其他用户的解法和讨论
- **进度追踪**：自动记录你的完成进度
- **学习路径**：提供结构化的学习路径

### 与 type-challenges 的区别

| 特性 | type-challenges | TypeHero |
|------|----------------|----------|
| **平台** | GitHub + Playground | 独立 Web 平台 |
| **编辑体验** | TypeScript Playground | 内置 Monaco Editor |
| **进度追踪** | 手动记录 | 自动追踪 |
| **社区讨论** | GitHub Issues | 平台内讨论区 |
| **题目来源** | 原创 + 社区贡献 | 包含 type-challenges 题目 + 原创 |
| **适合人群** | 有一定基础的开发者 | 初学者到进阶都适合 |

### 推荐使用方式

1. 访问 [typehero.dev](https://typehero.dev/)
2. 注册账号以保存进度
3. 从 "Explore" 页面选择难度适合的题目
4. 在编辑器中编写类型代码，实时查看验证结果

## 🎯 TypeScript Playground

[TypeScript Playground](https://www.typescriptlang.org/play) 是 TypeScript 官方提供的在线编辑器，虽然不是专门的练习平台，但它是类型实验和学习的利器。

### 核心功能

- **实时类型推断**：鼠标悬停查看任意表达式的推断类型
- **版本切换**：可以切换 TypeScript 版本，测试新特性
- **编译选项**：可以调整 `tsconfig` 选项观察行为变化
- **分享链接**：每段代码都可以生成分享链接

### 类型调试技巧

在 Playground 中调试类型时，以下技巧非常有用：

```ts
// 技巧 1：用类型别名 + 鼠标悬停查看展开结果
type Debug<T> = { [K in keyof T]: T[K] };

interface User {
  name: string;
  age: number;
}

// 鼠标悬停 Expanded 可以看到完整展开的类型
type Expanded = Debug<Partial<User> & { role: string }>;
// { name?: string; age?: number; role: string }

// 技巧 2：用 @ts-expect-error 验证类型错误
type IsString<T> = T extends string ? true : false;

// @ts-expect-error —— 预期此行会报错，如果不报错则说明类型有误
const test1: IsString<number> = true; // 应该是 false

// 技巧 3：用 Equal 精确比较两个类型是否相同
type Equal<X, Y> =
  (<T>() => T extends X ? 1 : 2) extends
  (<T>() => T extends Y ? 1 : 2) ? true : false;

type Test1 = Equal<string, string>;        // true
type Test2 = Equal<string, number>;        // false
type Test3 = Equal<{ a: 1 }, { a: 1 }>;   // true
type Test4 = Equal<any, string>;           // false

// 技巧 4：用 Expect 做类型断言
type Expect<T extends true> = T;

// 如果下面这行不报错，说明 MyPick 实现正确
type _test = Expect<Equal<
  MyPick<User, "name">,
  { name: string }
>>;

type MyPick<T, K extends keyof T> = { [P in K]: T[P] };
```

### 常用 Playground 配置

进行类型体操时，建议启用以下配置：

- **Strict Mode**：`strict: true`（确保最严格的类型检查）
- **Target**：`ESNext`（使用最新语法特性）
- **Show Errors Inline**：开启行内错误显示

## 📝 学习路径推荐

### 阶段一：入门（1-2 周）

1. 在 TypeScript Playground 熟悉基本操作
2. 完成 type-challenges 的所有 Easy 题目
3. 重点理解：映射类型、条件类型、`infer`、分布式条件类型

### 阶段二：进阶（2-4 周）

1. 完成 type-challenges 的 Medium 题目（前 20 道）
2. 在 TypeHero 上练习对应难度的题目
3. 重点攻克：递归类型、模板字面量类型、元组操作

### 阶段三：精通（持续练习）

1. 挑战 type-challenges 的 Hard 和 Extreme 题目
2. 阅读优秀开源库的类型定义（Zod、tRPC、ts-pattern 等）
3. 尝试为自己的项目编写复杂的类型工具

### 每日练习建议

- 每天花 **15-30 分钟** 做 1-2 道类型体操题目
- 先独立思考 10 分钟，实在想不出再看题解
- 看完题解后**一定要自己重新实现一遍**
- 用 Playground 实验各种边界情况
