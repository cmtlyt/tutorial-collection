# React 类型基础

> **版本**: v1.0  
> **最后更新**: 2026-04-22

## 📚 概念介绍

在 React 项目中使用 TypeScript，能够为组件的 Props、State、事件处理等提供完整的类型约束，从而在编译阶段就发现潜在的类型错误。本节将介绍 React 与 TypeScript 结合时最基础也最重要的类型概念：函数组件类型、Props 类型定义、Children 类型以及事件类型。

## 🎯 FC 与函数组件类型

### 直接定义函数组件（推荐）

在现代 React + TypeScript 项目中，**直接为函数的参数标注类型** 是最推荐的方式，无需使用 `React.FC`：

```tsx
interface GreetingProps {
  name: string;
  age?: number;
}

function Greeting({ name, age }: GreetingProps) {
  return (
    <div>
      <h1>Hello, {name}!</h1>
      {age !== undefined && <p>Age: {age}</p>}
    </div>
  );
}

// 使用
<Greeting name="Alice" />
<Greeting name="Bob" age={25} />
```

### 使用 React.FC

`React.FC`（即 `React.FunctionComponent`）是 React 提供的泛型类型，可以为函数组件附加类型约束。不过在 React 18+ 中，`React.FC` 已经移除了隐式的 `children` 属性，其行为与直接标注参数类型基本一致：

```tsx
import { FC } from 'react';

interface CardProps {
  title: string;
  subtitle?: string;
}

const Card: FC<CardProps> = ({ title, subtitle }) => {
  return (
    <div className="card">
      <h2>{title}</h2>
      {subtitle && <p>{subtitle}</p>}
    </div>
  );
};
```

### 两种方式的对比

```tsx
// 方式一：直接标注参数类型（推荐）
// 优点：简洁、灵活、支持泛型组件
function Button({ label, onClick }: { label: string; onClick: () => void }) {
  return <button onClick={onClick}>{label}</button>;
}

// 方式二：使用 React.FC
// 优点：明确返回类型为 ReactElement
const Button2: FC<{ label: string; onClick: () => void }> = ({ label, onClick }) => {
  return <button onClick={onClick}>{label}</button>;
};
```

:::tip
推荐使用方式一（直接标注参数类型），因为它更简洁，且在需要泛型组件时更灵活。`React.FC` 无法直接支持泛型参数。
:::

## 🎯 Props 类型定义

### 基本 Props 类型

```tsx
// 使用 interface 定义 Props
interface UserProfileProps {
  username: string;
  email: string;
  avatar?: string;        // 可选属性
  isOnline: boolean;
  role: 'admin' | 'user' | 'guest';  // 联合类型
}

function UserProfile({ username, email, avatar, isOnline, role }: UserProfileProps) {
  return (
    <div className="user-profile">
      {avatar && <img src={avatar} alt={username} />}
      <h2>{username}</h2>
      <p>{email}</p>
      <span>{isOnline ? '🟢 Online' : '⚪ Offline'}</span>
      <span>Role: {role}</span>
    </div>
  );
}
```

### 带默认值的 Props

```tsx
interface PaginationProps {
  total: number;
  pageSize?: number;
  current?: number;
  onChange: (page: number) => void;
}

function Pagination({
  total,
  pageSize = 10,
  current = 1,
  onChange,
}: PaginationProps) {
  const totalPages = Math.ceil(total / pageSize);

  return (
    <div className="pagination">
      <button disabled={current <= 1} onClick={() => onChange(current - 1)}>
        Previous
      </button>
      <span>{current} / {totalPages}</span>
      <button disabled={current >= totalPages} onClick={() => onChange(current + 1)}>
        Next
      </button>
    </div>
  );
}
```

### 回调函数 Props

```tsx
interface FormProps {
  onSubmit: (data: { name: string; email: string }) => void;
  onCancel: () => void;
  onValidate?: (field: string, value: string) => boolean;
}

function ContactForm({ onSubmit, onCancel, onValidate }: FormProps) {
  const handleSubmit = (event: React.FormEvent) => {
    event.preventDefault();
    const name = 'Alice';
    const email = 'alice@example.com';

    if (onValidate) {
      const isNameValid = onValidate('name', name);
      const isEmailValid = onValidate('email', email);
      if (!isNameValid || !isEmailValid) return;
    }

    onSubmit({ name, email });
  };

  return (
    <form onSubmit={handleSubmit}>
      <input type="text" placeholder="Name" />
      <input type="email" placeholder="Email" />
      <button type="submit">Submit</button>
      <button type="button" onClick={onCancel}>Cancel</button>
    </form>
  );
}
```

### 使用 type 还是 interface

```tsx
// interface - 可以声明合并，适合定义公共 API
interface ButtonProps {
  variant: 'primary' | 'secondary';
  size: 'small' | 'medium' | 'large';
}

// 扩展 interface
interface IconButtonProps extends ButtonProps {
  icon: string;
}

// type - 支持联合类型和交叉类型，更灵活
type AlertType = 'success' | 'warning' | 'error';

type AlertProps = {
  type: AlertType;
  message: string;
  closable?: boolean;
};

// 交叉类型组合
type ClickableCardProps = CardProps & {
  onClick: () => void;
  href?: string;
};
```

:::tip
在 React Props 类型定义中，`interface` 和 `type` 都可以使用。团队内保持一致即可。通常推荐 `interface` 用于组件 Props 定义，`type` 用于联合类型、交叉类型等场景。
:::

## 🎯 Children 类型

React 中 `children` 的类型根据使用场景有所不同：

### ReactNode（最常用）

`ReactNode` 是最宽泛的 children 类型，几乎可以接受任何可渲染的内容：

```tsx
import { ReactNode } from 'react';

interface LayoutProps {
  children: ReactNode;
  sidebar?: ReactNode;
}

function Layout({ children, sidebar }: LayoutProps) {
  return (
    <div className="layout">
      {sidebar && <aside>{sidebar}</aside>}
      <main>{children}</main>
    </div>
  );
}

// ReactNode 可以是：string、number、boolean、null、undefined、ReactElement、ReactFragment
<Layout sidebar={<nav>Menu</nav>}>
  <h1>Page Title</h1>
  <p>Content here</p>
</Layout>
```

### ReactElement

`ReactElement` 只接受 JSX 元素，不接受字符串、数字等原始类型：

```tsx
import { ReactElement } from 'react';

interface TabPanelProps {
  children: ReactElement | ReactElement[];
  activeIndex: number;
}

function TabPanel({ children, activeIndex }: TabPanelProps) {
  const panels = Array.isArray(children) ? children : [children];
  return <div>{panels[activeIndex]}</div>;
}

// 只能传入 JSX 元素
<TabPanel activeIndex={0}>
  <div>Tab 1 Content</div>
  <div>Tab 2 Content</div>
</TabPanel>
```

### 函数作为 Children（Render Props 模式）

```tsx
interface DataFetcherProps<T> {
  url: string;
  children: (data: T, loading: boolean) => ReactNode;
}

function DataFetcher<T>({ url, children }: DataFetcherProps<T>) {
  const data = {} as T;
  const loading = false;

  return <>{children(data, loading)}</>;
}

// 使用
<DataFetcher<{ name: string }> url="/api/user">
  {(data, loading) => (
    loading ? <p>Loading...</p> : <p>{data.name}</p>
  )}
</DataFetcher>
```

### PropsWithChildren 工具类型

```tsx
import { PropsWithChildren } from 'react';

// PropsWithChildren 会自动为 Props 添加可选的 children: ReactNode
type ContainerProps = PropsWithChildren<{
  maxWidth?: number;
  centered?: boolean;
}>;

function Container({ children, maxWidth = 1200, centered = true }: ContainerProps) {
  const style = {
    maxWidth: `${maxWidth}px`,
    margin: centered ? '0 auto' : undefined,
  };

  return <div style={style}>{children}</div>;
}
```

## 🎯 事件类型

### 常用事件类型

React 提供了与 DOM 事件对应的类型化事件对象：

```tsx
import { ChangeEvent, MouseEvent, KeyboardEvent, FormEvent, FocusEvent } from 'react';

function EventExamples() {
  // 鼠标事件
  const handleClick = (event: MouseEvent<HTMLButtonElement>) => {
    console.log('Clicked at:', event.clientX, event.clientY);
  };

  // 变更事件
  const handleChange = (event: ChangeEvent<HTMLInputElement>) => {
    console.log('Value:', event.target.value);
  };

  // 键盘事件
  const handleKeyDown = (event: KeyboardEvent<HTMLInputElement>) => {
    if (event.key === 'Enter') {
      console.log('Enter pressed');
    }
  };

  // 表单事件
  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    console.log('Form submitted');
  };

  // 焦点事件
  const handleFocus = (event: FocusEvent<HTMLInputElement>) => {
    console.log('Focused:', event.target.name);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input
        type="text"
        onChange={handleChange}
        onKeyDown={handleKeyDown}
        onFocus={handleFocus}
      />
      <button onClick={handleClick}>Submit</button>
    </form>
  );
}
```

### 事件类型的泛型参数

事件类型的泛型参数用于指定触发事件的 DOM 元素类型：

```tsx
import { ChangeEvent } from 'react';

function InputGroup() {
  // HTMLInputElement - input 元素
  const handleInputChange = (event: ChangeEvent<HTMLInputElement>) => {
    console.log(event.target.value);
  };

  // HTMLSelectElement - select 元素
  const handleSelectChange = (event: ChangeEvent<HTMLSelectElement>) => {
    console.log(event.target.value);
  };

  // HTMLTextAreaElement - textarea 元素
  const handleTextAreaChange = (event: ChangeEvent<HTMLTextAreaElement>) => {
    console.log(event.target.value);
  };

  return (
    <div>
      <input type="text" onChange={handleInputChange} />
      <select onChange={handleSelectChange}>
        <option value="a">A</option>
        <option value="b">B</option>
      </select>
      <textarea onChange={handleTextAreaChange} />
    </div>
  );
}
```

### 自定义事件处理器类型

```tsx
import { MouseEvent } from 'react';

// 为回调 Props 定义精确的事件处理器类型
interface ToolbarProps {
  onSave: (event: MouseEvent<HTMLButtonElement>) => void;
  onDelete: (event: MouseEvent<HTMLButtonElement>) => void;
  onExport: (format: 'pdf' | 'csv') => void;
}

function Toolbar({ onSave, onDelete, onExport }: ToolbarProps) {
  return (
    <div className="toolbar">
      <button onClick={onSave}>Save</button>
      <button onClick={onDelete}>Delete</button>
      <button onClick={() => onExport('pdf')}>Export PDF</button>
      <button onClick={() => onExport('csv')}>Export CSV</button>
    </div>
  );
}
```

## 📝 实际应用示例

### 综合示例：类型安全的表单组件

```tsx
import { ChangeEvent, FormEvent, ReactNode, useState } from 'react';

// 表单字段配置类型
interface FormField {
  name: string;
  label: string;
  type: 'text' | 'email' | 'password' | 'select';
  required?: boolean;
  options?: { value: string; label: string }[];
}

// 表单组件 Props
interface TypedFormProps {
  title: string;
  fields: FormField[];
  submitLabel?: string;
  children?: ReactNode;
  onSubmit: (values: Record<string, string>) => void;
}

function TypedForm({
  title,
  fields,
  submitLabel = 'Submit',
  children,
  onSubmit,
}: TypedFormProps) {
  const [values, setValues] = useState<Record<string, string>>(() => {
    const initial: Record<string, string> = {};
    for (const field of fields) {
      initial[field.name] = '';
    }
    return initial;
  });

  const handleChange = (
    event: ChangeEvent<HTMLInputElement | HTMLSelectElement>
  ) => {
    const { name, value } = event.target;
    setValues((prev) => ({ ...prev, [name]: value }));
  };

  const handleSubmit = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    onSubmit(values);
  };

  return (
    <form onSubmit={handleSubmit}>
      <h2>{title}</h2>
      {fields.map((field) => (
        <div key={field.name} className="form-field">
          <label htmlFor={field.name}>{field.label}</label>
          {field.type === 'select' ? (
            <select
              id={field.name}
              name={field.name}
              value={values[field.name]}
              onChange={handleChange}
              required={field.required}
            >
              <option value="">Select...</option>
              {field.options?.map((option) => (
                <option key={option.value} value={option.value}>
                  {option.label}
                </option>
              ))}
            </select>
          ) : (
            <input
              id={field.name}
              name={field.name}
              type={field.type}
              value={values[field.name]}
              onChange={handleChange}
              required={field.required}
            />
          )}
        </div>
      ))}
      {children}
      <button type="submit">{submitLabel}</button>
    </form>
  );
}

// 使用示例
function App() {
  const fields: FormField[] = [
    { name: 'name', label: 'Name', type: 'text', required: true },
    { name: 'email', label: 'Email', type: 'email', required: true },
    {
      name: 'role',
      label: 'Role',
      type: 'select',
      options: [
        { value: 'dev', label: 'Developer' },
        { value: 'pm', label: 'Product Manager' },
      ],
    },
  ];

  const handleSubmit = (values: Record<string, string>) => {
    console.log('Form values:', values);
  };

  return (
    <TypedForm title="User Registration" fields={fields} onSubmit={handleSubmit}>
      <p>By submitting, you agree to our terms.</p>
    </TypedForm>
  );
}
```
