# 类型安全的构建器模式

> **版本**: v1.0  
> **最后更新**: 2026-04-22

## 📚 概念介绍

构建器模式（Builder Pattern）是一种常用的创建型设计模式，通过链式调用逐步设置对象属性，最终构建出完整的对象。在 TypeScript 中，我们可以利用泛型和条件类型让构建器在**编译期**跟踪哪些属性已被设置，确保必填属性不会遗漏，使构建过程完全类型安全。

## 🎯 链式调用类型推断

### 基础构建器

先从一个简单的链式构建器开始，理解基本的返回 `this` 模式：

```ts
interface UserConfig {
  name: string;
  email: string;
  age?: number;
  role?: string;
}

class UserBuilder {
  private config: Partial<UserConfig> = {};

  setName(name: string): this {
    this.config.name = name;
    return this;
  }

  setEmail(email: string): this {
    this.config.email = email;
    return this;
  }

  setAge(age: number): this {
    this.config.age = age;
    return this;
  }

  setRole(role: string): this {
    this.config.role = role;
    return this;
  }

  build(): UserConfig {
    if (!this.config.name || !this.config.email) {
      throw new Error("name and email are required");
    }
    return this.config as UserConfig;
  }
}

const user = new UserBuilder()
  .setName("Alice")
  .setEmail("alice@example.com")
  .setAge(30)
  .build();

console.log(user);
// { name: "Alice", email: "alice@example.com", age: 30 }
```

这种方式的问题在于：`build()` 的必填检查只在运行时生效。如果忘记调用 `setName()`，编译器不会报错。

### 类型安全的构建器（编译期必填校验）

通过泛型参数跟踪已设置的属性，让 `build()` 方法只在所有必填属性都已设置后才可调用：

```ts
interface RequestConfig {
  url: string;
  method: "GET" | "POST" | "PUT" | "DELETE";
  headers?: Record<string, string>;
  body?: string;
  timeout?: number;
}

// 用泛型参数记录已设置的必填字段
class RequestBuilder<HasUrl extends boolean = false, HasMethod extends boolean = false> {
  private config: Partial<RequestConfig> = {};

  setUrl(url: string): RequestBuilder<true, HasMethod> {
    this.config.url = url;
    return this as unknown as RequestBuilder<true, HasMethod>;
  }

  setMethod(method: RequestConfig["method"]): RequestBuilder<HasUrl, true> {
    this.config.method = method;
    return this as unknown as RequestBuilder<HasUrl, true>;
  }

  setHeaders(headers: Record<string, string>): RequestBuilder<HasUrl, HasMethod> {
    this.config.headers = headers;
    return this as unknown as RequestBuilder<HasUrl, HasMethod>;
  }

  setBody(body: string): RequestBuilder<HasUrl, HasMethod> {
    this.config.body = body;
    return this as unknown as RequestBuilder<HasUrl, HasMethod>;
  }

  setTimeout(timeout: number): RequestBuilder<HasUrl, HasMethod> {
    this.config.timeout = timeout;
    return this as unknown as RequestBuilder<HasUrl, HasMethod>;
  }

  // build 只有在 HasUrl 和 HasMethod 都为 true 时才可调用
  build(this: RequestBuilder<true, true>): RequestConfig {
    return this.config as unknown as RequestConfig;
  }
}

// 正确：所有必填字段都已设置
const request = new RequestBuilder()
  .setUrl("https://api.example.com/users")
  .setMethod("GET")
  .setHeaders({ Authorization: "Bearer token" })
  .build();

console.log(request);

// @ts-expect-error - 缺少 method，build() 不可调用
new RequestBuilder().setUrl("https://api.example.com").build();

// @ts-expect-error - 缺少 url，build() 不可调用
new RequestBuilder().setMethod("POST").build();
```

## 🎯 状态机类型

构建器模式的一个高级应用是**类型状态机**——通过类型系统强制执行状态转换规则，确保操作只能在正确的状态下调用。

### 连接状态机

```ts
// 定义状态类型
interface Disconnected {
  readonly _state: "disconnected";
}
interface Connected {
  readonly _state: "connected";
}
interface Authenticated {
  readonly _state: "authenticated";
}

// 用泛型跟踪连接状态
class Connection<State extends Disconnected | Connected | Authenticated> {
  private host = "";
  private token = "";

  private constructor(private readonly state: State["_state"]) {}

  static create(): Connection<Disconnected> {
    return new Connection("disconnected");
  }

  // 只有断开状态才能连接
  connect(this: Connection<Disconnected>, host: string): Connection<Connected> {
    const connection = new Connection<Connected>("connected");
    connection.host = host;
    console.log(`Connected to ${host}`);
    return connection;
  }

  // 只有已连接状态才能认证
  authenticate(this: Connection<Connected>, token: string): Connection<Authenticated> {
    const connection = new Connection<Authenticated>("authenticated");
    connection.host = this.host;
    connection.token = token;
    console.log(`Authenticated with token`);
    return connection;
  }

  // 只有认证后才能查询
  query(this: Connection<Authenticated>, sql: string): string[] {
    console.log(`Executing query: ${sql}`);
    return [`Result from ${this.host}`];
  }

  // 任何已连接状态都可以断开
  disconnect(this: Connection<Connected> | Connection<Authenticated>): Connection<Disconnected> {
    console.log("Disconnected");
    return new Connection("disconnected");
  }
}

// 正确的状态转换流程
const results = Connection.create()
  .connect("db.example.com")
  .authenticate("secret-token")
  .query("SELECT * FROM users");

console.log(results);

// @ts-expect-error - 不能在断开状态下查询
Connection.create().query("SELECT 1");

// @ts-expect-error - 不能在未认证状态下查询
Connection.create().connect("db.example.com").query("SELECT 1");
```

## 🎯 类型安全的 Builder Pattern

### 通用的类型安全构建器

封装一个可复用的类型安全构建器工具类型：

```ts
// 通用构建器类型：追踪哪些必填字段已设置
type Builder<
  Target,
  RequiredKeys extends keyof Target,
  SetKeys extends keyof Target = never,
> = {
  set<K extends keyof Target>(
    key: K,
    value: Target[K],
  ): Builder<Target, RequiredKeys, SetKeys | K>;
  build: RequiredKeys extends SetKeys
    ? () => Target
    : "Error: missing required fields";
};

// 创建构建器的工厂函数
function createBuilder<
  Target,
  RequiredKeys extends keyof Target = never,
>(): Builder<Target, RequiredKeys> {
  const config: Partial<Target> = {};

  const builder = {
    set<K extends keyof Target>(key: K, value: Target[K]) {
      config[key] = value;
      return builder;
    },
    build() {
      return config as Target;
    },
  };

  return builder as Builder<Target, RequiredKeys>;
}

// 使用示例
interface ServerConfig {
  host: string;
  port: number;
  protocol: "http" | "https";
  maxConnections?: number;
  keepAlive?: boolean;
}

// host, port, protocol 为必填字段
const server = createBuilder<ServerConfig, "host" | "port" | "protocol">()
  .set("host", "localhost")
  .set("port", 3000)
  .set("protocol", "https")
  .set("keepAlive", true)
  .build();

console.log(server);
// { host: "localhost", port: 3000, protocol: "https", keepAlive: true }
```

### 链式构建器 + 条件约束

更高级的构建器模式，根据已设置的字段动态解锁后续选项：

```ts
interface EmailConfig {
  to: string;
  subject: string;
  body: string;
  cc?: string[];
  bcc?: string[];
  attachments?: string[];
}

class EmailBuilder<
  HasTo extends boolean = false,
  HasSubject extends boolean = false,
  HasBody extends boolean = false,
> {
  private config: Partial<EmailConfig> = {};

  to(address: string): EmailBuilder<true, HasSubject, HasBody> {
    this.config.to = address;
    return this as unknown as EmailBuilder<true, HasSubject, HasBody>;
  }

  subject(text: string): EmailBuilder<HasTo, true, HasBody> {
    this.config.subject = text;
    return this as unknown as EmailBuilder<HasTo, true, HasBody>;
  }

  body(content: string): EmailBuilder<HasTo, HasSubject, true> {
    this.config.body = content;
    return this as unknown as EmailBuilder<HasTo, HasSubject, true>;
  }

  // cc 只有设置了 to 之后才可调用
  cc(this: EmailBuilder<true, HasSubject, HasBody>, addresses: string[]): EmailBuilder<true, HasSubject, HasBody> {
    this.config.cc = addresses;
    return this;
  }

  // bcc 同理
  bcc(this: EmailBuilder<true, HasSubject, HasBody>, addresses: string[]): EmailBuilder<true, HasSubject, HasBody> {
    this.config.bcc = addresses;
    return this;
  }

  attachments(files: string[]): EmailBuilder<HasTo, HasSubject, HasBody> {
    this.config.attachments = files;
    return this as unknown as EmailBuilder<HasTo, HasSubject, HasBody>;
  }

  // 所有必填字段设置后才能发送
  send(this: EmailBuilder<true, true, true>): EmailConfig {
    console.log(`Sending email to ${this.config.to}: ${this.config.subject}`);
    return this.config as unknown as EmailConfig;
  }
}

// 正确用法：所有必填字段都已设置
const email = new EmailBuilder()
  .to("bob@example.com")
  .subject("Meeting Tomorrow")
  .cc(["alice@example.com"])
  .body("Let's meet at 10am.")
  .send();

console.log(email);

// @ts-expect-error - 缺少 body
new EmailBuilder().to("bob@example.com").subject("Hi").send();

// @ts-expect-error - cc 不能在 to 之前调用
new EmailBuilder().cc(["alice@example.com"]);
```

## 📝 实际应用示例

### 类型安全的查询构建器

将构建器模式应用于 SQL 查询构建，在编译期确保查询结构的正确性：

```ts
interface QueryParts {
  table: string;
  columns: string[];
  conditions: string[];
  orderBy?: { column: string; direction: "ASC" | "DESC" };
  limit?: number;
}

class QueryBuilder<HasTable extends boolean = false, HasColumns extends boolean = false> {
  private parts: Partial<QueryParts> = { conditions: [] };

  from(table: string): QueryBuilder<true, HasColumns> {
    this.parts.table = table;
    return this as unknown as QueryBuilder<true, HasColumns>;
  }

  select(
    this: QueryBuilder<true, HasColumns>,
    ...columns: string[]
  ): QueryBuilder<true, true> {
    this.parts.columns = columns;
    return this as unknown as QueryBuilder<true, true>;
  }

  where(
    this: QueryBuilder<true, true>,
    condition: string,
  ): QueryBuilder<true, true> {
    this.parts.conditions!.push(condition);
    return this;
  }

  orderBy(
    this: QueryBuilder<true, true>,
    column: string,
    direction: "ASC" | "DESC" = "ASC",
  ): QueryBuilder<true, true> {
    this.parts.orderBy = { column, direction };
    return this;
  }

  limit(
    this: QueryBuilder<true, true>,
    count: number,
  ): QueryBuilder<true, true> {
    this.parts.limit = count;
    return this;
  }

  toSQL(this: QueryBuilder<true, true>): string {
    const columns = this.parts.columns!.join(", ");
    let sql = `SELECT ${columns} FROM ${this.parts.table}`;

    if (this.parts.conditions!.length > 0) {
      sql += ` WHERE ${this.parts.conditions!.join(" AND ")}`;
    }

    if (this.parts.orderBy) {
      sql += ` ORDER BY ${this.parts.orderBy.column} ${this.parts.orderBy.direction}`;
    }

    if (this.parts.limit !== undefined) {
      sql += ` LIMIT ${this.parts.limit}`;
    }

    return sql;
  }
}

// 正确用法
const sql = new QueryBuilder()
  .from("users")
  .select("id", "name", "email")
  .where("age > 18")
  .where("status = 'active'")
  .orderBy("name", "ASC")
  .limit(10)
  .toSQL();

console.log(sql);
// SELECT id, name, email FROM users WHERE age > 18 AND status = 'active' ORDER BY name ASC LIMIT 10

// @ts-expect-error - 没有 from 就不能 select
new QueryBuilder().select("id");

// @ts-expect-error - 没有 select 就不能 where
new QueryBuilder().from("users").where("id = 1");

// @ts-expect-error - 没有 from 和 select 就不能 toSQL
new QueryBuilder().toSQL();
```
