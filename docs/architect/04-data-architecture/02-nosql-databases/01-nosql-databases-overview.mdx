# NoSQL 数据库 - 总览

> **版本**：v1.0
> **最后更新**：2026-04-24

## 📚 章节介绍

本章节讲解各类 NoSQL 数据库的原理、特点和适用场景，帮助你在架构设计中合理选择数据存储方案。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 理解文档数据库、键值存储、列式存储、图数据库的核心特点
- 掌握 Redis 数据结构与集群方案
- 能够根据数据特征选择合适的 NoSQL 方案
- 理解 SQL 与 NoSQL 的混合使用策略

## 📖 章节结构

### 第一部分：文档数据库
- MongoDB 核心原理与文档建模

### 第二部分：键值存储
- Redis 数据结构、持久化与集群方案

### 第三部分：列式存储
- HBase / Cassandra 宽列模型
- 时序数据库（InfluxDB、TDengine）

### 第四部分：图数据库
- Neo4j 图建模与查询

## 🔑 核心概念

### NoSQL 分类与选型

| 类型 | 代表产品 | 数据模型 | 适用场景 |
|------|---------|---------|---------|
| **文档型** | MongoDB | JSON 文档 | 灵活 Schema、内容管理 |
| **键值型** | Redis | Key-Value | 缓存、会话、排行榜 |
| **列式** | HBase、Cassandra | 宽列 | 海量数据、时序数据 |
| **图** | Neo4j | 节点-边 | 社交网络、推荐系统 |
