# 数据架构设计 - 总览

> **版本**：v1.0
> **最后更新**：2026-04-24

## 📚 章节介绍

本章节讲解企业级数据架构的设计方法，包括数据建模、数据流设计和数据治理。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 掌握 ER 建模和维度建模方法
- 理解数据仓库和数据湖的架构设计
- 掌握 ETL/ELT 和 CDC 等数据流方案
- 理解数据治理的核心要素

## 📖 章节结构

### 第一部分：数据建模
- ER 建模 / 维度建模
- 数据仓库设计 / 数据湖架构

### 第二部分：数据流设计
- ETL / ELT 流程
- 流批一体架构
- CDC（Change Data Capture）
- 实时数据管道

### 第三部分：数据治理
- 数据质量管理 / 元数据管理
- 数据血缘分析
- 数据安全与脱敏

## 🔑 核心概念

### 数据架构演进

```
单体数据库
    ↓
读写分离 + 分库分表
    ↓
数据仓库（离线分析）
    ↓
数据湖（多源异构）
    ↓
湖仓一体（Lakehouse）
    ↓
实时数据平台（流批一体）
```
