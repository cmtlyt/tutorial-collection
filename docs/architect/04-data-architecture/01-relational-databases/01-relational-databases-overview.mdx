## 🔑 核心概念

### 事务隔离级别

| 隔离级别 | 脏读 | 不可重复读 | 幻读 | 性能 |
|---------|------|----------|------|------|
| 读未提交 | ✓ | ✓ | ✓ | 最高 |
| 读已提交 | ✗ | ✓ | ✓ | 高 |
| 可重复读 | ✗ | ✗ | ✓* | 中 |
| 串行化 | ✗ | ✗ | ✗ | 最低 |

*InnoDB 通过 MVCC + 间隙锁在可重复读级别也可以防止幻读
