## 📚 章节介绍

本章节讲解基础设施层面的安全设计，包括网络安全、容器安全和合规审计。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 掌握网络安全防护方案（防火墙、WAF、网络隔离）
- 理解容器安全的最佳实践
- 了解等保合规和隐私保护要求
- 能够设计完整的安全审计方案

### 第二部分：容器安全

## 🔑 核心概念

### 纵深防御（Defense in Depth）

```
边界防护（防火墙、WAF、DDoS 防护）
    ↓
网络隔离（VPC、安全组、网络分段）
    ↓
应用安全（认证授权、输入验证）
    ↓
数据安全（加密、脱敏、访问控制）
    ↓
审计监控（日志审计、异常检测）
```

每一层都提供独立的安全防护，即使某一层被突破，其他层仍能提供保护。
