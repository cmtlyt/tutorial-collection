## 🔑 核心概念

### 认证 vs 授权

| 维度 | 认证（Authentication） | 授权（Authorization） |
|------|---------------------|---------------------|
| **解决的问题** | "你是谁？" | "你能做什么？" |
| **实现方式** | 密码、Token、证书 | RBAC、ABAC、ACL |
| **协议** | OIDC、SAML | OAuth 2.0 |

### 零信任架构原则

1. **永不信任，始终验证**：不基于网络位置授予信任
2. **最小权限**：仅授予完成任务所需的最小权限
3. **假设已被攻破**：设计时假设攻击者已在网络内部
4. **持续验证**：每次访问都需要认证和授权
