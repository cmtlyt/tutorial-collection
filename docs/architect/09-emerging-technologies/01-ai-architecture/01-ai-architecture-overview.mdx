## 🔑 核心概念

### AI 原生架构的挑战

AI 服务与传统微服务的差异：

| 维度 | 传统微服务 | AI 微服务 |
|------|----------|----------|
| **资源需求** | CPU 为主 | GPU/TPU 密集 |
| **响应时间** | 毫秒级 | 秒级（推理） |
| **部署单元** | 代码包 | 代码 + 模型文件 |
| **版本管理** | 代码版本 | 代码 + 模型 + 数据版本 |
| **扩缩容** | 快速 | 受限于 GPU 资源 |

### MLOps 生命周期

```
数据收集 → 数据处理 → 模型训练 → 模型评估
    ↑                                    ↓
监控反馈 ← 线上服务 ← 模型部署 ← 模型注册
```
