## 🔑 核心概念

### 边缘计算架构模型

```
云端（Cloud）
├── 全局管理与编排
├── 大规模数据分析
└── 模型训练

边缘（Edge）
├── 本地数据处理
├── 低延迟推理
└── 离线缓存

终端（Device）
├── 数据采集
├── 简单计算
└── 用户交互
```

### WebAssembly 应用场景

| 场景 | 说明 | 代表项目 |
|------|------|---------|
| **边缘计算** | 轻量级、快速启动的边缘函数 | Cloudflare Workers |
| **跨平台** | 一次编译，到处运行 | Figma |
| **插件系统** | 安全沙箱中运行第三方代码 | Envoy WASM Filter |
| **区块链** | 智能合约运行时 | Polkadot |
