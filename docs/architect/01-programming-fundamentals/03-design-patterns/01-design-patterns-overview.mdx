# 设计模式 - 总览

> **版本**：v1.0
> **最后更新**：2026-04-24

## 📚 章节介绍

本章节系统讲解 GoF 23 种经典设计模式，按照创建型、结构型和行为型分类，帮助你理解每种模式的意图、适用场景以及在架构设计中的应用。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 掌握创建型、结构型、行为型三大类设计模式
- 理解每种模式解决的核心问题和适用场景
- 能够在实际项目中识别和应用合适的设计模式
- 理解设计模式在分布式系统和架构层面的延伸

## 🔑 核心概念

### 设计模式与架构模式的关系

设计模式是代码级别的解决方案，而架构模式是系统级别的解决方案。许多架构模式正是设计模式在更大尺度上的应用：

| 设计模式 | 架构层面的延伸 |
|---------|--------------|
| **观察者模式** | 事件驱动架构、消息队列 |
| **代理模式** | API 网关、服务代理 |
| **外观模式** | BFF（Backend for Frontend） |
| **策略模式** | 负载均衡策略、路由策略 |
| **责任链模式** | 中间件管道、过滤器链 |
| **装饰器模式** | AOP、拦截器 |

### 选择设计模式的原则

1. **不要为了使用模式而使用模式**：先识别问题，再选择合适的模式
2. **优先选择简单的方案**：复杂的模式增加了认知负担
3. **关注模式的意图而非结构**：理解"为什么"比"怎么做"更重要
