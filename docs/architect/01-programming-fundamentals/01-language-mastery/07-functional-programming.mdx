## 📚 概念介绍

函数式编程（Functional Programming, FP）是一种编程范式，它将计算视为数学函数的求值，强调不可变性、纯函数和高阶函数。理解函数式编程的理论基础，能够帮助架构师设计更简洁、更可维护、更易于测试的系统。

## 🔑 核心概念

### 什么是函数式编程

函数式编程是一种声明式编程范式，它基于以下核心思想：

```
函数式编程的核心原则：

┌─────────────────────────────────────────┐
│ 1. 纯函数（Pure Functions）             │
│    - 相同输入总是产生相同输出            │
│    - 无副作用（不修改外部状态）          │
│    - 可预测、可测试、可缓存              │
├─────────────────────────────────────────┤
│ 2. 不可变性（Immutability）            │
│    - 数据一旦创建就不能被修改            │
│    - 通过创建新数据来表示变化            │
│    - 避免共享状态带来的问题              │
├─────────────────────────────────────────┤
│ 3. 高阶函数（Higher-Order Functions）   │
│    - 函数可以作为参数传递给其他函数      │
│    - 函数可以作为返回值                  │
│    - 函数可以赋值给变量                  │
├─────────────────────────────────────────┤
│ 4. 函数组合（Function Composition）     │
│    - 将简单函数组合成复杂函数            │
│    - 每个函数只做一件事                  │
│    - 通过组合构建复杂行为                │
├─────────────────────────────────────────┤
│ 5. 声明式编程（Declarative Programming）│
│    - 描述"做什么"而非"怎么做"            │
│    - 代码更接近问题域的描述              │
│    - 提升可读性和可维护性                │
└─────────────────────────────────────────┘
```

### 函数式编程的理论基础

函数式编程的理论基础来自 λ 演算（Lambda Calculus）和范畴论（Category Theory）：

```
λ 演算（Lambda Calculus）：
  - 由 Alonzo Church 在 1930 年代提出
  - 是最简单的通用编程模型
  - 只有三条基本规则：
    1. 变量：x, y, z, ...
    2. 函数抽象：λx. E（定义一个函数）
    3. 函数应用：(λx. E) M（调用函数）
  - 所有可计算的函数都可以用 λ 演算表达

范畴论（Category Theory）：
  - 数学的抽象分支
  - 研究结构和结构之间的映射
  - 为函数式编程提供了理论基础：
    - 函子（Functor）
    - 单子（Monad）
    - 适用函子（Applicative）
```

## 🧬 核心概念详解

### 纯函数

纯函数是函数式编程的基石：

```js
// ❌ 非纯函数：有副作用
let counter = 0;

function increment() {
  counter++; // 修改外部状态
  return counter;
}

console.log(increment()); // 1
console.log(increment()); // 2
// 相同调用产生不同结果，不可预测

// ❌ 非纯函数：依赖外部状态
const taxRate = 0.1;

function calculateTax(price) {
  return price * taxRate; // 依赖外部变量
}

// ✅ 纯函数：无副作用
function incrementPure(counter) {
  return counter + 1;
}

console.log(incrementPure(0)); // 1
console.log(incrementPure(0)); // 1
// 相同输入总是产生相同输出

// ✅ 纯函数：所有依赖通过参数传递
function calculateTaxPure(price, taxRate) {
  return price * taxRate;
}

console.log(calculateTaxPure(100, 0.1)); // 10
console.log(calculateTaxPure(100, 0.1)); // 10
// 可预测、可测试、可缓存
```

#### 纯函数的优势

```
纯函数的优势：

1. 可预测性
   - 相同输入 → 相同输出
   - 行为完全确定
   - 易于推理

2. 可测试性
   - 无需 mock 外部依赖
   - 无需设置测试环境
   - 测试简单直接

3. 可缓存性
   - 可以使用记忆化（Memoization）
   - 避免重复计算
   - 提升性能

4. 可并行性
   - 无共享状态
   - 无竞态条件
   - 天然适合并发

5. 可移植性
   - 不依赖外部环境
   - 可以在任何地方运行
   - 易于重构和移动
```

### 不可变性

不可变性意味着数据一旦创建就不能被修改：

```js
// ❌ 可变数据
const user = {
  name: "Alice",
  age: 30,
};

user.age = 31; // 修改对象
console.log(user.age); // 31

// 问题：
// 1. 难以追踪变化
// 2. 可能产生意外的副作用
// 3. 在并发环境下不安全

// ✅ 不可变数据
const userImmutable = Object.freeze({
  name: "Alice",
  age: 30,
});

// userImmutable.age = 31; // 静默失败（严格模式下报错）

// 创建新对象表示变化
const userUpdated = {
  ...userImmutable,
  age: 31,
};

console.log(userImmutable.age); // 30 - 原对象不变
console.log(userUpdated.age);   // 31 - 新对象

// 使用不可变数据结构库
import { produce } from "immer";

const state = {
  users: [
    { id: 1, name: "Alice" },
    { id: 2, name: "Bob" },
  ],
};

const nextState = produce(state, (draft) => {
  draft.users.push({ id: 3, name: "Charlie" });
  draft.users[0].name = "Alice Updated";
});

console.log(state.users.length);     // 2 - 原状态不变
console.log(nextState.users.length); // 3 - 新状态
console.log(nextState.users[0].name); // "Alice Updated"
```

#### 不可变性的实现方式

```
实现不可变性的方法：

1. Object.freeze()
   - 浅层冻结
   - 简单但有限

2. 展开运算符（Spread Operator）
   - 创建新对象/数组
   - 浅拷贝

3. 不可变数据结构库
   - Immutable.js
   - Immer
   - Mori

4. 语言级别支持
   - Clojure: 所有数据结构默认不可变
   - Haskell: 纯函数式语言
   - Rust: 所有权系统保证不可变
```

### 高阶函数

高阶函数是接受函数作为参数或返回函数的函数：

```js
// 1. 函数作为参数

// 接受函数作为参数
function map(array, fn) {
  const result = [];
  for (const item of array) {
    result.push(fn(item));
  }
  return result;
}

function filter(array, predicate) {
  const result = [];
  for (const item of array) {
    if (predicate(item)) {
      result.push(item);
    }
  }
  return result;
}

function reduce(array, fn, initial) {
  let accumulator = initial;
  for (const item of array) {
    accumulator = fn(accumulator, item);
  }
  return accumulator;
}

// 使用高阶函数
const numbers = [1, 2, 3, 4, 5];

const doubled = map(numbers, (x) => x * 2);
console.log(doubled); // [2, 4, 6, 8, 10]

const evens = filter(numbers, (x) => x % 2 === 0);
console.log(evens); // [2, 4]

const sum = reduce(numbers, (acc, x) => acc + x, 0);
console.log(sum); // 15

// 2. 函数作为返回值

function createMultiplier(factor) {
  return function (number) {
    return number * factor;
  };
}

const double = createMultiplier(2);
const triple = createMultiplier(3);

console.log(double(5)); // 10
console.log(triple(5)); // 15

// 3. 函数组合

function compose(f, g) {
  return function (x) {
    return f(g(x));
  };
}

function addOne(x) {
  return x + 1;
}

function multiplyByTwo(x) {
  return x * 2;
}

const addOneThenMultiplyByTwo = compose(multiplyByTwo, addOne);
console.log(addOneThenMultiplyByTwo(5)); // 12
// (5 + 1) * 2 = 12
```

### 函数组合

函数组合是将多个函数组合成一个新函数的技术：

```js
// 基础函数组合
function compose(...fns) {
  return function (x) {
    return fns.reduceRight((acc, fn) => fn(acc), x);
  };
}

function pipe(...fns) {
  return function (x) {
    return fns.reduce((acc, fn) => fn(acc), x);
  };
}

// 使用示例
const toUpperCase = (str) => str.toUpperCase();
const exclaim = (str) => `${str}!`;
const repeat = (str) => `${str} ${str}`;

// compose: 从右到左执行
const shout = compose(exclaim, toUpperCase);
console.log(shout("hello")); // "HELLO!"

// pipe: 从左到右执行
const excited = pipe(toUpperCase, exclaim, repeat);
console.log(excited("hello")); // "HELLO! HELLO!"

// 点自由风格（Point-free Style）
// 不显式提到参数
const greet = compose(
  (name) => `Hello, ${name}!`,
  (name) => name.toUpperCase()
);

console.log(greet("alice")); // "Hello, ALICE!"

// 函数组合的实际应用
const users = [
  { name: "Alice", age: 30, salary: 50000 },
  { name: "Bob", age: 25, salary: 45000 },
  { name: "Charlie", age: 35, salary: 60000 },
];

// 提取属性
const pluck = (key) => (obj) => obj[key];

// 过滤
const filterBy = (predicate) => (array) => array.filter(predicate);

// 映射
const mapBy = (fn) => (array) => array.map(fn);

// 排序
const sortBy = (key) => (array) =>
  [...array].sort((a, b) => a[key] - b[key]);

// 组合操作
const getNamesOfAdults = compose(
  mapBy(pluck("name")),
  filterBy((user) => user.age >= 30)
);

console.log(getNamesOfAdults(users)); // ["Alice", "Charlie"]

const getSalariesSorted = compose(
  mapBy(pluck("salary")),
  sortBy("salary")
);

console.log(getSalariesSorted(users)); // [45000, 50000, 60000]
```

## 🏗️ 函数式数据结构

### 持久化数据结构

持久化数据结构是指修改后会保留旧版本的数据结构：

```js
// 传统的可变链表
class MutableLinkedList {
  constructor(value) {
    this.value = value;
    this.next = null;
  }

  append(value) {
    const newNode = new MutableLinkedList(value);
    if (!this.next) {
      this.next = newNode;
    } else {
      this.next.append(value);
    }
    return this; // 返回自身，原链表被修改
  }
}

const list1 = new MutableLinkedList(1);
list1.append(2);
list1.append(3);
// list1 现在是 1 -> 2 -> 3

const list2 = list1.append(4);
// list1 和 list2 是同一个对象！
console.log(list1 === list2); // true

// 不可变链表
class ImmutableList {
  constructor(value, next = null) {
    this.value = value;
    this.next = next;
  }

  prepend(value) {
    return new ImmutableList(value, this); // 返回新链表
  }

  append(value) {
    if (!this.next) {
      return new ImmutableList(this.value, new ImmutableList(value));
    }
    return new ImmutableList(this.value, this.next.append(value));
  }

  toArray() {
    const result = [];
    let current = this;
    while (current) {
      result.push(current.value);
      current = current.next;
    }
    return result;
  }
}

const immList1 = new ImmutableList(1);
const immList2 = immList1.append(2);
const immList3 = immList2.append(3);
const immList4 = immList3.prepend(0);

console.log(immList1.toArray()); // [1]
console.log(immList2.toArray()); // [1, 2]
console.log(immList3.toArray()); // [1, 2, 3]
console.log(immList4.toArray()); // [0, 1, 2, 3]

// 每个操作都创建新链表，原链表保持不变
console.log(immList1 === immList2); // false
console.log(immList2 === immList3); // false
```

### 函数式选项类型

选项类型（Option/Maybe）用于安全地处理可能不存在的值：

```js
// Option 类型实现
class Option {
  static of(value) {
    return value === null || value === undefined
      ? None()
      : Some(value);
  }

  isNone() {
    return false;
  }

  isSome() {
    return false;
  }

  map(fn) {
    return this;
  }

  flatMap(fn) {
    return this;
  }

  getOrElse(defaultValue) {
    return defaultValue;
  }
}

class Some extends Option {
  constructor(value) {
    super();
    this.value = value;
  }

  isSome() {
    return true;
  }

  map(fn) {
    return Option.of(fn(this.value));
  }

  flatMap(fn) {
    return fn(this.value);
  }

  getOrElse(defaultValue) {
    return this.value;
  }
}

class None extends Option {
  isNone() {
    return true;
  }
}

// 使用 Option 类型
function findUserById(users, id) {
  const user = users.find((u) => u.id === id);
  return Option.of(user);
}

const users = [
  { id: 1, name: "Alice" },
  { id: 2, name: "Bob" },
];

const user1 = findUserById(users, 1);
const user3 = findUserById(users, 3);

console.log(user1.isSome()); // true
console.log(user3.isNone()); // true

// 链式操作
const userName = findUserById(users, 1)
  .map((user) => user.name)
  .map((name) => name.toUpperCase())
  .getOrElse("Unknown");

console.log(userName); // "ALICE"

const unknownUserName = findUserById(users, 3)
  .map((user) => user.name)
  .map((name) => name.toUpperCase())
  .getOrElse("Unknown");

console.log(unknownUserName); // "Unknown"
```

### 函数式错误处理

```js
// Result 类型：用于处理可能失败的操作
class Result {
  static success(value) {
    return new Success(value);
  }

  static failure(error) {
    return new Failure(error);
  }

  isSuccess() {
    return false;
  }

  isFailure() {
    return false;
  }

  map(fn) {
    return this;
  }

  flatMap(fn) {
    return this;
  }

  getOrElse(defaultValue) {
    return defaultValue;
  }

  match(patterns) {
    return this;
  }
}

class Success extends Result {
  constructor(value) {
    super();
    this.value = value;
  }

  isSuccess() {
    return true;
  }

  map(fn) {
    try {
      return Result.success(fn(this.value));
    } catch (error) {
      return Result.failure(error);
    }
  }

  flatMap(fn) {
    try {
      return fn(this.value);
    } catch (error) {
      return Result.failure(error);
    }
  }

  getOrElse(defaultValue) {
    return this.value;
  }

  match(patterns) {
    return patterns.success?.(this.value);
  }
}

class Failure extends Result {
  constructor(error) {
    super();
    this.error = error;
  }

  isFailure() {
    return true;
  }

  match(patterns) {
    return patterns.failure?.(this.error);
  }
}

// 使用 Result 类型
function divide(a, b) {
  if (b === 0) {
    return Result.failure(new Error("Division by zero"));
  }
  return Result.success(a / b);
}

function parseNumber(str) {
  const num = Number(str);
  if (isNaN(num)) {
    return Result.failure(new Error("Invalid number"));
  }
  return Result.success(num);
}

// 链式操作
const result = parseNumber("10")
  .flatMap((x) => divide(x, 2))
  .map((x) => x * 3);

console.log(result.isSuccess()); // true
console.log(result.getOrElse(0)); // 15

// 使用 match 进行模式匹配
const errorResult = parseNumber("invalid")
  .flatMap((x) => divide(x, 2))
  .map((x) => x * 3);

errorResult.match({
  success: (value) => console.log("Result:", value),
  failure: (error) => console.log("Error:", error.message),
});
// Error: Invalid number
```

### 函数式状态管理

```js
// 函数式状态管理：Redux 模式

// 1. 定义初始状态
const initialState = {
  count: 0,
  todos: [],
};

// 2. 定义 Action 类型
const Actions = {
  INCREMENT: "INCREMENT",
  DECREMENT: "DECREMENT",
  ADD_TODO: "ADD_TODO",
  REMOVE_TODO: "REMOVE_TODO",
};

// 3. 定义 Reducer（纯函数）
function reducer(state = initialState, action) {
  switch (action.type) {
    case Actions.INCREMENT:
      return {
        ...state,
        count: state.count + 1,
      };

    case Actions.DECREMENT:
      return {
        ...state,
        count: state.count - 1,
      };

    case Actions.ADD_TODO:
      return {
        ...state,
        todos: [...state.todos, action.payload],
      };

    case Actions.REMOVE_TODO:
      return {
        ...state,
        todos: state.todos.filter((_, i) => i !== action.payload),
      };

    default:
      return state;
  }
}

// 4. 创建 Store
function createStore(reducer) {
  let state = reducer(undefined, {});
  const listeners = [];

  return {
    getState() {
      return state;
    },

    dispatch(action) {
      state = reducer(state, action);
      listeners.forEach((listener) => listener());
    },

    subscribe(listener) {
      listeners.push(listener);
      return () => {
        const index = listeners.indexOf(listener);
        listeners.splice(index, 1);
      };
    },
  };
}

// 5. 使用 Store
const store = createStore(reducer);

// 订阅状态变化
store.subscribe(() => {
  console.log("State:", store.getState());
});

// 分发 Action
store.dispatch({ type: Actions.INCREMENT });
// State: { count: 1, todos: [] }

store.dispatch({ type: Actions.ADD_TODO, payload: "Learn FP" });
// State: { count: 1, todos: ["Learn FP"] }

store.dispatch({ type: Actions.INCREMENT });
// State: { count: 2, todos: ["Learn FP"] }
```

## 📊 函数式编程 vs 面向对象编程

| 特性 | 函数式编程 | 面向对象编程 |
|------|-----------|-------------|
| **核心抽象** | 函数 | 对象 |
| **状态管理** | 不可变 | 可变 |
| **数据与行为** | 分离 | 封装 |
| **并发处理** | 天然支持 | 需要锁 |
| **测试难度** | 简单 | 复杂 |
| **学习曲线** | 陡峭 | 平缓 |
| **适用场景** | 数据处理、并发 | 业务建模、UI |
| **典型语言** | Haskell, Clojure, F# | Java, C++, Python |

### 混合范式

现代编程语言通常支持多种范式：

```js
// 混合使用函数式和面向对象

// 1. 使用类封装数据
class User {
  constructor(id, name, email) {
    this.id = id;
    this.name = name;
    this.email = email;
  }

  // 2. 使用纯函数处理数据
  static fromDTO(dto) {
    return new User(dto.id, dto.name, dto.email);
  }

  toDTO() {
    return {
      id: this.id,
      name: this.name,
      email: this.email,
    };
  }
}

// 3. 使用函数式操作集合
const users = [
  new User(1, "Alice", "alice@example.com"),
  new User(2, "Bob", "bob@example.com"),
];

const userDTOs = users.map((user) => user.toDTO());
const adultUsers = users.filter((user) => user.age >= 18);

// 4. 使用高阶函数增强类
const withLogging = (Class) => {
  return class extends Class {
    constructor(...args) {
      super(...args);
      console.log(`Created ${Class.name}`);
    }
  };
};

const LoggedUser = withLogging(User);
const user = new LoggedUser(1, "Alice", "alice@example.com");
// Created User
```
