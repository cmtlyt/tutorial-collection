## 📚 章节介绍

本章节讲解高并发系统的设计方法，从**并发理论基础**开始建立可量化的分析框架，再深入并发处理模型、流量控制和缓存架构等工程实践，帮助你设计能够承载大规模流量的系统。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 建立并发理论基础（Little's Law、Amdahl/USL 定律、M/M/1 排队模型）

- 理解令牌桶、漏桶等流量控制算法

- 制定峰值流量应对方案

## 🔑 核心概念

### 高并发系统的核心思路

```
垂直优化（单机性能）
├── 异步非阻塞 I/O
├── 无锁数据结构
├── JIT 优化
└── 缓存加速

水平扩展（集群能力）
├── 无状态服务 → 水平扩容
├── 数据分片 → 分散压力
├── 读写分离 → 提升读性能
└── 多级缓存 → 减少后端压力
```

### 限流算法对比

| 算法 | 特点 | 适用场景 |
|------|------|---------|
| **令牌桶** | 允许突发流量 | API 限流 |
| **漏桶** | 均匀输出 | 流量整形 |
| **固定窗口** | 实现简单，有临界问题 | 简单限流 |
| **滑动窗口** | 更精确，无临界问题 | 精确限流 |
