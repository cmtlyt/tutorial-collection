## 📚 章节介绍

本章节讲解高可用系统的设计方法，先从**可用性理论基础**建立可量化的工程契约（SLI/SLO/SLA、CAP/PACELC、故障模型），再深入冗余设计、故障治理和弹性设计等工程实践，帮助你构建能够持续稳定运行的系统。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 用 SLI/SLO/SLA + Error Budget 量化可用性目标
- 理解 CAP/PACELC 定理与分布式八大谬误
- 掌握无状态服务设计和数据多副本策略
- 理解跨机房容灾和异地多活方案
- 掌握混沌工程和故障演练方法
- 能够设计自动扩缩容和容量规划方案

## 🔑 核心概念

### 高可用设计金字塔

```
        ╱ 异地多活 ╲          ← 最高等级
       ╱ 跨机房容灾 ╲
      ╱ 故障自愈与演练 ╲
     ╱ 熔断 / 降级 / 限流 ╲
    ╱ 冗余 / 负载均衡 / 健康检查╲  ← 基础保障
```

### 混沌工程原则

1. **建立稳态假说**：定义系统正常行为的指标
2. **引入真实世界事件**：模拟网络故障、服务宕机等
3. **在生产环境运行**：只有生产环境才能暴露真实问题
4. **最小化爆炸半径**：控制影响范围，逐步扩大
5. **持续自动化**：将实验纳入 CI/CD 流程
