# 在线资源与课程

> **版本**：v1.0
> **最后更新**：2026-04-28

## 📖 概述

相较于书籍提供的体系化深度，在线资源解决的是**时效性**和**广度**问题：新兴技术没有书、行业实践需要最新案例、跨领域需要快速补齐。本文聚焦高信噪比的博客、在线课程、官方文档、技术雷达，并给出一套"订阅 → 筛选 → 输出"的信息管理方法论，帮助你避开"收藏夹吃灰"的陷阱。

## 🎯 学习目标

- 掌握高质量架构类博客的订阅与阅读方法
- 知道主流在线课程的定位与取舍
- 学会用 ThoughtWorks 技术雷达等工具建立技术视野
- 建立可持续的信息流管理习惯

### 订阅策略

- **每个方向最多 3 个稳定订阅**：分布式、云原生、AI、工程文化各选一两个
- **用 RSS 阅读器**（如 NetNewsWire、Feedly、Inoreader）集中管理
- **每周固定时段阅读**（如周六上午 2h），避免碎片打断深度思考
- **每季度清理一次**：半年内没读过 3 篇以上的订阅源直接退订

**阅读技巧**：

- 与博客交叉阅读：官方讲"是什么"，博客讲"踩过什么坑"

## 📡 技术雷达与趋势工具

### ThoughtWorks 技术雷达

[ThoughtWorks Technology Radar](https://www.thoughtworks.com/radar) 每 6 个月发布一次，对新技术/方法/工具做四个级别的推荐：

```
Adopt     ← 我们强烈推荐使用
Trial     ← 值得在小范围试用
Assess    ← 值得关注和评估
Hold      ← 谨慎使用或避免
```

**使用方法**：

- 每期出来后**通读 Adopt 和 Hold 两个象限**，了解"该用什么"和"该停什么"
- 对 Assess 里自己方向相关的条目做深入调研
- 与自己团队做一份"**企业内部技术雷达**"，定期评审

## 📚 论文与技术报告

架构师到一定阶段后，**读论文**比读博客性价比更高：

### 入门级经典论文

| 论文 | 价值 |
|------|------|
| **The Google File System** (2003) | 分布式文件系统奠基 |
| **MapReduce: Simplified Data Processing on Large Clusters** (2004) | 大数据计算模型 |
| **Bigtable: A Distributed Storage System** (2006) | NoSQL 起源 |
| **Dynamo: Amazon's Highly Available Key-value Store** (2007) | 最终一致性架构 |
| **Paxos Made Simple** (Lamport) | 共识算法入门 |
| **In Search of an Understandable Consensus Algorithm (Raft)** (2014) | Raft 原论文 |
| **Spanner: Google's Globally-Distributed Database** (2012) | 全球分布式数据库 |

### 论文阅读方法

- 先读 **Abstract + Introduction + Conclusion**，判断是否值得深读
- 关注 **Related Work**，建立领域地图
- 重点读 **Architecture 和 Evaluation** 章节
- 复杂公式和证明可以跳过，理解直觉更重要
- 优先读**有开源实现**或**有实际系统背书**的论文

### 论文获取

- [arXiv](https://arxiv.org) — 预印本
- [Papers We Love](https://paperswelove.org) — 社区精选
- [Morning Paper (已归档)](https://blog.acolyer.org) — Adrian Colyer 的每日论文解读

## 🧹 信息流管理：避免"收藏夹吃灰"

### 原则

1. **信息源稀缺化**：宁可少而精，不要多而杂
2. **阅读必有输出**：读完一篇重要文章至少写 3 行总结
3. **定期清理收藏夹**：每月清一次，3 个月没动的直接删
4. **建立个人知识库**：用 Obsidian / Notion / Logseq 等工具结构化沉淀
5. **分层时间分配**：

```
每日 15 min     浏览 RSS 标题，只标记"必读"
每周 2 h        深度阅读本周标记的文章 + 输出笔记
每月 4 h        整理当月笔记，输出 1 篇总结文章
每季度 8 h      技术雷达 + 清理订阅源 + 调整学习计划
```

### 反模式

- ❌ 同时订阅 50 个博客，一篇都没读完
- ❌ 收藏了 200 篇"稍后阅读"，两年后还是没读
- ❌ 看完就忘，没有任何笔记沉淀
- ❌ 追逐热点，一个方向还没钻深就换下一个

## 🔗 相关概念

- **经典书籍**：深度优先，在线资源是广度与时效的补充
- **实战平台**：读完的内容需要动手验证才算内化
- **社区会议**：会议是在线资源的"现场版"，获取隐性知识
- **FinOps / 平台工程 / AI 架构**：新兴领域主要靠在线资源跟进
