## 📚 章节介绍

本章节汇总架构师学习路线中推荐的各类学习资源，包括经典书籍、在线资源、实践平台和社区会议。

## 📖 经典书籍

### 架构设计核心
- **《软件架构：架构模式、特征及实践指南》**（Fundamentals of Software Architecture - Mark Richards & Neal Ford）：架构师入门必读，系统讲解架构特征、风格和决策
- **《架构整洁之道》**（Clean Architecture - Robert C. Martin）：深入理解依赖规则和架构边界
- **《演进式架构》**（Building Evolutionary Architectures - Neal Ford, Rebecca Parsons）：如何设计支持增量变化的架构

### 领域驱动设计
- **《领域驱动设计》**（Domain-Driven Design - Eric Evans）：DDD 开山之作，战略设计的经典
- **《实现领域驱动设计》**（Implementing Domain-Driven Design - Vaughn Vernon）：DDD 落地实践指南

### 分布式系统
- **《设计数据密集型应用》**（Designing Data-Intensive Applications - Martin Kleppmann）：分布式系统和数据系统的百科全书，强烈推荐
- **《微服务架构设计模式》**（Microservices Patterns - Chris Richardson）：微服务架构的模式语言

### 系统设计
- **《系统设计面试》**（System Design Interview - Alex Xu）：系统设计的实战指南，案例丰富

### 工程文化
- **《凤凰项目》**（The Phoenix Project - Gene Kim）：以小说形式讲解 DevOps 转型
- **《独角兽项目》**（The Unicorn Project - Gene Kim）：从开发者视角看数字化转型

## 🚀 学习建议

1. **T 型能力**：在广泛了解各领域的基础上，深耕一到两个方向成为专家
2. **实践驱动**：每学一个架构模式，都尝试在真实项目中落地验证
3. **复盘总结**：定期复盘项目中的架构决策，分析成功与失败的原因
4. **源码阅读**：研读优秀开源项目的架构设计，学习业界最佳实践
5. **业务理解**：架构服务于业务，深入理解业务才能设计出好的架构
6. **权衡思维**：没有银弹，架构设计的核心是在约束条件下做最优取舍
