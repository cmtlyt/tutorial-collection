## 📖 章节结构

### 第一部分：主流云平台
- 阿里云 / AWS / Azure / GCP

- Serverless 平台（函数计算、云函数）

### 第二部分：云原生技术

## 🔑 核心概念

### 云服务模型

```
SaaS（软件即服务）    ← 用户直接使用
    ↑
PaaS（平台即服务）    ← 开发者部署应用
    ↑
IaaS（基础设施即服务） ← 运维管理基础设施
    ↑
物理硬件              ← 云厂商管理
```

### 服务网格架构

服务网格将网络通信能力从应用代码中剥离到基础设施层：

```
应用 A → Sidecar Proxy ↔ Sidecar Proxy → 应用 B
                    ↕
              Control Plane（Istio）
```
