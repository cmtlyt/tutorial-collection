# CI/CD 与 DevOps - 总览

> **版本**：v1.0
> **最后更新**：2026-04-24

## 📚 章节介绍

本章节讲解持续集成、持续部署和基础设施即代码的核心实践，帮助你构建高效的软件交付流水线。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 设计完整的 CI/CD 流水线
- 掌握蓝绿部署、金丝雀发布等部署策略
- 理解 GitOps 和基础设施即代码（IaC）
- 能够搭建自动化测试和代码质量门禁

## 📖 章节结构

### 第一部分：持续集成
- Jenkins / GitLab CI / GitHub Actions
- 构建流水线设计
- 自动化测试集成
- 代码质量门禁

### 第二部分：持续部署
- 蓝绿部署 / 金丝雀发布 / 滚动更新 / 灰度发布
- GitOps（ArgoCD、Flux）

### 第三部分：基础设施即代码（IaC）
- Terraform / Ansible / Puppet
- 环境一致性管理

## 🔑 核心概念

### 部署策略对比

| 策略 | 停机时间 | 回滚速度 | 资源成本 | 适用场景 |
|------|---------|---------|---------|---------|
| **蓝绿部署** | 无 | 极快 | 2x | 关键业务 |
| **金丝雀发布** | 无 | 快 | 1.x | 需要验证的变更 |
| **滚动更新** | 无 | 中 | 1x | 常规变更 |
| **灰度发布** | 无 | 快 | 1.x | 按用户群验证 |
