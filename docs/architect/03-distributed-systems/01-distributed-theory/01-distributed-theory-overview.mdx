## 🔑 核心概念

### CAP 定理

在一个分布式系统中，以下三者最多只能同时满足两个：
- **C（Consistency）**：所有节点在同一时刻看到相同的数据
- **A（Availability）**：每个请求都能在合理时间内收到响应
- **P（Partition Tolerance）**：系统在网络分区时仍能运作

由于网络分区不可避免，实际上是在 **CP** 和 **AP** 之间做选择。

### 理论到实践的映射

| 理论 | 实践应用 |
|------|---------|
| CP 系统 | ZooKeeper、etcd、HBase |
| AP 系统 | Cassandra、DynamoDB、Eureka |
| 最终一致性 | DNS、消息队列、CDN |
| Raft 共识 | etcd、Consul、TiKV |
