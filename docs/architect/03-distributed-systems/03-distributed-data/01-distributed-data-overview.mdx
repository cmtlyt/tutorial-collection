## 📚 章节介绍

本章节讲解分布式系统中的数据管理挑战和解决方案，包括分布式事务、分布式存储和分布式缓存。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 掌握分布式事务的各种实现方案及其权衡

- 能够为不同业务场景选择合适的数据一致性方案

## 📖 章节结构

### 第一部分：分布式事务

### 第二部分：分布式存储

### 第三部分：分布式缓存
- Redis Cluster

- 缓存一致性问题
- 缓存雪崩、穿透、击穿

## 🔑 核心概念

### 分布式事务方案对比

| 方案 | 一致性 | 性能 | 复杂度 | 适用场景 |
|------|-------|------|-------|---------|
| **2PC** | 强一致 | 低 | 中 | 数据库跨库事务 |
| **Saga** | 最终一致 | 高 | 高 | 长事务、跨服务 |
| **TCC** | 最终一致 | 中 | 高 | 资金类业务 |
| **本地消息表** | 最终一致 | 高 | 低 | 通用异步场景 |

### 缓存三大问题

- **缓存穿透**：查询不存在的数据 → 布隆过滤器 / 空值缓存
- **缓存击穿**：热点 key 过期 → 互斥锁 / 永不过期
- **缓存雪崩**：大量 key 同时过期 → 随机过期时间 / 多级缓存
