# 分布式可靠性 - 总览

> **版本**：v1.0
> **最后更新**：2026-04-24

## 📚 章节介绍

本章节讲解如何构建可靠的分布式系统，包括容错设计模式和高可用架构方案。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 掌握熔断、限流、降级等容错设计模式
- 理解高可用架构的设计原则
- 能够设计容灾和故障转移方案
- 建立系统化的可靠性工程思维

## 📖 章节结构

### 第一部分：容错设计
- 熔断器模式（Circuit Breaker）
- 限流（Rate Limiting）
- 降级（Degradation）
- 重试与退避策略（Exponential Backoff）
- 超时控制

### 第二部分：高可用设计
- 主从复制
- 多活架构
- 故障转移（Failover）
- 数据备份与恢复
- 容灾设计

## 🔑 核心概念

### 熔断器状态机

```
关闭状态（正常）
    ↓ 错误率超过阈值
打开状态（拒绝请求）
    ↓ 超时后进入半开
半开状态（试探性放行）
    ↓ 成功 → 关闭 / 失败 → 打开
```

### 高可用等级

| 可用性等级 | 年停机时间 | 典型场景 |
|-----------|----------|---------|
| 99.9%（3 个 9） | 约 8.8 小时 | 普通业务系统 |
| 99.99%（4 个 9） | 约 52.6 分钟 | 核心业务系统 |
| 99.999%（5 个 9） | 约 5.3 分钟 | 金融、支付系统 |
