## 学习建议

1. **先用起来**：不要等学完所有类型知识再开始写 TypeScript，从 JavaScript 项目加上基础类型注解开始
2. **渐进式严格**：先用宽松配置，逐步开启 strict 选项，体会每个选项解决的问题
3. **多读类型报错**：TypeScript 的错误信息非常详细，学会阅读类型报错是核心技能
4. **刷类型体操**：type-challenges 是提升类型编程能力的最佳途径
5. **读优秀源码**：Zod、tRPC 等项目的类型设计堪称教科书级别
6. **关注版本更新**：TypeScript 每季度发布新版本，持续关注新特性
