## 📖 概述

LLM 应用开发是将大语言模型集成到实际应用中的过程。本章节介绍主流的 LLM 应用开发框架和工具，包括 LangChain、LlamaIndex 等，帮助开发者快速构建智能应用。

## 🏗️ LangChain 基础

### 什么是 LangChain

LangChain 是一个用于构建 LLM 应用的开源框架，提供了丰富的组件和工具，简化了与 LLM 的交互过程。

### 核心概念

#### 1. Chains（链）

Chain 是将多个组件（如 LLM、工具、提示词）串联在一起的工作流。

#### 2. Agents（智能体）

Agent 是能够自主决策、使用工具完成复杂任务的智能系统。

#### 3. Memory（记忆）

Memory 用于在对话中维护历史信息，实现上下文感知。

#### 4. Tools（工具）

Tools 是 LLM 可以调用的外部功能，如搜索、计算、数据库查询等。

### Chains（链）详解

#### 简单链

```javascript
import { ChatOpenAI } from '@langchain/openai';
import { ChatPromptTemplate } from '@langchain/core/prompts';
import { StringOutputParser } from '@langchain/core/output_parsers';

// 创建 LLM
const llm = new ChatOpenAI({ model: 'gpt-4' });

// 创建提示词模板
const prompt = ChatPromptTemplate.fromTemplate(
  '将以下内容翻译成{language}：{text}'
);

// 创建输出解析器
const outputParser = new StringOutputParser();

// 构建链
const chain = prompt.pipe(llm).pipe(outputParser);

// 运行链
const result = await chain.invoke({
  language: '英文',
  text: '你好，世界！',
});

console.log(result); // Hello, World!
```

#### 顺序链

```javascript
import { ChatOpenAI } from '@langchain/openai';
import { ChatPromptTemplate } from '@langchain/core/prompts';
import { StringOutputParser } from '@langchain/core/output_parsers';

// LLM 实例
const llm = new ChatOpenAI({ model: 'gpt-4' });

// 第一步：总结
const summarizePrompt = ChatPromptTemplate.fromTemplate(
  '请总结以下内容：\n\n{content}'
);
const summarizeChain = summarizePrompt.pipe(llm).pipe(new StringOutputParser());

// 第二步：翻译
const translatePrompt = ChatPromptTemplate.fromTemplate(
  '将以下内容翻译成{language}：\n\n{summary}'
);
const translateChain = translatePrompt.pipe(llm).pipe(new StringOutputParser());

// 组合成顺序链
const fullChain = summarizeChain.pipe((summary) => 
  translateChain.invoke({ summary, language: '英文' })
);

// 运行
const result = await fullChain.invoke({
  content: '人工智能是计算机科学的一个分支...'
});

console.log(result);
```

### Memory（记忆）系统

#### 对话缓冲记忆

```javascript
import { ChatOpenAI } from '@langchain/openai';
import { ChatPromptTemplate } from '@langchain/core/prompts';
import { ConversationBufferMemory } from '@langchain/memory';

// LLM 实例
const llm = new ChatOpenAI({ model: 'gpt-4' });

// 创建记忆
const memory = new ConversationBufferMemory({
  returnMessages: true,
  memoryKey: 'history',
});

// 创建提示词模板（包含历史消息）
const prompt = ChatPromptTemplate.fromMessages([
  ['system', '你是一个友好的助手。'],
  ['placeholder', '{history}'],
  ['user', '{input}'],
]);

// 构建链
const chain = prompt.pipe(llm);

// 第一次对话
const input1 = '我叫张三';
const response1 = await chain.invoke({
  input: input1,
  history: await memory.loadMemoryVariables({}).history,
});

// 保存到记忆
await memory.saveContext({ input: input1 }, { output: response1.content });

// 第二次对话
const input2 = '我叫什么名字？';
const response2 = await chain.invoke({
  input: input2,
  history: await memory.loadMemoryVariables({}).history,
});

console.log(response2.content); // 应该记住用户叫张三
```

### Agents（智能体）

#### ReAct Agent

```javascript
import { ChatOpenAI } from '@langchain/openai';
import { initializeAgentExecutorWithOptions } from 'langchain/agents';
import { SerpAPI } from '@langchain/community/tools/serpapi';
import { Calculator } from '@langchain/community/tools/calculator';

// 初始化 LLM
const llm = new ChatOpenAI({ model: 'gpt-4', temperature: 0 });

// 准备工具
const tools = [
  new SerpAPI({ apiKey: process.env.SERPAPI_API_KEY }),
  new Calculator(),
];

// 创建 Agent
const agentExecutor = await initializeAgentExecutorWithOptions(tools, llm, {
  agentType: 'zero-shot-react-description',
  verbose: true,
});

// 运行 Agent
const result = await agentExecutor.run(
  '苹果公司现在的股价是多少？如果我有100股，价值多少美元？'
);

console.log(result);
```

Agent 的工作原理（Python 示例）：

```python
from langchain.agents import AgentExecutor, create_react_agent
from langchain.tools import Tool
from langchain_openai import ChatOpenAI
from langchain import hub

# ReAct Agent 的核心思想：Reasoning + Acting
# 1. Thought（思考）：分析当前情况
# 2. Action（行动）：选择合适的工具
# 3. Observation（观察）：获取工具执行结果
# 4. 重复上述步骤直到完成

def search_tool(query: str) -> str:
    """搜索工具"""
    return f"搜索结果：{query}"

def calculator_tool(expression: str) -> str:
    """计算器工具"""
    try:
        result = eval(expression)
        return f"计算结果：{result}"
    except:
        return "计算错误"

# 定义工具
tools = [
    Tool(
        name="Search",
        func=search_tool,
        description="用于搜索信息的工具"
    ),
    Tool(
        name="Calculator",
        func=calculator_tool,
        description="用于数学计算的工具"
    )
]

# 初始化 LLM
llm = ChatOpenAI(model="gpt-4", temperature=0)

# 加载 ReAct prompt
prompt = hub.pull("hwchase17/react")

# 创建 Agent
agent = create_react_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

# 运行
result = agent_executor.invoke({
    "input": "搜索苹果公司的股价，然后计算100股的价值"
})

print(result)
```

## 📚 LlamaIndex

### 什么是 LlamaIndex

LlamaIndex 是专注于数据索引和检索的框架，特别适合构建 RAG（检索增强生成）应用。LlamaIndex.TS 是其 TypeScript 版本，为 JavaScript/TypeScript 开发者提供了完整的支持。

### 核心概念

#### 1. Documents（文档）
原始数据源，可以是 PDF、网页、数据库等。

#### 2. Nodes（节点）
文档的分割单元，便于检索和处理。

#### 3. Index（索引）
对节点进行索引，支持高效的检索。

#### 4. Query Engine（查询引擎）
处理用户查询并生成答案。

### 快速开始

```javascript
import { VectorStoreIndex, SimpleDirectoryReader } from 'llamaindex';

// 读取文档
const documents = await SimpleDirectoryReader('data').loadData();

// 创建索引
const index = await VectorStoreIndex.fromDocuments(documents);

// 创建查询引擎
const queryEngine = index.asQueryEngine();

// 查询
const response = await queryEngine.query('什么是机器学习？');

console.log(response.toString());
```

**注意**：LlamaIndex.TS 使用模块化包结构，需要安装基础包和特定提供商包：

```bash
npm install llamaindex @llamaindex/openai
```

### 文档分割

```javascript
import { SentenceSplitter } from 'llamaindex';

// 创建分割器
const splitter = new SentenceSplitter({
  chunkSize: 1000,  // 每个 chunk 的最大字符数
  chunkOverlap: 200,  // chunk 之间的重叠字符数
```

### 向量索引

```javascript
import { VectorStoreIndex, storageContextFromDefaults } from 'llamaindex';
import { OpenAIEmbedding } from '@llamaindex/openai';

// 自定义嵌入模型
const embeddingModel = new OpenAIEmbedding({
  apiKey: process.env.OPENAI_API_KEY,
  model: 'text-embedding-ada-002',
});

// 创建存储上下文
const storageContext = await storageContextFromDefaults({
  vectorStoreType: 'simple',
  persistDir: './storage',
});

// 创建索引
const index = await VectorStoreIndex.fromDocuments(
  documents,
  {
    storageContext,
    embedModel: embeddingModel,
  }
);

// 持久化索引
await index.storageContext.persist();
```

### 查询引擎

```javascript
// 基础查询引擎
const queryEngine = index.asQueryEngine();

// 自定义查询引擎
const queryEngine = index.asQueryEngine({
  similarityTopK: 3,  // 返回前 3 个最相关的文档
  streaming: true,  // 流式输出
});

// 查询
const response = await queryEngine.query('什么是深度学习？');

// 流式输出
for await (const chunk of response.responseStream) {
  process.stdout.write(chunk);
}
```

### RAG 实现原理（Python 示例）

```python
from llama_index import VectorStoreIndex, SimpleDirectoryReader
from llama_index.embeddings.openai import OpenAIEmbedding
from llama_index.llms.openai import ChatOpenAI

# RAG 的核心流程：
# 1. 加载文档
# 2. 分割文档
# 3. 创建向量索引
# 4. 查询时检索相关文档
# 5. 将检索到的文档作为上下文传递给 LLM

# 1. 加载文档
documents = SimpleDirectoryReader("data").loadData()

# 2. 分割文档（自动进行）
# LlamaIndex 会自动将文档分割成合适的 chunks

# 3. 创建向量索引
# 使用 OpenAI 的 embedding 模型
embed_model = OpenAIEmbedding(api_key="your-api-key")
index = VectorStoreIndex.from_documents(
    documents,
    embed_model=embed_model
)

# 4. 创建查询引擎
query_engine = index.asQueryEngine(
    similarity_top_k=3,  # 检索前 3 个最相关的文档
    llm=ChatOpenAI(model="gpt-4")  # 使用 GPT-4 生成答案
)

# 5. 查询
response = query_engine.query("什么是机器学习？")

print(response)
```

### LangGraph

LangGraph 是 LangChain 团队开发的状态机框架，用于构建复杂的多 Agent 系统。

**安装**：

```bash
npm install @langchain/langgraph @langchain/openai
```

**使用示例**：

```javascript
import { StateGraph, Annotation } from '@langchain/langgraph';
import { ChatOpenAI } from '@langchain/openai';

// 定义状态
const StateAnnotation = Annotation.Root({
  messages: Annotation({
    reducer: (x, y) => x.concat(y),
    default: () => [],
  }),
});

// 定义节点
const agentNode = async (state) => {
  const llm = new ChatOpenAI({ model: 'gpt-4' });
  const response = await llm.invoke(state.messages);
  return { messages: [response] };
};

// 创建工作流
const workflow = new StateGraph(StateAnnotation);

// 添加节点
workflow.addNode('agent', agentNode);

// 设置入口点
workflow.setEntryPoint('agent');

// 添加边
workflow.addEdge('agent', '__end__');

// 编译图
const app = workflow.compile();

// 运行
const result = await app.invoke({
  messages: [{ role: 'user', content: '你好' }],
});

console.log(result);
```

## 💡 实践案例

### 案例 1：智能问答系统

```javascript
import { ChatOpenAI } from '@langchain/openai';
import { ChatPromptTemplate } from '@langchain/core/prompts';
import { ConversationBufferMemory } from '@langchain/memory';

// LLM 实例
const llm = new ChatOpenAI({ model: 'gpt-4' });

// 记忆
const memory = new ConversationBufferMemory({
  returnMessages: true,
  memoryKey: 'history',
});

// 提示词模板
const prompt = ChatPromptTemplate.fromMessages([
  ['system', `你是一个专业的技术顾问。
  请用简洁、专业的语言回答用户的问题。
  如果不确定答案，请诚实地说不知道。`],
  ['placeholder', '{history}'],
  ['user', '{input}'],
]);

// 构建链
const chain = prompt.pipe(llm);

// 问答函数
async function askQuestion(question) {
  const history = await memory.loadMemoryVariables({}).history;
  const response = await chain.invoke({ input: question, history });
  
  await memory.saveContext(
    { input: question },
    { output: response.content }
  );
  
  return response.content;
}

// 使用
const answer1 = await askQuestion('什么是 React？');
console.log(answer1);

const answer2 = await askQuestion('它和 Vue 有什么区别？');
console.log(answer2);
```

```javascript
try {
  const response = await llm.invoke(prompt);
```
