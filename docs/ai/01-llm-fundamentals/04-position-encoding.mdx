# 位置编码详解

## 📖 概述

位置编码（Positional Encoding）是 Transformer 架构中的关键组件，用于为输入序列中的每个位置添加位置信息。由于 Transformer 的自注意力机制本身不包含序列顺序信息，位置编码的引入使得模型能够理解 token 在序列中的位置关系。

## 🎯 为什么需要位置编码？

### Transformer 的局限性

Transformer 的自注意力机制是**置换不变**（Permutation Invariant）的：

```python
# 示例：改变顺序不会改变注意力计算
sentence1 = ["我", "爱", "编程"]
sentence2 = ["编程", "爱", "我"]

# 对于 Self-Attention 来说，这两个序列的处理方式相同
# 因为它只计算 token 之间的相似度，不考虑位置
```

### 位置信息的重要性

在自然语言中，位置信息至关重要：

1. **语法结构**
   - "狗咬人" vs "人咬狗"
   - 语法关系依赖于词序

2. **语义理解**
   - "不很好" vs "很好不"
   - 否定词的位置改变语义

3. **指代关系**
   - "小明说他很累" - "他"指代"小明"
   - 位置关系帮助确定指代

## 🔢 位置编码的类型

### 1. 正弦位置编码（Sinusoidal Positional Encoding）

原始 Transformer 论文中提出的方法。

#### 数学公式

对于位置 `pos` 和维度 `i`：

```
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
```

其中：
- `pos`：位置索引（0, 1, 2, ...）
- `i`：维度索引（0, 1, 2, ..., d_model/2）
- `d_model`：模型维度

#### 代码实现

```python
import torch
import math

class SinusoidalPositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        """
        正弦位置编码
        
        参数:
            d_model: 模型维度
            max_len: 最大序列长度
        """
        super().__init__()
        
        # 创建位置编码矩阵
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)
        
        # 计算频率项
        div_term = torch.exp(torch.arange(0, d_model, 2).float() * 
                            (-math.log(10000.0) / d_model))
        
        # 计算正弦和余弦
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        
        # 添加 batch 维度
        pe = pe.unsqueeze(0)
        
        # 注册为 buffer（不是可学习参数）
        self.register_buffer('pe', pe)
    
    def forward(self, x):
        """
        前向传播
        
        参数:
            x: (batch_size, seq_len, d_model)
        
        返回:
            x + pe: (batch_size, seq_len, d_model)
        """
        x = x + self.pe[:, :x.size(1), :]
        return x
```

#### 特性

1. **固定编码**：不需要学习，计算效率高
2. **外推能力**：可以外推到训练时未见过的长度
3. **相对位置信息**：相邻位置的编码相似
4. **多尺度表示**：不同维度编码不同频率的位置信息

#### 频率分析

```
维度 0,1:   周期 = 2π * 10000^0 = 2π           (低频，全局位置)
维度 2,3:   周期 = 2π * 10000^1 = 2π*10        (中频)
维度 4,5:   周期 = 2π * 10000^2 = 2π*100       (高频，局部位置)
...
```

- 低频维度编码全局位置信息
- 高频维度编码局部位置信息
- 类似于傅里叶变换的多尺度表示

### 2. 可学习位置编码（Learned Positional Encoding）

将位置编码作为可学习参数，通过训练学习。

#### 代码实现

```python
class LearnedPositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        """
        可学习位置编码
        
        参数:
            d_model: 模型维度
            max_len: 最大序列长度
        """
        super().__init__()
        
        # 可学习的位置嵌入
        self.position_embeddings = nn.Embedding(max_len, d_model)
    
    def forward(self, x):
        """
        前向传播
        
        参数:
            x: (batch_size, seq_len, d_model)
        
        返回:
            x + position_embeddings: (batch_size, seq_len, d_model)
        """
        batch_size, seq_len, _ = x.size()
        
        # 创建位置索引
        positions = torch.arange(seq_len, dtype=torch.long, device=x.device)
        positions = positions.unsqueeze(0).expand(batch_size, -1)
        
        # 获取位置嵌入
        position_embeddings = self.position_embeddings(positions)
        
        return x + position_embeddings
```

#### 特性

1. **灵活性强**：可以学习最适合任务的位置表示
2. **需要训练**：增加了模型参数
3. **外推能力差**：难以外推到训练时未见过的长度
4. **性能更好**：在某些任务上表现更好

### 3. 相对位置编码（Relative Positional Encoding）

编码相对位置而非绝对位置。

#### 核心思想

```
绝对位置：位置 0, 1, 2, 3, 4, ...
相对位置：距离 -2, -1, 0, +1, +2, ...
```

#### 优势

1. **平移不变性**：序列平移不影响相对位置
2. **更好的泛化**：可以处理不同长度的序列
3. **更符合直觉**：语言中的关系往往是相对的

#### 实现示例

```python
class RelativePositionalEncoding(nn.Module):
    def __init__(self, d_model, max_relative_position=128):
        """
        相对位置编码
        
        参数:
            d_model: 模型维度
            max_relative_position: 最大相对距离
        """
        super().__init__()
        
        self.max_relative_position = max_relative_position
        self.d_model = d_model
        
        # 相对位置嵌入
        self.relative_embeddings = nn.Embedding(
            2 * max_relative_position + 1, d_model
        )
    
    def forward(self, seq_len):
        """
        生成相对位置编码
        
        参数:
            seq_len: 序列长度
        
        返回:
            relative_positions: (seq_len, seq_len, d_model)
        """
        # 生成相对位置矩阵
        range_vec = torch.arange(seq_len)
        relative_mat = range_vec[None, :] - range_vec[:, None]
        
        # 裁剪到最大相对距离
        relative_mat = torch.clamp(
            relative_mat, 
            -self.max_relative_position, 
            self.max_relative_position
        )
        
        # 偏移到非负索引
        relative_mat = relative_mat + self.max_relative_position
        
        # 获取相对位置嵌入
        relative_embeddings = self.relative_embeddings(relative_mat)
        
        return relative_embeddings
```

### 4. RoPE（Rotary Positional Encoding）

旋转位置编码，通过旋转操作编码位置信息。

#### 核心思想

将位置信息编码为旋转角度，通过旋转操作引入位置信息。

#### 数学公式

对于查询 `q` 和键 `k`：

```
q_m = R(θ, m) * q
k_n = R(θ, n) * k

其中 R(θ, m) 是旋转矩阵
```

#### 优势

1. **相对位置感知**：自然地编码相对位置
2. **外推能力强**：可以外推到更长的序列
3. **计算高效**：不需要额外的位置嵌入

#### 代码实现

```python
import torch
import torch.nn as nn
import math

class RotaryPositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        """
        旋转位置编码
        
        参数:
            d_model: 模型维度（必须是偶数）
            max_len: 最大序列长度
        """
        super().__init__()
        
        assert d_model % 2 == 0, "d_model 必须是偶数"
        
        self.d_model = d_model
        
        # 计算旋转角度
        theta = 1.0 / (10000 ** (torch.arange(0, d_model, 2).float() / d_model))
        
        # 创建位置索引
        position = torch.arange(max_len).unsqueeze(1)
        
        # 计算旋转角度
        angle = position * theta
        
        # 预计算 sin 和 cos
        self.register_buffer('sin', torch.sin(angle))
        self.register_buffer('cos', torch.cos(angle))
    
    def rotate_half(self, x):
        """
        将输入分成两半并交换
        
        参数:
            x: (batch_size, seq_len, d_model)
        
        返回:
            (batch_size, seq_len, d_model)
        """
        x1, x2 = x[..., ::2], x[..., 1::2]
        return torch.cat((-x2, x1), dim=-1)
    
    def forward(self, x):
        """
        前向传播
        
        参数:
            x: (batch_size, seq_len, d_model)
        
        返回:
            rotated_x: (batch_size, seq_len, d_model)
        """
        seq_len = x.size(1)
        
        # 获取对应长度的 sin 和 cos
        sin = self.sin[:seq_len, :]
        cos = self.cos[:seq_len, :]
        
        # 应用旋转
        rotated_x = x * cos + self.rotate_half(x) * sin
        
        return rotated_x
```

## 📊 不同位置编码的比较

| 特性 | 正弦编码 | 可学习编码 | 相对编码 | RoPE |
|------|---------|-----------|---------|------|
| 可学习性 | 固定 | 可学习 | 可学习 | 固定 |
| 外推能力 | 强 | 弱 | 强 | 强 |
| 计算效率 | 高 | 中 | 中 | 高 |
| 参数量 | 无 | 有 | 有 | 无 |
| 相对位置 | 隐式 | 隐式 | 显式 | 显式 |
| 流行度 | 中 | 高 | 中 | 高 |

## 💡 实践建议

### 选择指南

1. **短序列任务**
   - 推荐可学习位置编码
   - 性能通常更好

2. **长序列任务**
   - 推荐正弦编码或 RoPE
   - 外推能力更强

3. **需要相对位置信息**
   - 推荐相对位置编码或 RoPE
   - 更符合语言特性

### 超参数选择

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| `max_len` | 512/1024/2048 | 最大序列长度 |
| `d_model` | 512/768/1024 | 模型维度 |
| `max_relative_position` | 128/256 | 最大相对距离 |

### 常见问题

1. **序列长度超过 max_len**
   - 正弦编码：可以外推，但性能下降
   - 可学习编码：无法处理，需要重新训练
   - RoPE：可以外推，性能较好

2. **位置编码与词嵌入的融合**
   ```python
   # 标准做法：相加
   output = token_embedding + positional_encoding
   
   # 替代做法：拼接
   output = torch.cat([token_embedding, positional_encoding], dim=-1)
   ```

3. **位置编码的初始化**
   - 可学习编码：通常使用正态分布初始化
   - 可以用正弦编码初始化，然后微调

## 🔍 可视化位置编码

### 正弦编码的可视化

```python
import matplotlib.pyplot as plt
import numpy as np

def visualize_positional_encoding(d_model=512, max_len=100):
    """
    可视化位置编码
    
    参数:
        d_model: 模型维度
        max_len: 最大位置
    """
    # 创建位置编码
    pe = np.zeros((max_len, d_model))
    position = np.arange(max_len)[:, np.newaxis]
    div_term = np.exp(np.arange(0, d_model, 2) * 
                     -(np.log(10000.0) / d_model))
    
    pe[:, 0::2] = np.sin(position * div_term)
    pe[:, 1::2] = np.cos(position * div_term)
    
    # 绘制热力图
    plt.figure(figsize=(12, 8))
    plt.imshow(pe, cmap='viridis', aspect='auto')
    plt.colorbar()
    plt.xlabel('Dimension')
    plt.ylabel('Position')
    plt.title('Positional Encoding')
    plt.show()
    
    # 绘制不同维度的波形
    plt.figure(figsize=(12, 8))
    for dim in [0, 2, 4, 6, 8]:
        plt.plot(pe[:, dim], label=f'Dim {dim}')
    plt.xlabel('Position')
    plt.ylabel('Value')
    plt.title('Positional Encoding for Different Dimensions')
    plt.legend()
    plt.show()

visualize_positional_encoding()
```
