## 🏗️ 模型架构

### 核心创新

#### 1. 滑动窗口注意力（Sliding Window Attention）

**原理**
- 注意力范围限制在固定窗口内
- 窗口大小通常为 4096 tokens
- 减少计算复杂度
- 支持更长的序列

**优势**
- 计算效率高
- 内存占用少
- 推理速度快
- 适合长文本处理

#### 2. 分组查询注意力（Grouped Query Attention, GQA）

**原理**
- 将查询头分组，共享键值
- 减少键值投影的计算量
- 平衡性能和效率

**优势**
- 内存占用减少
- 推理速度提升
- 性能损失很小

**对比**
| 特性 | MHA | GQA | MQA |
|------|-----|-----|-----|
| 查询头数 | h | h | h |
| 键值头数 | h | h/g | 1 |
| 内存 | 高 | 中 | 低 |
| 性能 | 最佳 | 接近 | 较差 |

#### 3. 混合前馈网络（Mixture of Experts, MoE）

**原理**
- 使用多个专家网络
- 路由器选择激活的专家
- 每次只激活部分专家

**Mixtral 的 MoE 设计**
```python
class MixtralMoE(nn.Module):
    def __init__(self, d_model, n_experts=8, n_active=2):
        super().__init__()
        self.n_experts = n_experts
        self.n_active = n_active
        
        # 路由器
        self.gate = nn.Linear(d_model, n_experts)
        
        # 专家网络
        self.experts = nn.ModuleList([
            Expert(d_model) for _ in range(n_experts)
        ])
    
    def forward(self, x):
        # 计算路由权重
        gate_logits = self.gate(x)
        
        # 选择 top-k 专家
        topk_weights, topk_indices = torch.topk(
            gate_logits, self.n_active, dim=-1
        )
        
        # 激活专家并聚合输出
        output = self.aggregate_experts(x, topk_weights, topk_indices)
        return output
```

**优势**
- 参数量大但推理快
- 性能随专家数量提升
- 训练和推理效率高

#### 4. 混合前馈网络

**设计**
- 交替使用两种前馈网络
- 增强模型表达能力
- 提高训练稳定性

## 🚀 使用方法

### Hugging Face 使用

```python
from transformers import AutoTokenizer, AutoModelForCausalLM

# 加载模型
model_name = "mistralai/Mistral-7B-v0.3"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

# 生成文本
input_text = "Explain the concept of machine learning."
inputs = tokenizer(input_text, return_tensors="pt")

outputs = model.generate(
    inputs.input_ids,
    max_length=500,
    temperature=0.7,
    top_p=0.9
)

generated_text = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(generated_text)
```

### 使用 Mixtral

```python
from transformers import AutoTokenizer, AutoModelForCausalLM
import torch

# 加载 Mixtral（需要更多显存）
model_name = "mistralai/Mixtral-8x7B-v0.1"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype=torch.float16,
    device_map="auto"
)

# 生成
input_text = "Write a Python function to sort a list."
inputs = tokenizer(input_text, return_tensors="pt").to(model.device)

outputs = model.generate(
    inputs.input_ids,
    max_length=500,
    temperature=0.7
)

generated_text = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(generated_text)
```

## 🔧 微调 Mistral

### 使用 QLoRA 微调

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from peft import LoraConfig, get_peft_model, TaskType
import torch

# 加载模型
model_name = "mistralai/Mistral-7B-v0.3"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype=torch.float16,
    device_map="auto"
)

# 配置 QLoRA
lora_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"],
    bias="none"
)

# 应用 QLoRA
model = get_peft_model(model, lora_config)

# 训练配置
training_args = TrainingArguments(
    output_dir="./mistral-finetuned",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4,
    learning_rate=2e-4,
    fp16=True,
    logging_steps=10
)

# 开始训练
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    tokenizer=tokenizer
)

trainer.train()
```

### 优化技巧

1. **利用滑动窗口**
   - 适合长文本处理
   - 减少内存占用
   - 提高推理速度

2. **MoE 推理优化**
   - 使用 vLLM 加速
   - 批处理提高吞吐量
   - 注意显存使用

3. **量化部署**
   - 4-bit 量化减少内存
   - 使用 llama.cpp
   - 性能损失很小

4. **批处理优化**
   - 增加批大小
   - 使用梯度累积
   - 注意显存限制
