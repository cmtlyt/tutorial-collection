## 🏗️ 模型架构

### 核心架构特点

Claude 基于 Transformer 架构，但有一些独特设计：

1. **宪法 AI（Constitutional AI）**
   - 通过宪法约束模型行为
   - 强化学习 + 监督学习
   - 提高安全性
   - 减少有害输出

2. **长上下文支持**
   - 优化的注意力机制
   - 高效的内存管理
   - 支持 200K tokens
   - 长文档处理能力强

3. **多模态能力**
   - 原生支持图像理解
   - 文本 + 图像输入
   - 视觉推理能力强
   - Claude 3 引入

4. **宪法 AI（Constitutional AI）**

## 🚀 使用方法

### Anthropic API 使用

```python
import anthropic

# 初始化客户端
client = anthropic.Anthropic(api_key="YOUR_API_KEY")

# 聊天补全
message = client.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=500,
    temperature=0.7,
    messages=[
        {
            "role": "user",
            "content": "Explain quantum computing in simple terms."
        }
    ]
)

print(message.content[0].text)
```

### 多模态使用

```python
import anthropic

client = anthropic.Anthropic(api_key="YOUR_API_KEY")

# 图像理解
message = client.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=500,
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": "Describe this image in detail."
                },
                {
                    "type": "image",
                    "source": {
                        "type": "base64",
                        "media_type": "image/jpeg",
                        "data": "base64_encoded_image_data"
                    }
                }
            ]
        }
    ]
)

print(message.content[0].text)
```

### 流式输出

```python
import anthropic

client = anthropic.Anthropic(api_key="YOUR_API_KEY")

# 流式响应
with client.messages.stream(
    model="claude-3-5-sonnet-20241022",
    max_tokens=500,
    messages=[
        {"role": "user", "content": "Write a short story about AI."}
    ]
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
```

### 工具使用（Tool Use）

```python
import anthropic
import json

client = anthropic.Anthropic(api_key="YOUR_API_KEY")

# 定义工具
tools = [
    {
        "name": "get_weather",
        "description": "Get the current weather in a given location",
        "input_schema": {
            "type": "object",
            "properties": {
                "location": {
                    "type": "string",
                    "description": "The city and state, e.g. San Francisco, CA"
                }
            },
            "required": ["location"]
        }
    }
]

# 调用
message = client.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=500,
    tools=tools,
    messages=[
        {"role": "user", "content": "What's the weather like in Boston?"}
    ]
)

# 处理工具调用
if message.stop_reason == "tool_use":
    tool_use = next(block for block in message.content if block.type == "tool_use")
    print(f"Tool: {tool_use.name}, Args: {tool_use.input}")
```

## 🔧 高级功能

### 批处理

```python
import anthropic

client = anthropic.Anthropic(api_key="YOUR_API_KEY")

# 批处理请求
messages = [
    {"role": "user", "content": "Translate to French: Hello"},
    {"role": "user", "content": "Translate to German: Hello"},
    {"role": "user", "content": "Translate to Spanish: Hello"}
]

for msg in messages:
    response = client.messages.create(
        model="claude-3-5-haiku-20241022",
        max_tokens=100,
        messages=[msg]
    )
    print(response.content[0].text)
```
