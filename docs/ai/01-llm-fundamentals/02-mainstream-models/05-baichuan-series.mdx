## 📖 概述

Baichuan（百川）是百川智能开发的大语言模型系列。Baichuan 系列专注于中文领域，以其出色的中文理解能力、开放的许可政策和商业友好的授权，成为企业和开发者的热门选择。

## 🏗️ 模型架构

### 核心架构特点

Baichuan 基于 Transformer 架构，采用了一些优化设计：

1. **SwiGLU 激活函数**
   - 替代传统的 ReLU
   - 性能更好
   - 训练更稳定

2. **旋转位置编码（RoPE）**
   - 更好的位置表示
   - 支持外推
   - 计算高效

3. **ALiBi 位置编码**（Baichuan 2）
   - 支持外推到更长序列
   - 训练效率高
   - 适合长上下文

4. **查询键值分离（GQA）**（Baichuan 2）
   - 减少内存占用
   - 提高推理速度
   - 平衡性能和效率

### 架构对比

| 特性 | Baichuan-7B | Baichuan-13B | Baichuan 2 |
|------|-------------|--------------|------------|
| 归一化 | RMSNorm | RMSNorm | RMSNorm |
| 激活函数 | SwiGLU | SwiGLU | SwiGLU |
| 位置编码 | RoPE | RoPE | ALiBi |
| 注意力 | MHA | MHA | GQA |
| 上下文 | 2K | 4K | 4-8K |

## 🚀 使用方法

### Hugging Face 使用

```python
from transformers import AutoTokenizer, AutoModelForCausalLM

# 加载模型
model_name = "baichuan-inc/Baichuan2-13B-Chat"
tokenizer = AutoTokenizer.from_pretrained(model_name, trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    device_map="auto",
    torch_dtype="auto",
    trust_remote_code=True
)

# 准备输入
messages = [
    {"role": "user", "content": "解释人工智能的基本概念"}
]

# 应用聊天模板
input_ids = tokenizer.apply_chat_template(messages, return_tensors="pt").to(model.device)

# 生成输出
outputs = model.generate(
    input_ids,
    max_new_tokens=512,
    temperature=0.7,
    top_p=0.9,
    repetition_penalty=1.1
)

# 解码输出
generated_text = tokenizer.decode(outputs[0][input_ids.shape[-1]:], skip_special_tokens=True)
print(generated_text)
```

### 使用 Baichuan API

```python
import requests

# Baichuan API
url = "https://api.baichuan-ai.com/v1/chat/completions"

headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}

data = {
    "model": "Baichuan3-Turbo",
    "messages": [
        {"role": "user", "content": "写一个 Python 函数实现快速排序"}
    ],
    "temperature": 0.7,
    "max_tokens": 500
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result['choices'][0]['message']['content'])
```

### 本地部署

#### 使用 llama.cpp

```bash
# 安装 llama.cpp
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp
make

# 转换模型
python convert.py ../Baichuan2-13B --outtype f16

# 量化模型
./quantize ../Baichuan2-13B/ggml-model-f16.gguf ../Baichuan2-13B/ggml-model-q4_0.gguf q4_0

# 运行推理
./main -m ../Baichuan2-13B/ggml-model-q4_0.gguf -p "你好，请介绍一下自己" -n 256
```

## 🔧 微调 Baichuan

### 使用 LoRA 微调

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from peft import LoraConfig, get_peft_model, TaskType
import torch

# 加载模型
model_name = "baichuan-inc/Baichuan2-13B-Base"
tokenizer = AutoTokenizer.from_pretrained(model_name, trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    device_map="auto",
    torch_dtype=torch.float16,
    trust_remote_code=True
)

# 配置 LoRA
lora_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    target_modules=["W_pack", "o_proj", "gate_proj", "up_proj", "down_proj"],
    bias="none"
)

# 应用 LoRA
model = get_peft_model(model, lora_config)

# 训练配置
training_args = TrainingArguments(
    output_dir="./baichuan-finetuned",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4,
    learning_rate=2e-4,
    fp16=True,
    logging_steps=10,
    save_steps=100
)

# 开始训练
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    tokenizer=tokenizer
)

trainer.train()
```

### 模型选择

| 使用场景 | 推荐模型 | 硬件要求 |
|---------|---------|---------|
| 个人实验 | Baichuan2-7B | 单张 12GB GPU |
| 企业应用 | Baichuan2-13B | 单张 24GB GPU |
| 高性能 | Baichuan3 (API) | 无需 GPU |
| 中文问答 | Baichuan2-13B-Chat | 单张 24GB GPU |

### 优化技巧

1. **利用中文优势**
   - 适合中文任务
   - 中文理解能力强
   - 中文生成质量高

2. **量化部署**
   - 4-bit 量化减少内存
   - 使用 llama.cpp
   - 性能损失很小

3. **批处理优化**
   - 增加批大小
   - 使用梯度累积
   - 注意显存限制

4. **温度调节**
   - 生成任务使用较高温度（0.7-0.9）
   - 问答任务使用较低温度（0.3-0.5）
   - 代码任务使用低温度（0.1-0.3）
