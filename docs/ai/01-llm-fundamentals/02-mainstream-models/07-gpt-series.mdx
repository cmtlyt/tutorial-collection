## 🏗️ 模型架构

### 核心架构特点

GPT 基于 Transformer Decoder 架构，主要特点：

1. **自回归生成**
   - 从左到右生成
   - 因果掩码
   - 适合文本生成

2. **多头自注意力**
   - 捕捉长距离依赖
   - 并行计算
   - 表达能力强

3. **位置编码**
   - 学习式位置编码
   - 引入位置信息
   - 支持可变长度

4. **前馈网络**
   - 两层全连接
   - 中间有激活函数
   - 增强表达能力

### 架构演进

| 特性 | GPT-1 | GPT-2 | GPT-3 | GPT-4 |
|------|-------|-------|-------|-------|
| 架构 | Decoder | Decoder | Decoder | Decoder |
| 参数量 | 117M | 1.5B | 175B | ~1.8T |
| 上下文 | 512 | 1024 | 2048 | 32K |
| 模态 | 文本 | 文本 | 文本 | 多模态 |
| 对齐 | 无 | 无 | 无 | RLHF |

## 🚀 使用方法

### OpenAI API 使用

```python
from openai import OpenAI

# 初始化客户端
client = OpenAI(api_key="YOUR_API_KEY")

# 聊天补全
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain quantum computing in simple terms."}
    ],
    max_tokens=500,
    temperature=0.7
)

print(response.choices[0].message.content)
```

### 多模态使用

```python
from openai import OpenAI

client = OpenAI(api_key="YOUR_API_KEY")

# 图像理解
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[

            "role": "user",

                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://example.com/image.jpg"
                    }
                }
            ]
        }
    ],
    max_tokens=500
)

print(response.choices[0].message.content)
```

### 函数调用

```python
from openai import OpenAI
import json

client = OpenAI(api_key="YOUR_API_KEY")

# 定义函数
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "parameters": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    }
]

# 调用
messages = [
    {"role": "user", "content": "What's the weather like in Boston?"}
]

response = client.chat.completions.create(
    model="gpt-4o",
    messages=messages,
    tools=tools
)

# 解析函数调用
tool_call = response.choices[0].message.tool_calls[0]
function_name = tool_call.function.name
function_args = json.loads(tool_call.function.arguments)

print(f"Function: {function_name}, Args: {function_args}")
```

### 流式输出

```python
from openai import OpenAI

client = OpenAI(api_key="YOUR_API_KEY")

stream = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "user", "content": "Write a short story about AI."}
    ],
    stream=True
)

for chunk in stream:
    if chunk.choices[0].delta.content is not None:
        print(chunk.choices[0].delta.content, end="")
```

### 语音 API

```python
from openai import OpenAI

client = OpenAI(api_key="YOUR_API_KEY")

# 语音转文字
audio_file = open("speech.mp3", "rb")
transcript = client.audio.transcriptions.create(
    model="whisper-1",
    file=audio_file
)

print(transcript.text)

# 文字转语音
response = client.audio.speech.create(
    model="tts-1",
    voice="alloy",
    input="Hello! Welcome to our AI assistant."
)

response.stream_to_file("output.mp3")
```

## 💡 最佳实践

### 模型选择

| 使用场景 | 推荐模型 | 成本 | 速度 |

| 复杂推理 | GPT-4o | 高 | 快 |

### 优化技巧

1. **Prompt 优化**
   - 明确指令
   - 提供示例
   - 使用结构化输出

2. **温度调节**
   - 创意任务：0.7-1.0
   - 事实性任务：0.1-0.3
   - 代码任务：0.1-0.2

3. **上下文管理**
   - 合理设置 max_tokens
   - 使用系统提示
   - 管理对话历史

4. **成本优化**
   - 使用 GPT-4o-mini
   - 缓存常见响应
   - 批处理请求

5. **安全考虑**
   - 内容过滤
   - 输入验证
   - 输出审查

## 🔧 高级功能

### 批处理

```python
from openai import OpenAI

client = OpenAI(api_key="YOUR_API_KEY")

# 批处理 API
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "user", "content": "Translate to French: Hello"},
        {"role": "user", "content": "Translate to German: Hello"},
        {"role": "user", "content": "Translate to Spanish: Hello"}
    ],
    n=3  # 每个请求生成 3 个响应
)
```

### 结构化输出

```python
from openai import OpenAI
from pydantic import BaseModel

client = OpenAI(api_key="YOUR_API_KEY")

class Product(BaseModel):
    name: str
    price: float
    category: str

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "user", "content": "Extract product info: iPhone 15 Pro $999"}
    ],
    response_format={"type": "json_object"}
)

product = Product.model_validate_json(response.choices[0].message.content)
print(product)
```
