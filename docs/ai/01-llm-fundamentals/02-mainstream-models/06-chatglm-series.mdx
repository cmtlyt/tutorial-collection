## 📖 概述

ChatGLM（Chat General Language Model）是清华大学 KEG 实验室和智谱 AI 联合开发的大语言模型系列。ChatGLM 系列以其独特的 GLM 架构、优秀的双语能力和低成本部署特点，在学术界和工业界都有重要影响。

## 🏗️ 模型架构

### GLM 架构特点

ChatGLM 采用 GLM（General Language Model）架构，与标准的 Transformer 有一些区别：

1. **前缀解码器（Prefix Decoder）**
   - 结合自编码和自回归
   - 双向编码 + 单向生成
   - 适合理解和生成任务

2. **旋转位置编码（RoPE）**
   - 更好的位置表示
   - 支持外推
   - 计算高效

3. **DeepNorm**
   - 替代传统的 LayerNorm
   - 更适合深层网络
   - 训练更稳定

4. **查询键值分离（GQA）**
   - ChatGLM3 引入
   - 减少内存占用
   - 提高推理速度

### 架构对比

| 特性 | ChatGLM-6B | ChatGLM2-6B | ChatGLM3-6B |
|------|------------|-------------|--------------|
| 架构类型 | Prefix Decoder | Prefix Decoder | Prefix Decoder |
| 归一化 | DeepNorm | DeepNorm | DeepNorm |
| 位置编码 | RoPE | RoPE | RoPE |
| 注意力 | MHA | MHA | GQA |
| 上下文 | 2K | 8K | 8K |

### GLM vs Transformer

| 特性 | Transformer | GLM |
|------|-------------|-----|
| 编码方式 | 单向（Decoder）或双向（Encoder） | 前缀解码 |
| 训练目标 | 单一目标 | 多任务训练 |
| 适用任务 | 生成或理解 | 生成 + 理解 |
| 效率 | 高 | 中等 |

## 🚀 使用方法

### Hugging Face 使用

```python
from transformers import AutoTokenizer, AutoModelForCausalLM

# 加载模型
model_name = "THUDM/chatglm3-6b"
tokenizer = AutoTokenizer.from_pretrained(model_name, trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    device_map="auto",
    torch_dtype="auto",
    trust_remote_code=True
)

# 准备输入
messages = [
    {"role": "user", "content": "解释量子计算的基本原理"}
]

# 应用聊天模板
input_ids = tokenizer.apply_chat_template(messages, return_tensors="pt").to(model.device)

# 生成输出
outputs = model.generate(
    input_ids,
    max_new_tokens=512,
    temperature=0.7,
    top_p=0.9,
    repetition_penalty=1.1
)

# 解码输出
generated_text = tokenizer.decode(outputs[0][input_ids.shape[-1]:], skip_special_tokens=True)
print(generated_text)
```

### 使用工具调用（ChatGLM3）

```python
from transformers import AutoTokenizer, AutoModelForCausalLM
import json

# 加载模型
model_name = "THUDM/chatglm3-6b"
tokenizer = AutoTokenizer.from_pretrained(model_name, trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    device_map="auto",
    torch_dtype="auto",
    trust_remote_code=True
)

# 定义工具
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "获取指定城市的天气信息",
            "parameters": {
                "type": "object",
                "properties": {
                    "city": {
                        "type": "string",
                        "description": "城市名称"
                    }
                },
                "required": ["city"]
            }
        }
    }
]

# 准备输入
messages = [
    {"role": "user", "content": "北京今天的天气怎么样？"}
]

# 生成工具调用
input_ids = tokenizer.apply_chat_template(
    messages,
    tools=tools,
    return_tensors="pt"
).to(model.device)

outputs = model.generate(
    input_ids,
    max_new_tokens=256,
    temperature=0.7
)

# 解析工具调用
generated_text = tokenizer.decode(outputs[0][input_ids.shape[-1]:], skip_special_tokens=True)
print(generated_text)
```

## 🔧 微调 ChatGLM

### 使用 LoRA 微调

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments
from peft import LoraConfig, get_peft_model, TaskType
import torch

# 加载模型
model_name = "THUDM/chatglm3-6b"
tokenizer = AutoTokenizer.from_pretrained(model_name, trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    device_map="auto",
    torch_dtype=torch.float16,
    trust_remote_code=True
)

# 配置 LoRA
lora_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    target_modules=["query_key_value", "dense", "dense_h_to_4h", "dense_4h_to_h"],
    bias="none"
)

# 应用 LoRA
model = get_peft_model(model, lora_config)

# 训练配置
training_args = TrainingArguments(
    output_dir="./chatglm-finetuned",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4,
    learning_rate=2e-4,
    fp16=True,
    logging_steps=10,
    save_steps=100
)

# 开始训练

    model=model,
    args=training_args,

    tokenizer=tokenizer

trainer.train()
```
