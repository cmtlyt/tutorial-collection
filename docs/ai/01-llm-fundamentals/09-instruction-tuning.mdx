# 指令微调详解

## 📖 概述

指令微调（Instruction Tuning）是一种特殊的微调方法，通过在指令-响应对上训练模型，使模型能够理解和遵循自然语言指令。这是现代大语言模型（如 ChatGPT、Claude）能够进行对话和完成复杂任务的关键技术。

## 🎯 为什么需要指令微调？

### 预训练模型的局限

1. **补全模式**
   - 预训练模型学习文本补全
   - 不理解"指令"的概念
   - 缺乏任务意识

2. **格式不匹配**
   - 预训练数据是连续文本
   - 实际应用需要特定格式
   - 输入输出关系不明确

3. **交互能力弱**
   - 无法理解用户意图
   - 缺乏对话能力
   - 难以处理复杂任务

### 指令微调的优势

1. **任务理解**
   - 理解自然语言指令
   - 识别任务类型
   - 提取关键信息

2. **格式规范**
   - 遵循输出格式要求
   - 结构化输出
   - 易于解析

3. **交互能力**
   - 支持对话
   - 多轮交互
   - 上下文理解

## 🔢 指令微调的核心概念

### 1. 指令（Instruction）

指令是告诉模型要做什么的自然语言描述。

#### 指令类型

##### 任务描述型

```
请将以下文本翻译成英文：
输入：你好世界
输出：
```

##### 问答型

```
问题：什么是机器学习？
回答：
```

##### 示例型（Few-shot）

```
任务：情感分类
示例1：
输入：这部电影太棒了！
输出：正面

示例2：
输入：这个产品很糟糕。
输出：负面

输入：今天天气不错。
输出：
```

## 💻 指令微调实现

### 1. 数据准备

```python
import json
from datasets import Dataset
from transformers import AutoTokenizer

class InstructionDataset:
    def __init__(self, data_path, tokenizer, max_length=512):
        """
        指令数据集
        
        参数:
            data_path: 数据文件路径
            tokenizer: 分词器
            max_length: 最大序列长度
        """
        self.tokenizer = tokenizer
        self.max_length = max_length
        
        # 加载数据
        with open(data_path, 'r', encoding='utf-8') as f:
            self.data = [json.loads(line) for line in f]
    
    def format_prompt(self, example):
        """
        格式化提示
        
        参数:
            example: 数据样本
        
        返回:
            prompt: 格式化后的提示
        """
        instruction = example['instruction']
        input_text = example.get('input', '')
        output = example['output']
        
        # 格式化
        if input_text:
            prompt = f"指令：{instruction}\n输入：{input_text}\n输出："
        else:
            prompt = f"指令：{instruction}\n输出："
        
        return prompt
    
    def __len__(self):
        return len(self.data)
    
    def __getitem__(self, idx):
        example = self.data[idx]
        
        # 格式化提示
        prompt = self.format_prompt(example)
        output = example['output']
        
        # 组合输入和输出
        full_text = prompt + output
        
        # 分词
        encoding = self.tokenizer(
            full_text,
            truncation=True,
            max_length=self.max_length,
            padding='max_length',
            return_tensors='pt'
        )
        
        # 计算标签（只在输出部分计算损失）
        prompt_length = len(self.tokenizer(prompt, add_special_tokens=False)['input_ids'])
        labels = encoding['input_ids'].clone()
        labels[:, :prompt_length] = -100  # 忽略提示部分的损失
        
        return {
            'input_ids': encoding['input_ids'].squeeze(0),
            'attention_mask': encoding['attention_mask'].squeeze(0),
            'labels': labels.squeeze(0)
        }

# 使用示例
def prepare_instruction_data():
    """准备指令数据"""
    # 加载分词器
    tokenizer = AutoTokenizer.from_pretrained('llama-7b')
    
    # 创建数据集
    dataset = InstructionDataset(
        data_path='instruction_data.jsonl',
        tokenizer=tokenizer,
        max_length=512
    )
    
    return dataset
```

### 2. 模型训练

```python
import torch
from transformers import AutoModelForCausalLM, TrainingArguments, Trainer

class InstructionTrainer:
    def __init__(self, model_name, train_dataset, val_dataset=None):
        """
        指令微调训练器
        
        参数:
            model_name: 预训练模型名称
            train_dataset: 训练数据集
            val_dataset: 验证数据集
        """
        self.model_name = model_name
        self.train_dataset = train_dataset
        self.val_dataset = val_dataset
        
        # 加载模型
        self.model = AutoModelForCausalLM.from_pretrained(
            model_name,
            torch_dtype=torch.float16,
            device_map="auto"
        )
        
        # 加载分词器
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        
        # 设置 pad_token
        if self.tokenizer.pad_token is None:
            self.tokenizer.pad_token = self.tokenizer.eos_token
    
    def train(self, output_dir, num_epochs=3, batch_size=4, learning_rate=2e-5):
        """
        训练模型
        
        参数:
            output_dir: 输出目录
            num_epochs: 训练轮数
            batch_size: 批次大小
            learning_rate: 学习率
        """
        # 训练参数
        training_args = TrainingArguments(
            output_dir=output_dir,
            num_train_epochs=num_epochs,
            per_device_train_batch_size=batch_size,
            per_device_eval_batch_size=batch_size,
            learning_rate=learning_rate,
            warmup_steps=100,
            logging_steps=10,
            save_steps=500,
            evaluation_strategy="steps",
            eval_steps=500,
            save_total_limit=2,
            fp16=True,
            gradient_checkpointing=True,
            optim="adamw_torch"
        )
        
        # 创建训练器
        trainer = Trainer(
            model=self.model,
            args=training_args,
            train_dataset=self.train_dataset,
            eval_dataset=self.val_dataset,
            tokenizer=self.tokenizer
        )
        
        # 训练
        trainer.train()
        
        # 保存模型
        trainer.save_model(output_dir)
        
        return trainer

# 使用示例
def instruction_finetuning_example():
    """指令微调示例"""
    # 准备数据
    train_dataset = prepare_instruction_data()
    val_dataset = prepare_instruction_data()  # 假设有验证数据
    
    # 创建训练器
    trainer = InstructionTrainer(
        model_name='llama-7b',
        train_dataset=train_dataset,
        val_dataset=val_dataset
    )
    
    # 训练
    trainer.train(
        output_dir='./instruction_finetuned_model',
        num_epochs=3,
        batch_size=4,
        learning_rate=2e-5
    )
```

### 3. 推理

```python
class InstructionInference:
    def __init__(self, model_path, tokenizer_path=None):
        """
        指令推理
        
        参数:
            model_path: 模型路径
            tokenizer_path: 分词器路径
        """
        # 加载模型
        self.model = AutoModelForCausalLM.from_pretrained(
            model_path,
            torch_dtype=torch.float16,
            device_map="auto"
        )
        
        # 加载分词器
        tokenizer_path = tokenizer_path or model_path
        self.tokenizer = AutoTokenizer.from_pretrained(tokenizer_path)
    
    def generate(self, instruction, input_text=None, max_length=512, temperature=0.7):
        """
        生成响应
        
        参数:
            instruction: 指令
            input_text: 输入文本
            max_length: 最大长度
            temperature: 温度参数
        
        返回:
            response: 生成的响应
        """
        # 格式化提示
        if input_text:
            prompt = f"指令：{instruction}\n输入：{input_text}\n输出："
        else:
            prompt = f"指令：{instruction}\n输出："
        
        # 分词
        inputs = self.tokenizer(
            prompt,
            return_tensors='pt',
            truncation=True,
            max_length=max_length
        ).to(self.model.device)
        
        # 生成
        with torch.no_grad():
            outputs = self.model.generate(
                **inputs,
                max_length=max_length,
                temperature=temperature,
                do_sample=True,
                top_p=0.95,
                pad_token_id=self.tokenizer.eos_token_id
            )
        
        # 解码
        response = self.tokenizer.decode(outputs[0], skip_special_tokens=True)
        
        # 提取输出部分
        output_start = response.find("输出：") + len("输出：")
        response = response[output_start:].strip()
        
        return response

# 使用示例
def instruction_inference_example():
    """指令推理示例"""
    # 创建推理器
    inference = InstructionInference('./instruction_finetuned_model')
    
    # 生成响应
    response = inference.generate(
        instruction="请将以下文本翻译成英文",
        input_text="你好世界",
        max_length=100,
        temperature=0.7
    )
    
    print(f"响应：{response}")
```

## 🔧 高级技术

### 1. 多任务指令微调

在多个任务上同时训练，提高泛化能力。

```python
class MultiTaskInstructionDataset:
    def __init__(self, data_paths, tokenizer, max_length=512):
        """
        多任务指令数据集
        
        参数:
            data_paths: 数据文件路径字典 {task_name: path}
            tokenizer: 分词器
            max_length: 最大序列长度
        """
        self.tokenizer = tokenizer
        self.max_length = max_length
        
        # 加载所有任务的数据
        self.data = []
        for task_name, path in data_paths.items():
            with open(path, 'r', encoding='utf-8') as f:
                task_data = [json.loads(line) for line in f]
                for example in task_data:
                    example['task'] = task_name
                    self.data.append(example)
    
    def format_prompt(self, example):
        """格式化提示"""
        task = example['task']
        instruction = example['instruction']
        input_text = example.get('input', '')
        
        # 添加任务标识
        prompt = f"任务：{task}\n指令：{instruction}"
        
        if input_text:
            prompt += f"\n输入：{input_text}"
        
        prompt += "\n输出："
        
        return prompt
    
    # ... 其他方法与 InstructionDataset 类似
```

### 2. 对话式指令微调

针对对话场景的特殊微调。

```python
class ConversationDataset:
    def __init__(self, data_path, tokenizer, max_length=512):
        """
        对话数据集
        
        参数:
            data_path: 数据文件路径
            tokenizer: 分词器
            max_length: 最大序列长度
        """
        self.tokenizer = tokenizer
        self.max_length = max_length
        
        # 加载数据
        with open(data_path, 'r', encoding='utf-8') as f:
            self.data = [json.loads(line) for line in f]
    
    def format_conversation(self, conversations):
        """
        格式化对话
        
        参数:
            conversations: 对话列表
        
        返回:
            formatted: 格式化后的对话
        """
        formatted = ""
        for turn in conversations:
            role = turn['role']
            content = turn['content']
            
            if role == 'user':
                formatted += f"用户：{content}\n"
            elif role == 'assistant':
                formatted += f"助手：{content}\n"
        
        return formatted
    
    def __getitem__(self, idx):
        example = self.data[idx]
        conversations = example['conversations']
        
        # 格式化对话
        formatted = self.format_conversation(conversations)
        
        # 分词
        encoding = self.tokenizer(
            formatted,
            truncation=True,
            max_length=self.max_length,
            padding='max_length',
            return_tensors='pt'
        )
        
        return {
            'input_ids': encoding['input_ids'].squeeze(0),
            'attention_mask': encoding['attention_mask'].squeeze(0),
            'labels': encoding['input_ids'].squeeze(0)
        }
```

### 3. 混合训练

结合指令微调和预训练数据。

```python
class MixedDataset(torch.utils.data.Dataset):
    def __init__(self, instruction_dataset, pretrain_dataset, mix_ratio=0.5):
        """
        混合数据集
        
        参数:
            instruction_dataset: 指令数据集
            pretrain_dataset: 预训练数据集
            mix_ratio: 指令数据比例
        """
        self.instruction_dataset = instruction_dataset
        self.pretrain_dataset = pretrain_dataset
        self.mix_ratio = mix_ratio
        
        # 计算每个数据集的样本数
        total_size = len(instruction_dataset) + len(pretrain_dataset)
        self.instruction_size = int(total_size * mix_ratio)
        self.pretrain_size = total_size - self.instruction_size
    
    def __len__(self):
        return self.instruction_size + self.pretrain_size
    
    def __getitem__(self, idx):
        if idx < self.instruction_size:
            # 从指令数据集采样
            return self.instruction_dataset[idx % len(self.instruction_dataset)]
        else:
            # 从预训练数据集采样
            return self.pretrain_dataset[(idx - self.instruction_size) % len(self.pretrain_dataset)]
```

## 💡 实践建议

### 数据质量

1. **指令清晰**
   - 使用明确的指令
   - 避免歧义
   - 提供示例

2. **输出准确**
   - 确保输出正确
   - 格式一致
   - 完整回答

3. **多样性**
   - 覆盖多种任务
   - 不同难度
   - 多个领域

### 训练技巧

1. **学习率**
   - 通常 1e-5 到 5e-5
   - 使用预热
   - 监控损失

2. **Batch Size**
   - 根据显存调整
   - 通常 4-16
   - 梯度累积

3. **训练轮数**
   - 通常 1-3 轮
   - 避免过拟合
   - 早停

### 评估方法

1. **自动评估**
   - BLEU、ROUGE
   - 准确率
   - F1 分数

2. **人工评估**
   - 质量
   - 相关性
   - 有用性

3. **用户反馈**
   - 满意度
   - 使用率
   - 转化率
