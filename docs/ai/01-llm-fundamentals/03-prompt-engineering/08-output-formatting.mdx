# Output Formatting

> **版本**：v1.1  
> **最后更新**：2026-04-16

## 📖 概述

Output Formatting（输出格式化）是 Prompt Engineering 中的重要技术，通过明确的指令和示例，控制模型输出的格式、结构和风格，使其更易于使用和处理。

## 🎯 核心概念

### 什么是 Output Formatting？

**定义**：通过提示指令和示例，引导模型按照特定的格式、结构或样式生成输出。

**核心目标**：
- 统一输出格式
- 便于后续处理
- 提高可读性
- 增强可用性

### 为什么重要？

1. **自动化处理**
   - 结构化输出易于解析
   - 减少后处理工作
   - 提高自动化程度

2. **一致性**
   - 统一的输出格式
   - 降低处理复杂度
   - 提高可靠性

3. **可读性**
   - 清晰的结构
   - 易于理解
   - 便于人工审查

## 💡 基础格式

### 1. JSON 格式

```python
prompt = """
分析以下文本，提取关键信息并以 JSON 格式输出：

文本：苹果公司今天发布了新款 iPhone 15，售价 799 美元起，将于下月上市。

请提取以下信息：
- 公司
- 产品
- 价格
- 上市时间

输出格式：
{
  "company": "公司名称",
  "product": "产品名称",
  "price": "价格",
  "launch_date": "上市时间"
}
"""

# 输出：
# {
#   "company": "苹果公司",
#   "product": "iPhone 15",
#   "price": "799 美元",
#   "launch_date": "下月"
# }
```

### 2. 列表格式

```python
prompt = """
列出 Python 中常用的数据结构，每个结构用一行表示。

输出格式：
- 数据结构名称：简要描述

示例：
- 列表：可变的有序集合
- 元组：不可变的有序集合

请列出至少 5 种数据结构：
"""

# 输出：
# - 列表：可变的有序集合
# - 元组：不可变的有序集合
# - 字典：键值对的无序集合
# - 集合：不重复元素的无序集合
# - 字符串：不可变的字符序列
```

### 3. 表格格式

```python
prompt = """

比较维度：

|------|---------|---------|-----------|
| Python | ... | ... | ... |
| JavaScript | ... | ... | ... |

# | Java | 静态类型 | JVM | 企业应用、Android |
```

## 📊 格式类型对比

| 格式类型 | 适用场景 | 优点 | 缺点 |
|---------|---------|------|------|
| JSON | 数据提取、API | 结构化、易解析 | 不易读 |
| 列表 | 要点列举 | 清晰、简洁 | 不适合复杂信息 |
| 表格 | 对比展示 | 直观、易比较 | 不适合长文本 |
| Markdown | 文档生成 | 易读、通用 | 需要后处理 |
| XML | 数据交换 | 标准化、灵活 | 冗长 |

## ⚠️ 注意事项

### 1. 格式验证

模型可能不完全遵循格式：
- 需要后处理验证
- 提供多个示例
- 明确格式要求

### 2. 复杂度权衡

复杂格式可能降低质量：
- 简单格式更可靠
- 复杂格式需要更多示例
- 权衡格式复杂度和输出质量

### 3. Token 消耗

格式指令消耗 Token：
- 简洁的格式描述
- 必要时使用示例
- 平衡指令长度和效果
