# Role-playing

> **版本**：v1.0  
> **最后更新**：2026-04-14

## 📖 概述

Role-playing（角色扮演）是一种强大的提示技术，通过为模型分配特定角色，引导模型以特定的视角、语气和专业知识来回应，从而获得更精准、更专业的输出。

## 🎯 核心概念

### 什么是 Role-playing？

**定义**：在提示中明确指定模型应该扮演的角色，让模型以该角色的身份、知识背景和表达方式来回应。

**核心思想**：
- 角色定义行为模式
- 专业知识引导输出
- 语气风格影响表达
- 上下文框架增强一致性

### 为什么有效？

1. **激活特定知识**
   - 模型训练中包含各种角色的数据
   - 角色提示激活相关知识
   - 提高输出专业性

2. **统一表达风格**
   - 角色定义语气和风格
   - 保持输出一致性
   - 提升用户体验

3. **设定行为边界**
   - 角色限制回答范围
   - 避免无关信息
   - 提高回答针对性

## 💡 基础示例

### 专业角色

**医生角色**

```python
prompt = """
你是一名经验丰富的内科医生，有 20 年的临床经验。请用专业但易懂的语言回答以下问题：

问题：经常感到疲劳可能是什么原因？请给出可能的原因和建议。
"""

# 输出会更专业，包含医学知识
```

**律师角色**

```python
prompt = """
你是一名资深律师，专精于商业法。请从法律角度分析以下情况：

情况：一家公司未按时支付供应商货款，供应商想要追讨。请给出法律建议。
"""

# 输出会引用相关法律，给出专业建议
```

**教师角色**

```python
prompt = """
你是一名有 10 年教学经验的数学老师。请用简单易懂的方式解释以下概念：

概念：什么是微积分？请用生活中的例子来解释。
"""

# 输出会适合教学，使用类比和例子
```

## 🎯 角色设计要素

### 1. 身份定义

```python
# 好的身份定义
prompt = """
你是一名有 15 年经验的资深数据科学家，
曾在 Google 和 Meta 工作过，
专精于机器学习和深度学习，
发表过多篇顶级会议论文。
"""

# 包含：
# - 职业身份
# - 经验年限
# - 工作背景
# - 专业领域
# - 成就
```

### 2. 专业知识

```python
# 定义专业知识范围
prompt = """
你是一名网络安全专家，精通：
- 网络攻击和防御技术
- 密码学原理
- 安全协议和标准
- 漏洞分析和修复
- 安全审计和合规
"""

# 列出具体的知识领域
```

### 3. 语气风格

```python
# 定义语气和风格
prompt = """
你是一名大学教授，讲课风格：
- 专业但不晦涩
- 善于用比喻和例子
- 鼓励学生思考
- 耐心细致
"""

# 描述沟通风格
```

### 4. 行为准则

```python
# 定义行为准则
prompt = """
你是一名心理咨询师，请遵循以下原则：
- 保持同理心和理解
- 不做诊断，只提供建议
- 尊重隐私和保密
- 引导而非说教
- 遇到严重情况建议寻求专业帮助
"""

# 设定行为边界
```

## 🎨 高级技巧

### 1. 多角色协作

```python
prompt = """
请模拟一个产品开发团队的讨论会议，包含以下角色：

产品经理：负责产品规划和需求分析
设计师：负责用户体验和界面设计
工程师：负责技术实现和可行性评估

讨论主题：如何改进移动应用的登录流程

请模拟他们的对话，每个角色从自己的角度发表意见。
"""

# 输出会包含多视角的讨论
```

### 2. 角色转换

```python
prompt = """
首先，你是一名乐观的创业者，描述创业的好处。
然后，转换成一名谨慎的投资人，分析创业的风险。
最后，综合两种观点，给出平衡的建议。
"""

# 输出会展示不同角色的观点
```

### 3. 角色深化

```python
prompt = """
你是一名历史学家，专门研究中国古代史。请深入分析以下历史事件：

事件：秦始皇统一六国

请从以下角度分析：
1. 政治角度：统一的政治意义
2. 经济角度：统一的经济影响
3. 文化角度：统一的文化融合
4. 军事角度：统一的军事策略
5. 长远影响：对后世的影响

请引用史实，提供深入的分析。
"""

# 深度角色，提供专业分析
```

### 4. 角色约束

```python
prompt = """
你是一名律师，但请注意：
- 只提供一般性法律信息，不构成法律建议
- 建议用户咨询专业律师
- 不提供具体的法律咨询
- 不承诺任何结果

现在请解释什么是"知识产权"。
"""

# 明确角色的限制和边界
```

## 💡 最佳实践

### 1. 选择合适的角色

```python
# 根据任务选择角色
task_to_role = {
    "医疗咨询": "医生",
    "法律问题": "律师",
    "教学": "老师",
    "编程": "程序员",
    "设计": "设计师",
    "写作": "作家",
    "分析": "分析师"
}

role = task_to_role.get(task_type, "专业顾问")
```

### 2. 角色描述要具体

```python
# 好的角色描述
good_role = """
你是一名有 10 年经验的 Python 开发工程师，
专精于 Web 开发和数据分析，
使用过 Django、Flask、Pandas 等框架，
在大型科技公司工作过，
代码风格注重可读性和性能。
"""

# 差的角色描述
bad_role = """
你是一个程序员。
"""
```

### 3. 保持角色一致性

```python
# 在多轮对话中保持角色
prompt = """
你是一名健身教练。请保持这个角色，回答以下问题：

问题1：如何减肥？
（回答）

问题2：如何增肌？
（保持健身教练的角色回答）

问题3：如何提高柔韧性？
（继续保持角色）
"""
```

### 4. 角色与任务匹配

```python
# 确保角色与任务匹配
if task == "写代码":
    role = "程序员"
elif task == "解释概念":
    role = "老师"
elif task == "创意写作":
    role = "作家"
else:
    role = "专业顾问"
```

## ⚠️ 注意事项

### 1. 角色限制

角色不是万能的：
- 模型不是真正的专家
- 可能产生错误信息
- 重要决策需咨询真人专家

### 2. 伦理考虑

某些角色需要谨慎：
- 医疗角色：不提供诊断
- 法律角色：不构成法律建议
- 财务角色：不提供投资建议

### 3. 角色一致性

在多轮对话中：
- 保持角色一致
- 避免角色混淆
- 必要时重新设定角色
