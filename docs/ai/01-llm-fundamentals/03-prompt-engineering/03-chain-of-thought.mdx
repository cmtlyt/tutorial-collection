# Chain of Thought (CoT)

> **版本**：v1.0  
> **最后更新**：2026-04-14

## 📖 概述

Chain of Thought（思维链）是一种强大的提示技术，通过引导模型逐步展示推理过程，显著提升复杂问题的解决能力。CoT 特别适用于需要多步推理的任务。

## 🎯 核心概念

### 什么是 Chain of Thought？

**定义**：通过在提示中要求模型"逐步思考"或"展示推理过程"，引导模型分解复杂问题，逐步推导出答案。

**核心思想**：
- 显式展示推理步骤
- 分解复杂问题
- 逐步推导结论
- 提高推理准确性

### 为什么有效？

1. **显式推理**
   - 强制模型展示思考过程
   - 避免直接猜测答案
   - 提高可解释性

2. **问题分解**
   - 将复杂问题拆解
   - 逐步解决子问题
   - 降低错误率

3. **自我验证**
   - 在推理过程中检查
   - 发现并纠正错误
   - 提高答案质量

## 💡 基础示例

### 数学问题

**Without CoT**

```python
prompt = """
计算：23 * 47 = ?
"""

# 可能的错误输出：1081（错误）
```

**With CoT**

```python
prompt = """
计算：23 * 47 = ?
请逐步展示计算过程。
"""

# 输出：
# 23 * 47 的计算过程：
# 1. 分解：23 * 47 = 23 * (40 + 7)
# 2. 计算：23 * 40 = 920
# 3. 计算：23 * 7 = 161
# 4. 相加：920 + 161 = 1081
# 
# 答案：1081
```

**Without CoT**

```python
prompt = """

```

**With CoT**

```python
prompt = """

# 输出：
# 推理过程：

# 2. 已知事实：小花是一只猫
# 3. 应用前提：因为小花是猫，所以小花喜欢吃鱼
# 4. 结论：小花喜欢吃鱼
```


## 🎯 CoT 模式

### 1. Zero-shot CoT

**方法**：在提示中添加"让我们逐步思考"

```python
prompt = """
问题：一个农场有鸡和兔子共 35 只，共有 94 条腿。问鸡和兔子各有多少只？

让我们逐步思考：
"""

# 输出：
# 让我们逐步思考：
# 1. 设鸡有 x 只，兔子有 y 只
# 2. 根据题意：
#    x + y = 35  (总数)
#    2x + 4y = 94  (腿数)
# 3. 从第一个方程：x = 35 - y
# 4. 代入第二个方程：2(35 - y) + 4y = 94
# 5. 展开：70 - 2y + 4y = 94
# 6. 合并：70 + 2y = 94
# 7. 解得：2y = 24，y = 12
# 8. 所以：x = 35 - 12 = 23
# 
# 答案：鸡 23 只，兔子 12 只
```

### 2. Few-shot CoT

**方法**：提供带有推理过程的示例

```python
prompt = """
解决数学问题，展示推理过程：

示例 1：
问题：15 + 27 = ?
推理：
15 + 27 = 15 + (25 + 2) = (15 + 25) + 2 = 40 + 2 = 42
答案：42

示例 2：
问题：56 - 29 = ?
推理：
56 - 29 = 56 - (30 - 1) = 56 - 30 + 1 = 26 + 1 = 27
答案：27

现在请解决：
问题：38 + 47 = ?
推理：
"""

# 输出：
# 推理：
# 38 + 47 = 38 + (40 + 7) = (38 + 40) + 7 = 78 + 7 = 85
# 答案：85
```

### 3. 结构化 CoT

**方法**：使用结构化的推理格式

```python
prompt = """
分析以下问题，使用以下结构：
1. 理解问题
2. 识别关键信息
3. 制定计划
4. 执行步骤
5. 得出结论

问题：一个班级有 30 名学生，其中 60% 是女生。如果 5 名女生转走，那么女生占总人数的百分比是多少？
"""

# 输出：
# 1. 理解问题：需要计算女生转走后的百分比
# 2. 识别关键信息：
#    - 总人数：30 名
#    - 女生比例：60%
#    - 转走的女生：5 名
# 3. 制定计划：
#    - 计算初始女生人数
#    - 计算转走后的女生人数
#    - 计算转走后的总人数
#    - 计算新的百分比
# 4. 执行步骤：
#    - 初始女生：30 × 60% = 18 名
#    - 转走后女生：18 - 5 = 13 名
#    - 转走后总人数：30 - 5 = 25 名
#    - 新百分比：13/25 = 52%
# 5. 得出结论：女生占总人数的 52%
```

## 💡 最佳实践

### 1. 选择合适的 CoT 类型

```python
# 简单问题：Zero-shot CoT
if complexity == "low":
    prompt = f"{problem}\n让我们逐步思考："

# 中等问题：Few-shot CoT
elif complexity == "medium":
    prompt = f"{examples}\n{problem}\n推理："

# 复杂问题：结构化 CoT
else:
    prompt = f"{structure}\n{problem}"
```

### 2. 优化推理提示

```python
# 好的推理提示
good_prompts = [
    "请逐步展示推理过程",
    "分解问题并逐步解决",
    "展示你的思考步骤",
    "详细解释你的推理",
]

# 避免模糊的提示
bad_prompts = [
    "想一想",
    "解释一下",
    "为什么",
]
```

### 3. 控制推理长度

```python
# 设置推理步骤限制
prompt = f"""
{problem}

请逐步推理，限制在 5 个步骤以内。
"""

# 或者要求简洁的推理
prompt = f"""
{problem}

请简洁地展示关键推理步骤。
"""
```

### 4. 验证推理过程

```python
# 要求模型验证自己的推理
prompt = f"""
{problem}

请逐步推理，然后验证你的答案是否正确。
"""
```

## ⚠️ 注意事项

### 1. Token 消耗

CoT 会显著增加 Token 消耗：
- 简单任务可能不需要
- 权衡准确度和成本
- 考虑使用更简洁的推理

### 2. 推理质量

不是所有 CoT 都有效：
- 推理可能不准确
- 需要验证结果
- 可能产生幻觉

### 3. 适用范围

CoT 不是万能的：
- 创意任务效果有限
- 简单任务可能过度
- 需要根据任务选择
