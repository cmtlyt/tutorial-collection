# Tree of Thoughts

> **版本**：v1.1  
> **最后更新**：2026-04-16

## 📖 概述

Tree of Thoughts（思维树）是一种高级提示技术，通过构建推理树来探索多个可能的解决路径，特别适用于需要规划和决策的复杂任务。

## 🎯 核心概念

### 什么是 Tree of Thoughts？

**定义**：将问题解决过程建模为一棵树，每个节点代表一个思考步骤或中间状态，通过系统地探索和评估不同路径来找到最优解。

**核心思想**：
- 将复杂问题分解为多个步骤
- 每个步骤可能有多个选择
- 构建完整的搜索树
- 系统地评估和选择路径

### 与 CoT 的区别

| 特性 | Chain of Thought | Tree of Thoughts |
|------|-----------------|-----------------|
| 推理方式 | 线性推理 | 树状推理 |
| 路径数量 | 单一路径 | 多路径探索 |
| 回溯能力 | 无 | 可回溯 |
| 适用场景 | 单步推理 | 多步规划 |
| 复杂度 | 低 | 高 |

## 💡 基本原理

### 思维树结构

```
根节点（问题）
    ↓
分支 1    分支 2    分支 3
    ↓        ↓        ↓
子分支...  子分支...  子分支...
    ↓        ↓        ↓
叶节点（解决方案）
```

### 工作流程

```
1. 定义问题（根节点）
   ↓
2. 生成多个初始思路（第一层分支）
   ↓
3. 对每个思路深入思考（子分支）
   ↓
4. 评估每个路径的质量
   ↓
5. 选择最优路径或组合
   ↓
6. 得到最终解决方案
```

### 1. Generate-and-Test（生成测试）

```python
def generate_and_test(problem, max_depth=3, branches_per_node=3):
    """
    生成测试法
    
    生成多个完整路径，选择最优的
    """
    solutions = []
    
    # 生成多个完整路径
    for i in range(branches_per_node):
        path = generate_path(problem, max_depth)
        quality = evaluate_path(path)
        solutions.append({
            "path": path,
            "quality": quality
        })
    
    # 选择质量最高的路径
    best_solution = max(solutions, key=lambda x: x["quality"])
    
    return best_solution
```

### 2. BFS（广度优先搜索）

```python
def bfs_tree_of_thoughts(problem, max_depth=3, branches_per_node=3):
    """
    广度优先搜索
    
    逐层探索所有可能路径
    """
    queue = [(problem, [])]  # (当前状态, 路径)
    solutions = []
    
    while queue and len(solutions) < branches_per_node:
        current_state, path = queue.pop(0)
        
        # 如果达到最大深度，记录解决方案
        if len(path) >= max_depth:
            solutions.append({
                "path": path,
                "state": current_state
            })
            continue
        
        # 生成下一层的分支
        branches = generate_branches(current_state)
        for branch in branches:
            new_path = path + [branch]
            new_state = apply_branch(current_state, branch)
            queue.append((new_state, new_path))
    
    # 选择最优解决方案
    return select_best_solution(solutions)
```

### 3. DFS（深度优先搜索）

```python
def dfs_tree_of_thoughts(problem, max_depth=3, branches_per_node=3):
    """
    深度优先搜索
    
    深入探索每条路径
    """
    solutions = []
    
    def dfs(current_state, path, depth):
        # 如果达到最大深度，记录解决方案
        if depth >= max_depth:
            solutions.append({
                "path": path,
                "state": current_state
            })
            return
        
        # 生成下一层的分支
        branches = generate_branches(current_state)
        for branch in branches[:branches_per_node]:
            new_path = path + [branch]
            new_state = apply_branch(current_state, branch)
            dfs(new_state, new_path, depth + 1)
    
    dfs(problem, [], 0)
    
    # 选择最优解决方案
    return select_best_solution(solutions)
```

### 4. Best-First Search（最佳优先搜索）

```python
def best_first_search(problem, max_depth=3, branches_per_node=3):
    """
    最佳优先搜索
    
    优先探索最有希望的路径
    """
    import heapq
    
    # 优先队列：(质量, 当前状态, 路径)
    pq = []
    heapq.heappush(pq, (0, problem, []))
    
    solutions = []
    
    while pq and len(solutions) < branches_per_node:
        quality, current_state, path = heapq.heappop(pq)
        
        # 如果达到最大深度，记录解决方案
        if len(path) >= max_depth:
            solutions.append({
                "path": path,
                "state": current_state,
                "quality": quality
            })
            continue
        
        # 生成下一层的分支
        branches = generate_branches(current_state)
        for branch in branches[:branches_per_node]:
            new_path = path + [branch]
            new_state = apply_branch(current_state, branch)
            new_quality = evaluate_state(new_state)
            heapq.heappush(pq, (new_quality, new_state, new_path))
    
    # 选择最优解决方案
    return max(solutions, key=lambda x: x["quality"])
```

## 🎨 高级技巧

### 1. 动态分支

```python
def dynamic_branching(problem, max_depth=3):
    """
    动态分支数量
    
    根据问题复杂度动态调整分支数量
    """
    def dfs(current_state, path, depth):
        if depth >= max_depth:
            return [path]
        
        # 根据当前状态决定分支数量
        complexity = evaluate_complexity(current_state)
        num_branches = get_branch_count(complexity)
        
        branches = generate_branches(current_state)
        solutions = []
        
        for branch in branches[:num_branches]:
            new_state = apply_branch(current_state, branch)
            solutions.extend(dfs(new_state, path + [branch], depth + 1))
        
        return solutions
    
    return dfs(problem, [], 0)
```

### 2. 剪枝策略

```python
def pruning_tree_of_thoughts(problem, max_depth=3, branches_per_node=3):
    """
    带剪枝的 Tree of Thoughts
    
    剪除明显不优的分支
    """
    def dfs(current_state, path, depth, best_quality):
        if depth >= max_depth:
            return [(path, current_state)]
        
        branches = generate_branches(current_state)
        solutions = []
        
        for branch in branches[:branches_per_node]:
            new_state = apply_branch(current_state, branch)
            quality = evaluate_state(new_state)
            
            # 剪枝：如果质量明显低于最优，跳过
            if quality < best_quality * 0.7:
                continue
            
            # 更新最优质量
            best_quality = max(best_quality, quality)
            
            solutions.extend(dfs(new_state, path + [branch], depth + 1, best_quality))
        
        return solutions
    
    return dfs(problem, [], 0, 0)
```

### 3. 路径组合

```python
def path_combination(problem, max_depth=3, branches_per_node=3):
    """
    路径组合
    
    从多个路径中组合最优方案
    """
    # 生成多个完整路径
    all_solutions = []
    for i in range(branches_per_node):
        path = generate_path(problem, max_depth)
        all_solutions.append(path)
    
    # 分析每个路径的优势
    path_analysis = []
    for path in all_solutions:
        analysis = analyze_path(path)
        path_analysis.append({
            "path": path,
            "analysis": analysis
        })
    
    # 组合最优部分
    combined_solution = combine_best_parts(path_analysis)
    
    return combined_solution
```

### 2. 控制树的大小

```python
def control_tree_size(problem, max_tokens=5000):
    """
    控制 Token 消耗
    """
    # 估算每个节点的 Token 数
    tokens_per_node = 100
    
    # 计算最大节点数
    max_nodes = max_tokens // tokens_per_node
    
    # 根据最大节点数调整深度和分支数
    if max_nodes < 27:  # 3^3
        return {"depth": 2, "branches": 3}
    elif max_nodes < 125:  # 5^3
        return {"depth": 3, "branches": 5}
    else:
        return {"depth": 3, "branches": 7}
```

### 3. 质量评估

```python
def evaluate_solution(path, problem):
    """
    评估解决方案的质量
    """
    # 多维度评估
    scores = {
        "completeness": check_completeness(path, problem),
        "feasibility": check_feasibility(path),
        "efficiency": check_efficiency(path),
        "creativity": check_creativity(path)
    }
    
    # 加权总分
    weights = {
        "completeness": 0.4,
        "feasibility": 0.3,
        "efficiency": 0.2,
        "creativity": 0.1
    }
    
    total_score = sum(scores[k] * weights[k] for k in scores)
    
    return {
        "scores": scores,
        "total": total_score
    }
```

## ⚠️ 注意事项

### 1. Token 消耗高

Tree of Thoughts 会消耗大量 Token：
- 需要生成多个路径
- 每个路径都需要完整推理
- 成本显著增加

**建议**：
- 限制树的深度和分支数
- 使用剪枝策略
- 对关键任务使用

### 2. 计算复杂度高

构建和搜索思维树计算复杂：
- 需要评估多个路径
- 可能需要多次生成
- 延迟较高

**建议**：
- 使用并行生成
- 优化评估函数
- 考虑缓存结果

### 3. 质量评估困难

评估不同路径的质量具有挑战性：
- 需要明确的评估标准
- 可能存在主观性
- 需要领域知识

**建议**：
- 定义清晰的评估指标
- 使用多维度评估
- 结合专家知识
