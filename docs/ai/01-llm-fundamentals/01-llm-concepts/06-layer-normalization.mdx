# 层归一化详解

> **版本**：v1.1  
> **最后更新**：2026-04-16  

## 📖 概述

层归一化（Layer Normalization，LayerNorm）是 Transformer 架构中的关键组件，用于稳定训练过程、加速收敛。它在每个子层周围与残差连接一起使用，是训练深层神经网络的重要技术。

## 🎯 为什么需要归一化？

### 深层网络的挑战

1. **内部协变量偏移（Internal Covariate Shift）**
   - 深层网络中，每层的输入分布不断变化
   - 导致训练不稳定，收敛缓慢
   - 需要更小的学习率

2. **梯度消失/爆炸**
   - 深层网络中梯度可能变得极小或极大
   - 导致训练困难或发散
   - 影响模型性能

3. **数值稳定性**
   - 激活值可能过大或过小
   - 导致数值计算问题
   - 影响模型稳定性

### 归一化的作用

1. **稳定激活值分布**
   - 将激活值归一化到标准范围
   - 减少内部协变量偏移
   - 提高训练稳定性

2. **加速收敛**
   - 允许使用更大的学习率
   - 减少训练时间
   - 提高最终性能

3. **改善梯度流**
   - 缓解梯度消失/爆炸
   - 便于训练深层网络
   - 提高模型表达能力

## 🔢 归一化类型

### 1. 批归一化（Batch Normalization）

#### 数学公式

对于特征维度 `d`：

```
μ_B = (1/m) * Σ_{i=1}^{m} x_i
σ²_B = (1/m) * Σ_{i=1}^{m} (x_i - μ_B)²
x̂_i = (x_i - μ_B) / √(σ²_B + ε)
y_i = γ * x̂_i + β
```

其中：
- `μ_B`：batch 均值
- `σ²_B`：batch 方差
- `x̂_i`：归一化后的值
- `γ`：可学习的缩放参数
- `β`：可学习的偏移参数
- `ε`：小常数，防止除零

#### 特点

- **归一化维度**：对每个特征，在 batch 维度上归一化
- **依赖 batch**：需要足够的 batch size
- **训练/推理不一致**：推理时使用移动平均
- **不适合序列**：对变长序列处理困难

#### 代码实现

```python
import torch
import torch.nn as nn

class BatchNormalization(nn.Module):
    def __init__(self, num_features, eps=1e-5, momentum=0.1):
        """
        批归一化
        
        参数:
            num_features: 特征数量
            eps: 防止除零的小常数
            momentum: 移动平均的动量
        """
        super().__init__()
        
        self.num_features = num_features
        self.eps = eps
        self.momentum = momentum
        
        # 可学习参数
        self.gamma = nn.Parameter(torch.ones(num_features))
        self.beta = nn.Parameter(torch.zeros(num_features))
        
        # 移动平均统计量（推理时使用）
        self.register_buffer('running_mean', torch.zeros(num_features))
        self.register_buffer('running_var', torch.ones(num_features))
    
    def forward(self, x):
        """
        前向传播
        
        参数:
            x: (batch_size, num_features, ...)
        
        返回:
            output: (batch_size, num_features, ...)
        """
        if self.training:
            # 训练模式：计算当前 batch 的统计量
            mean = x.mean(dim=0)
            var = x.var(dim=0)
            
            # 更新移动平均
            self.running_mean = (1 - self.momentum) * self.running_mean + \
                               self.momentum * mean.detach()
            self.running_var = (1 - self.momentum) * self.running_var + \
                              self.momentum * var.detach()
        else:
            # 推理模式：使用移动平均
            mean = self.running_mean
            var = self.running_var
        
        # 归一化
        x_normalized = (x - mean) / torch.sqrt(var + self.eps)
        
        # 缩放和偏移
        output = self.gamma * x_normalized + self.beta
        
        return output
```

### 2. 层归一化（Layer Normalization）

#### 数学公式

对于样本 `i`：

```
μ_i = (1/d) * Σ_{j=1}^{d} x_{i,j}
σ²_i = (1/d) * Σ_{j=1}^{d} (x_{i,j} - μ_i)²
x̂_{i,j} = (x_{i,j} - μ_i) / √(σ²_i + ε)
y_{i,j} = γ_j * x̂_{i,j} + β_j
```

其中：
- `μ_i`：样本 i 的均值
- `σ²_i`：样本 i 的方差
- `x̂_{i,j}`：归一化后的值
- `γ_j`：可学习的缩放参数
- `β_j`：可学习的偏移参数
- `d`：特征维度

#### 特点

- **归一化维度**：对每个样本，在特征维度上归一化
- **独立于 batch**：不依赖 batch size
- **训练/推理一致**：不需要移动平均
- **适合序列**：对变长序列处理友好

#### 代码实现

```python
class LayerNormalization(nn.Module):
    def __init__(self, normalized_shape, eps=1e-5, elementwise_affine=True):
        """
        层归一化
        
        参数:
            normalized_shape: 归一化的形状 (d_model,) 或 (d_model, seq_len)
            eps: 防止除零的小常数
            elementwise_affine: 是否使用可学习的缩放和偏移
        """
        super().__init__()
        
        self.normalized_shape = normalized_shape
        self.eps = eps
        self.elementwise_affine = elementwise_affine
        
        if self.elementwise_affine:
            self.gamma = nn.Parameter(torch.ones(normalized_shape))
            self.beta = nn.Parameter(torch.zeros(normalized_shape))
    
    def forward(self, x):
        """
        前向传播
        
        参数:
            x: (batch_size, ..., normalized_shape)
        
        返回:
            output: (batch_size, ..., normalized_shape)
        """
        # 计算均值和方差
        mean = x.mean(dim=-1, keepdim=True)
        var = x.var(dim=-1, keepdim=True, unbiased=False)
        
        # 归一化
        x_normalized = (x - mean) / torch.sqrt(var + self.eps)
        
        # 缩放和偏移
        if self.elementwise_affine:
            output = self.gamma * x_normalized + self.beta
        else:
            output = x_normalized
        
        return output
```

### 3. 实例归一化（Instance Normalization）

#### 特点

- **归一化维度**：对每个样本的每个通道独立归一化
- **主要用于图像**：风格迁移等任务
- **不适合 NLP**：在序列数据上效果不佳

### 4. 组归一化（Group Normalization）

#### 特点

- **归一化维度**：将通道分组，在组内归一化
- **不依赖 batch**：适合小 batch size
- **介于 BatchNorm 和 LayerNorm 之间**

## 📊 BatchNorm vs LayerNorm

| 特性 | BatchNorm | LayerNorm |
|------|-----------|-----------|
| 归一化维度 | 特征维度 | 样本维度 |
| 依赖 batch | 是 | 否 |
| 训练/推理 | 不一致 | 一致 |
| 适合 batch size | 大 | 任意 |
| 适合序列 | 否 | 是 |
| Transformer | 很少使用 | 广泛使用 |

### 为什么 Transformer 使用 LayerNorm？

1. **变长序列**
   - NLP 处理的序列长度不固定
   - BatchNorm 对变长序列处理困难
   - LayerNorm 自然支持变长序列

2. **小 batch size**
   - 大模型训练时 batch size 受限
   - BatchNorm 在小 batch 上效果差
   - LayerNorm 不受影响

3. **自回归生成**
   - 生成时一次处理一个 token
   - BatchNorm 无法工作（batch size = 1）
   - LayerNorm 可以正常工作

4. **训练稳定性**
   - LayerNorm 在 Transformer 上表现更稳定
   - 不需要维护移动平均统计量

## 🔧 LayerNorm 在 Transformer 中的应用

### 位置

```
输入
    ↓
自注意力
    ↓
残差连接
    ↓
层归一化 ← Post-LN
    ↓
前馈网络
    ↓
残差连接
    ↓
层归一化 ← Post-LN
    ↓
输出
```

### Pre-LN vs Post-LN

#### Post-LN（原始 Transformer）

```
x = LayerNorm(x + Sublayer(x))
```

- 归一化在残差连接之后
- 训练初期不稳定
- 需要学习率预热

#### Pre-LN（现代 Transformer）

```
x = x + Sublayer(LayerNorm(x))
```

- 归一化在残差连接之前
- 训练更稳定
- 不需要学习率预热
- 可以使用更大的学习率

### 代码实现

```python
class TransformerLayerPostLN(nn.Module):
    """Post-LN Transformer 层"""
    def __init__(self, d_model, d_ff, n_heads, dropout=0.1):
        super().__init__()
        
        self.self_attention = MultiHeadAttention(d_model, n_heads, dropout)
        self.feed_forward = FeedForwardNetwork(d_model, d_ff, dropout)
        
        # 层归一化（在残差连接之后）
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, mask=None):
        # 自注意力 + 残差连接 + 层归一化
        attn_output, _ = self.self_attention(x, x, x, mask)
        x = self.norm1(x + self.dropout(attn_output))
        
        # 前馈网络 + 残差连接 + 层归一化
        ff_output = self.feed_forward(x)
        x = self.norm2(x + self.dropout(ff_output))
        
        return x

class TransformerLayerPreLN(nn.Module):
    """Pre-LN Transformer 层"""
    def __init__(self, d_model, d_ff, n_heads, dropout=0.1):
        super().__init__()
        
        self.self_attention = MultiHeadAttention(d_model, n_heads, dropout)
        self.feed_forward = FeedForwardNetwork(d_model, d_ff, dropout)
        
        # 层归一化（在残差连接之前）
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, mask=None):
        # 层归一化 + 自注意力 + 残差连接
        x = x + self.dropout(self.self_attention(
            self.norm1(x), self.norm1(x), self.norm1(x), mask
        )[0])
        
        # 层归一化 + 前馈网络 + 残差连接
        x = x + self.dropout(self.feed_forward(self.norm2(x)))
        
        return x
```

## 💡 实践建议

### 超参数选择

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| `eps` | 1e-5 | 防止除零 |
| `elementwise_affine` | True | 使用可学习参数 |
| `bias` | True | 使用偏置 |

### 初始化

```python
# 标准初始化
layer_norm = nn.LayerNorm(d_model)

# 自定义初始化
layer_norm = nn.LayerNorm(d_model)
nn.init.ones_(layer_norm.weight)
nn.init.zeros_(layer_norm.bias)
```

### 常见问题

1. **数值不稳定**
   - 检查 eps 值是否过小
   - 使用混合精度训练时注意

2. **训练不收敛**
   - 尝试 Pre-LN 而不是 Post-LN
   - 检查学习率是否合适

3. **推理性能下降**
   - 确保 LayerNorm 在 eval 模式
   - 检查是否有 batch 统计量泄漏

```python
import matplotlib.pyplot as plt

def visualize_normalization_effect(x, normalized_x):
    """
    可视化归一化效果
    
    参数:
        x: 归一化前的数据
        normalized_x: 归一化后的数据
    """
    fig, axes = plt.subplots(1, 2, figsize=(12, 5))
    
    # 归一化前
    axes[0].hist(x.flatten().numpy(), bins=50)
    axes[0].set_title('Before Normalization')
    axes[0].set_xlabel('Value')
    axes[0].set_ylabel('Frequency')
    
    # 归一化后
    axes[1].hist(normalized_x.flatten().numpy(), bins=50)
    axes[1].set_title('After Normalization')
    axes[1].set_xlabel('Value')
    axes[1].set_ylabel('Frequency')
    
    plt.tight_layout()
    plt.show()
    
    # 打印统计信息
    print(f"归一化前 - 均值: {x.mean():.4f}, 标准差: {x.std():.4f}")
    print(f"归一化后 - 均值: {normalized_x.mean():.4f}, 标准差: {normalized_x.std():.4f}")
```

### 激活值分布分析

```python
def analyze_activation_distribution(model, input_data):
    """
    分析激活值分布
    
    参数:
        model: 模型
        input_data: 输入数据
    """
    activations = []
    
    # Hook 函数
    def hook_fn(module, input, output):
        activations.append(output.detach())
    
    # 注册 hook
    hooks = []
    for module in model.modules():
        if isinstance(module, nn.LayerNorm):
            hook = module.register_forward_hook(hook_fn)
            hooks.append(hook)
    
    # 前向传播
    with torch.no_grad():
        _ = model(input_data)
    
    # 移除 hook
    for hook in hooks:
        hook.remove()
    
    # 分析分布
    for i, activation in enumerate(activations):
        print(f"LayerNorm {i+1}:")
        print(f"  均值: {activation.mean():.4f}")
        print(f"  标准差: {activation.std():.4f}")
        print(f"  最小值: {activation.min():.4f}")
        print(f"  最大值: {activation.max():.4f}")
        print()
```
