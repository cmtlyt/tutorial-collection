# Transformer 架构详解

> **版本**：v1.0  
> **最后更新**：2026-04-14

## 📖 概述

Transformer 是一种基于自注意力机制的深度神经网络架构，由 Google 在 2017 年的论文《Attention Is All You Need》中提出。它彻底改变了自然语言处理领域，成为现代大语言模型的基础架构。

## 🏗️ 整体架构

### 编码器-解码器结构

原始 Transformer 采用编码器-解码器（Encoder-Decoder）结构：

```
输入序列 → 编码器 → 上下文向量 → 解码器 → 输出序列
```

#### 编码器（Encoder）
- **作用**：将输入序列编码为连续表示
- **组成**：N 个相同的层堆叠
- **每层包含**：
  1. 多头自注意力机制（Multi-Head Self-Attention）
  2. 位置前馈网络（Position-wise Feed-Forward Network）
  3. 残差连接（Residual Connection）
  4. 层归一化（Layer Normalization）

#### 解码器（Decoder）
- **作用**：根据编码器的输出生成目标序列
- **组成**：N 个相同的层堆叠
- **每层包含**：
  1. 掩码多头自注意力机制（Masked Multi-Head Self-Attention）
  2. 编码器-解码器注意力（Encoder-Decoder Attention）
  3. 位置前馈网络（Position-wise Feed-Forward Network）
  4. 残差连接（Residual Connection）
  5. 层归一化（Layer Normalization）

## 🔑 核心组件

### 1. 嵌入层（Embedding Layer）

#### 词嵌入（Token Embedding）
- 将离散的 token 映射到连续的向量空间
- 维度：`d_model`（通常为 512 或 768）
- 可学习参数

#### 位置编码（Positional Encoding）
- 为序列中的每个位置添加位置信息
- 可以是可学习的或固定的（正弦/余弦）

### 2. 注意力机制（Attention Mechanism）

#### 自注意力（Self-Attention）
- 允许序列中的每个位置关注其他所有位置
- 捕捉长距离依赖关系

#### 多头注意力（Multi-Head Attention）
- 并行执行多个注意力头
- 每个头学习不同的表示子空间
- 增强模型的表达能力

#### 编码器-解码器注意力
- 解码器关注编码器的输出
- 建立输入和输出之间的对齐关系

### 3. 前馈网络（Feed-Forward Network）

- 位置独立的前馈网络
- 对每个位置单独应用
- 两层全连接网络，中间有 ReLU 激活

### 4. 残差连接（Residual Connection）

```
输出 = LayerNorm(x + Sublayer(x))
```

- 解决深层网络的梯度消失问题
- 便于训练深层网络
- 每个子层周围都有残差连接

### 5. 层归一化（Layer Normalization）

- 稳定训练过程
- 加速收敛
- 对每个样本的所有特征进行归一化

## 📊 关键超参数

| 参数 | 典型值 | 说明 |
|------|--------|------|
| `d_model` | 512/768/1024 | 模型维度 |
| `d_ff` | 2048/3072 | 前馈网络维度 |
| `n_heads` | 8/12/16 | 注意力头数 |
| `n_layers` | 6/12/24 | 层数 |
| `dropout` | 0.1 | Dropout 比率 |

## 🔄 计算流程

### 编码器前向传播

```python
# 伪代码
def encoder_forward(x):
    # 1. 嵌入
    x = token_embedding(x) + positional_encoding(x)
    
    # 2. 通过 N 个编码器层
    for layer in encoder_layers:
        x = layer(x)
    
    return x

def encoder_layer_forward(x):
    # 自注意力
    attn_output = multi_head_attention(x, x, x)
    x = layer_norm(x + attn_output)
    
    # 前馈网络
    ff_output = feed_forward(x)
    x = layer_norm(x + ff_output)
    
    return x
```

### 解码器前向传播

```python
# 伪代码
def decoder_forward(x, encoder_output):
    # 1. 嵌入
    x = token_embedding(x) + positional_encoding(x)
    
    # 2. 通过 N 个解码器层
    for layer in decoder_layers:
        x = layer(x, encoder_output)
    
    return x

def decoder_layer_forward(x, encoder_output):
    # 掩码自注意力
    attn_output = masked_multi_head_attention(x, x, x)
    x = layer_norm(x + attn_output)
    
    # 编码器-解码器注意力
    attn_output = multi_head_attention(x, encoder_output, encoder_output)
    x = layer_norm(x + attn_output)
    
    # 前馈网络
    ff_output = feed_forward(x)
    x = layer_norm(x + ff_output)
    
    return x
```

## 🎯 关键创新点

### 1. 完全基于注意力
- 摒弃了 RNN/LSTM 的循环结构
- 实现完全并行化
- 捕捉长距离依赖更有效

### 2. 多头注意力
- 从多个子空间学习信息
- 增强模型表达能力
- 类似于使用多个卷积核

### 3. 位置编码
- 引入序列顺序信息
- 支持可变长度序列
- 可以外推到更长的序列

### 4. 残差连接和层归一化
- 便于训练深层网络
- 稳定训练过程
- 加速收敛

## 📈 变体和发展

### 仅编码器（Encoder-only）
- **BERT**：双向编码器，适合理解任务
- **RoBERTa**：BERT 的改进版本
- **ALBERT**：轻量级 BERT

### 仅解码器（Decoder-only）
- **GPT 系列**：自回归生成，适合生成任务
- **LLaMA**：高效的开源模型
- **Qwen**：通义千问系列

### 编码器-解码器（Encoder-Decoder）
- **T5**：文本到文本转换
- **BART**：序列到序列预训练
- **mT5**：多语言 T5

## 💡 实践要点

### 训练技巧
1. **学习率预热**：前几个 epoch 使用较小的学习率
2. **标签平滑**：防止模型过度自信
3. **Dropout**：防止过拟合
4. **梯度裁剪**：防止梯度爆炸

### 推理优化
1. **KV Cache**：缓存键值对，加速生成
2. **Beam Search**：集束搜索，提高生成质量
3. **Top-k/Top-p 采样**：控制生成多样性

### 常见问题
1. **内存占用**：注意力矩阵的平方复杂度
2. **长序列处理**：使用稀疏注意力或线性注意力
3. **推理速度**：使用 KV Cache 和批处理
