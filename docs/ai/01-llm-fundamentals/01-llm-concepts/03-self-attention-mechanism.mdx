# Self-Attention 机制详解

> **版本**：v1.0  
> **最后更新**：2026-04-14

## 📖 概述

Self-Attention（自注意力）是 Transformer 架构的核心组件，它允许序列中的每个位置关注其他所有位置，从而捕捉长距离依赖关系。这是 Transformer 相比 RNN/LSTM 的关键创新。

## 🎯 核心思想

### 什么是 Self-Attention？

Self-Attention 机制通过计算序列中每个元素与其他所有元素之间的相关性，为每个元素生成一个加权表示。

**直观理解**：
- 当处理句子 "The animal didn't cross the street because it was too tired" 时
- 单词 "it" 应该关注 "animal" 而不是 "street"
- Self-Attention 机制能够自动学习这种依赖关系

### 与传统注意力的区别

| 特性 | 传统注意力 | Self-Attention |
|------|-----------|----------------|
| 查询来源 | 解码器的隐藏状态 | 序列本身 |
| 键值来源 | 编码器的隐藏状态 | 序列本身 |
| 应用场景 | 编码器-解码器 | 序列内部 |

## 🔢 数学原理

### 基本公式

给定查询（Query）、键（Key）、值（Value）矩阵：

```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```

其中：
- `Q`：查询矩阵，形状为 `(n, d_k)`
- `K`：键矩阵，形状为 `(m, d_k)`
- `V`：值矩阵，形状为 `(m, d_v)`
- `d_k`：键的维度
- `n`：查询数量
- `m`：键值对数量

### 计算步骤

#### 步骤 1：计算注意力分数

```
scores = QK^T
```

- 查询和键的点积
- 衡量查询和键之间的相似度
- 结果形状：`(n, m)`

#### 步骤 2：缩放

```
scaled_scores = scores / √d_k
```

- 除以 `√d_k` 防止点积过大
- 避免 softmax 进入饱和区
- 保持梯度稳定

#### 步骤 3：Softmax 归一化

```
attention_weights = softmax(scaled_scores)
```

- 将分数转换为概率分布
- 每行的和为 1
- 结果形状：`(n, m)`

#### 步骤 4：加权求和

```
output = attention_weights × V
```

- 使用注意力权重对值进行加权求和
- 结果形状：`(n, d_v)`

### 完整计算流程

```python
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(query, key, value, mask=None):
    """
    缩放点积注意力
    
    参数:
        query: (batch_size, n_heads, seq_len, d_k)
        key: (batch_size, n_heads, seq_len, d_k)
        value: (batch_size, n_heads, seq_len, d_v)
        mask: (batch_size, 1, 1, seq_len) 或 (batch_size, 1, seq_len, seq_len)
    
    返回:
        output: (batch_size, n_heads, seq_len, d_v)
        attention_weights: (batch_size, n_heads, seq_len, seq_len)
    """
    d_k = query.size(-1)
    
    # 1. 计算注意力分数
    scores = torch.matmul(query, key.transpose(-2, -1))
    
    # 2. 缩放
    scores = scores / torch.sqrt(torch.tensor(d_k, dtype=torch.float32))
    
    # 3. 应用掩码（可选）
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)
    
    # 4. Softmax 归一化
    attention_weights = F.softmax(scores, dim=-1)
    
    # 5. 加权求和
    output = torch.matmul(attention_weights, value)
    
    return output, attention_weights
```

## 🧩 多头注意力（Multi-Head Attention）

### 为什么需要多头注意力？

单个注意力头可能无法捕捉所有类型的依赖关系：
- 有些头关注语法结构
- 有些头关注语义关系
- 有些头关注指代关系

多头注意力允许模型从不同的表示子空间学习信息。

### 架构

```
输入 X
    ↓
线性投影 → Q₁, K₁, V₁  ──→ Attention₁ → O₁
线性投影 → Q₂, K₂, V₂  ──→ Attention₂ → O₂
...
线性投影 → Qₕ, Kₕ, Vₕ  ──→ Attentionₕ → Oₕ
    ↓
拼接 [O₁, O₂, ..., Oₕ]
    ↓
线性投影 → 输出
```

### 数学表示

```
MultiHead(Q, K, V) = Concat(head₁, ..., headₕ)W^O

其中 head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)
```

参数：
- `W_i^Q`：第 i 个头的查询投影矩阵
- `W_i^K`：第 i 个头的键投影矩阵
- `W_i^V`：第 i 个头的值投影矩阵
- `W^O`：输出投影矩阵
- `h`：注意力头数

### 维度关系

假设：
- `d_model`：模型维度
- `h`：注意力头数
- `d_k = d_v = d_model / h`：每个头的维度

则：
- `Q, K, V`：`(seq_len, d_model)`
- `Q_i, K_i, V_i`：`(seq_len, d_k)`
- `head_i`：`(seq_len, d_v)`
- `Concat(head₁, ..., headₕ)`：`(seq_len, d_model)`
- `输出`：`(seq_len, d_model)`

### 代码实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads, dropout=0.1):
        """
        多头注意力层
        
        参数:
            d_model: 模型维度
            n_heads: 注意力头数
            dropout: Dropout 比率
        """
        super().__init__()
        assert d_model % n_heads == 0, "d_model 必须能被 n_heads 整除"
        
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        
        # 线性投影层
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
        
        self.dropout = nn.Dropout(dropout)
        
    def forward(self, query, key, value, mask=None):
        """
        前向传播
        
        参数:
            query: (batch_size, seq_len, d_model)
            key: (batch_size, seq_len, d_model)
            value: (batch_size, seq_len, d_model)
            mask: (batch_size, 1, seq_len, seq_len)
        
        返回:
            output: (batch_size, seq_len, d_model)
            attention_weights: (batch_size, n_heads, seq_len, seq_len)
        """
        batch_size = query.size(0)
        
        # 1. 线性投影
        Q = self.W_q(query)  # (batch_size, seq_len, d_model)
        K = self.W_k(key)    # (batch_size, seq_len, d_model)
        V = self.W_v(value)  # (batch_size, seq_len, d_model)
        
        # 2. 重塑为多头
        Q = Q.view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        K = K.view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        # 形状: (batch_size, n_heads, seq_len, d_k)
        
        # 3. 计算注意力
        output, attention_weights = scaled_dot_product_attention(Q, K, V, mask)
        
        # 4. 拼接多头
        output = output.transpose(1, 2).contiguous()
        output = output.view(batch_size, -1, self.d_model)
        # 形状: (batch_size, seq_len, d_model)
        
        # 5. 输出投影
        output = self.W_o(output)
        
        return output, attention_weights
```

## 🎭 不同类型的注意力

### 1. 自注意力（Self-Attention）

```
Q = K = V = X
```

- 查询、键、值都来自同一个序列
- 用于编码器和解码器的自注意力层

### 2. 掩码自注意力（Masked Self-Attention）

```
Q = K = V = X
应用因果掩码
```

- 防止位置关注未来的位置
- 用于解码器的自注意力层
- 确保自回归生成

### 3. 编码器-解码器注意力（Cross-Attention）

```
Q = X_decoder
K = V = X_encoder
```

- 查询来自解码器
- 键值来自编码器
- 建立输入和输出之间的对齐

### 掩码实现

```python
def create_causal_mask(seq_len):
    """
    创建因果掩码
    
    参数:
        seq_len: 序列长度
    
    返回:
        mask: (seq_len, seq_len)
    """
    mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1)
    mask = mask.masked_fill(mask == 1, float('-inf'))
    return mask

# 使用示例
seq_len = 5
mask = create_causal_mask(seq_len)
"""
输出:
tensor([[0., -inf, -inf, -inf, -inf],
        [0.,   0., -inf, -inf, -inf],
        [0.,   0.,   0., -inf, -inf],
        [0.,   0.,   0.,   0., -inf],
        [0.,   0.,   0.,   0.,   0.]])
"""
```

## 🔍 注意力模式分析

### 常见注意力模式

1. **语法注意力**
   - 关注词性相同的词
   - 关注主谓宾关系

2. **语义注意力**
   - 关注语义相关的词
   - 关注同义词、反义词

3. **位置注意力**
   - 关注相邻的词
   - 关注固定距离的词

4. **指代注意力**
   - 代词关注其指代的实体
   - 解决指代消解问题

### 不同头学到的模式

研究表明，不同的注意力头会学习到不同的模式：
- 有些头关注语法结构
- 有些头关注语义关系
- 有些头关注位置信息
- 有些头几乎没有明确的作用

## ⚡ 优化技巧

### 1. Flash Attention

- 减少 GPU 内存访问
- 加速注意力计算
- 支持更长的序列

### 2. 稀疏注意力

- 只计算部分位置的注意力
- 降低计算复杂度
- 适用于超长序列

### 3. 线性注意力

- 将注意力复杂度从 O(n²) 降到 O(n)
- 使用核函数近似
- 适合超长序列

### 4. KV Cache

- 缓存键值对
- 避免重复计算
- 加速自回归生成

```python
# KV Cache 示例
class KVCache:
    def __init__(self, n_heads, d_k, max_len):
        self.n_heads = n_heads
        self.d_k = d_k
        self.max_len = max_len
        
        self.k_cache = torch.zeros(n_heads, max_len, d_k)
        self.v_cache = torch.zeros(n_heads, max_len, d_k)
        self.current_len = 0
    
    def update(self, k, v):
        """
        更新缓存
        
        参数:
            k: (n_heads, seq_len, d_k)
            v: (n_heads, seq_len, d_k)
        """
        seq_len = k.size(1)
        self.k_cache[:, self.current_len:self.current_len+seq_len, :] = k
        self.v_cache[:, self.current_len:self.current_len+seq_len, :] = v
        self.current_len += seq_len
        
        return self.k_cache[:, :self.current_len, :], self.v_cache[:, :self.current_len, :]
```

## 💡 实践建议

### 超参数选择

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| `n_heads` | 8/12/16 | 头数，通常为 4 的倍数 |
| `d_k` | 64/128 | 每个头的维度 |
| `dropout` | 0.1 | 注意力权重的 dropout |

### 常见问题

1. **注意力权重过于平滑**
   - 检查缩放因子是否正确
   - 考虑增加温度参数

2. **注意力权重过于尖锐**
   - 可能导致过拟合
   - 考虑增加 dropout

3. **内存不足**
   - 使用梯度检查点
   - 使用 Flash Attention
   - 减少序列长度
