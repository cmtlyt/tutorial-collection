# LLM 应用开发

> **版本**：v1.2  
> **最后更新**：2026-04-30

## 📖 概述

LLM 应用开发是将大语言模型集成到实际应用中的过程。本章节介绍主流的 LLM 应用开发框架和工具，包括 LangChain、LlamaIndex 等，帮助开发者快速构建智能应用。

## 🏗️ LangChain 基础

### 什么是 LangChain

LangChain 是一个用于构建 LLM 应用的开源框架，提供了丰富的组件和工具，简化了与 LLM 的交互过程。

### 核心概念

#### 1. Chains（链）

Chain 是将多个组件（如 LLM、工具、提示词）串联在一起的工作流。

#### 2. Agents（智能体）

Agent 是能够自主决策、使用工具完成复杂任务的智能系统。

#### 3. Memory（记忆）

Memory 用于在对话中维护历史信息，实现上下文感知。

#### 4. Tools（工具）

Tools 是 LLM 可以调用的外部功能，如搜索、计算、数据库查询等。

### Chains（链）详解

#### 简单链

```javascript
import { ChatOpenAI } from '@langchain/openai';
import { ChatPromptTemplate } from '@langchain/core/prompts';
import { StringOutputParser } from '@langchain/core/output_parsers';

// 创建 LLM
const llm = new ChatOpenAI({ model: 'gpt-4o' });

// 创建提示词模板
const prompt = ChatPromptTemplate.fromTemplate(
  '将以下内容翻译成{language}：{text}'
);

// 创建输出解析器
const outputParser = new StringOutputParser();

// 构建链
const chain = prompt.pipe(llm).pipe(outputParser);

// 运行链
const result = await chain.invoke({
  language: '英文',
  text: '你好，世界！',
});

console.log(result); // Hello, World!
```

#### 顺序链

```javascript
import { ChatOpenAI } from '@langchain/openai';
import { ChatPromptTemplate } from '@langchain/core/prompts';
import { StringOutputParser } from '@langchain/core/output_parsers';

// LLM 实例
const llm = new ChatOpenAI({ model: 'gpt-4o' });

// 第一步：总结
const summarizePrompt = ChatPromptTemplate.fromTemplate(
  '请总结以下内容：\n\n{content}'
);
const summarizeChain = summarizePrompt.pipe(llm).pipe(new StringOutputParser());

// 第二步：翻译
const translatePrompt = ChatPromptTemplate.fromTemplate(
  '将以下内容翻译成{language}：\n\n{summary}'
);
const translateChain = translatePrompt.pipe(llm).pipe(new StringOutputParser());

// 组合成顺序链
const fullChain = summarizeChain.pipe((summary) => 
  translateChain.invoke({ summary, language: '英文' })
);

// 运行
const result = await fullChain.invoke({
  content: '人工智能是计算机科学的一个分支...'
});

console.log(result);
```

### Memory（记忆）系统

#### 最简单的上下文记忆

最简单的多轮对话可以从消息数组开始：每轮调用前传入已有历史，调用后把用户消息和模型回复追加到数组中。

```javascript
import { ChatOpenAI } from '@langchain/openai';

const llm = new ChatOpenAI({
  model: 'gpt-4o',
  temperature: 0.7,
});

const messages = [
  ['system', '你是一个专业的程序员。'],
  ['user', '如何学习 JavaScript？'],
];

const response1 = await llm.invoke(messages);
console.log(response1.content);

messages.push(['assistant', response1.content]);
messages.push(['user', '请根据我刚才的问题，给一个 3 周学习计划。']);

const response2 = await llm.invoke(messages);
console.log(response2.content);
```

#### LangGraph 短期记忆

当对话需要交给 Agent 管理时，可以使用 LangGraph 的 checkpointer。相同 `thread_id` 下的多次调用会共享同一份会话状态。

```javascript
import { createAgent } from 'langchain';
import { MemorySaver } from '@langchain/langgraph';

const checkpointer = new MemorySaver();

const agent = createAgent({
  model: 'openai:gpt-4o',
  tools: [],
  systemPrompt: '你是一个友好的助手。',
  checkpointer,
});

const config = {
  configurable: {
    thread_id: 'user-zhangsan-session-1',
  },
};

await agent.invoke(
  {
    messages: [{ role: 'user', content: '我叫张三。' }],
  },
  config
);

const result = await agent.invoke(
  {
    messages: [{ role: 'user', content: '我叫什么名字？' }],
  },
  config
);

console.log(result.messages.at(-1).content);
```

#### 长对话上下文管理

长对话不要无限追加历史消息。常见做法是只保留最近消息、按 token 截断，或把较早对话总结成一条系统上下文。

```javascript
import { ChatOpenAI } from '@langchain/openai';

const llm = new ChatOpenAI({ model: 'gpt-4o-mini' });

function keepRecentMessages(messages, maxMessages) {
  const systemMessages = messages.filter(([role]) => role === 'system');
  const chatMessages = messages.filter(([role]) => role !== 'system');
  return [...systemMessages, ...chatMessages.slice(-maxMessages)];
}

const messages = [
  ['system', '你是一个专业的技术顾问。'],
  ['user', '什么是 React？'],
  ['assistant', 'React 是一个用于构建用户界面的 JavaScript 库。'],
  ['user', '它和 Vue 有什么区别？'],
];

const compactMessages = keepRecentMessages(messages, 3);
const response = await llm.invoke(compactMessages);

console.log(response.content);
```

#### 自定义工具

```javascript
import { DynamicStructuredTool } from '@langchain/core/tools';
import { z } from 'zod';

// 创建自定义工具
const weatherTool = new DynamicStructuredTool({
  name: 'get_weather',
  description: '获取指定城市的天气信息',
```

### Agents（智能体）

#### 使用 createAgent

LangChain v1 中可以使用 `createAgent` 创建 Agent。它在 LangGraph 之上封装了常见的状态管理、持久化和工具调用流程。

```javascript
import { createAgent, tool } from 'langchain';
import { z } from 'zod';

const stockValueTool = tool(
  async ({ price, shares }) => {
    return `${shares} 股的总价值是 ${(price * shares).toFixed(2)} 美元。`;
  },
  {
    name: 'stock_value_calculator',
    description: '根据股价和股数计算股票总价值。',
    schema: z.object({
      price: z.number().positive().describe('每股价格'),
      shares: z.number().int().positive().describe('持有股数'),
    }),
  }
);

const agent = createAgent({
  model: 'openai:gpt-4o',
  tools: [stockValueTool],
  systemPrompt: '你是一个会使用工具解决问题的助手。',
});

const result = await agent.invoke({
  messages: [
    {
      role: 'user',
      content: '如果我有 100 股，每股 12.5 美元，总价值是多少？',
    },
  ],
});

console.log(result.messages.at(-1).content);
```

Agent 的核心循环是：读取用户目标，判断是否需要工具，调用工具获得观察结果，再生成最终回答。复杂 Agent 建议用 LangGraph 管理状态、分支、持久化和人工确认节点。

## 📚 LlamaIndex

### 什么是 LlamaIndex

LlamaIndex 是专注于数据索引和检索的框架，特别适合构建 RAG（检索增强生成）应用。LlamaIndex.TS 是其 TypeScript 版本，为 JavaScript/TypeScript 开发者提供了完整的支持。

### 核心概念

#### 1. Documents（文档）
原始数据源，可以是 PDF、网页、数据库等。

#### 2. Nodes（节点）
文档的分割单元，便于检索和处理。

#### 3. Index（索引）
对节点进行索引，支持高效的检索。

#### 4. Query Engine（查询引擎）
处理用户查询并生成答案。

### 快速开始

```javascript
import { Document, VectorStoreIndex } from 'llamaindex';

const documents = [
  new Document({
    text: '机器学习是一类让计算机从数据中学习规律的方法。',
    id_: 'machine-learning-intro',
  }),
];

const index = await VectorStoreIndex.fromDocuments(documents);
const queryEngine = index.asQueryEngine();

const response = await queryEngine.query({
  query: '什么是机器学习？',
});

console.log(response.toString());
```

**注意**：LlamaIndex.TS 使用模块化包结构，需要安装基础包和特定提供商包：

### LangGraph

LangGraph 是 LangChain 团队开发的状态机框架，用于构建复杂的多 Agent 系统。

**安装**：

```bash
pnpm add @langchain/langgraph @langchain/openai
```

**使用示例**：

```javascript
import { StateGraph, Annotation } from '@langchain/langgraph';
import { ChatOpenAI } from '@langchain/openai';

// 定义状态
const StateAnnotation = Annotation.Root({
  messages: Annotation({
    reducer: (x, y) => x.concat(y),
    default: () => [],
  }),
});

// 定义节点
const agentNode = async (state) => {
  const llm = new ChatOpenAI({ model: 'gpt-4o' });
  const response = await llm.invoke(state.messages);
  return { messages: [response] };
};

// 创建工作流
const workflow = new StateGraph(StateAnnotation);

// 添加节点
workflow.addNode('agent', agentNode);

// 设置入口点
workflow.setEntryPoint('agent');

// 添加边
workflow.addEdge('agent', '__end__');

// 编译图
const app = workflow.compile();

// 运行
const result = await app.invoke({
  messages: [{ role: 'user', content: '你好' }],
});

console.log(result);
```

## 🎯 最佳实践

### 1. Prompt 优化

- 使用清晰、具体的指令
- 提供示例（Few-shot）
- 明确输出格式
- 控制输出长度

### 2. 错误处理

```javascript
import { ChatOpenAI } from '@langchain/openai';

const llm = new ChatOpenAI({ model: 'gpt-4o-mini' });

async function invokeWithRetry(llm, messages, maxRetries = 2) {
  for (let attempt = 0; attempt <= maxRetries; attempt += 1) {
    try {
      const response = await llm.invoke(messages);
      return response.content;
    } catch (error) {
      if (error.status !== 429 || attempt === maxRetries) {
        throw error;
      }

      await new Promise((resolve) => setTimeout(resolve, 1000 * (attempt + 1)));
    }
  }
}

const content = await invokeWithRetry(llm, [
  ['user', '解释什么是上下文窗口。'],
]);

console.log(content);
```

### 3. 成本优化

- 根据任务复杂度选择更小的模型（如 mini 版本）
- 压缩上下文
- 使用缓存
- 批处理请求

### 4. 性能优化

- 使用流式输出
- 并行处理
- 缓存常见查询
- 使用向量数据库加速检索

### 5. 安全性

- 验证用户输入
- 限制工具访问权限
- 实施速率限制
- 记录和监控
