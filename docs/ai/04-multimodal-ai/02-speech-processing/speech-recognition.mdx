# 语音识别（ASR）

> **版本**：v1.0  
> **最后更新**：2026-04-15

## 📖 概述

自动语音识别（Automatic Speech Recognition，ASR）是将语音信号转换为文本的技术。随着深度学习的发展，ASR 技术已经取得了巨大进步，从传统的声学模型到现在的端到端模型，识别准确率和鲁棒性都得到了显著提升。本章节将详细介绍主流的 ASR 模型及其应用。

## 🎯 为什么需要语音识别？

### 从语音到文本

1. **自然交互**
   - 最自然的交流方式
   - 解放双手
   - 提升用户体验

2. **广泛应用**
   - 智能助手
   - 会议记录
   - 客服系统
   - 无障碍辅助

3. **技术演进**
   - 从 GMM-HMM 到深度学习
   - 从混合模型到端到端
   - 从单一语言到多语言

## 🔢 主要 ASR 模型

### 1. Whisper

#### 核心思想

Whisper 是 OpenAI 于 2022 年推出的开源语音识别模型，通过在大规模弱监督数据上训练，实现了强大的多语言识别能力和鲁棒性。

#### 技术特点

1. **弱监督学习**
   - 使用 68 万小时的多语言音频数据
   - 包含不同质量、不同环境的声音
   - 无需人工标注的转录文本

2. **端到端架构**
   - Transformer 编码器-解码器架构
   - 统一处理语音识别和翻译
   - 支持多种任务

3. **多语言支持**
   - 支持 99 种语言
   - 零样本跨语言迁移
   - 中英文表现优异

#### 代码实现

```javascript
import { pipeline } from '@xenova/transformers';

class WhisperASR {
  constructor() {
    this.model = null;
  }

  /**
   * 加载 Whisper 模型
   */
  async loadModel() {
    // 使用 Hugging Face 的 Whisper 模型
    this.model = await pipeline(
      'automatic-speech-recognition',
      'Xenova/whisper-tiny'
    );
  }

  /**
   * 语音识别
   * 
   * @param {string|ArrayBuffer} audio - 音频文件路径或音频数据
   * @param {Object} options - 识别选项
   * @returns {Promise<Object>} - 识别结果
   */
  async transcribe(audio, options = {}) {
    if (!this.model) {
      await this.loadModel();
    }

    const {
      language = 'chinese',
      task = 'transcribe',
      chunkLength = 30,
      strideLength = 5
    } = options;

    // 识别语音
    const result = await this.model(audio, {
      language: language,
      task: task,
      chunk_length_s: chunkLength,
      stride_length_s: strideLength
    });

    return {
      text: result.text,
      chunks: this.parseChunks(result)
    };
  }

  /**
   * 语音翻译
   * 
   * @param {string|ArrayBuffer} audio - 音频文件路径或音频数据
   * @param {string} sourceLanguage - 源语言
   * @param {string} targetLanguage - 目标语言
   * @returns {Promise<Object>} - 翻译结果
   */
  async translate(audio, sourceLanguage, targetLanguage) {
    if (!this.model) {
      await this.loadModel();
    }

    const result = await this.model(audio, {
      language: sourceLanguage,
      task: 'translate'
    });

    return {
      text: result.text,
      sourceLanguage: sourceLanguage,
      targetLanguage: targetLanguage
    };
  }

  /**
   * 带时间戳的识别
   * 
   * @param {string|ArrayBuffer} audio - 音频文件路径或音频数据
   * @returns {Promise<Object>} - 带时间戳的识别结果
   */
  async transcribeWithTimestamps(audio) {
    if (!this.model) {
      await this.loadModel();
    }

    const result = await this.model(audio, {
      return_timestamps: true
    });

    return {
      text: result.text,
      segments: this.parseSegments(result)
    };
  }

  /**
   * 解析识别块
   * 
   * @param {Object} result - 识别结果
   * @returns {Array} - 识别块列表
   */
  parseChunks(result) {
    if (!result.chunks) {
      return [];
    }

    return result.chunks.map(chunk => ({
      text: chunk.text,
      timestamp: chunk.timestamp,
      confidence: chunk.confidence || 0.95
    }));
  }

  /**
   * 解析识别段落
   * 
   * @param {Object} result - 识别结果
   * @returns {Array} - 段落列表
   */
  parseSegments(result) {
    if (!result.segments) {
      return [];
    }

    return result.segments.map(segment => ({
      id: segment.id,
      text: segment.text,
      start: segment.start,
      end: segment.end,
      confidence: segment.confidence || 0.95
    }));
  }

  /**
   * 实时语音识别
   * 
   * @param {MediaStream} stream - 音频流
   * @param {Function} onResult - 结果回调
   * @param {Object} options - 识别选项
   * @returns {Promise<void>}
   */
  async transcribeRealtime(stream, onResult, options = {}) {
    const {
      chunkDuration = 2000,
      overlapDuration = 500
    } = options;

    const audioContext = new AudioContext({ sampleRate: 16000 });
    const source = audioContext.createMediaStreamSource(stream);
    const processor = audioContext.createScriptProcessor(4096, 1, 1);

    let audioBuffer = [];
    let lastTranscribedTime = 0;

    processor.onaudioprocess = async (event) => {
      const inputData = event.inputBuffer.getChannelData(0);
      audioBuffer.push(...inputData);

      const currentTime = Date.now();
      const elapsed = currentTime - lastTranscribedTime;

      if (elapsed >= chunkDuration) {
        const audioData = new Float32Array(audioBuffer);
        
        try {
          const result = await this.transcribe(audioData, options);
          onResult(result);
        } catch (error) {
          console.error('识别错误:', error);
        }

        // 保留重叠部分
        const overlapSamples = Math.floor(
          (overlapDuration / 1000) * audioContext.sampleRate
        );
        audioBuffer = audioBuffer.slice(-overlapSamples);
        
        lastTranscribedTime = currentTime;
      }
    };

    source.connect(processor);
    processor.connect(audioContext.destination);
  }
}

// 使用示例
async function example() {
  const whisper = new WhisperASR();
  
  // 语音识别
  const result = await whisper.transcribe('audio.wav', {
    language: 'chinese',
    chunkLength: 30
  });
  
  console.log('识别文本:', result.text);
  console.log('识别块:', result.chunks);
  
  // 语音翻译
  const translation = await whisper.translate(
    'audio.wav',
    'chinese',
    'english'
  );
  
  console.log('翻译结果:', translation.text);
  
  // 带时间戳的识别
  const timestamped = await whisper.transcribeWithTimestamps('audio.wav');
  console.log('带时间戳的识别:', timestamped.segments);
}
```

### 2. SpeechRecognition

#### 核心思想

Web Speech API 的 SpeechRecognition 接口是浏览器内置的语音识别功能，提供简单易用的语音转文本能力。

#### 技术特点

1. **浏览器原生支持**
   - 无需额外安装
   - 跨平台兼容
   - 实时识别

2. **简单易用**
   - 简洁的 API 设计
   - 事件驱动
   - 易于集成

3. **多浏览器支持**
   - Chrome、Edge、Safari
   - 移动端支持
   - 渐进增强

#### 代码实现

```javascript
class WebSpeechRecognition {
  constructor(options = {}) {
    const {
      language = 'zh-CN',
      continuous = false,
      interimResults = false,
      maxAlternatives = 1
    } = options;

    // 检查浏览器支持
    if (!('webkitSpeechRecognition' in window) && !('SpeechRecognition' in window)) {
      throw new Error('浏览器不支持语音识别');
    }

    const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
    
    this.recognition = new SpeechRecognition();
    this.recognition.lang = language;
    this.recognition.continuous = continuous;
    this.recognition.interimResults = interimResults;
    this.recognition.maxAlternatives = maxAlternatives;
    
    this.isListening = false;
    this.callbacks = {};
  }

  /**
   * 开始识别
   * 
   * @returns {Promise<void>}
   */
  start() {
    return new Promise((resolve, reject) => {
      if (this.isListening) {
        reject(new Error('正在识别中'));
        return;
      }

      this.recognition.onstart = () => {
        this.isListening = true;
        this.trigger('start', null);
        resolve();
      };

      this.recognition.onend = () => {
        this.isListening = false;
        this.trigger('end', null);
      };

      this.recognition.onresult = (event) => {
        const results = this.parseResults(event);
        this.trigger('result', results);
      };

      this.recognition.onerror = (event) => {
        this.isListening = false;
        this.trigger('error', event.error);
        reject(new Error(event.error));
      };

      try {
        this.recognition.start();
      } catch (error) {
        reject(error);
      }
    });
  }

  /**
   * 停止识别
   * 
   * @returns {Promise<void>}
   */
  stop() {
    return new Promise((resolve, reject) => {
      if (!this.isListening) {
        resolve();
        return;
      }

      this.recognition.onend = () => {
        this.isListening = false;
        resolve();
      };

      this.recognition.onerror = (event) => {
        this.isListening = false;
        reject(new Error(event.error));
      };

      try {
        this.recognition.stop();
      } catch (error) {
        reject(error);
      }
    });
  }

  /**
   * 解析识别结果
   * 
   * @param {SpeechRecognitionEvent} event - 识别事件
   * @returns {Object} - 解析结果
   */
  parseResults(event) {
    const results = [];
    
    for (let i = event.resultIndex; i < event.results.length; i++) {
      const result = event.results[i];
      const alternatives = [];
      
      for (let j = 0; j < result.length; j++) {
        alternatives.push({
          transcript: result[j].transcript,
          confidence: result[j].confidence
        });
      }
      
      results.push({
        isFinal: result.isFinal,
        alternatives: alternatives
      });
    }
    
    return results;
  }

  /**
   * 添加事件监听器
   * 
   * @param {string} event - 事件名称
   * @param {Function} callback - 回调函数
   */
  on(event, callback) {
    if (!this.callbacks[event]) {
      this.callbacks[event] = [];
    }
    this.callbacks[event].push(callback);
  }

  /**
   * 移除事件监听器
   * 
   * @param {string} event - 事件名称
   * @param {Function} callback - 回调函数
   */
  off(event, callback) {
    if (!this.callbacks[event]) {
      return;
    }
    
    const index = this.callbacks[event].indexOf(callback);
    if (index > -1) {
      this.callbacks[event].splice(index, 1);
    }
  }

  /**
   * 触发事件
   * 
   * @param {string} event - 事件名称
   * @param {*} data - 事件数据
   */
  trigger(event, data) {
    if (!this.callbacks[event]) {
      return;
    }
    
    this.callbacks[event].forEach(callback => {
      callback(data);
    });
  }

  /**
   * 获取识别状态
   * 
   * @returns {boolean} - 是否正在识别
   */
  getStatus() {
    return this.isListening;
  }

  /**
   * 更新语言设置
   * 
   * @param {string} language - 语言代码
   */
  setLanguage(language) {
    this.recognition.lang = language;
  }

  /**
   * 更新连续识别设置
   * 
   * @param {boolean} continuous - 是否连续识别
   */
  setContinuous(continuous) {
    this.recognition.continuous = continuous;
  }

  /**
   * 更新临时结果设置
   * 
   * @param {boolean} interimResults - 是否返回临时结果
   */
  setInterimResults(interimResults) {
    this.recognition.interimResults = interimResults;
  }
}

// 使用示例
async function example() {
  const recognition = new WebSpeechRecognition({
    language: 'zh-CN',
    continuous: true,
    interimResults: true
  });
  
  // 监听事件
  recognition.on('start', () => {
    console.log('开始识别...');
  });
  
  recognition.on('result', (results) => {
    results.forEach(result => {
      if (result.isFinal) {
        console.log('最终结果:', result.alternatives[0].transcript);
      } else {
        console.log('临时结果:', result.alternatives[0].transcript);
      }
    });
  });
  
  recognition.on('error', (error) => {
    console.error('识别错误:', error);
  });
  
  recognition.on('end', () => {
    console.log('识别结束');
  });
  
  // 开始识别
  await recognition.start();
  
  // 等待用户说话...
  
  // 停止识别
  await recognition.stop();
}
```

### 3. 中文 ASR 模型

#### 核心思想

针对中文语音识别的特殊性，多个团队开发了专门的中文 ASR 模型，在中文识别准确率、方言支持、实时性等方面进行了优化。

#### 主要模型

##### 3.1 WeNet

WeNet 是由科大讯飞和清华大学联合开发的开源端到端语音识别工具包，专注于生产级应用。

**技术特点：**
- 端到端架构（Conformer + Transformer）
- 支持流式和非流式识别
- 多平台支持（服务器、移动端、嵌入式）
- 中英文混合识别

##### 3.2 Paraformer

Paraformer 是阿里巴巴达摩院推出的非自回归端到端语音识别模型。

**技术特点：**
- 非自回归架构，推理速度快
- 预测器（Predictor）机制
- 多语言支持
- 鲁棒性强

##### 3.3 FunASR

FunASR 是阿里巴巴达摩院开源的语音识别工具包。

**技术特点：**
- 多种模型架构
- 语音端点检测（VAD）
- 说话人分离（Diarization）
- 语音活动检测（VAD）

#### 代码实现

```javascript
class ChineseASR {
  constructor(modelType = 'wenet') {
    this.modelType = modelType;
    this.model = null;
  }

  /**
   * 加载中文 ASR 模型
   */
  async loadModel() {
    switch (this.modelType) {
      case 'wenet':
        this.model = await this.loadWeNet();
        break;
      case 'paraformer':
        this.model = await this.loadParaformer();
        break;
      case 'funasr':
        this.model = await this.loadFunASR();
        break;
      default:
        throw new Error(`不支持的模型类型: ${this.modelType}`);
    }
  }

  /**
   * 加载 WeNet 模型
   * 
   * @returns {Promise<Object>} - WeNet 模型
   */
  async loadWeNet() {
    // 使用 Hugging Face 的 WeNet 模型
    const model = await pipeline(
      'automatic-speech-recognition',
      'Wenet/wenet-chinese'
    );
    
    return {
      type: 'wenet',
      model: model
    };
  }

  /**
   * 加载 Paraformer 模型
   * 
   * @returns {Promise<Object>} - Paraformer 模型
   */
  async loadParaformer() {
    // 使用 Hugging Face 的 Paraformer 模型
    const model = await pipeline(
      'automatic-speech-recognition',
      'Alibaba-Damo-AI-Lab/paraformer-zh'
    );
    
    return {
      type: 'paraformer',
      model: model
    };
  }

  /**
   * 加载 FunASR 模型
   * 
   * @returns {Promise<Object>} - FunASR 模型
   */
  async loadFunASR() {
    // 使用 Hugging Face 的 FunASR 模型
    const model = await pipeline(
      'automatic-speech-recognition',
      'FunASR/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch'
    );
    
    return {
      type: 'funasr',
      model: model
    };
  }

  /**
   * 语音识别
   * 
   * @param {string|ArrayBuffer} audio - 音频文件路径或音频数据
   * @param {Object} options - 识别选项
   * @returns {Promise<Object>} - 识别结果
   */
  async transcribe(audio, options = {}) {
    if (!this.model) {
      await this.loadModel();
    }

    const {
      language = 'chinese',
      samplingRate = 16000,
      chunkLength = 30
    } = options;

    // 预处理音频
    const processedAudio = await this.preprocessAudio(audio, {
      samplingRate: samplingRate
    });

    // 识别语音
    const result = await this.model.model(processedAudio, {
      language: language,
      chunk_length_s: chunkLength
    });

    return {
      text: result.text,
      model: this.model.type,
      confidence: this.calculateConfidence(result)
    };
  }

  /**
   * 实时语音识别
   * 
   * @param {MediaStream} stream - 音频流
   * @param {Function} onResult - 结果回调
   * @param {Object} options - 识别选项
   * @returns {Promise<void>}
   */
  async transcribeRealtime(stream, onResult, options = {}) {
    const {
      chunkDuration = 2000,
      overlapDuration = 500,
      samplingRate = 16000
    } = options;

    const audioContext = new AudioContext({ sampleRate: samplingRate });
    const source = audioContext.createMediaStreamSource(stream);
    const processor = audioContext.createScriptProcessor(4096, 1, 1);

    let audioBuffer = [];
    let lastTranscribedTime = 0;

    processor.onaudioprocess = async (event) => {
      const inputData = event.inputBuffer.getChannelData(0);
      audioBuffer.push(...inputData);

      const currentTime = Date.now();
      const elapsed = currentTime - lastTranscribedTime;

      if (elapsed >= chunkDuration) {
        const audioData = new Float32Array(audioBuffer);
        
        try {
          const result = await this.transcribe(audioData, options);
          onResult(result);
        } catch (error) {
          console.error('识别错误:', error);
        }

        // 保留重叠部分
        const overlapSamples = Math.floor(
          (overlapDuration / 1000) * audioContext.sampleRate
        );
        audioBuffer = audioBuffer.slice(-overlapSamples);
        
        lastTranscribedTime = currentTime;
      }
    };

    source.connect(processor);
    processor.connect(audioContext.destination);
  }

  /**
   * 预处理音频
   * 
   * @param {string|ArrayBuffer} audio - 音频数据
   * @param {Object} options - 预处理选项
   * @returns {Promise<ArrayBuffer>} - 处理后的音频
   */
  async preprocessAudio(audio, options) {
    const { samplingRate } = options;

    // 如果是文件路径，需要先加载
    if (typeof audio === 'string') {
      const response = await fetch(audio);
      audio = await response.arrayBuffer();
    }

    // 重采样到目标采样率
    const audioContext = new AudioContext({ sampleRate: samplingRate });
    const audioBuffer = await audioContext.decodeAudioData(audio);
    
    // 转换为单声道
    const channelData = audioBuffer.getChannelData(0);
    
    return channelData;
  }

  /**
   * 计算置信度
   * 
   * @param {Object} result - 识别结果
   * @returns {number} - 置信度
   */
  calculateConfidence(result) {
    // 基于识别结果的多个因素计算置信度
    if (!result || !result.text) {
      return 0.0;
    }

    let confidence = 0.95; // 基础置信度

    // 文本长度因素
    const textLength = result.text.length;
    if (textLength > 0 && textLength < 10) {
      confidence *= 0.9; // 短文本可能不够准确
    } else if (textLength >= 10 && textLength < 50) {
      confidence *= 1.0; // 中等长度文本
    } else {
      confidence *= 0.95; // 长文本可能有累积误差
    }

    // 文本质量因素
    const hasSpecialChars = /[^\u4e00-\u9fa5a-zA-Z0-9\s]/.test(result.text);
    if (hasSpecialChars) {
      confidence *= 0.95; // 包含特殊字符可能降低置信度
    }

    // 模型类型因素
    if (this.model.type === 'wenet') {
      confidence *= 0.98; // WeNet 通常表现较好
    } else if (this.model.type === 'paraformer') {
      confidence *= 0.97; // Paraformer 表现也很好
    } else if (this.model.type === 'funasr') {
      confidence *= 0.96; // FunASR 表现良好
    }

    // 确保置信度在合理范围内
    return Math.max(0.0, Math.min(1.0, confidence));
  }

  /**
   * 批量识别
   * 
   * @param {Array<string>} audioFiles - 音频文件列表
   * @param {Object} options - 识别选项
   * @returns {Promise<Array>} - 识别结果列表
   */
  async batchTranscribe(audioFiles, options = {}) {
    const results = [];
    
    for (const audioFile of audioFiles) {
      try {
        const result = await this.transcribe(audioFile, options);
        results.push({
          file: audioFile,
          success: true,
          result: result
        });
      } catch (error) {
        results.push({
          file: audioFile,
          success: false,
          error: error.message
        });
      }
    }
    
    return results;
  }
}

// 使用示例
async function example() {
  // 使用 WeNet 模型
  const wenetASR = new ChineseASR('wenet');
  const wenetResult = await wenetASR.transcribe('audio.wav');
  console.log('WeNet 识别结果:', wenetResult);
  
  // 使用 Paraformer 模型
  const paraformerASR = new ChineseASR('paraformer');
  const paraformerResult = await paraformerASR.transcribe('audio.wav');
  console.log('Paraformer 识别结果:', paraformerResult);
  
  // 批量识别
  const audioFiles = ['audio1.wav', 'audio2.wav', 'audio3.wav'];
  const batchResults = await wenetASR.batchTranscribe(audioFiles);
  console.log('批量识别结果:', batchResults);
}
```
