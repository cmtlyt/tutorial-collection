# LLaMA 系列模型详解

> **版本**：v1.0  
> **最后更新**：2026-04-14

## 📖 概述

LLaMA（Large Language Model Meta AI）是 Meta（前 Facebook）开发的一系列开源大语言模型。LLaMA 系列以其出色的性能、开放的许可和活跃的社区生态，成为开源 LLM 领域的标杆。

## 🏆 模型系列

### LLaMA 1（2023年2月）

**基本信息**
- 发布时间：2023年2月
- 参数规模：7B, 13B, 33B, 65B
- 上下文长度：2K tokens
- 训练数据：1.4T tokens
- 许可证：非商业许可

**特点**
- 首个证明小参数模型可以媲美大参数模型
- 使用公开数据集训练
- 性能超越许多更大的模型
- 仅限研究使用

### LLaMA 2（2023年7月）

**基本信息**
- 发布时间：2023年7月

- 训练数据：2T tokens

**改进点**

**性能表现**

## 🏗️ 模型架构

### 核心架构特点

LLaMA 基于 Transformer 架构，但做了多项优化：

1. **RMSNorm（Root Mean Square Layer Normalization）**
   - 替代传统的 LayerNorm
   - 计算更高效
   - 训练更稳定

2. **SwiGLU 激活函数**
   - 替代传统的 ReLU
   - 性能更好
   - 参数量略增

3. **旋转位置编码（RoPE）**
   - 更好的位置表示
   - 支持外推
   - 计算高效

4. **查询键值分离（GQA）**
   - LLaMA 3.1 引入
   - 减少内存占用
   - 提高推理速度

### 架构对比

| 特性 | LLaMA 1 | LLaMA 2 | LLaMA 3 | LLaMA 3.1 |
|------|---------|---------|---------|-----------|
| 归一化 | RMSNorm | RMSNorm | RMSNorm | RMSNorm |
| 激活函数 | SwiGLU | SwiGLU | SwiGLU | SwiGLU |
| 位置编码 | RoPE | RoPE | RoPE | RoPE |
| 注意力 | MHA | MHA | GQA | GQA |
| 上下文 | 2K | 4K | 8K | 128K |

## 🚀 使用方法

### Hugging Face 使用

```python
from transformers import AutoTokenizer, AutoModelForCausalLM

# 加载模型和分词器
model_name = "meta-llama/Meta-Llama-3.1-8B"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

# 准备输入
input_text = "Explain quantum computing in simple terms."
inputs = tokenizer(input_text, return_tensors="pt")

# 生成输出
outputs = model.generate(
    inputs.input_ids,
    max_length=500,
    temperature=0.7,
    top_p=0.9
)

# 解码输出
generated_text = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(generated_text)
```

### 本地部署

#### 使用 llama.cpp

```bash
# 安装 llama.cpp
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp
make

# 下载模型权重
# 需要从 Meta 官方申请访问权限

# 转换模型
python convert.py ../llama-3.1-8b --outtype f16

# 量化模型
./quantize ../llama-3.1-8b/ggml-model-f16.gguf ../llama-3.1-8b/ggml-model-q4_0.gguf q4_0

# 运行推理
./main -m ../llama-3.1-8b/ggml-model-q4_0.gguf -p "Hello, how are you?" -n 256
```

#### 使用 vLLM

```bash
# 安装 vLLM
pip install vllm

# 启动 API 服务器
python -m vllm.entrypoints.api_server \
    --model meta-llama/Meta-Llama-3.1-8B \
    --tensor-parallel-size 1 \
    --gpu-memory-utilization 0.9
```

### API 调用示例

```python
import requests

# 使用本地部署的 API
url = "http://localhost:8000/v1/completions"

headers = {
    "Content-Type": "application/json"
}

data = {
    "model": "meta-llama/Meta-Llama-3.1-8B",

    "max_tokens": 500,
    "temperature": 0.7

result = response.json()
print(result['choices'][0]['text'])
```

## 🔧 微调 LLaMA

### 使用 LoRA 微调

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments, Trainer
from peft import LoraConfig, get_peft_model, TaskType

# 加载模型
model_name = "meta-llama/Meta-Llama-3.1-8B"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

# 配置 LoRA
lora_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"]
)

# 应用 LoRA
model = get_peft_model(model, lora_config)

# 训练配置
training_args = TrainingArguments(
    output_dir="./llama-finetuned",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4,
    learning_rate=2e-4,
    fp16=True,
    logging_steps=10
)

# 创建 Trainer
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    tokenizer=tokenizer
)

# 开始训练
trainer.train()
```

## 💡 最佳实践

### 参数选择建议

| 使用场景 | 推荐模型 | 硬件要求 |
|---------|---------|---------|
| 个人实验 | LLaMA 3.1 8B | 单张 16GB GPU |
| 企业应用 | LLaMA 3.1 70B | 2-4张 A100 |
| 研究实验 | LLaMA 3.1 405B | 8张 A100 |
| 边缘部署 | LLaMA 3 8B (量化) | 8GB GPU |

### 优化技巧

1. **量化**
   - 使用 4-bit 量化减少内存
   - 性能损失很小
   - 推理速度提升

2. **批处理**
   - 增加批大小提高吞吐量
   - 注意显存限制
   - 使用梯度累积

3. **KV Cache**
   - 缓存键值对
   - 加速生成
   - 减少重复计算

4. **Flash Attention**
   - 加速注意力计算
   - 减少内存占用
   - 支持长序列
