# CrewAI

> **版本**：v1.1  
> **最后更新**：2026-04-16

## 📖 概述

CrewAI 是一个专注于多 Agent 团队协作的框架，它允许你创建具有不同角色的 Agent 团队，并通过任务分配和工作流编排来完成复杂任务。CrewAI 的核心理念是模拟真实团队的工作方式，让每个 Agent 扮演特定的角色，协同合作达成目标。

## 🏗️ CrewAI 核心架构

### Agent 团队模式

CrewAI 采用团队协作模式：

```
用户任务
    ↓
┌─────────────────────────────────┐
│  Crew（团队）                    │
│  - 管理多个 Agent                │
│  - 分配任务                      │
│  - 协调工作流                    │
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│  Agents（Agent 团队）            │
│  ┌─────────────┬─────────────┐  │
│  │ 研究员 Agent │ 开发者 Agent │  │
│  │ - 收集信息  │ - 编写代码  │  │
│  │ - 分析数据  │ - 实现功能  │  │
│  └─────────────┴─────────────┘  │
│  ┌─────────────┬─────────────┐  │
│  │ 测试员 Agent │ 审查员 Agent │  │
│  │ - 编写测试  │ - 代码审查  │  │
│  │ - 验证功能  │ - 质量保证  │  │
│  └─────────────┴─────────────┘  │
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│  Tasks（任务队列）               │
│  - 任务 1 → 任务 2 → 任务 3     │
│  - 并行任务                      │
│  - 依赖关系                      │
└─────────────────────────────────┘
    ↓
最终结果
```

### 核心组件

#### 1. Agent（智能体）
CrewAI 的基础单元，具有：
- **角色（Role）**：定义 Agent 的专业领域
- **目标（Goal）**：Agent 要达成的目标
- **背景（Backstory）**：Agent 的背景故事
- **工具（Tools）**：Agent 可用的工具集
- **记忆（Memory）**：短期和长期记忆

#### 2. Task（任务）
定义具体的工作内容：
- **描述（Description）**：任务的详细描述
- **预期输出（Expected Output）**：任务的预期结果
- **Agent（Agent）**：负责执行任务的 Agent
- **工具（Tools）**：任务可用的工具
- **依赖（Dependencies）**：任务之间的依赖关系

#### 3. Crew（团队）
管理 Agent 和任务：
- **Agents**：团队中的所有 Agent
- **Tasks**：团队要完成的所有任务
- **流程（Process）**：任务的执行顺序
- **记忆（Memory）**：团队的共享记忆

#### 4. Process（流程）
定义任务的执行方式：
- **顺序执行（Sequential）**：按顺序执行任务
- **层级执行（Hierarchical）**：基于 Agent 层级执行
- **自定义流程**：自定义执行逻辑

## 🔑 基础使用

### 创建简单的 Agent 团队

```python
from crewai import Agent, Task, Crew, Process
from langchain_openai import ChatOpenAI

# 1. 配置 LLM
llm = ChatOpenAI(
    model="gpt-4",
    temperature=0,
    api_key="your-api-key"
)

# 2. 创建研究员 Agent
researcher = Agent(
    role="研究员",
    goal="收集和分析相关信息",
    backstory="""你是一位经验丰富的研究员，
擅长从各种来源收集信息并进行深入分析。
你注重细节，能够发现数据中的模式和趋势。""",
    verbose=True,
    llm=llm
)

# 3. 创建开发者 Agent
developer = Agent(
    role="开发者",
    goal="根据研究结果开发解决方案",
    backstory="""你是一位资深的软件开发者，
擅长将需求转化为高质量的代码。
你注重代码质量和可维护性。""",
    verbose=True,
    llm=llm
)

# 4. 创建任务
research_task = Task(
    description="研究 AI Agent 的最新进展和技术趋势",
    expected_output="一份详细的研究报告，包括技术趋势、主要框架和最佳实践",
    agent=researcher
)

development_task = Task(
    description="基于研究结果，设计并实现一个简单的 AI Agent 框架",
    expected_output="完整的代码实现和文档",
    agent=developer
)

# 5. 创建团队
crew = Crew(
    agents=[researcher, developer],
    tasks=[research_task, development_task],
    process=Process.sequential,
    verbose=True
)

# 6. 执行任务
result = crew.kickoff()

print("最终结果:")
print(result)
```

### 使用工具的 Agent

```python
from crewai import Agent, Task, Crew, Process
from langchain_openai import ChatOpenAI
from langchain.tools import Tool

# 1. 配置 LLM
llm = ChatOpenAI(
    model="gpt-4",
    temperature=0,
    api_key="your-api-key"
)

# 2. 定义工具
def search_tool(query):
    """搜索工具"""
    # 实现搜索逻辑
    return f"搜索结果: {query}"

def calculator_tool(expression):
    """计算器工具"""
    try:
        result = eval(expression)
        return f"计算结果: {result}"
    except Exception as e:
        return f"计算错误: {str(e)}"

# 3. 创建工具列表
tools = [
    Tool(name="Search", func=search_tool, description="搜索信息"),
    Tool(name="Calculator", func=calculator_tool, description="执行计算")
]

# 4. 创建带工具的 Agent
analyst = Agent(
    role="数据分析师",
    goal="分析数据并生成报告",
    backstory="""你是一位数据分析师，
擅长使用各种工具收集和分析数据。""",
    tools=tools,
    verbose=True,
    llm=llm
)

# 5. 创建任务
analysis_task = Task(
    description="搜索 AI 市场数据并计算增长率",
    expected_output="数据分析报告",
    agent=analyst
)

# 6. 创建团队
crew = Crew(
    agents=[analyst],
    tasks=[analysis_task],
    verbose=True
)

# 7. 执行任务
result = crew.kickoff()
```

## 📋 任务分配

### 顺序任务

```python
from crewai import Agent, Task, Crew, Process
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-4",
    temperature=0,
    api_key="your-api-key"
)

# 创建 Agent
researcher = Agent(
    role="研究员",
    goal="收集信息",
    backstory="你是一位研究员。",
    verbose=True,
    llm=llm
)

writer = Agent(
    role="作家",
    goal="撰写文章",
    backstory="你是一位作家。",
    verbose=True,
    llm=llm
)

editor = Agent(
    role="编辑",
    goal="编辑和润色",
    backstory="你是一位编辑。",
    verbose=True,
    llm=llm
)

# 创建顺序任务
task1 = Task(
    description="研究 AI Agent 的最新进展",
    expected_output="研究报告",
    agent=researcher
)

task2 = Task(
    description="基于研究报告撰写文章",
    expected_output="文章草稿",
    agent=writer,
    context=[task1]  # 依赖 task1 的结果
)

task3 = Task(
    description="编辑和润色文章",
    expected_output="最终文章",
    agent=editor,
    context=[task2]  # 依赖 task2 的结果
)

# 创建团队
crew = Crew(
    agents=[researcher, writer, editor],
    tasks=[task1, task2, task3],
    process=Process.sequential,  # 顺序执行
    verbose=True
)

# 执行任务
result = crew.kickoff()
```

```python
    agents=[researcher1, researcher2, researcher3, synthesizer],

result = crew.kickoff()
```

### 复杂依赖关系

```python
from crewai import Agent, Task, Crew, Process
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-4",
    temperature=0,
    api_key="your-api-key"
)

data_collector = Agent(
    role="数据收集员",
    goal="收集数据",
    backstory="你擅长数据收集。",

    llm=llm
)

data_analyst = Agent(
    role="数据分析师",
    goal="分析数据",
    backstory="你擅长数据分析。",
    verbose=True,
    llm=llm
)

report_writer = Agent(
    role="报告撰写人",
    goal="撰写报告",
    backstory="你擅长撰写报告。",

    llm=llm

    role="可视化专家",
    goal="创建可视化",
    backstory="你擅长数据可视化。",
    verbose=True,
    llm=llm
)

# 创建任务（复杂依赖）
task1 = Task(
    description="收集销售数据",
    expected_output="原始数据",
    agent=data_collector
)

task2 = Task(
    description="分析销售趋势",
    expected_output="分析结果",
    agent=data_analyst,
    context=[task1]  # 依赖 task1
)

task3 = Task(
    description="创建销售趋势图表",
    expected_output="可视化图表",
    agent=visualizer,
    context=[task1]  # 依赖 task1（与 task2 并行）
)

task4 = Task(
    description="撰写销售报告",
    expected_output="最终报告",
    agent=report_writer,
    context=[task2, task3]  # 依赖 task2 和 task3
)

# 创建团队
crew = Crew(
    agents=[data_collector, data_analyst, report_writer, visualizer],
    tasks=[task1, task2, task3, task4],
    process=Process.sequential,
    verbose=True
)

# 执行任务
result = crew.kickoff()
```

```python

from langchain_openai import ChatOpenAI
from langchain.tools import Tool
from langchain.utilities import SerpAPIWrapper

# 1. 配置 LLM
llm = ChatOpenAI(
    model="gpt-4",
    temperature=0,
    api_key="your-api-key"
)

search = SerpAPIWrapper()
search_tool = Tool(
    name="Search",
    func=search.run,
    description="搜索互联网"
```

### 回调处理

```python
from crewai import Agent, Task, Crew
from langchain_openai import ChatOpenAI

def on_task_start(task):

def on_task_end(task, output):

    print(f"输出: {output}")

def on_agent_start(agent):
    print(f"Agent 开始工作: {agent.role}")

def on_agent_end(agent, output):
    print(f"Agent 结束工作: {agent.role}")

    temperature=0,
    api_key="your-api-key"

task = Task(

    expected_output="任务结果",
    agent=agent
)

crew = Crew(
```

## 💡 常见问题

### Q1: 如何处理 Agent 之间的冲突？

**解决方案：**
```python
# 使用层级结构
manager = Agent(
    role="管理者",
    goal="协调团队",
    backstory="你是团队管理者，负责协调和决策。",
    verbose=True,
    llm=llm
)

worker1 = Agent(
    role="工作者 1",
    goal="完成任务",
    backstory="你服从管理者的安排。",
    verbose=True,
    llm=llm
)

crew = Crew(
    agents=[manager, worker1],
    tasks=[task1, task2],
    process=Process.hierarchical,  # 层级结构
    manager_llm=llm,
    verbose=True
)
```

### Q2: 如何优化任务执行顺序？

**解决方案：**
```python
# 明确任务依赖关系
task1 = Task(
    description="收集数据",
    expected_output="数据",
    agent=collector
)

task2 = Task(
    description="分析数据",
    expected_output="分析结果",
    agent=analyst,
    context=[task1]  # 明确依赖 task1
)

task3 = Task(
    description="撰写报告",
    expected_output="报告",
    agent=writer,
    context=[task2]  # 明确依赖 task2
)

crew = Crew(
    agents=[collector, analyst, writer],
    tasks=[task1, task2, task3],
    process=Process.sequential,
    verbose=True
)
```

### Q4: 如何处理执行失败？

**解决方案：**
```python
try:
    result = crew.kickoff()
    print("成功:", result)
except Exception as e:
    print("失败:", str(e))
    
    # 重试逻辑
    max_retries = 3
    for i in range(max_retries):
        try:
            result = crew.kickoff()
            print(f"重试 {i+1} 成功:", result)
            break
        except Exception as retry_error:
            print(f"重试 {i+1} 失败:", str(retry_error))
```
