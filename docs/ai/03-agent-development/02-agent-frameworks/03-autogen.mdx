# AutoGen

> **版本**：v1.0  
> **最后更新**：2026-04-15

## 📖 概述

AutoGen 是由微软开发的多 Agent 对话框架，它通过让多个 Agent 相互协作来解决复杂任务。AutoGen 的核心思想是使用可定制的、可对话的 Agent，这些 Agent 可以通过自然语言进行交流，共同完成目标。

## 🏗️ AutoGen 核心架构

### 多 Agent 协作模式

AutoGen 支持多种协作模式：

```
用户交互
    ↓
┌─────────────────────────────────┐
│  用户代理（User Proxy Agent）    │
│  - 接收用户输入                  │
│  - 转发消息给其他 Agent          │
│  - 展示最终结果                  │
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│  助手代理（Assistant Agent）     │
│  - 执行主要任务                  │
│  - 调用工具和代码                │
│  - 协调其他 Agent                │
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│  代码执行器（Code Executor）     │
│  - 执行 Python 代码              │
│  - 返回执行结果                  │
│  - 处理执行错误                  │
└─────────────────────────────────┘
```

### 核心组件

#### 1. ConversableAgent（可对话 Agent）
AutoGen 的基础 Agent 类，支持：
- 自然语言对话
- 工具调用
- 代码执行
- 人类交互

#### 2. UserProxyAgent（用户代理）
代表人类用户的 Agent，负责：
- 接收用户输入
- 决定何时需要人类干预
- 展示 Agent 的输出

#### 3. AssistantAgent（助手 Agent）
执行具体任务的 Agent，负责：
- 分析问题
- 调用工具
- 生成代码
- 协调其他 Agent

#### 4. CodeExecutor（代码执行器）
执行 Python 代码的组件：
- 安全的代码执行环境
- 结果捕获和返回
- 错误处理

## 🔑 基础使用

### 简单的两 Agent 对话

```python
import autogen

# 1. 配置 LLM
config_list = [
    {
        "model": "gpt-4",
        "api_key": "your-api-key",
    }
]

# 2. 创建助手 Agent
assistant = autogen.AssistantAgent(
    name="assistant",
    llm_config={
        "config_list": config_list,
        "temperature": 0,
    },
    system_message="你是一个有帮助的 AI 助手。"
)

# 3. 创建用户代理
user_proxy = autogen.UserProxyAgent(
    name="user_proxy",
    human_input_mode="NEVER",  # 不需要人类输入
    max_consecutive_auto_reply=10,
    code_execution_config={
        "work_dir": "coding",
        "use_docker": False,
    },
)

# 4. 启动对话
user_proxy.initiate_chat(
    assistant,
    message="计算斐波那契数列的前 10 项"
)
```

```python
import autogen

config_list = [
    {
        "model": "gpt-4",
        "api_key": "your-api-key",
    }
]

# 1. 创建用户代理
user_proxy = autogen.UserProxyAgent(
    name="user_proxy",
    human_input_mode="NEVER",
    max_consecutive_auto_reply=10,
    code_execution_config=False,
)

# 2. 创建研究 Agent
researcher = autogen.AssistantAgent(
    name="researcher",
    llm_config={"config_list": config_list},
    system_message="""你是一个研究专家。
你的任务是收集和分析信息。
当你需要更多信息时，向编码器请求帮助。"""
)

# 3. 创建编码 Agent
coder = autogen.AssistantAgent(
    name="coder",
    llm_config={"config_list": config_list},
    system_message="""你是一个编程专家。
你的任务是编写代码来解决问题。
只输出代码，不需要解释。"""
)

    name="executor",
    human_input_mode="NEVER",
    max_consecutive_auto_reply=10,
    code_execution_config={
        "work_dir": "coding",
        "use_docker": False,
    },
)

# 5. 定义群组对话
groupchat = autogen.GroupChat(
    agents=[user_proxy, researcher, coder, executor],
    messages=[],
    max_round=20

    groupchat=groupchat,
    llm_config={"config_list": config_list}
)

# 6. 启动群组对话

    manager,
    message="研究如何使用 Python 实现一个简单的推荐系统，并编写示例代码"
```

### 消息过滤和转换

```python
import autogen

# 1. 定义消息过滤器
def message_filter(message):
    """过滤消息"""
    # 只保留包含特定关键词的消息
    if "重要" in message.get("content", ""):
        return True
    return False

# 2. 定义消息转换器
def message_transformer(message):
    """转换消息"""
    content = message.get("content", "")
    # 添加时间戳
    import datetime
    timestamp = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    message["content"] = f"[{timestamp}] {content}"
    return message

# 3. 创建 Agent
assistant = autogen.AssistantAgent(
    name="assistant",
    llm_config={
        "config_list": config_list,
        "temperature": 0,
    },
    system_message="你是一个有帮助的助手。",
)

# 4. 应用过滤和转换
assistant.register_filter(message_filter)
assistant.register_transformer(message_transformer)

# 5. 启动对话
user_proxy = autogen.UserProxyAgent(
    name="user_proxy",
    human_input_mode="NEVER",
)

user_proxy.initiate_chat(
    assistant,
```

## 🎯 最佳实践

### 1. Agent 设计

#### ✅ 好的 Agent 设计
- **明确的角色**：每个 Agent 有清晰的职责
- **合适的系统消息**：详细说明 Agent 的任务和行为
- **合理的配置**：根据任务调整温度、最大回复数等参数

#### ❌ 避免
- 角色模糊
- 系统消息过于简单
- 配置不当

### Q3: 如何实现 Agent 之间的异步通信？

**解决方案：**
```python
import asyncio
import autogen

async def async_chat():
    # 创建 Agent
    assistant = autogen.AssistantAgent(
        name="assistant",
        llm_config={
            "config_list": config_list,
            "temperature": 0,
        },
    )
    
    user_proxy = autogen.UserProxyAgent(
        name="user_proxy",
        human_input_mode="NEVER",
    )
    
    # 异步启动对话
    await user_proxy.a_initiate_chat(
        assistant,
        message="异步消息"
    )

# 运行异步对话
asyncio.run(async_chat())
```
