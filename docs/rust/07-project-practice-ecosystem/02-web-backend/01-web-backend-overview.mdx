## 🔑 核心概念

### Axum：现代 Rust Web 框架
Axum 是由 Tokio 团队开发的 Web 框架，充分利用了 Rust 的类型系统：
1. **提取器（Extractor）**：通过类型系统自动从请求中提取参数
2. **处理函数**：任何满足签名要求的异步函数都可以作为路由处理函数
3. **Tower 中间件**：与 Tower 生态完全兼容，可复用丰富的中间件

### SQLx：编译期 SQL 检查
SQLx 是一个纯 Rust 的异步 SQL 库，能在编译期验证 SQL 语句的正确性，在保持原生 SQL 灵活性的同时提供类型安全保证。
