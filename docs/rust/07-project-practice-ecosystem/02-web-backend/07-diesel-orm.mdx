# Diesel ORM

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

Diesel 是 Rust 生态中最成熟的 ORM 框架，通过宏和类型系统在**编译期**保证 SQL 查询的正确性。它采用同步设计，提供了强大的 QueryDSL（查询领域特定语言），支持 PostgreSQL、MySQL 和 SQLite。Diesel 的核心理念是"如果它编译通过，SQL 就是正确的"。

## 🎯 项目设置

### 安装 Diesel CLI

```bash
# 安装 Diesel CLI（以 SQLite 为例）
cargo install diesel_cli --no-default-features --features sqlite
```

### Cargo.toml 依赖

```toml
[dependencies]
diesel = { version = "2", features = ["sqlite", "r2d2"] }
dotenvy = "0.15"
```

### Schema 定义与迁移

```bash
# 初始化 Diesel
diesel setup --database-url="test.db"

# 创建迁移
diesel migration generate create_users
```

迁移文件 `up.sql`：

```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL UNIQUE,
    active BOOLEAN NOT NULL DEFAULT TRUE
);

CREATE TABLE posts (
    id INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL,
    title VARCHAR(200) NOT NULL,
    body TEXT NOT NULL,
    published BOOLEAN NOT NULL DEFAULT FALSE,
    user_id INTEGER NOT NULL REFERENCES users(id)
);
```

迁移文件 `down.sql`：

```sql
DROP TABLE posts;
DROP TABLE users;
```

```bash
# 运行迁移
diesel migration run --database-url="test.db"
```

运行后 Diesel 会自动生成 `src/schema.rs`：

```rust
// src/schema.rs（自动生成）
diesel::table! {
    users (id) {
        id -> Integer,
        username -> Text,
        email -> Text,
        active -> Bool,
    }
}

diesel::table! {
    posts (id) {
        id -> Integer,
        title -> Text,
        body -> Text,
        published -> Bool,
        user_id -> Integer,
    }
}

diesel::joinable!(posts -> users (user_id));
diesel::allow_tables_to_appear_in_same_query!(users, posts);
```

## 📦 模型定义

```rust
use diesel::prelude::*;

// 查询用模型
#[derive(Queryable, Selectable, Debug)]
#[diesel(table_name = crate::schema::users)]
pub struct User {
    pub id: i32,
    pub username: String,
    pub email: String,
    pub active: bool,
}

// 插入用模型
#[derive(Insertable)]
#[diesel(table_name = crate::schema::users)]
pub struct NewUser<'a> {
    pub username: &'a str,
    pub email: &'a str,
}

#[derive(Queryable, Selectable, Debug, Associations)]
#[diesel(belongs_to(User))]
#[diesel(table_name = crate::schema::posts)]
pub struct Post {
    pub id: i32,
    pub title: String,
    pub body: String,
    pub published: bool,
    pub user_id: i32,
}

#[derive(Insertable)]
#[diesel(table_name = crate::schema::posts)]
pub struct NewPost<'a> {
    pub title: &'a str,
    pub body: &'a str,
    pub user_id: i32,
}

// 更新用模型
#[derive(AsChangeset)]
#[diesel(table_name = crate::schema::users)]
pub struct UpdateUser<'a> {
    pub username: Option<&'a str>,
    pub email: Option<&'a str>,
    pub active: Option<bool>,
}
```

## 🔧 CRUD 操作

```rust
use diesel::prelude::*;
use diesel::sqlite::SqliteConnection;

mod schema {
    diesel::table! {
        users (id) {
            id -> Integer,
            username -> Text,
            email -> Text,
            active -> Bool,
        }
    }
}

use schema::users;

#[derive(Queryable, Debug)]
struct User {
    id: i32,
    username: String,
    email: String,
    active: bool,
}

#[derive(Insertable)]
#[diesel(table_name = users)]
struct NewUser<'a> {
    username: &'a str,
    email: &'a str,
}

fn establish_connection() -> SqliteConnection {
    let database_url = "test.db";
    SqliteConnection::establish(database_url)
        .unwrap_or_else(|_| panic!("无法连接到 {}", database_url))
}

fn create_user(conn: &mut SqliteConnection, username: &str, email: &str) -> usize {
    let new_user = NewUser { username, email };

    diesel::insert_into(users::table)
        .values(&new_user)
        .execute(conn)
        .expect("插入用户失败")
}

fn list_users(conn: &mut SqliteConnection) -> Vec<User> {
    users::table
        .filter(users::active.eq(true))
        .order(users::username.asc())
        .limit(10)
        .load::<User>(conn)
        .expect("查询用户失败")
}

fn find_user(conn: &mut SqliteConnection, user_id: i32) -> Option<User> {
    users::table
        .find(user_id)
        .first::<User>(conn)
        .optional()
        .expect("查询用户失败")
}

fn update_user(conn: &mut SqliteConnection, user_id: i32, new_name: &str) -> usize {
    diesel::update(users::table.find(user_id))
        .set(users::username.eq(new_name))
        .execute(conn)
        .expect("更新用户失败")
}

fn delete_user(conn: &mut SqliteConnection, user_id: i32) -> usize {
    diesel::delete(users::table.find(user_id))
        .execute(conn)
        .expect("删除用户失败")
}

fn main() {
    let conn = &mut establish_connection();

    // 创建
    create_user(conn, "alice", "alice@example.com");
    create_user(conn, "bob", "bob@example.com");

    // 查询
    let all_users = list_users(conn);
    for user in &all_users {
        println!("{}: {} ({})", user.id, user.username, user.email);
    }

    // 更新
    update_user(conn, 1, "Alice Updated");

    // 查找
    if let Some(user) = find_user(conn, 1) {
        println!("找到用户: {:?}", user);
    }

    // 删除
    let deleted_count = delete_user(conn, 2);
    println!("删除了 {} 条记录", deleted_count);
}
```

## 🔍 查询 DSL

```rust
use diesel::prelude::*;

// 假设已有 schema 和 model 定义

fn complex_queries(conn: &mut SqliteConnection) {
    use schema::users::dsl::*;

    // WHERE 条件组合
    let results = users
        .filter(active.eq(true))
        .filter(username.like("%ali%"))
        .load::<User>(conn)
        .unwrap();

    // OR 条件
    let results = users
        .filter(username.eq("alice").or(username.eq("bob")))
        .load::<User>(conn)
        .unwrap();

    // 计数
    let total: i64 = users
        .filter(active.eq(true))
        .count()
        .get_result(conn)
        .unwrap();

    // 分页
    let page = 1;
    let per_page = 10;
    let paginated = users
        .order(id.desc())
        .limit(per_page)
        .offset((page - 1) * per_page)
        .load::<User>(conn)
        .unwrap();

    // SELECT 指定列
    let names: Vec<String> = users
        .select(username)
        .load::<String>(conn)
        .unwrap();

    println!("总数: {}, 名称: {:?}", total, names);
}
```
