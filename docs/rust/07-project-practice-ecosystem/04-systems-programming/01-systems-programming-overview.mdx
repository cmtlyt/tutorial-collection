## 📚 章节介绍

系统编程是 Rust 的核心定位领域。本章节将讲解 FFI、unsafe 操作、嵌入式开发以及操作系统级编程，展示 Rust 在底层系统开发中的强大能力。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 通过 FFI 与 C 库进行互操作
- 理解 unsafe Rust 在系统编程中的角色
- 了解嵌入式开发的 no_std 编程模式
- 掌握文件系统、网络编程等操作系统级操作

## 🔑 核心概念

### FFI：与 C 的零成本互操作
Rust 通过 `extern "C"` 实现与 C ABI 的兼容，可以直接调用 C 库函数，也可以将 Rust 函数导出给 C 代码使用。bindgen 和 cbindgen 工具可以自动生成绑定代码。

### no_std：无标准库编程
在嵌入式等受限环境中，Rust 支持 `#![no_std]` 模式，仅依赖核心库（core）和可选的 alloc 库，不依赖操作系统。
