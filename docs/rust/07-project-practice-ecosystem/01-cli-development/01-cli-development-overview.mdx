## 📚 章节介绍

Rust 是构建命令行工具的绝佳选择，拥有丰富的 CLI 开发生态。本章节将介绍主流的 CLI 框架和常用工具库，帮助你快速构建实用的命令行应用。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 使用 clap 构建功能完善的 CLI 应用
- 集成进度条、交互式提示等用户界面组件
- 使用 serde 处理 JSON/TOML/YAML 等数据格式
- 使用正则表达式和文件遍历处理文本数据

## 📖 章节结构

### 第一部分：CLI 框架
- clap（参数解析）
- indicatif（进度条）
- dialoguer（交互式提示）
- console（终端样式）

### 第二部分：实用工具
- serde / serde_json（序列化与反序列化）
- toml / yaml 配置解析
- regex（正则表达式）
- walkdir（文件遍历）

## 🔑 核心概念

### clap：声明式参数解析
clap 提供了两种参数定义方式：
1. **derive 模式**：通过 `#[derive(Parser)]` 宏从结构体定义中自动生成参数解析器，类型安全且简洁
2. **builder 模式**：通过链式调用构建参数解析器，更加灵活

### serde：通用序列化框架
serde 是 Rust 生态中最流行的序列化/反序列化框架，通过 derive 宏为任意类型自动实现序列化，支持 JSON、TOML、YAML、MessagePack 等多种格式。
