# indicatif 进度条

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

indicatif 是 Rust 生态中最流行的终端进度条库，提供了丰富的进度指示器，包括进度条、旋转器（Spinner）、多进度条等功能，能够显著提升 CLI 工具的用户体验。

## 🎯 基础进度条

### 简单进度条

```rust
use indicatif::ProgressBar;
use std::thread;
use std::time::Duration;

fn main() {
    let total_steps = 100;
    let progress_bar = ProgressBar::new(total_steps);

    for _ in 0..total_steps {
        thread::sleep(Duration::from_millis(20));
        progress_bar.inc(1);
    }

    progress_bar.finish_with_message("完成！");
}
```

### 自定义样式

```rust
use indicatif::{ProgressBar, ProgressStyle};
use std::thread;
use std::time::Duration;

fn main() {
    let progress_bar = ProgressBar::new(256);

    progress_bar.set_style(
        ProgressStyle::with_template(
            "{spinner:.green} [{elapsed_precise}] [{bar:40.cyan/blue}] {pos}/{len} ({eta})"
        )
        .unwrap()
        .progress_chars("#>-"),
    );

    for _ in 0..256 {
        thread::sleep(Duration::from_millis(15));
        progress_bar.inc(1);
    }

    progress_bar.finish_with_message("下载完成");
}
```

### 常用模板变量

| 变量 | 说明 |
|------|------|
| `{bar}` | 进度条本体 |
| `{pos}` | 当前进度 |
| `{len}` | 总进度 |
| `{percent}` | 百分比 |
| `{eta}` | 预计剩余时间 |
| `{elapsed}` | 已用时间 |
| `{spinner}` | 旋转动画 |
| `{msg}` | 自定义消息 |
| `{per_sec}` | 每秒处理速度 |

## 🔄 旋转器（Spinner）

用于表示不确定时长的操作：

```rust
use indicatif::{ProgressBar, ProgressStyle};
use std::thread;
use std::time::Duration;

fn main() {
    let spinner = ProgressBar::new_spinner();

    spinner.set_style(
        ProgressStyle::with_template("{spinner:.blue} {msg}")
            .unwrap()
            .tick_strings(&["⠋", "⠙", "⠹", "⠸", "⠼", "⠴", "⠦", "⠧", "⠇", "⠏", "✔"]),
    );

    spinner.set_message("正在连接服务器...");

    for _ in 0..50 {
        thread::sleep(Duration::from_millis(50));
        spinner.tick();
    }

    spinner.finish_with_message("连接成功！");
}
```

## 📊 多进度条

### MultiProgress

同时显示多个进度条，适合并行任务：

```rust
use indicatif::{MultiProgress, ProgressBar, ProgressStyle};
use std::thread;
use std::time::Duration;

fn main() {
    let multi_progress = MultiProgress::new();

    let style = ProgressStyle::with_template(
        "{prefix:.bold.dim} [{bar:30.green/white}] {pos}/{len} {msg}"
    )
    .unwrap()
    .progress_chars("█▉▊▋▌▍▎▏  ");

    let progress_bar1 = multi_progress.add(ProgressBar::new(100));
    progress_bar1.set_style(style.clone());
    progress_bar1.set_prefix("文件 1");

    let progress_bar2 = multi_progress.add(ProgressBar::new(200));
    progress_bar2.set_style(style.clone());
    progress_bar2.set_prefix("文件 2");

    let progress_bar3 = multi_progress.add(ProgressBar::new(150));
    progress_bar3.set_style(style);
    progress_bar3.set_prefix("文件 3");

    let handle1 = thread::spawn(move || {
        for _ in 0..100 {
            thread::sleep(Duration::from_millis(30));
            progress_bar1.inc(1);
        }
        progress_bar1.finish_with_message("完成");
    });

    let handle2 = thread::spawn(move || {
        for _ in 0..200 {
            thread::sleep(Duration::from_millis(20));
            progress_bar2.inc(1);
        }
        progress_bar2.finish_with_message("完成");
    });

    let handle3 = thread::spawn(move || {
        for _ in 0..150 {
            thread::sleep(Duration::from_millis(25));
            progress_bar3.inc(1);
        }
        progress_bar3.finish_with_message("完成");
    });

    handle1.join().unwrap();
    handle2.join().unwrap();
    handle3.join().unwrap();
}
```

## 📝 实际应用示例

### 模拟文件下载器

```rust
use indicatif::{MultiProgress, ProgressBar, ProgressStyle, HumanBytes, HumanDuration};
use std::thread;
use std::time::{Duration, Instant};

struct DownloadTask {
    name: String,
    size_bytes: u64,
}

fn simulate_download(multi_progress: &MultiProgress, task: DownloadTask) -> thread::JoinHandle<()> {
    let progress_bar = multi_progress.add(ProgressBar::new(task.size_bytes));

    progress_bar.set_style(
        ProgressStyle::with_template(
            "{prefix:>12.cyan.bold} [{bar:25}] {bytes}/{total_bytes} ({bytes_per_sec}, {eta})"
        )
        .unwrap()
        .progress_chars("━━╸━"),
    );

    progress_bar.set_prefix(task.name);

    thread::spawn(move || {
        let chunk_size = task.size_bytes / 100;
        let started_at = Instant::now();

        for _ in 0..100 {
            let delay = Duration::from_millis(rand_delay());
            thread::sleep(delay);
            progress_bar.inc(chunk_size);
        }

        let elapsed = started_at.elapsed();
        progress_bar.finish_with_message(format!(
            "完成 ({}, {})",
            HumanBytes(task.size_bytes),
            HumanDuration(elapsed)
        ));
    })
}

fn rand_delay() -> u64 {
    // 模拟 10~50ms 的网络延迟
    10 + (std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .unwrap()
        .subsec_nanos() % 40) as u64
}

fn main() {
    let tasks = vec![
        DownloadTask { name: "rustc".into(), size_bytes: 50_000_000 },
        DownloadTask { name: "cargo".into(), size_bytes: 30_000_000 },
        DownloadTask { name: "std-lib".into(), size_bytes: 80_000_000 },
    ];

    let multi_progress = MultiProgress::new();
    let handles: Vec<_> = tasks
        .into_iter()
        .map(|task| simulate_download(&multi_progress, task))
        .collect();

    for handle in handles {
        handle.join().unwrap();
    }

    println!("所有下载完成！");
}
```
