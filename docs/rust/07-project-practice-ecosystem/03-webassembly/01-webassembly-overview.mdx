## 📚 章节介绍

Rust 是编译到 WebAssembly（Wasm）的最佳语言之一，能将 Rust 的高性能带入浏览器和边缘计算环境。本章节将介绍 Wasm 工具链和前端框架集成。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 使用 wasm-bindgen 和 wasm-pack 构建 Wasm 模块
- 实现 Rust 与 JavaScript 的互操作
- 使用 Yew、Leptos 或 Dioxus 构建前端应用
- 理解 Wasm 的性能优势和适用场景

## 🔑 核心概念

### wasm-bindgen：Rust 与 JS 的桥梁
wasm-bindgen 提供了 Rust 与 JavaScript 之间的高层绑定，自动处理类型转换和内存管理，让 Rust 代码可以像原生 JavaScript 一样操作 DOM 和调用 Web API。

### Rust 前端框架对比
- **Yew**：类 React 组件模型，生态最成熟
- **Leptos**：细粒度响应式，性能优异，API 设计现代
- **Dioxus**：跨平台（Web/Desktop/Mobile），类 React 语法
