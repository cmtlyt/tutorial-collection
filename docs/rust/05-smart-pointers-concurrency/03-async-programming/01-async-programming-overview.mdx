## 🔑 核心概念

### Future：惰性的异步计算
Rust 的 Future 是惰性的，创建后不会自动执行，必须由异步运行时（如 Tokio）驱动轮询（poll）才会推进计算。这与 JavaScript 的 Promise（创建即执行）有本质区别。

### Pin：固定内存地址
Pin 确保被包裹的值不会在内存中移动，这对于自引用的 Future 至关重要。大部分情况下开发者无需直接操作 Pin，但理解其原理有助于排查异步编程中的编译错误。
