# Pin 与 Unpin

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

`Pin<P>` 是一个**包装器类型**，它确保被包裹的指针所指向的值不会在内存中被移动。这对于异步编程至关重要，因为编译器生成的 Future 状态机可能包含**自引用**结构（结构体中的某个字段引用了另一个字段），一旦值在内存中移动，自引用就会失效。

- **`Pin<P>`**：保证指针 `P` 指向的值不会被移动
- **`Unpin`**：标记 trait，表示类型可以安全地从 `Pin` 中移出。大多数常规类型自动实现 `Unpin`
- **`!Unpin`**：表示类型不能安全移动，`async fn` 生成的 Future 通常是 `!Unpin` 的

## 🎯 为什么需要 Pin

### 自引用问题

```rust
// 概念演示（不可运行）：自引用结构的问题
//
// struct SelfReferential {
//     data: String,
//     ptr: *const String, // 指向 data 字段
// }
//
// 如果这个结构体被移动到新的内存地址：
// - data 字段的地址变了
// - 但 ptr 仍然指向旧地址
// - ptr 变成了悬垂指针！

// async 生成的 Future 可能包含类似的自引用：
async fn example() {
    let data = String::from("hello");
    let reference = &data; // Future 状态机中的"自引用"
    println!("{}", reference);
    // 在 .await 暂停点之后，data 和 reference 都保存在 Future 的状态中
    // 如果 Future 被移动，reference 会指向错误的地址
    tokio::time::sleep(std::time::Duration::from_millis(10)).await;
    println!("{}", reference); // 如果 Future 被移动，这里会出问题
}

#[tokio::main]
async fn main() {
    example().await;
}
```

## 🎯 Pin 的基本用法

```rust
use std::pin::Pin;

fn main() {
    // 大多数类型实现了 Unpin，可以自由使用 Pin
    let mut value = 42;
    let pinned = Pin::new(&mut value);
    println!("Pinned 值: {}", *pinned);

    // Pin<Box<T>>
    let boxed = Box::pin(String::from("固定在堆上"));
    println!("Box::pin: {}", boxed);

    // 对于 Unpin 类型，Pin 不会限制任何操作
    let mut pinned_vec = Box::pin(vec![1, 2, 3]);
    // Vec 是 Unpin 的，所以可以获取可变引用
    pinned_vec.as_mut().push(4);
    println!("修改后: {:?}", pinned_vec);
}
```

## 🎯 Unpin 与 !Unpin

```rust
use std::pin::Pin;
use std::marker::PhantomPinned;

// 自动实现 Unpin 的类型（大多数类型）
struct MovableStruct {
    data: String,
    number: i32,
}

// 手动标记为 !Unpin
struct ImmovableStruct {
    data: String,
    _pin: PhantomPinned, // 使结构体不实现 Unpin
}

fn main() {
    // Unpin 类型可以从 Pin 中取出
    let movable = Box::pin(MovableStruct {
        data: String::from("可移动"),
        number: 42,
    });
    println!("可移动结构: {}, {}", movable.data, movable.number);

    // !Unpin 类型被 Pin 后不能安全地移动
    let immovable = Box::pin(ImmovableStruct {
        data: String::from("不可移动"),
        _pin: PhantomPinned,
    });
    println!("不可移动结构: {}", immovable.data);

    // 以下操作对 !Unpin 类型是不允许的：
    // let moved = *immovable; // 编译错误
}
```

## 🎯 Pin 在异步编程中的应用

```rust
use std::future::Future;
use std::pin::Pin;
use std::task::{Context, Poll};

// Future 的 poll 方法要求 Pin<&mut Self>
// 这确保了 Future 在被轮询期间不会被移动
struct MyFuture {
    count: u32,
}

impl Future for MyFuture {
    type Output = u32;

    fn poll(self: Pin<&mut Self>, _cx: &mut Context<'_>) -> Poll<Self::Output> {
        // 对于 Unpin 类型，可以安全地获取 &mut self
        let this = self.get_mut();
        this.count += 1;
        if this.count >= 3 {
            Poll::Ready(this.count)
        } else {
            _cx.waker().wake_by_ref();
            Poll::Pending
        }
    }
}

#[tokio::main]
async fn main() {
    let future = MyFuture { count: 0 };
    let result = future.await;
    println!("经过 {} 次 poll 完成", result);
}
```

### 固定 Future 到堆上

```rust
use std::pin::Pin;
use std::future::Future;

// 接受 Pin<Box<dyn Future>> 的函数
async fn execute_pinned(future: Pin<Box<dyn Future<Output = String>>>) -> String {
    future.await
}

async fn greet(name: &str) -> String {
    format!("Hello, {}!", name)
}

#[tokio::main]
async fn main() {
    // Box::pin 将 Future 固定到堆上
    let name = String::from("Rust");
    let future = Box::pin(async move {
        format!("Hello, {}!", name)
    });

    let result = execute_pinned(future).await;
    println!("{}", result);
}
```

## 🎯 tokio::pin! 宏

```rust
use tokio::pin;
use tokio::time::{sleep, Duration};

async fn task_a() -> &'static str {
    sleep(Duration::from_millis(100)).await;
    "任务A完成"
}

async fn task_b() -> &'static str {
    sleep(Duration::from_millis(50)).await;
    "任务B完成"
}

#[tokio::main]
async fn main() {
    let future_a = task_a();
    let future_b = task_b();

    // tokio::pin! 将 Future 固定在栈上
    // 在 select! 等宏中需要 Pin 的 Future
    pin!(future_a);
    pin!(future_b);

    // 现在可以在 select! 中使用
    tokio::select! {
        result = &mut future_a => println!("A 先完成: {}", result),
        result = &mut future_b => println!("B 先完成: {}", result),
    }
}
```

## 📝 实际应用示例

### 动态 Future 集合

```rust
use std::pin::Pin;
use std::future::Future;
use tokio::time::{sleep, Duration};

type BoxFuture<T> = Pin<Box<dyn Future<Output = T> + Send>>;

fn create_task(id: usize, delay_ms: u64) -> BoxFuture<String> {
    Box::pin(async move {
        sleep(Duration::from_millis(delay_ms)).await;
        format!("任务 {} 完成 (延迟 {}ms)", id, delay_ms)
    })
}

#[tokio::main]
async fn main() {
    // 存储不同类型的 Future 需要使用 Pin<Box<dyn Future>>
    let tasks: Vec<BoxFuture<String>> = vec![
        create_task(1, 100),
        create_task(2, 50),
        create_task(3, 150),
    ];

    // 并发执行所有任务
    let results = futures::future::join_all(tasks).await;
    for result in results {
        println!("{}", result);
    }
}
```

:::info 依赖说明
以上示例需要在 `Cargo.toml` 中添加：
```toml
[dependencies]
tokio = { version = "1", features = ["full"] }
futures = "0.3"
```
:::
