# 异步锁与同步原语

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

在异步编程中，标准库的 `std::sync::Mutex` 在持有锁期间会阻塞整个线程，可能导致其他异步任务无法执行。Tokio 提供了一系列**异步同步原语**，它们在等待时会让出执行权，不会阻塞线程。

核心原语：
- **`tokio::sync::Mutex`**：异步互斥锁
- **`tokio::sync::RwLock`**：异步读写锁
- **`tokio::sync::Semaphore`**：异步信号量
- **`tokio::sync::Notify`**：异步通知
- **`tokio::sync::Barrier`**：异步屏障
- **`tokio::sync::oneshot`**：一次性通道

## 🎯 tokio::sync::Mutex

### 异步 Mutex vs 标准库 Mutex

```rust
use std::sync::Arc;
use tokio::sync::Mutex;
use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    let data = Arc::new(Mutex::new(Vec::new()));
    let mut handles = vec![];

    for i in 0..5 {
        let data = Arc::clone(&data);
        let handle = tokio::spawn(async move {
            // lock().await 不会阻塞线程，而是让出执行权
            let mut vec = data.lock().await;
            vec.push(i);

            // 可以在持有锁时 .await（标准库 Mutex 不能这样做）
            sleep(Duration::from_millis(10)).await;

            vec.push(i + 100);
        });
        handles.push(handle);
    }

    for handle in handles {
        handle.await.unwrap();
    }

    let result = data.lock().await;
    println!("数据: {:?}", *result);
}
```

:::warning 何时使用哪种 Mutex
- **`std::sync::Mutex`**：锁持有时间短且不需要跨 `.await` 持有锁时使用，性能更高
- **`tokio::sync::Mutex`**：需要在持有锁期间执行 `.await` 时使用
:::

## 🎯 tokio::sync::RwLock

```rust
use std::sync::Arc;
use tokio::sync::RwLock;
use tokio::time::{sleep, Duration};

struct AsyncCache {
    data: RwLock<Vec<String>>,
}

impl AsyncCache {
    fn new() -> Self {
        AsyncCache {
            data: RwLock::new(Vec::new()),
        }
    }

    async fn read_all(&self) -> Vec<String> {
        // 多个读者可以同时获取读锁
        let data = self.data.read().await;
        data.clone()
    }

    async fn add(&self, item: String) {
        // 写锁是独占的
        let mut data = self.data.write().await;
        data.push(item);
    }
}

#[tokio::main]
async fn main() {
    let cache = Arc::new(AsyncCache::new());

    // 写入数据
    cache.add(String::from("item-1")).await;
    cache.add(String::from("item-2")).await;

    let mut handles = vec![];

    // 多个并发读取
    for i in 0..3 {
        let cache = Arc::clone(&cache);
        let handle = tokio::spawn(async move {
            let data = cache.read_all().await;
            println!("读者 {}: {:?}", i, data);
        });
        handles.push(handle);
    }

    // 一个写入
    {
        let cache = Arc::clone(&cache);
        let handle = tokio::spawn(async move {
            sleep(Duration::from_millis(10)).await;
            cache.add(String::from("item-3")).await;
            println!("写入完成");
        });
        handles.push(handle);
    }

    for handle in handles {
        handle.await.unwrap();
    }

    println!("最终数据: {:?}", cache.read_all().await);
}
```

## 🎯 tokio::sync::Semaphore

信号量限制同时访问资源的并发数量。

```rust
use std::sync::Arc;
use tokio::sync::Semaphore;
use tokio::time::{sleep, Duration, Instant};

#[tokio::main]
async fn main() {
    // 限制最多 3 个并发任务
    let semaphore = Arc::new(Semaphore::new(3));
    let start = Instant::now();
    let mut handles = vec![];

    for i in 0..8 {
        let semaphore = Arc::clone(&semaphore);
        let handle = tokio::spawn(async move {
            // acquire 获取许可，如果已满则等待
            let _permit = semaphore.acquire().await.unwrap();
            println!(
                "[{:>6.0}ms] 任务 {} 开始（并发槽位: {}/3）",
                start.elapsed().as_secs_f64() * 1000.0,
                i,
                3 - semaphore.available_permits()
            );

            sleep(Duration::from_millis(100)).await;

            println!(
                "[{:>6.0}ms] 任务 {} 完成",
                start.elapsed().as_secs_f64() * 1000.0,
                i
            );
            // _permit 离开作用域时自动释放
        });
        handles.push(handle);
    }

    for handle in handles {
        handle.await.unwrap();
    }

    println!("所有任务完成，总耗时: {:?}", start.elapsed());
}
```

## 🎯 tokio::sync::Notify

`Notify` 提供线程/任务间的简单通知机制。

```rust
use std::sync::Arc;
use tokio::sync::Notify;
use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    let notify = Arc::new(Notify::new());

    let notify_clone = Arc::clone(&notify);
    let waiter = tokio::spawn(async move {
        println!("等待者: 等待通知...");
        notify_clone.notified().await;
        println!("等待者: 收到通知！");
    });

    // 延迟后发送通知
    sleep(Duration::from_millis(100)).await;
    println!("发送通知");
    notify.notify_one();

    waiter.await.unwrap();
}
```

## 🎯 tokio::sync::oneshot

一次性通道用于发送单个值，常用于请求-响应模式。

```rust
use tokio::sync::oneshot;
use tokio::time::{sleep, Duration};

async fn compute_result(response_tx: oneshot::Sender<i64>) {
    sleep(Duration::from_millis(100)).await;
    let result = 42 * 42;
    let _ = response_tx.send(result);
}

#[tokio::main]
async fn main() {
    let (tx, rx) = oneshot::channel();

    tokio::spawn(compute_result(tx));

    // 等待结果
    match rx.await {
        Ok(result) => println!("计算结果: {}", result),
        Err(_) => println!("发送者被丢弃"),
    }

    // 用 oneshot 实现请求-响应
    let (resp_tx, resp_rx) = oneshot::channel();

    tokio::spawn(async move {
        sleep(Duration::from_millis(50)).await;
        resp_tx.send(String::from("pong")).unwrap();
    });

    println!("ping -> {}", resp_rx.await.unwrap());
}
```

## 📝 实际应用示例

### 连接池（信号量实现）

```rust
use std::sync::Arc;
use tokio::sync::{Semaphore, Mutex};
use tokio::time::{sleep, Duration};

struct ConnectionPool {
    semaphore: Semaphore,
    connections: Mutex<Vec<usize>>,
}

impl ConnectionPool {
    fn new(max_size: usize) -> Self {
        let connections: Vec<usize> = (0..max_size).collect();
        ConnectionPool {
            semaphore: Semaphore::new(max_size),
            connections: Mutex::new(connections),
        }
    }

    async fn acquire(&self) -> PoolGuard<'_> {
        let permit = self.semaphore.acquire().await.unwrap();
        let conn_id = self.connections.lock().await.pop().unwrap();
        println!("获取连接 #{}", conn_id);
        PoolGuard {
            pool: self,
            conn_id,
            _permit: permit,
        }
    }
}

struct PoolGuard<'a> {
    pool: &'a ConnectionPool,
    conn_id: usize,
    _permit: tokio::sync::SemaphorePermit<'a>,
}

impl<'a> Drop for PoolGuard<'a> {
    fn drop(&mut self) {
        println!("归还连接 #{}", self.conn_id);
        // 注意：在 Drop 中无法使用 async，这里用 try_lock
        if let Ok(mut connections) = self.pool.connections.try_lock() {
            connections.push(self.conn_id);
        }
    }
}

#[tokio::main]
async fn main() {
    let pool = Arc::new(ConnectionPool::new(3));
    let mut handles = vec![];

    for i in 0..6 {
        let pool = Arc::clone(&pool);
        let handle = tokio::spawn(async move {
            let _conn = pool.acquire().await;
            println!("任务 {} 使用连接", i);
            sleep(Duration::from_millis(100)).await;
            println!("任务 {} 完成", i);
        });
        handles.push(handle);
    }

    for handle in handles {
        handle.await.unwrap();
    }
}
```
