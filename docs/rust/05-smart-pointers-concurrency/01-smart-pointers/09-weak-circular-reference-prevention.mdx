# 弱引用与循环引用防护

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

`Weak<T>` 是 `Rc<T>` 和 `Arc<T>` 的弱引用版本。与强引用不同，`Weak` **不会增加强引用计数**，因此不会阻止值被释放。弱引用的主要用途是打破**循环引用**，防止内存泄漏。

关键特性：
- `Weak` 不拥有数据的所有权，不会阻止值被丢弃
- 使用 `Weak::upgrade()` 尝试获取强引用，返回 `Option<Rc<T>>`
- 当所有强引用被丢弃后，`upgrade()` 返回 `None`

## 🎯 循环引用问题

### 内存泄漏的产生

```rust
use std::cell::RefCell;
use std::rc::Rc;

#[derive(Debug)]
struct Node {
    value: i32,
    // 使用 Rc 指向其他节点会导致循环引用
    next: RefCell<Option<Rc<Node>>>,
}

impl Drop for Node {
    fn drop(&mut self) {
        println!("Node {} 被释放", self.value);
    }
}

fn main() {
    let node_a = Rc::new(Node {
        value: 1,
        next: RefCell::new(None),
    });

    let node_b = Rc::new(Node {
        value: 2,
        next: RefCell::new(None),
    });

    // 创建循环引用：A -> B -> A
    *node_a.next.borrow_mut() = Some(Rc::clone(&node_b));
    *node_b.next.borrow_mut() = Some(Rc::clone(&node_a));

    println!("node_a 强引用计数: {}", Rc::strong_count(&node_a));
    println!("node_b 强引用计数: {}", Rc::strong_count(&node_b));

    // 离开作用域时，引用计数只会减到 1，不会归零
    // Node 的 drop 永远不会被调用 —— 内存泄漏！
}
```

## 🎯 使用 Weak 打破循环

```rust
use std::cell::RefCell;
use std::rc::{Rc, Weak};

#[derive(Debug)]
struct Node {
    value: i32,
    next: RefCell<Option<Rc<Node>>>,
    prev: RefCell<Option<Weak<Node>>>, // 使用 Weak 打破循环
}

impl Drop for Node {
    fn drop(&mut self) {
        println!("Node {} 被释放", self.value);
    }
}

fn main() {
    let node_a = Rc::new(Node {
        value: 1,
        next: RefCell::new(None),
        prev: RefCell::new(None),
    });

    let node_b = Rc::new(Node {
        value: 2,
        next: RefCell::new(None),
        prev: RefCell::new(None),
    });

    // A -> B（强引用）
    *node_a.next.borrow_mut() = Some(Rc::clone(&node_b));

    // B -> A（弱引用，不增加强引用计数）
    *node_b.prev.borrow_mut() = Some(Rc::downgrade(&node_a));

    println!("node_a 强引用: {}, 弱引用: {}",
        Rc::strong_count(&node_a),
        Rc::weak_count(&node_a)
    );
    println!("node_b 强引用: {}, 弱引用: {}",
        Rc::strong_count(&node_b),
        Rc::weak_count(&node_b)
    );

    // 通过弱引用访问数据
    if let Some(prev) = node_b.prev.borrow().as_ref() {
        match prev.upgrade() {
            Some(node) => println!("B 的前驱节点值: {}", node.value),
            None => println!("前驱节点已被释放"),
        }
    }

    // 离开作用域时，所有节点都能正确释放
}
```

## 🎯 Weak 的核心 API

```rust
use std::rc::{Rc, Weak};

fn main() {
    let strong = Rc::new(String::from("hello"));

    // Rc::downgrade 创建弱引用
    let weak: Weak<String> = Rc::downgrade(&strong);

    println!("强引用计数: {}", Rc::strong_count(&strong));
    println!("弱引用计数: {}", Rc::weak_count(&strong));

    // upgrade：尝试从弱引用获取强引用
    match weak.upgrade() {
        Some(value) => println!("upgrade 成功: {}", value),
        None => println!("值已被释放"),
    }

    // 丢弃所有强引用
    drop(strong);

    // 值已释放，upgrade 返回 None
    match weak.upgrade() {
        Some(value) => println!("upgrade 成功: {}", value),
        None => println!("值已被释放，upgrade 返回 None"),
    }
}
```

## 🎯 树结构：父子关系

树结构中，父节点拥有子节点（强引用），子节点指向父节点使用弱引用，这是 `Weak` 最经典的应用。

```rust
use std::cell::RefCell;
use std::rc::{Rc, Weak};

#[derive(Debug)]
struct TreeNode {
    value: String,
    parent: RefCell<Weak<TreeNode>>,
    children: RefCell<Vec<Rc<TreeNode>>>,
}

impl TreeNode {
    fn new(value: &str) -> Rc<TreeNode> {
        Rc::new(TreeNode {
            value: String::from(value),
            parent: RefCell::new(Weak::new()),
            children: RefCell::new(Vec::new()),
        })
    }

    fn add_child(parent: &Rc<TreeNode>, child: &Rc<TreeNode>) {
        // 子节点记录父节点（弱引用）
        *child.parent.borrow_mut() = Rc::downgrade(parent);
        // 父节点记录子节点（强引用）
        parent.children.borrow_mut().push(Rc::clone(child));
    }

    fn parent_name(&self) -> String {
        match self.parent.borrow().upgrade() {
            Some(parent) => parent.value.clone(),
            None => String::from("(无父节点)"),
        }
    }

    fn print_tree(node: &Rc<TreeNode>, depth: usize) {
        let indent = "  ".repeat(depth);
        println!(
            "{}├─ {} [强: {}, 弱: {}]",
            indent,
            node.value,
            Rc::strong_count(node),
            Rc::weak_count(node),
        );
        for child in node.children.borrow().iter() {
            TreeNode::print_tree(child, depth + 1);
        }
    }
}

impl Drop for TreeNode {
    fn drop(&mut self) {
        println!("释放节点: {}", self.value);
    }
}

fn main() {
    let root = TreeNode::new("根节点");
    let child1 = TreeNode::new("子节点A");
    let child2 = TreeNode::new("子节点B");
    let grandchild = TreeNode::new("孙节点A1");

    TreeNode::add_child(&root, &child1);
    TreeNode::add_child(&root, &child2);
    TreeNode::add_child(&child1, &grandchild);

    TreeNode::print_tree(&root, 0);

    println!("\n孙节点的父节点: {}", grandchild.parent_name());
    println!("子节点A的父节点: {}", child1.parent_name());
    println!("根节点的父节点: {}", root.parent_name());

    println!("\n--- 离开作用域 ---");
    // 所有节点都能被正确释放，不会内存泄漏
}
```

## 📝 实际应用示例

### 观察者模式中使用 Weak 避免循环

```rust
use std::cell::RefCell;
use std::rc::{Rc, Weak};

trait EventHandler {
    fn handle(&self, event: &str);
    fn name(&self) -> &str;
}

struct EventEmitter {
    listeners: RefCell<Vec<Weak<dyn EventHandler>>>,
}

impl EventEmitter {
    fn new() -> Self {
        EventEmitter {
            listeners: RefCell::new(Vec::new()),
        }
    }

    fn subscribe(&self, listener: &Rc<dyn EventHandler>) {
        self.listeners
            .borrow_mut()
            .push(Rc::downgrade(listener));
    }

    fn emit(&self, event: &str) {
        let mut listeners = self.listeners.borrow_mut();
        // 清理已释放的监听器并通知存活的监听器
        listeners.retain(|weak| {
            if let Some(listener) = weak.upgrade() {
                listener.handle(event);
                true
            } else {
                false // 监听器已被释放，移除
            }
        });
    }

    fn listener_count(&self) -> usize {
        self.listeners.borrow().len()
    }
}

struct Logger {
    label: String,
}

impl EventHandler for Logger {
    fn handle(&self, event: &str) {
        println!("  [{}] 收到: {}", self.label, event);
    }

    fn name(&self) -> &str {
        &self.label
    }
}

fn main() {
    let emitter = EventEmitter::new();

    let logger1: Rc<dyn EventHandler> = Rc::new(Logger {
        label: String::from("主日志"),
    });
    let logger2: Rc<dyn EventHandler> = Rc::new(Logger {
        label: String::from("审计日志"),
    });

    emitter.subscribe(&logger1);
    emitter.subscribe(&logger2);

    println!("监听器数量: {}", emitter.listener_count());
    println!("发送事件 'start':");
    emitter.emit("start");

    // 丢弃 logger2
    drop(logger2);

    println!("\n丢弃审计日志后，发送事件 'update':");
    emitter.emit("update");
    println!("监听器数量: {}", emitter.listener_count());
}
```
