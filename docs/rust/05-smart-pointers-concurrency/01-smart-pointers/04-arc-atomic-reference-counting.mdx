# Arc（原子引用计数）

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

`Arc<T>`（Atomic Reference Counting）是 `Rc<T>` 的线程安全版本。它使用**原子操作**来维护引用计数，因此可以安全地在多个线程之间共享数据。`Arc` 的性能比 `Rc` 略低（原子操作的开销），所以在单线程场景中应优先使用 `Rc`。

## 🎯 基本用法

### 创建与克隆

```rust
use std::sync::Arc;
use std::thread;

fn main() {
    let data = Arc::new(vec![1, 2, 3, 4, 5]);
    println!("初始引用计数: {}", Arc::strong_count(&data));

    let mut handles = vec![];

    for i in 0..3 {
        let data_clone = Arc::clone(&data);
        let handle = thread::spawn(move || {
            println!("线程 {} 读取数据: {:?}", i, data_clone);
            println!("线程 {} 中引用计数: {}", i, Arc::strong_count(&data_clone));
        });
        handles.push(handle);
    }

    for handle in handles {
        handle.join().unwrap();
    }

    println!("所有线程结束后引用计数: {}", Arc::strong_count(&data));
}
```

### Arc vs Rc：线程安全对比

```rust
use std::sync::Arc;
// use std::rc::Rc;
use std::thread;

fn main() {
    // Arc 可以安全地跨线程共享
    let arc_data = Arc::new(42);
    let arc_clone = Arc::clone(&arc_data);

    let handle = thread::spawn(move || {
        println!("线程中读取 Arc 数据: {}", arc_clone);
    });
    handle.join().unwrap();

    // Rc 不能跨线程使用 —— 以下代码无法编译
    // let rc_data = Rc::new(42);
    // let rc_clone = Rc::clone(&rc_data);
    // thread::spawn(move || {
    //     println!("{}", rc_clone); // 编译错误：Rc 没有实现 Send
    // });

    println!("主线程中的 Arc 数据: {}", arc_data);
}
```

## 🎯 Arc 与 Mutex 组合

`Arc<T>` 本身只提供共享的不可变访问。要在多线程中修改共享数据，需要将 `Arc` 与 `Mutex` 或 `RwLock` 结合使用。

```rust
use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let counter = Arc::new(Mutex::new(0));
    let mut handles = vec![];

    for _ in 0..10 {
        let counter_clone = Arc::clone(&counter);
        let handle = thread::spawn(move || {
            let mut value = counter_clone.lock().unwrap();
            *value += 1;
        });
        handles.push(handle);
    }

    for handle in handles {
        handle.join().unwrap();
    }

    println!("最终计数: {}", *counter.lock().unwrap());
}
```

## 🎯 多线程共享数据结构

```rust
use std::sync::Arc;
use std::thread;
use std::collections::HashMap;

fn main() {
    // 构建一个共享的只读查找表
    let mut lookup = HashMap::new();
    lookup.insert("apple", 3.5);
    lookup.insert("banana", 1.2);
    lookup.insert("cherry", 5.0);
    lookup.insert("date", 8.0);

    let shared_lookup = Arc::new(lookup);
    let mut handles = vec![];

    let fruits = vec!["apple", "banana", "cherry", "date"];

    for fruit in fruits {
        let lookup_clone = Arc::clone(&shared_lookup);
        let handle = thread::spawn(move || {
            if let Some(price) = lookup_clone.get(fruit) {
                println!("{} 的价格: {:.2} 元", fruit, price);
            }
        });
        handles.push(handle);
    }

    for handle in handles {
        handle.join().unwrap();
    }
}
```

## 📝 实际应用示例

### 多线程日志收集器

```rust
use std::sync::{Arc, Mutex};
use std::thread;
use std::time::Instant;

struct Logger {
    entries: Vec<String>,
    start_time: Instant,
}

impl Logger {
    fn new() -> Self {
        Logger {
            entries: Vec::new(),
            start_time: Instant::now(),
        }
    }

    fn log(&mut self, thread_name: &str, message: &str) {
        let elapsed = self.start_time.elapsed();
        let entry = format!(
            "[{:>6.2}ms] [{}] {}",
            elapsed.as_secs_f64() * 1000.0,
            thread_name,
            message
        );
        self.entries.push(entry);
    }

    fn print_all(&self) {
        println!("=== 日志记录 ===");
        for entry in &self.entries {
            println!("{}", entry);
        }
        println!("共 {} 条日志", self.entries.len());
    }
}

fn main() {
    let logger = Arc::new(Mutex::new(Logger::new()));
    let mut handles = vec![];

    for i in 0..4 {
        let logger_clone = Arc::clone(&logger);
        let handle = thread::spawn(move || {
            let thread_name = format!("worker-{}", i);

            logger_clone
                .lock()
                .unwrap()
                .log(&thread_name, "任务开始");

            // 模拟工作
            let result = (0..1000).sum::<i64>();

            logger_clone
                .lock()
                .unwrap()
                .log(&thread_name, &format!("计算完成, 结果: {}", result));
        });
        handles.push(handle);
    }

    for handle in handles {
        handle.join().unwrap();
    }

    logger.lock().unwrap().print_all();
}
```
