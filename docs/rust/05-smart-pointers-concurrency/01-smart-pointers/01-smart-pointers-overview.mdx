# 智能指针 - 总览

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 章节介绍

智能指针是 Rust 内存管理的重要工具，它们不仅持有指向数据的指针，还附带额外的元数据和功能。本章节将讲解 Rust 中常用的智能指针类型及其使用场景。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 掌握 Box、Rc、Arc 等常用智能指针的使用场景
- 理解内部可变性（Cell / RefCell）的概念
- 使用 Mutex 和 RwLock 实现线程安全的共享数据
- 理解 Deref 和 Drop trait 的作用
- 使用弱引用（Weak）防止循环引用

## 🔑 核心概念

### 内部可变性
Rust 通常要求可变访问必须是独占的，但 Cell 和 RefCell 提供了"内部可变性"模式，允许通过不可变引用修改数据：
- **Cell\<T\>**：适用于 Copy 类型，通过整体替换值来实现可变性
- **RefCell\<T\>**：适用于任意类型，在运行时检查借用规则

### 引用计数 vs 原子引用计数
- **Rc\<T\>**：单线程引用计数，不能跨线程使用
- **Arc\<T\>**：原子引用计数，线程安全，可跨线程共享
