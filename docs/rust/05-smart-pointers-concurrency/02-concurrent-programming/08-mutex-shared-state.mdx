# Mutex 共享状态

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

`Mutex<T>`（Mutual Exclusion，互斥锁）是 Rust 中保护共享状态的主要工具。它确保同一时刻只有一个线程可以访问被保护的数据。在多线程并发场景中，`Mutex` 配合 `Arc` 使用是最常见的共享可变状态模式。

## 🎯 多线程中的 Mutex

### 共享计数器

```rust
use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let counter = Arc::new(Mutex::new(0));
    let mut handles = vec![];

    for _ in 0..10 {
        let counter = Arc::clone(&counter);
        let handle = thread::spawn(move || {
            // lock() 获取锁，返回 MutexGuard
            let mut num = counter.lock().unwrap();
            *num += 1;
            // MutexGuard 离开作用域时自动释放锁
        });
        handles.push(handle);
    }

    for handle in handles {
        handle.join().unwrap();
    }

    println!("计数器最终值: {}", *counter.lock().unwrap());
}
```

### 锁的作用域控制

```rust
use std::sync::{Arc, Mutex};
use std::thread;
use std::time::Duration;

fn main() {
    let data = Arc::new(Mutex::new(Vec::new()));
    let mut handles = vec![];

    for i in 0..5 {
        let data = Arc::clone(&data);
        let handle = thread::spawn(move || {
            // 显式控制锁的作用域，减少锁持有时间
            {
                let mut vec = data.lock().unwrap();
                vec.push(i);
            } // 锁在这里释放

            // 不持有锁的情况下做耗时操作
            thread::sleep(Duration::from_millis(10));

            {
                let mut vec = data.lock().unwrap();
                vec.push(i + 100);
            }
        });
        handles.push(handle);
    }

    for handle in handles {
        handle.join().unwrap();
    }

    let result = data.lock().unwrap();
    println!("数据: {:?}", *result);
    println!("元素数量: {}", result.len());
}
```

## 🎯 避免死锁

### 死锁示例与解决

```rust
use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let resource_a = Arc::new(Mutex::new(String::from("资源A")));
    let resource_b = Arc::new(Mutex::new(String::from("资源B")));

    // 正确做法：所有线程按相同顺序获取锁
    let ra = Arc::clone(&resource_a);
    let rb = Arc::clone(&resource_b);
    let handle1 = thread::spawn(move || {
        let a = ra.lock().unwrap();
        let b = rb.lock().unwrap();
        println!("线程1: {} + {}", a, b);
    });

    let ra = Arc::clone(&resource_a);
    let rb = Arc::clone(&resource_b);
    let handle2 = thread::spawn(move || {
        // 同样先锁 A 再锁 B，保持一致的锁顺序
        let a = ra.lock().unwrap();
        let b = rb.lock().unwrap();
        println!("线程2: {} + {}", a, b);
    });

    handle1.join().unwrap();
    handle2.join().unwrap();

    // 错误做法（可能死锁）：
    // 线程1: 先锁 A，再锁 B
    // 线程2: 先锁 B，再锁 A
    // 两个线程可能各持有一个锁，互相等待对方释放
}
```

### 使用 try_lock 避免阻塞

```rust
use std::sync::{Arc, Mutex};
use std::thread;
use std::time::Duration;

fn main() {
    let data = Arc::new(Mutex::new(0));

    let data_clone = Arc::clone(&data);
    let long_task = thread::spawn(move || {
        let mut value = data_clone.lock().unwrap();
        println!("长任务获取锁，处理中...");
        thread::sleep(Duration::from_millis(300));
        *value += 100;
        println!("长任务完成");
    });

    // 短暂等待让长任务先获取锁
    thread::sleep(Duration::from_millis(50));

    // 使用 try_lock 非阻塞尝试
    for attempt in 1..=5 {
        match data.try_lock() {
            Ok(value) => {
                println!("第 {} 次尝试成功，值: {}", attempt, *value);
                break;
            }
            Err(_) => {
                println!("第 {} 次尝试，锁被占用，稍后重试", attempt);
                thread::sleep(Duration::from_millis(100));
            }
        }
    }

    long_task.join().unwrap();
    println!("最终值: {}", *data.lock().unwrap());
}
```

## 📝 实际应用示例

### 线程安全的统计收集器

```rust
use std::sync::{Arc, Mutex};
use std::thread;
use std::collections::HashMap;
use std::time::Instant;

struct StatsCollector {
    counters: HashMap<String, u64>,
    start_time: Instant,
}

impl StatsCollector {
    fn new() -> Self {
        StatsCollector {
            counters: HashMap::new(),
            start_time: Instant::now(),
        }
    }

    fn increment(&mut self, key: &str) {
        let counter = self.counters.entry(key.to_string()).or_insert(0);
        *counter += 1;
    }

    fn report(&self) {
        let elapsed = self.start_time.elapsed();
        println!("=== 统计报告 ({:.2}ms) ===", elapsed.as_secs_f64() * 1000.0);
        let mut entries: Vec<_> = self.counters.iter().collect();
        entries.sort_by_key(|(k, _)| k.clone());
        for (key, value) in entries {
            println!("  {}: {}", key, value);
        }
    }
}

fn main() {
    let stats = Arc::new(Mutex::new(StatsCollector::new()));
    let mut handles = vec![];

    let categories = vec!["page_view", "api_call", "error", "page_view", "api_call"];

    for (i, category) in categories.into_iter().enumerate() {
        let stats = Arc::clone(&stats);
        let handle = thread::spawn(move || {
            for _ in 0..100 {
                stats.lock().unwrap().increment(category);
            }
            println!("线程 {} 完成: {} 类别", i, category);
        });
        handles.push(handle);
    }

    for handle in handles {
        handle.join().unwrap();
    }

    stats.lock().unwrap().report();
}
```
