## 📚 章节介绍

Rust 通过所有权系统和类型系统在编译期保证线程安全，实现了"无畏并发"。本章节将讲解 Rust 的线程管理、消息传递、共享状态以及 Send/Sync trait。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 创建和管理线程

- 使用 Mutex 和 RwLock 安全地共享状态
- 理解原子类型的使用场景
- 掌握 Send 和 Sync trait 的语义

## 🔑 核心概念

### 无畏并发
Rust 的类型系统通过 Send 和 Sync 两个标记 trait 在编译期捕获并发错误：
- **Send**：类型的值可以安全地在线程间转移所有权
- **Sync**：类型的引用可以安全地在线程间共享

大多数类型自动实现这两个 trait，编译器会在不满足条件时报错，从根本上杜绝数据竞争。

### 消息传递 vs 共享状态
- **消息传递（Channel）**：线程间通过发送消息通信，遵循"不要通过共享内存来通信，而是通过通信来共享内存"的理念
- **共享状态（Mutex/RwLock）**：多个线程通过锁机制安全地访问共享数据
