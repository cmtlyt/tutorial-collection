# 函数定义

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

函数是 Rust 程序的基本组成单元，使用 `fn` 关键字定义。Rust 函数采用蛇形命名法（snake_case），支持参数类型标注和返回值类型声明。函数体中的最后一个表达式会作为返回值，这是 Rust "表达式导向"设计的体现。

## 🎯 基本函数定义

### 无参数无返回值

```rust
fn greet() {
    println!("Hello, Rust!");
}

fn main() {
    greet();
    greet();
}
```

### 带参数的函数

函数参数必须声明类型：

```rust
fn greet_person(name: &str) {
    println!("Hello, {}!", name);
}

fn print_sum(a: i32, b: i32) {
    println!("{} + {} = {}", a, b, a + b);
}

fn main() {
    greet_person("Alice");
    greet_person("Bob");
    print_sum(3, 5);
}
```

### 带返回值的函数

使用 `->` 声明返回值类型：

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b // 最后一个表达式作为返回值，不加分号
}

fn multiply(a: f64, b: f64) -> f64 {
    a * b
}

fn is_even(number: i32) -> bool {
    number % 2 == 0
}

fn main() {
    let sum = add(3, 5);
    println!("3 + 5 = {}", sum);

    let product = multiply(2.5, 4.0);
    println!("2.5 * 4.0 = {}", product);

    println!("4 is even: {}", is_even(4));
    println!("7 is even: {}", is_even(7));
}
```

### 提前返回（return）

虽然通常使用最后一个表达式作为返回值，但也可以使用 `return` 提前返回：

```rust
fn find_first_negative(numbers: &[i32]) -> Option<i32> {
    for &number in numbers {
        if number < 0 {
            return Some(number); // 提前返回
        }
    }
    None // 最后一个表达式
}

fn main() {
    let data = [3, 7, -2, 5, -8];
    match find_first_negative(&data) {
        Some(value) => println!("First negative: {}", value),
        None => println!("No negative numbers"),
    }
}
```

## 📊 多种参数类型

### 引用参数

```rust
fn string_length(text: &str) -> usize {
    text.len()
}

fn first_element(slice: &[i32]) -> Option<&i32> {
    slice.first()
}

fn main() {
    let name = String::from("Rust");
    println!("Length of '{}': {}", name, string_length(&name));

    let numbers = vec![10, 20, 30];
    if let Some(first) = first_element(&numbers) {
        println!("First element: {}", first);
    }
}
```

### 可变引用参数

```rust
fn append_greeting(message: &mut String, name: &str) {
    message.push_str("Hello, ");
    message.push_str(name);
    message.push('!');
}

fn sort_and_dedup(numbers: &mut Vec<i32>) {
    numbers.sort();
    numbers.dedup();
}

fn main() {
    let mut greeting = String::new();
    append_greeting(&mut greeting, "World");
    println!("{}", greeting);

    let mut data = vec![3, 1, 4, 1, 5, 9, 2, 6, 5];
    println!("Before: {:?}", data);
    sort_and_dedup(&mut data);
    println!("After: {:?}", data);
}
```

### 所有权转移参数

```rust
fn consume_and_print(text: String) {
    println!("Consumed: {}", text);
    // text 在函数结束时被释放
}

fn take_and_return(mut text: String) -> String {
    text.push_str(" (processed)");
    text // 返回所有权
}

fn main() {
    let message = String::from("Hello");
    consume_and_print(message);
    // message 已被移动，不能再使用

    let original = String::from("Data");
    let processed = take_and_return(original);
    println!("{}", processed);
}
```

## 📝 实际应用示例

### 温度转换工具

```rust
fn celsius_to_fahrenheit(celsius: f64) -> f64 {
    celsius * 9.0 / 5.0 + 32.0
}

fn fahrenheit_to_celsius(fahrenheit: f64) -> f64 {
    (fahrenheit - 32.0) * 5.0 / 9.0
}

fn format_temperature(value: f64, unit: char) -> String {
    format!("{:.1}°{}", value, unit)
}

fn main() {
    let temps_c = [0.0, 20.0, 37.0, 100.0];

    println!("{:<12} {:<12}", "Celsius", "Fahrenheit");
    println!("{}", "-".repeat(24));

    for &celsius in &temps_c {
        let fahrenheit = celsius_to_fahrenheit(celsius);
        println!(
            "{:<12} {:<12}",
            format_temperature(celsius, 'C'),
            format_temperature(fahrenheit, 'F')
        );
    }
}
```

### 数组统计函数

```rust
fn calculate_stats(data: &[f64]) -> (f64, f64, f64, f64) {
    if data.is_empty() {
        return (0.0, 0.0, 0.0, 0.0);
    }

    let sum: f64 = data.iter().sum();
    let count = data.len() as f64;
    let mean = sum / count;

    let mut min = data[0];
    let mut max = data[0];
    for &value in &data[1..] {
        if value < min {
            min = value;
        }
        if value > max {
            max = value;
        }
    }

    (mean, min, max, sum)
}

fn main() {
    let scores = [85.5, 92.0, 78.5, 95.0, 88.0, 72.5, 91.0];
    let (mean, min, max, sum) = calculate_stats(&scores);

    println!("Statistics for {:?}", scores);
    println!("  Mean: {:.1}", mean);
    println!("  Min:  {:.1}", min);
    println!("  Max:  {:.1}", max);
    println!("  Sum:  {:.1}", sum);
}
```
