## 🔑 核心概念

### 闭包的三种 Trait
Rust 的闭包根据捕获环境变量的方式，分为三种 trait：
1. **Fn**：以不可变引用捕获，可以多次调用
2. **FnMut**：以可变引用捕获，可以多次调用但需要可变绑定
3. **FnOnce**：以所有权捕获，只能调用一次

### 模块系统
Rust 的模块系统通过 `mod`、`pub`、`use` 三个关键字实现代码的组织、封装和复用，提供了灵活而严格的访问控制机制。
