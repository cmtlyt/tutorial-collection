# 表达式与语句

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

Rust 是一门**表达式导向**的语言。理解表达式（expression）和语句（statement）的区别对于掌握 Rust 至关重要。表达式会产生一个值，而语句不产生值。在 Rust 中，几乎所有结构都是表达式，包括 `if`、`match`、代码块 `{}`，这使得代码更简洁灵活。

## 🎯 语句（Statement）

语句执行某些操作但**不返回值**。Rust 中有两种语句：

### 声明语句

```rust
fn main() {
    // let 绑定是语句，不产生值
    let x = 5;
    let y = 10;

    // 因此不能这样写（C 语言风格）：
    // let a = (let b = 5); // 错误！let 是语句，不产生值

    println!("x = {}, y = {}", x, y);
}
```

### 表达式语句

在表达式末尾加分号 `;`，就变成了语句，值会被丢弃：

```rust
fn main() {
    let x = 5;

    // 这是一个表达式语句：表达式 x + 1 的值被丢弃
    x + 1;

    // 函数调用也是表达式，加分号后变成语句
    println!("x = {}", x);
}
```

## 📐 表达式（Expression）

表达式会求值并产生一个结果。Rust 中绝大多数代码都是表达式：

### 基本表达式

```rust
fn main() {
    // 数字字面量是表达式
    let a = 42;

    // 运算是表达式
    let b = a + 8;

    // 函数调用是表达式
    let c = add(a, b);

    println!("a = {}, b = {}, c = {}", a, b, c);
}

fn add(x: i32, y: i32) -> i32 {
    x + y
}
```

### 代码块表达式

代码块 `{}` 是表达式，其值是块内最后一个表达式的值（不加分号）：

```rust
fn main() {
    let result = {
        let x = 10;
        let y = 20;
        x + y // 不加分号，作为块的返回值
    };

    println!("Result: {}", result); // 30

    // 如果最后一行加了分号，块返回 ()
    let unit_result = {
        let x = 10;
        x + 20; // 加了分号，值被丢弃
    };
    println!("Unit result: {:?}", unit_result); // ()
}
```

### if 表达式

```rust
fn main() {
    let condition = true;

    // if 是表达式，可以返回值
    let value = if condition { 42 } else { 0 };
    println!("Value: {}", value);

    // 嵌套在其他表达式中
    let description = format!(
        "The number is {}",
        if value > 10 { "large" } else { "small" }
    );
    println!("{}", description);
}
```

### match 表达式

```rust
fn main() {
    let number = 3;

    let name = match number {
        1 => "one",
        2 => "two",
        3 => "three",
        _ => "other",
    };

    println!("{} is {}", number, name);
}
```

### loop 表达式

```rust
fn main() {
    let mut counter = 0;

    // loop 通过 break 返回值
    let result = loop {
        counter += 1;
        if counter == 5 {
            break counter * 10;
        }
    };

    println!("Result: {}", result); // 50
}
```

## ⚠️ 分号的重要性

分号决定了一个东西是表达式还是语句：

```rust
// 正确：最后一行是表达式，作为返回值
fn add_correct(a: i32, b: i32) -> i32 {
    a + b // 表达式，返回值
}

// 错误：加了分号变成语句，返回 ()
// fn add_wrong(a: i32, b: i32) -> i32 {
//     a + b; // 语句，返回 ()，类型不匹配
// }

fn main() {
    println!("3 + 5 = {}", add_correct(3, 5));
}
```

## 📝 实际应用示例

### 利用表达式简化代码

```rust
fn describe_number(number: i32) -> String {
    // 利用表达式组合，避免临时变量和 return
    let sign = if number > 0 {
        "positive"
    } else if number < 0 {
        "negative"
    } else {
        "zero"
    };

    let parity = if number % 2 == 0 { "even" } else { "odd" };

    let magnitude = match number.abs() {
        0..=9 => "single digit",
        10..=99 => "double digit",
        100..=999 => "triple digit",
        _ => "large",
    };

    format!("{} is {}, {}, {}", number, sign, parity, magnitude)
}

fn main() {
    let test_numbers = [0, 7, -42, 123, -1000];

    for &number in &test_numbers {
        println!("{}", describe_number(number));
    }
}
```

### 代码块表达式构建复杂值

```rust
fn main() {
    let config = {
        let base_port = 8000;
        let offset = 80;
        let port = base_port + offset;

        let host = if cfg!(debug_assertions) {
            "localhost"
        } else {
            "0.0.0.0"
        };

        format!("{}:{}", host, port)
    };

    println!("Server address: {}", config);
}
```
