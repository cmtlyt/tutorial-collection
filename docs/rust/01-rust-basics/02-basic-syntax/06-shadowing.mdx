# 遮蔽（Shadowing）

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

遮蔽（Shadowing）是 Rust 中一个独特的特性：你可以用同一个名字声明一个新变量，新变量会"遮蔽"之前的同名变量。遮蔽与 `mut` 不同——它实际上创建了一个全新的变量，可以改变类型，而旧变量被新变量隐藏，无法再访问。

## 🎯 基本遮蔽

### 同一作用域内的遮蔽

```rust
fn main() {
    let x = 5;
    println!("x = {}", x); // 5

    let x = x + 1;
    println!("x = {}", x); // 6

    let x = x * 2;
    println!("x = {}", x); // 12
}
```

### 遮蔽 vs mut

```rust
fn main() {
    // 遮蔽：创建新变量，可以改变类型
    let spaces = "   ";             // &str 类型
    let spaces = spaces.len();       // usize 类型（遮蔽，合法）
    println!("Number of spaces: {}", spaces);

    // mut：只能修改值，不能改变类型
    // let mut spaces2 = "   ";
    // spaces2 = spaces2.len();  // 错误！不能将 usize 赋给 &str
}
```

### 关键区别

| 特性 | 遮蔽（Shadowing） | 可变绑定（mut） |
|------|-------------------|-----------------|
| 关键字 | 再次使用 `let` | 使用 `let mut` |
| 类型变化 | ✅ 允许改变类型 | ❌ 类型不可变 |
| 本质 | 创建全新变量 | 修改同一变量 |
| 旧值 | 被遮蔽，无法访问 | 被覆盖 |
| 新绑定可变性 | 默认不可变 | 保持可变 |

## 🔍 内层作用域的遮蔽

在内层作用域中声明的同名变量只在该作用域内有效，离开作用域后外层变量恢复可见：

```rust
fn main() {
    let x = 10;
    println!("Outer x = {}", x); // 10

    {
        let x = x + 20;
        println!("Inner x = {}", x); // 30
    }

    // 内层的遮蔽结束，外层的 x 恢复
    println!("Outer x again = {}", x); // 10
}
```

### 多层嵌套遮蔽

```rust
fn main() {
    let value = 1;
    println!("Level 0: {}", value); // 1

    {
        let value = value + 10;
        println!("Level 1: {}", value); // 11

        {
            let value = value + 100;
            println!("Level 2: {}", value); // 111
        }

        println!("Back to Level 1: {}", value); // 11
    }

    println!("Back to Level 0: {}", value); // 1
}
```

## 🎯 遮蔽的常见用途

### 1. 类型转换时保留语义

```rust
fn main() {
    // 字符串输入 → 解析为数字，变量名不变更符合语义
    let age = "25";
    let age: u32 = age.parse().expect("Not a number");
    println!("Age: {}", age);
}
```

### 2. 逐步处理数据

```rust
fn main() {
    let input = "  Hello, Rust!  ";
    let input = input.trim();
    let input = input.to_uppercase();
    println!("Processed: {}", input);
}
```

### 3. 不可变化可变变量

```rust
fn main() {
    // 先用 mut 构建数据，完成后遮蔽为不可变
    let mut data = Vec::new();
    data.push(1);
    data.push(2);
    data.push(3);

    // 完成构建后，遮蔽为不可变，防止后续意外修改
    let data = data;
    println!("Final data: {:?}", data);
    // data.push(4); // 错误：data 现在是不可变的
}
```

## 📝 实际应用示例

### 用户输入处理

```rust
use std::io;

fn main() {
    println!("Enter your birth year:");

    let mut input = String::new();
    io::stdin()
        .read_line(&mut input)
        .expect("Failed to read input");

    // 遮蔽：从 String 转换为 u32
    let input: u32 = match input.trim().parse() {
        Ok(year) => year,
        Err(_) => {
            println!("Invalid input, using default year 2000");
            2000
        }
    };

    let current_year = 2026;
    let age = current_year - input;
    println!("You are approximately {} years old", age);
}
```

### 配置值处理链

```rust
fn main() {
    let config_value = "  42  ";
    let config_value = config_value.trim();          // &str: "42"
    let config_value: i32 = config_value
        .parse()
        .expect("Invalid config");                   // i32: 42
    let config_value = config_value.max(0);           // 确保非负
    let config_value = config_value.min(100);         // 确保不超过 100

    println!("Final config value: {}", config_value);
}
```

## 🔗 相关概念

- **不可变绑定与可变绑定**：遮蔽与 mut 的区别
- **类型推断与类型标注**：遮蔽时可以改变类型
- **常量与静态变量**：const 和 static 不支持遮蔽
