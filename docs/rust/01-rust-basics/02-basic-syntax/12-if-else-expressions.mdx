# if / else 表达式

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

在 Rust 中，`if / else` 是**表达式**而非语句，这意味着它可以返回一个值。条件必须是 `bool` 类型，Rust 不会自动将其他类型转换为布尔值（没有"隐式真值"概念）。

## 🎯 基本用法

### if 表达式

```rust
fn main() {
    let temperature = 35;

    if temperature > 30 {
        println!("It's hot outside!");
    }
}
```

### if / else

```rust
fn main() {
    let number = 7;

    if number % 2 == 0 {
        println!("{} is even", number);
    } else {
        println!("{} is odd", number);
    }
}
```

### if / else if / else

```rust
fn main() {
    let score = 85;

    let grade = if score >= 90 {
        "A"
    } else if score >= 80 {
        "B"
    } else if score >= 70 {
        "C"
    } else if score >= 60 {
        "D"
    } else {
        "F"
    };

    println!("Score: {}, Grade: {}", score, grade);
}
```

## 🔄 if 作为表达式

Rust 的 if 是表达式，可以返回值并赋给变量：

```rust
fn main() {
    let age = 20;

    // if 表达式返回值
    let status = if age >= 18 { "adult" } else { "minor" };
    println!("Status: {}", status);

    // 用于函数返回值
    let abs_value = absolute(-42);
    println!("Absolute: {}", abs_value);
}

fn absolute(number: i32) -> i32 {
    if number >= 0 {
        number
    } else {
        -number
    }
}
```

:::warning
当 if 作为表达式使用时，所有分支的返回类型必须一致：
```rust
fn main() {
    let condition = true;

    // 正确：两个分支都返回 i32
    let value = if condition { 5 } else { 10 };
    println!("{}", value);

    // 错误：类型不一致
    // let value = if condition { 5 } else { "hello" };
}
```
:::

## 📊 条件表达式

Rust 的条件必须是 `bool` 类型：

```rust
fn main() {
    let number = 5;

    // 正确：使用比较运算符
    if number > 0 {
        println!("Positive");
    }

    // 错误：Rust 不会隐式转换为 bool
    // if number {   // 错误！expected `bool`, found integer
    //     println!("Non-zero");
    // }

    // 正确的方式
    if number != 0 {
        println!("Non-zero");
    }

    // 逻辑组合
    let age = 25;
    let has_license = true;

    if age >= 18 && has_license {
        println!("Can drive");
    }

    if age < 13 || age > 65 {
        println!("Discounted ticket");
    } else {
        println!("Full price ticket");
    }
}
```

## 📝 实际应用示例

### 简单的计算器

```rust
fn calculate(left: f64, operator: char, right: f64) -> Result<f64, String> {
    if operator == '+' {
        Ok(left + right)
    } else if operator == '-' {
        Ok(left - right)
    } else if operator == '*' {
        Ok(left * right)
    } else if operator == '/' {
        if right == 0.0 {
            Err(String::from("Division by zero"))
        } else {
            Ok(left / right)
        }
    } else {
        Err(format!("Unknown operator: {}", operator))
    }
}

fn main() {
    let operations = vec![
        (10.0, '+', 5.0),
        (10.0, '-', 3.0),
        (4.0, '*', 7.0),
        (20.0, '/', 4.0),
        (10.0, '/', 0.0),
    ];

    for (left, op, right) in operations {
        match calculate(left, op, right) {
            Ok(result) => println!("{} {} {} = {}", left, op, right, result),
            Err(error) => println!("{} {} {} => Error: {}", left, op, right, error),
        }
    }
}
```

### 数据分类

```rust
fn classify_bmi(bmi: f64) -> &'static str {
    if bmi < 18.5 {
        "Underweight"
    } else if bmi < 25.0 {
        "Normal"
    } else if bmi < 30.0 {
        "Overweight"
    } else {
        "Obese"
    }
}

fn main() {
    let test_values = [16.0, 22.5, 27.3, 32.1];

    for bmi in test_values {
        println!("BMI {:.1}: {}", bmi, classify_bmi(bmi));
    }
}
```
