# match 模式匹配

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

`match` 是 Rust 中最强大的控制流结构之一，类似于其他语言的 `switch`，但远比它更强大。`match` 是一个表达式，可以返回值。Rust 编译器会确保 `match` 穷尽所有可能的模式，遗漏任何一种情况都会导致编译错误，这极大地提升了代码的安全性。

## 🎯 基本语法

```rust
fn main() {
    let number = 3;

    match number {
        1 => println!("One"),
        2 => println!("Two"),
        3 => println!("Three"),
        _ => println!("Something else"), // _ 是通配符，匹配所有其他值
    }
}
```

### match 作为表达式

```rust
fn main() {
    let day = "Wednesday";

    let day_type = match day {
        "Monday" | "Tuesday" | "Wednesday" | "Thursday" | "Friday" => "Weekday",
        "Saturday" | "Sunday" => "Weekend",
        _ => "Unknown",
    };

    println!("{} is a {}", day, day_type);
}
```

## 🔍 模式种类

### 字面量匹配

```rust
fn main() {
    let status_code = 404;

    let message = match status_code {
        200 => "OK",
        301 => "Moved Permanently",
        404 => "Not Found",
        500 => "Internal Server Error",
        _ => "Unknown Status",
    };

    println!("{}: {}", status_code, message);
}
```

### 范围匹配

```rust
fn main() {
    let score = 85;

    let grade = match score {
        90..=100 => "A",
        80..=89 => "B",
        70..=79 => "C",
        60..=69 => "D",
        0..=59 => "F",
        _ => "Invalid",
    };

    println!("Score {}: Grade {}", score, grade);

    // 字符范围
    let character = 'f';
    let char_type = match character {
        'a'..='z' => "lowercase",
        'A'..='Z' => "uppercase",
        '0'..='9' => "digit",
        _ => "other",
    };
    println!("'{}' is {}", character, char_type);
}
```

### 多个模式（OR 模式）

```rust
fn main() {
    let value = 3;

    match value {
        1 | 3 | 5 | 7 | 9 => println!("{} is odd", value),
        2 | 4 | 6 | 8 | 10 => println!("{} is even", value),
        _ => println!("{} is out of range", value),
    }
}
```

### 解构元组

```rust
fn main() {
    let point = (3, -5);

    match point {
        (0, 0) => println!("Origin"),
        (x, 0) => println!("On x-axis at x={}", x),
        (0, y) => println!("On y-axis at y={}", y),
        (x, y) if x > 0 && y > 0 => println!("First quadrant: ({}, {})", x, y),
        (x, y) => println!("Somewhere else: ({}, {})", x, y),
    }
}
```

### 匹配守卫（Match Guard）

使用 `if` 在匹配分支中添加额外条件：

```rust
fn main() {
    let number = 4;

    match number {
        n if n < 0 => println!("{} is negative", n),
        n if n == 0 => println!("zero"),
        n if n % 2 == 0 => println!("{} is positive and even", n),
        n => println!("{} is positive and odd", n),
    }
}
```

### 绑定变量（@ 绑定）

```rust
fn main() {
    let age = 25;

    match age {
        0 => println!("Newborn"),
        child @ 1..=12 => println!("Child, age {}", child),
        teen @ 13..=17 => println!("Teenager, age {}", teen),
        adult @ 18..=64 => println!("Adult, age {}", adult),
        senior @ 65.. => println!("Senior, age {}", senior),
        _ => unreachable!(),
    }
}
```

## 📦 匹配 Option 和 Result

### 匹配 Option

```rust
fn find_item(items: &[&str], target: &str) -> Option<usize> {
    for (index, &item) in items.iter().enumerate() {
        if item == target {
            return Some(index);
        }
    }
    None
}

fn main() {
    let fruits = ["apple", "banana", "cherry"];

    match find_item(&fruits, "banana") {
        Some(index) => println!("Found at index {}", index),
        None => println!("Not found"),
    }

    match find_item(&fruits, "grape") {
        Some(index) => println!("Found at index {}", index),
        None => println!("Not found"),
    }
}
```

### 匹配 Result

```rust
fn divide(numerator: f64, denominator: f64) -> Result<f64, String> {
    if denominator == 0.0 {
        Err(String::from("Cannot divide by zero"))
    } else {
        Ok(numerator / denominator)
    }
}

fn main() {
    let operations = vec![(10.0, 3.0), (10.0, 0.0), (100.0, 7.0)];

    for (a, b) in operations {
        match divide(a, b) {
            Ok(result) => println!("{} / {} = {:.2}", a, b, result),
            Err(error) => println!("{} / {} => Error: {}", a, b, error),
        }
    }
}
```

## 💡 穷尽性检查

Rust 编译器会确保 match 覆盖所有可能的值：

```rust
enum Direction {
    North,
    South,
    East,
    West,
}

fn describe_direction(direction: Direction) -> &'static str {
    match direction {
        Direction::North => "Going north",
        Direction::South => "Going south",
        Direction::East => "Going east",
        Direction::West => "Going west",
        // 如果漏掉任何一个变体，编译器会报错
    }
}

fn main() {
    println!("{}", describe_direction(Direction::North));
    println!("{}", describe_direction(Direction::East));
}
```

## 📝 实际应用示例

### 简单的命令解析器

```rust
fn execute_command(input: &str) {
    let parts: Vec<&str> = input.trim().splitn(2, ' ').collect();
    let command = parts[0];
    let argument = parts.get(1).copied().unwrap_or("");

    match command {
        "echo" => println!("{}", argument),
        "upper" => println!("{}", argument.to_uppercase()),
        "lower" => println!("{}", argument.to_lowercase()),
        "len" => println!("{}", argument.len()),
        "reverse" => {
            let reversed: String = argument.chars().rev().collect();
            println!("{}", reversed);
        }
        "help" => {
            println!("Available commands:");
            println!("  echo <text>    - Print text");
            println!("  upper <text>   - Convert to uppercase");
            println!("  lower <text>   - Convert to lowercase");
            println!("  len <text>     - Print text length");
            println!("  reverse <text> - Reverse text");
            println!("  help           - Show this help");
        }
        unknown => println!("Unknown command: '{}'. Type 'help' for available commands.", unknown),
    }
}

fn main() {
    let commands = vec![
        "echo Hello World",
        "upper hello rust",
        "reverse abcdef",
        "len hello",
        "unknown test",
    ];

    for command in commands {
        print!("> {} => ", command);
        execute_command(command);
    }
}
```
