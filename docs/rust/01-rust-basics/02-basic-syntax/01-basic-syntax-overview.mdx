## 🔑 核心概念

### 默认不可变
Rust 的变量默认是不可变的，需要使用 `let mut` 才能声明可变变量。这种设计鼓励开发者更多地使用不可变数据，减少程序中的状态变化，从而降低出错概率。

### 表达式导向
Rust 是表达式导向的语言，几乎所有语法结构都是表达式，包括 if/else、match 和代码块。表达式可以产生值，这使得 Rust 代码更加简洁灵活。
