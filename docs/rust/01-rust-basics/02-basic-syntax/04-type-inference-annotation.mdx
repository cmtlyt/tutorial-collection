# 类型推断与类型标注

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

Rust 拥有强大的类型推断系统，在大多数情况下编译器能够自动推断变量的类型，无需手动标注。但在某些场景下（如解析字符串、使用泛型等），编译器无法确定类型时，就需要开发者显式地提供类型标注。

## 🎯 类型推断

### 编译器自动推断

```rust
fn main() {
    // 编译器推断为 i32（整数默认类型）
    let number = 42;

    // 编译器推断为 f64（浮点数默认类型）
    let pi = 3.14;

    // 编译器推断为 bool
    let is_valid = true;

    // 编译器推断为 &str
    let greeting = "Hello";

    // 编译器推断为 String
    let name = String::from("Rust");

    println!("{} {} {} {} {}", number, pi, is_valid, greeting, name);
}
```

### 基于上下文推断

编译器会根据变量的使用方式来推断类型：

```rust
fn main() {
    // 编译器根据 push 的值推断 Vec<i32>
    let mut numbers = Vec::new();
    numbers.push(1);
    numbers.push(2);
    numbers.push(3);
    println!("numbers: {:?}", numbers);

    // 编译器根据返回值推断类型
    let parsed: i32 = "42".parse().expect("Failed to parse");
    println!("parsed: {}", parsed);

    // 如果不标注类型，编译器不知道 parse 成什么类型
    // let ambiguous = "42".parse().expect("Failed to parse");
    // 错误：type annotations needed
}
```

### 基于函数签名推断

```rust
fn double(value: i32) -> i32 {
    value * 2
}

fn main() {
    // 编译器根据函数参数类型推断 x 为 i32
    let x = 5;
    let result = double(x);
    println!("{} doubled is {}", x, result);
}
```

## 📌 类型标注

### 变量类型标注

```rust
fn main() {
    // 使用冒号标注类型
    let age: u32 = 25;
    let temperature: f32 = 36.6;
    let initial: char = 'R';
    let is_student: bool = false;

    println!("Age: {}, Temp: {}, Initial: {}, Student: {}",
        age, temperature, initial, is_student);

    // 使用类型后缀
    let count = 100u32;
    let distance = 3.5f32;
    let big_number = 1_000_000i64;

    println!("Count: {}, Distance: {}, Big: {}", count, distance, big_number);
}
```

### 必须标注的场景

#### 1. 字符串解析

```rust
fn main() {
    // 必须告诉编译器要解析成什么类型
    let integer: i64 = "12345".parse().expect("Not a number");
    let float: f64 = "3.14".parse().expect("Not a float");

    // 也可以使用 turbofish 语法
    let integer2 = "67890".parse::<i64>().expect("Not a number");

    println!("{} {} {}", integer, float, integer2);
}
```

#### 2. 集合类型

```rust
fn main() {
    // 空集合必须标注类型
    let empty_vec: Vec<i32> = Vec::new();
    let empty_vec2 = Vec::<String>::new();

    println!("Empty vecs: {:?} {:?}", empty_vec, empty_vec2);

    // 使用 collect 时必须标注目标类型
    let numbers: Vec<i32> = (1..=5).collect();
    let numbers2 = (1..=5).collect::<Vec<i32>>();

    println!("Collected: {:?} {:?}", numbers, numbers2);
}
```

#### 3. 有歧义的数字运算

```rust
fn main() {
    // 当需要非默认类型时必须标注
    let small: u8 = 255;
    let medium: u16 = 65535;
    let large: u64 = 1_000_000_000_000;

    println!("small: {}, medium: {}, large: {}", small, medium, large);
}
```

## 🐟 Turbofish 语法

Turbofish 语法 `::<T>` 用于在表达式中指定泛型参数的具体类型：

```rust
fn main() {
    // 在方法调用时指定类型
    let number = "42".parse::<i32>().expect("Parse failed");
    println!("Parsed: {}", number);

    // 在函数调用时指定类型
    let values = vec![1, 2, 3, 4, 5];
    let sum = values.iter().sum::<i32>();
    println!("Sum: {}", sum);

    // 在 collect 时指定类型
    let chars: Vec<char> = "hello".chars().collect();
    let chars2 = "world".chars().collect::<Vec<char>>();
    println!("chars: {:?}", chars);
    println!("chars2: {:?}", chars2);
}
```

## 📝 实际应用示例

### 配置解析

```rust
fn main() {
    let config_values = vec![
        ("port", "8080"),
        ("max_connections", "100"),
        ("timeout_seconds", "30"),
    ];

    for (key, value) in &config_values {
        let parsed: u32 = value.parse().expect(&format!("Failed to parse {}", key));
        println!("{} = {}", key, parsed);
    }

    // 解析不同类型
    let ratio: f64 = "0.75".parse().expect("Failed to parse ratio");
    let enabled: bool = "true".parse().expect("Failed to parse bool");
    println!("ratio: {}, enabled: {}", ratio, enabled);
}
```
