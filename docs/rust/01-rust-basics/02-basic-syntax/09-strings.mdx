# 字符串（String vs &str）

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

Rust 中有两种核心字符串类型：`String` 和 `&str`。`String` 是拥有所有权的、可增长的、堆分配的 UTF-8 编码字符串；`&str` 是字符串切片，是对 UTF-8 编码数据的不可变引用。理解这两者的区别是 Rust 学习中的重要一环。

## 🎯 &str：字符串切片

`&str` 是对一段 UTF-8 字节序列的不可变引用，通常称为"字符串切片"：

```rust
fn main() {
    // 字符串字面量的类型是 &str
    let greeting: &str = "Hello, World!";
    println!("{}", greeting);

    // 可以对字符串字面量取切片
    let hello = &greeting[0..5];
    let world = &greeting[7..12];
    println!("{} {}", hello, world);
}
```

## 📦 String：拥有所有权的字符串

`String` 存储在堆上，拥有数据的所有权，可以动态增长：

### 创建 String

```rust
fn main() {
    // 从字面量创建
    let name = String::from("Rust");
    let greeting = "Hello".to_string();
    let owned = "World".to_owned();

    println!("{} {} {}", name, greeting, owned);

    // 创建空字符串
    let mut buffer = String::new();
    buffer.push_str("Building ");
    buffer.push_str("a string");
    println!("{}", buffer);

    // 使用 with_capacity 预分配
    let mut large = String::with_capacity(100);
    large.push_str("Pre-allocated string");
    println!("{} (capacity: {})", large, large.capacity());
}
```

### 修改 String

```rust
fn main() {
    let mut message = String::from("Hello");

    // 追加字符串
    message.push_str(", World");

    // 追加单个字符
    message.push('!');

    println!("{}", message);

    // 插入
    message.insert(5, ',');
    message.insert_str(6, " Beautiful");
    println!("{}", message);

    // 替换
    let new_message = message.replace("Beautiful", "Wonderful");
    println!("{}", new_message);

    // 删除
    let mut trimming = String::from("Hello!!!");
    trimming.truncate(5);
    println!("{}", trimming);

    // 清空
    trimming.clear();
    println!("Empty: '{}'", trimming);
}
```

## 🔄 String 与 &str 的转换

```rust
fn main() {
    // &str → String
    let slice: &str = "hello";
    let owned1: String = slice.to_string();
    let owned2: String = String::from(slice);
    let owned3: String = slice.to_owned();
    println!("{} {} {}", owned1, owned2, owned3);

    // String → &str（自动解引用）
    let owned = String::from("world");
    let borrowed: &str = &owned;
    println!("{}", borrowed);

    // 函数参数推荐使用 &str，兼容两种类型
    print_greeting(&owned);         // String 自动转为 &str
    print_greeting("literal");       // &str 直接传入
}

fn print_greeting(text: &str) {
    println!("Greeting: {}", text);
}
```

## 📊 String 与 &str 的区别

| 特性 | `String` | `&str` |
|------|----------|--------|
| 所有权 | 拥有数据 | 借用数据 |
| 存储位置 | 堆 | 指向堆/栈/静态区 |
| 可变性 | 可增长、可修改 | 不可变 |
| 大小 | 运行时确定 | 编译期/运行时 |
| 内存布局 | (指针, 长度, 容量) | (指针, 长度) |

## 🔗 字符串拼接

```rust
fn main() {
    // 使用 + 运算符（左边必须是 String，右边是 &str）
    let hello = String::from("Hello");
    let world = String::from(", World!");
    let combined = hello + &world;
    // 注意：hello 的所有权被移动了，不能再使用
    println!("{}", combined);

    // 使用 format! 宏（不移动所有权，推荐）
    let first = String::from("Rust");
    let second = String::from("Programming");
    let sentence = format!("{} {} is great!", first, second);
    println!("{}", sentence);
    // first 和 second 仍然可用
    println!("Still usable: {} {}", first, second);

    // 使用 push_str 逐步构建
    let mut result = String::new();
    for word in ["Rust", "is", "fast"] {
        if !result.is_empty() {
            result.push(' ');
        }
        result.push_str(word);
    }
    println!("{}", result);
}
```

## 🔍 字符串常用方法

```rust
fn main() {
    let text = "  Hello, Rust World!  ";

    // 长度和判空
    println!("Length: {}", text.len());          // 字节长度
    println!("Is empty: {}", text.is_empty());

    // 去除空白
    let trimmed = text.trim();
    println!("Trimmed: '{}'", trimmed);

    // 大小写转换
    println!("Upper: {}", trimmed.to_uppercase());
    println!("Lower: {}", trimmed.to_lowercase());

    // 查找和判断
    println!("Contains 'Rust': {}", trimmed.contains("Rust"));
    println!("Starts with 'Hello': {}", trimmed.starts_with("Hello"));
    println!("Ends with '!': {}", trimmed.ends_with('!'));

    // 分割
    let csv = "apple,banana,cherry";
    let fruits: Vec<&str> = csv.split(',').collect();
    println!("Fruits: {:?}", fruits);

    // 字符遍历
    for character in "Hi🦀".chars() {
        println!("Char: {}", character);
    }
}
```

## ⚠️ UTF-8 和索引

Rust 的字符串是 UTF-8 编码的，不支持通过整数索引直接访问字符，因为一个字符可能占多个字节：

```rust
fn main() {
    let hello = "你好世界";

    // 字节长度 vs 字符数
    println!("Bytes: {}", hello.len());         // 12（每个中文 3 字节）
    println!("Chars: {}", hello.chars().count()); // 4

    // 按字符访问
    let first_char = hello.chars().nth(0);
    println!("First char: {:?}", first_char); // Some('你')

    // 安全地取子串
    let first_two: String = hello.chars().take(2).collect();
    println!("First two chars: {}", first_two); // 你好
}
```

## 📝 实际应用示例

### 单词计数器

```rust
fn count_words(text: &str) -> usize {
    text.split_whitespace().count()
}

fn word_frequency(text: &str) -> Vec<(&str, usize)> {
    let mut frequency: std::collections::HashMap<&str, usize> = std::collections::HashMap::new();

    for word in text.split_whitespace() {
        *frequency.entry(word).or_insert(0) += 1;
    }

    let mut result: Vec<(&str, usize)> = frequency.into_iter().collect();
    result.sort_by(|a, b| b.1.cmp(&a.1));
    result
}

fn main() {
    let text = "the quick brown fox jumps over the lazy dog the fox";

    println!("Word count: {}", count_words(text));

    println!("\nWord frequency:");
    for (word, count) in word_frequency(text) {
        println!("  {}: {}", word, count);
    }
}
```

## 🔗 相关概念

- **向量（Vec）**：String 本质上类似 `Vec<u8>` 并保证 UTF-8
- **数组与切片**：`&str` 类似于 `&[u8]` 的字符串版本
- **所有权系统**：String 和 &str 的所有权模型
