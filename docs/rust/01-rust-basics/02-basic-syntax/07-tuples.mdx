# 元组（Tuple）

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

元组（Tuple）是 Rust 中的复合类型，可以将多个不同类型的值组合在一起。元组的长度在编译期确定，一旦声明后无法增长或缩小。元组适合用来临时组合几个相关的值，尤其是函数需要返回多个值的场景。

## 🎯 创建元组

```rust
fn main() {
    // 基本元组
    let point = (10, 20);
    println!("Point: {:?}", point);

    // 不同类型的元组
    let person = ("Alice", 30, true);
    println!("Person: {:?}", person);

    // 带类型标注
    let record: (i32, f64, &str) = (42, 3.14, "hello");
    println!("Record: {:?}", record);

    // 单元素元组（注意末尾逗号）
    let single = (42,);
    println!("Single: {:?}", single);

    // 单元类型（空元组）
    let unit: () = ();
    println!("Unit: {:?}", unit);
}
```

## 🔍 访问元组元素

### 通过索引访问

```rust
fn main() {
    let coordinates = (100, 200, 300);

    let x = coordinates.0;
    let y = coordinates.1;
    let z = coordinates.2;

    println!("x: {}, y: {}, z: {}", x, y, z);
}
```

### 通过解构访问

```rust
fn main() {
    let person = ("Bob", 25, "engineer");

    // 完整解构
    let (name, age, role) = person;
    println!("{} is a {} year old {}", name, age, role);

    // 忽略部分值
    let (name, _, _) = person;
    println!("Name only: {}", name);

    // 使用 .. 忽略剩余值
    let (first, ..) = person;
    println!("First: {}", first);
}
```

## 🔄 元组与函数

### 函数返回多个值

```rust
fn min_max(numbers: &[i32]) -> (i32, i32) {
    let mut min = numbers[0];
    let mut max = numbers[0];

    for &num in &numbers[1..] {
        if num < min {
            min = num;
        }
        if num > max {
            max = num;
        }
    }

    (min, max)
}

fn main() {
    let numbers = [3, 1, 4, 1, 5, 9, 2, 6];
    let (min, max) = min_max(&numbers);
    println!("Min: {}, Max: {}", min, max);
}
```

### 函数参数为元组

```rust
fn distance(point1: (f64, f64), point2: (f64, f64)) -> f64 {
    let dx = point2.0 - point1.0;
    let dy = point2.1 - point1.1;
    (dx * dx + dy * dy).sqrt()
}

fn main() {
    let origin = (0.0, 0.0);
    let target = (3.0, 4.0);
    let dist = distance(origin, target);
    println!("Distance: {}", dist); // 5.0
}
```

## 📊 可变元组

```rust
fn main() {
    let mut position = (0, 0);
    println!("Start: {:?}", position);

    position.0 += 5;
    position.1 += 3;
    println!("After move: {:?}", position);

    position.0 -= 2;
    position.1 += 1;
    println!("After another move: {:?}", position);
}
```

## 📝 实际应用示例

### 解析坐标字符串

```rust
fn parse_coordinate(input: &str) -> Result<(f64, f64), String> {
    let parts: Vec<&str> = input.split(',').collect();
    if parts.len() != 2 {
        return Err(format!("Expected 2 values, got {}", parts.len()));
    }

    let x: f64 = parts[0].trim().parse()
        .map_err(|_| format!("Invalid x value: {}", parts[0]))?;
    let y: f64 = parts[1].trim().parse()
        .map_err(|_| format!("Invalid y value: {}", parts[1]))?;

    Ok((x, y))
}

fn main() {
    match parse_coordinate("3.5, 7.2") {
        Ok((x, y)) => println!("Coordinate: ({}, {})", x, y),
        Err(error) => println!("Error: {}", error),
    }

    match parse_coordinate("invalid") {
        Ok((x, y)) => println!("Coordinate: ({}, {})", x, y),
        Err(error) => println!("Error: {}", error),
    }
}
```

### 枚举和统计

```rust
fn count_types(values: &[i32]) -> (usize, usize, usize) {
    let mut positives = 0;
    let mut negatives = 0;
    let mut zeros = 0;

    for &value in values {
        match value.cmp(&0) {
            std::cmp::Ordering::Greater => positives += 1,
            std::cmp::Ordering::Less => negatives += 1,
            std::cmp::Ordering::Equal => zeros += 1,
        }
    }

    (positives, negatives, zeros)
}

fn main() {
    let data = [3, -1, 0, 7, -5, 0, 2, -3];
    let (pos, neg, zero) = count_types(&data);
    println!("Positives: {}, Negatives: {}, Zeros: {}", pos, neg, zero);
}
```
