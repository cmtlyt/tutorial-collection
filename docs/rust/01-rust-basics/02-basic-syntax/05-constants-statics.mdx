# 常量与静态变量

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

除了 `let` 绑定之外，Rust 还提供了 `const`（常量）和 `static`（静态变量）两种声明方式。常量在编译期求值并内联到使用处，而静态变量拥有固定的内存地址和 `'static` 生命周期。两者都必须显式标注类型。

## 🎯 常量（const）

### 基本语法

```rust
// 常量必须标注类型，值必须是编译期可计算的
const MAX_CONNECTIONS: u32 = 1000;
const PI: f64 = 3.14159265358979;
const APP_NAME: &str = "MyApp";
const IS_DEBUG: bool = false;

fn main() {
    println!("App: {}", APP_NAME);
    println!("Max connections: {}", MAX_CONNECTIONS);
    println!("Pi: {}", PI);
    println!("Debug mode: {}", IS_DEBUG);
}
```

### 常量表达式

常量的值必须在编译期可以确定，支持常量表达式：

```rust
const SECONDS_PER_MINUTE: u32 = 60;
const MINUTES_PER_HOUR: u32 = 60;
const SECONDS_PER_HOUR: u32 = SECONDS_PER_MINUTE * MINUTES_PER_HOUR;
const SECONDS_PER_DAY: u32 = SECONDS_PER_HOUR * 24;

const BUFFER_SIZE: usize = 1024 * 4; // 4KB

fn main() {
    println!("Seconds per hour: {}", SECONDS_PER_HOUR);
    println!("Seconds per day: {}", SECONDS_PER_DAY);
    println!("Buffer size: {} bytes", BUFFER_SIZE);
}
```

### 常量的作用域

常量可以在任何作用域中声明，包括全局作用域和函数内部：

```rust
const GLOBAL_LIMIT: u32 = 100;

fn process() {
    const LOCAL_LIMIT: u32 = 50;
    println!("Global: {}, Local: {}", GLOBAL_LIMIT, LOCAL_LIMIT);
}

fn main() {
    process();
    println!("Global limit: {}", GLOBAL_LIMIT);
    // LOCAL_LIMIT 在这里不可访问
}
```

### 命名约定

常量使用 `SCREAMING_SNAKE_CASE`（全大写蛇形命名）：

```rust
const MAX_RETRIES: u32 = 3;
const DEFAULT_TIMEOUT_MS: u64 = 5000;
const BASE_URL: &str = "https://api.example.com";

fn main() {
    println!("Retries: {}, Timeout: {}ms", MAX_RETRIES, DEFAULT_TIMEOUT_MS);
    println!("API: {}", BASE_URL);
}
```

## 📌 静态变量（static）

### 不可变静态变量

```rust
static VERSION: &str = "1.0.0";
static MAX_THREADS: u32 = 8;

fn main() {
    println!("Version: {}", VERSION);
    println!("Max threads: {}", MAX_THREADS);
}
```

### 可变静态变量

可变静态变量的访问是 `unsafe` 的，因为多线程环境下可能产生数据竞争：

```rust
static mut REQUEST_COUNT: u64 = 0;

fn increment_counter() {
    unsafe {
        REQUEST_COUNT += 1;
    }
}

fn main() {
    increment_counter();
    increment_counter();
    increment_counter();

    unsafe {
        println!("Total requests: {}", REQUEST_COUNT);
    }
}
```

:::warning
可变静态变量（`static mut`）在实际项目中应尽量避免使用。如果需要全局可变状态，推荐使用 `std::sync::Mutex`、`std::sync::atomic` 等线程安全方案。
:::

## 📊 const vs static vs let

| 特性 | `const` | `static` | `let` |
|------|---------|----------|-------|
| 必须标注类型 | ✅ | ✅ | ❌（可推断） |
| 编译期求值 | ✅ | ✅ | ❌ |
| 固定内存地址 | ❌（内联） | ✅ | ✅ |
| 可在全局作用域 | ✅ | ✅ | ❌ |
| 支持可变 | ❌ | ✅（unsafe） | ✅（mut） |
| 生命周期 | 无（内联） | `'static` | 受作用域限制 |
| 遮蔽（Shadowing） | ❌ | ❌ | ✅ |

### 如何选择

```rust
// 用 const：编译期已知的配置值、数学常数
const MAX_SIZE: usize = 1024;
const GOLDEN_RATIO: f64 = 1.618033988749895;

// 用 static：需要固定内存地址的全局数据
static GREETING: &str = "Hello, World!";

fn main() {
    // 用 let：运行时计算的值
    let user_input = String::from("hello");
    let processed = user_input.to_uppercase();

    println!("Max size: {}", MAX_SIZE);
    println!("Golden ratio: {}", GOLDEN_RATIO);
    println!("Greeting: {}", GREETING);
    println!("Processed: {}", processed);
}
```

## 📝 实际应用示例

### 应用配置常量

```rust
const APP_VERSION: &str = "2.1.0";
const DEFAULT_PORT: u16 = 8080;
const MAX_PAYLOAD_SIZE: usize = 10 * 1024 * 1024; // 10 MB
const REQUEST_TIMEOUT_SECS: u64 = 30;
const MAX_RETRY_ATTEMPTS: u32 = 3;

fn print_config() {
    println!("=== Application Config ===");
    println!("Version: {}", APP_VERSION);
    println!("Port: {}", DEFAULT_PORT);
    println!("Max payload: {} bytes ({} MB)", MAX_PAYLOAD_SIZE, MAX_PAYLOAD_SIZE / 1024 / 1024);
    println!("Timeout: {}s", REQUEST_TIMEOUT_SECS);
    println!("Max retries: {}", MAX_RETRY_ATTEMPTS);
}

fn main() {
    print_config();
}
```
