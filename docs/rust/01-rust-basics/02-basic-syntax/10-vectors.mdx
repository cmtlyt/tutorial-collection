# 向量（Vec）

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

`Vec<T>`（向量）是 Rust 标准库提供的动态数组类型，存储在堆上，长度可以在运行时动态增长或缩小。与固定长度的数组不同，Vec 是实际项目中最常用的集合类型之一，适用于需要动态管理同类型元素列表的场景。

## 🎯 创建 Vec

```rust
fn main() {
    // 使用 Vec::new 创建空向量
    let mut numbers: Vec<i32> = Vec::new();
    numbers.push(1);
    numbers.push(2);
    numbers.push(3);
    println!("numbers: {:?}", numbers);

    // 使用 vec! 宏创建（推荐）
    let fruits = vec!["apple", "banana", "cherry"];
    println!("fruits: {:?}", fruits);

    // 创建带初始值的向量
    let zeros = vec![0; 5]; // 5 个 0
    println!("zeros: {:?}", zeros);

    // 使用 with_capacity 预分配
    let mut buffer = Vec::with_capacity(100);
    buffer.push(1);
    println!("Length: {}, Capacity: {}", buffer.len(), buffer.capacity());
}
```

## 🔍 访问元素

```rust
fn main() {
    let colors = vec!["red", "green", "blue", "yellow"];

    // 通过索引访问（越界会 panic）
    let first = colors[0];
    println!("First: {}", first);

    // 通过 get 方法安全访问（返回 Option）
    match colors.get(10) {
        Some(color) => println!("Color: {}", color),
        None => println!("Index out of bounds"),
    }

    // 获取首尾元素
    println!("First: {:?}", colors.first());
    println!("Last: {:?}", colors.last());
}
```

## ✏️ 修改 Vec

```rust
fn main() {
    let mut tasks = vec!["coding", "testing"];
    println!("Initial: {:?}", tasks);

    // 末尾添加
    tasks.push("deploying");
    println!("After push: {:?}", tasks);

    // 末尾移除
    let removed = tasks.pop();
    println!("Popped: {:?}, remaining: {:?}", removed, tasks);

    // 指定位置插入
    tasks.insert(1, "reviewing");
    println!("After insert: {:?}", tasks);

    // 指定位置移除
    let removed = tasks.remove(0);
    println!("Removed '{}': {:?}", removed, tasks);

    // 扩展
    let more_tasks = vec!["monitoring", "optimizing"];
    tasks.extend(more_tasks);
    println!("Extended: {:?}", tasks);

    // 清空
    tasks.clear();
    println!("Cleared: {:?} (len: {})", tasks, tasks.len());
}
```

## 🔄 遍历 Vec

```rust
fn main() {
    let scores = vec![85, 92, 78, 95, 88];

    // 不可变遍历
    for score in &scores {
        println!("Score: {}", score);
    }

    // 可变遍历
    let mut values = vec![1, 2, 3, 4, 5];
    for value in &mut values {
        *value *= 10;
    }
    println!("Scaled: {:?}", values);

    // 带索引遍历
    for (index, score) in scores.iter().enumerate() {
        println!("#{}: {}", index + 1, score);
    }

    // 消费遍历（移动所有权）
    let names = vec![String::from("Alice"), String::from("Bob")];
    for name in names {
        println!("Hello, {}!", name);
    }
    // names 已被消费，不能再使用
}
```

## 🛠️ 常用方法

```rust
fn main() {
    let mut numbers = vec![3, 1, 4, 1, 5, 9, 2, 6];

    // 查询
    println!("Length: {}", numbers.len());
    println!("Is empty: {}", numbers.is_empty());
    println!("Contains 5: {}", numbers.contains(&5));

    // 排序
    numbers.sort();
    println!("Sorted: {:?}", numbers);

    // 去重（需要先排序）
    numbers.dedup();
    println!("Deduped: {:?}", numbers);

    // 反转
    numbers.reverse();
    println!("Reversed: {:?}", numbers);

    // 截断
    numbers.truncate(4);
    println!("Truncated: {:?}", numbers);

    // 保留符合条件的元素
    let mut values = vec![1, 2, 3, 4, 5, 6, 7, 8];
    values.retain(|&x| x % 2 == 0);
    println!("Even only: {:?}", values);
}
```

## 🔗 Vec 与切片

```rust
fn print_sum(values: &[i32]) {
    let total: i32 = values.iter().sum();
    println!("Sum: {}", total);
}

fn main() {
    let numbers = vec![10, 20, 30, 40, 50];

    // Vec 自动解引用为切片
    print_sum(&numbers);

    // 取部分切片
    print_sum(&numbers[1..4]);
}
```

## 📝 实际应用示例

### 学生成绩管理

```rust
fn calculate_statistics(scores: &[f64]) -> (f64, f64, f64) {
    if scores.is_empty() {
        return (0.0, 0.0, 0.0);
    }

    let sum: f64 = scores.iter().sum();
    let average = sum / scores.len() as f64;

    let mut sorted = scores.to_vec();
    sorted.sort_by(|a, b| a.partial_cmp(b).unwrap());

    let min = sorted[0];
    let max = sorted[sorted.len() - 1];

    (average, min, max)
}

fn main() {
    let mut all_scores: Vec<f64> = Vec::new();

    // 模拟添加成绩
    let new_scores = vec![85.5, 92.0, 78.5, 95.0, 88.0, 72.5, 91.0];
    all_scores.extend(new_scores);

    // 过滤出优秀成绩（>= 90）
    let excellent: Vec<&f64> = all_scores.iter().filter(|&&s| s >= 90.0).collect();
    println!("Excellent scores: {:?}", excellent);

    // 统计
    let (avg, min, max) = calculate_statistics(&all_scores);
    println!("Average: {:.1}, Min: {:.1}, Max: {:.1}", avg, min, max);
    println!("Total students: {}", all_scores.len());
}
```
