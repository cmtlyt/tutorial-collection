# HashMap 与 BTreeMap

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

HashMap 和 BTreeMap 是 Rust 标准库提供的两种键值对集合。HashMap 使用哈希表实现，提供平均 O(1) 的查找性能；BTreeMap 使用 B 树实现，键按排序顺序存储，提供 O(log n) 的查找性能。两者的 API 非常相似，根据是否需要键排序来选择使用。

## 🎯 HashMap

### 创建与基本操作

```rust
use std::collections::HashMap;

fn main() {
    // 创建空 HashMap
    let mut scores: HashMap<String, i32> = HashMap::new();

    // 插入键值对
    scores.insert(String::from("Alice"), 95);
    scores.insert(String::from("Bob"), 87);
    scores.insert(String::from("Charlie"), 92);

    println!("{:?}", scores);

    // 使用 collect 从元组迭代器创建
    let teams = vec!["Red", "Blue", "Green"];
    let points = vec![100, 85, 92];
    let team_scores: HashMap<&str, i32> = teams.into_iter().zip(points).collect();
    println!("{:?}", team_scores);
}
```

### 访问值

```rust
use std::collections::HashMap;

fn main() {
    let mut capitals = HashMap::new();
    capitals.insert("China", "Beijing");
    capitals.insert("Japan", "Tokyo");
    capitals.insert("France", "Paris");

    // 通过 get 方法（返回 Option<&V>）
    match capitals.get("China") {
        Some(capital) => println!("Capital of China: {}", capital),
        None => println!("Not found"),
    }

    // 使用 if let 简化
    if let Some(capital) = capitals.get("Japan") {
        println!("Capital of Japan: {}", capital);
    }

    // 判断是否包含键
    println!("Has France: {}", capitals.contains_key("France"));
    println!("Has Germany: {}", capitals.contains_key("Germany"));
}
```

### 更新值

```rust
use std::collections::HashMap;

fn main() {
    let mut scores = HashMap::new();

    // 直接覆盖
    scores.insert("Alice", 90);
    scores.insert("Alice", 95); // 覆盖旧值
    println!("Alice: {}", scores["Alice"]); // 95

    // 仅在键不存在时插入
    scores.entry("Bob").or_insert(80);
    scores.entry("Bob").or_insert(100); // Bob 已存在，不会覆盖
    println!("Bob: {}", scores["Bob"]); // 80

    // 基于旧值更新
    let text = "hello world hello rust hello world";
    let mut word_count = HashMap::new();

    for word in text.split_whitespace() {
        let count = word_count.entry(word).or_insert(0);
        *count += 1;
    }
    println!("Word counts: {:?}", word_count);
}
```

### 遍历

```rust
use std::collections::HashMap;

fn main() {
    let mut inventory = HashMap::new();
    inventory.insert("apple", 30);
    inventory.insert("banana", 15);
    inventory.insert("cherry", 45);

    // 遍历键值对
    for (item, quantity) in &inventory {
        println!("{}: {}", item, quantity);
    }

    // 仅遍历键
    let items: Vec<&&str> = inventory.keys().collect();
    println!("Items: {:?}", items);

    // 仅遍历值
    let total: i32 = inventory.values().sum();
    println!("Total quantity: {}", total);
}
```

### 删除

```rust
use std::collections::HashMap;

fn main() {
    let mut config = HashMap::new();
    config.insert("debug", "true");
    config.insert("port", "8080");
    config.insert("host", "localhost");

    println!("Before: {:?}", config);

    // 移除键值对
    let removed = config.remove("debug");
    println!("Removed: {:?}", removed);
    println!("After: {:?}", config);

    // 保留符合条件的项
    config.insert("timeout", "30");
    config.insert("log_level", "info");
    config.retain(|key, _| key.len() <= 4);
    println!("Retained: {:?}", config);
}
```

## 🌲 BTreeMap

BTreeMap 的 API 与 HashMap 几乎完全相同，但键会按排序顺序存储：

```rust
use std::collections::BTreeMap;

fn main() {
    let mut ordered = BTreeMap::new();
    ordered.insert("cherry", 3);
    ordered.insert("apple", 1);
    ordered.insert("banana", 2);

    // 键按字典序排列
    for (key, value) in &ordered {
        println!("{}: {}", key, value);
    }
    // 输出：apple: 1, banana: 2, cherry: 3

    // 范围查询（HashMap 不支持）
    let range: Vec<(&&str, &i32)> = ordered.range("apple"..="banana").collect();
    println!("Range [apple, banana]: {:?}", range);

    // 获取最小/最大键
    println!("First: {:?}", ordered.iter().next());
    println!("Last: {:?}", ordered.iter().next_back());
}
```

## 📊 HashMap vs BTreeMap

| 特性 | HashMap | BTreeMap |
|------|---------|----------|
| 内部实现 | 哈希表 | B 树 |
| 查找复杂度 | O(1) 平均 | O(log n) |
| 键的顺序 | 无序 | 有序（排序） |
| 范围查询 | ❌ | ✅ |
| 键的要求 | Hash + Eq | Ord |
| 最佳场景 | 快速查找 | 需要排序或范围查询 |

## 📝 实际应用示例

### 简单的联系人管理

```rust
use std::collections::HashMap;

fn main() {
    let mut contacts: HashMap<String, Vec<String>> = HashMap::new();

    // 添加联系人和电话
    contacts
        .entry(String::from("Alice"))
        .or_insert_with(Vec::new)
        .push(String::from("123-456-7890"));

    contacts
        .entry(String::from("Alice"))
        .or_insert_with(Vec::new)
        .push(String::from("098-765-4321"));

    contacts
        .entry(String::from("Bob"))
        .or_insert_with(Vec::new)
        .push(String::from("555-123-4567"));

    // 查找联系人
    let name = "Alice";
    match contacts.get(name) {
        Some(phones) => {
            println!("{}:", name);
            for phone in phones {
                println!("  - {}", phone);
            }
        }
        None => println!("{} not found", name),
    }

    // 列出所有联系人
    println!("\nAll contacts:");
    for (name, phones) in &contacts {
        println!("  {} ({} numbers)", name, phones.len());
    }
}
```
