# 基本数据类型

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

Rust 是静态类型语言，每个值都有确定的类型。Rust 的基本数据类型（也称标量类型）包括整数、浮点数、布尔值和字符四种。理解这些类型的范围、行为和使用场景是编写正确 Rust 程序的基础。

## 🔢 整数类型

### 有符号整数与无符号整数

| 类型 | 大小 | 有符号范围 | 无符号范围 |
|------|------|-----------|-----------|
| `i8` / `u8` | 8 bit | -128 ~ 127 | 0 ~ 255 |
| `i16` / `u16` | 16 bit | -32,768 ~ 32,767 | 0 ~ 65,535 |
| `i32` / `u32` | 32 bit | -2³¹ ~ 2³¹-1 | 0 ~ 2³²-1 |
| `i64` / `u64` | 64 bit | -2⁶³ ~ 2⁶³-1 | 0 ~ 2⁶⁴-1 |
| `i128` / `u128` | 128 bit | -2¹²⁷ ~ 2¹²⁷-1 | 0 ~ 2¹²⁸-1 |
| `isize` / `usize` | 平台相关 | 取决于架构 | 取决于架构 |

:::tip
`isize` 和 `usize` 的大小取决于运行平台：64 位系统上是 64 bit，32 位系统上是 32 bit。`usize` 常用于索引和集合大小。
:::

### 整数字面量

```rust
fn main() {
    // 十进制
    let decimal = 98_222;

    // 十六进制
    let hex = 0xff;

    // 八进制
    let octal = 0o77;

    // 二进制
    let binary = 0b1111_0000;

    // 字节（仅限 u8）
    let byte = b'A';

    // 带类型后缀
    let typed = 42u32;
    let long = 100_000i64;

    println!("decimal: {}", decimal);
    println!("hex: {}", hex);
    println!("octal: {}", octal);
    println!("binary: {}", binary);
    println!("byte: {}", byte);
    println!("typed: {}", typed);
    println!("long: {}", long);
}
```

### 整数溢出

```rust
fn main() {
    let max_u8: u8 = 255;
    println!("Max u8: {}", max_u8);

    // debug 模式下溢出会 panic
    // release 模式下会按补码回绕

    // 使用 wrapping 系列方法显式处理溢出
    let wrapped = max_u8.wrapping_add(1);
    println!("255 wrapping_add 1: {}", wrapped); // 0

    // 使用 checked 系列方法返回 Option
    let checked = max_u8.checked_add(1);
    println!("255 checked_add 1: {:?}", checked); // None

    // 使用 saturating 系列方法饱和到边界
    let saturated = max_u8.saturating_add(10);
    println!("255 saturating_add 10: {}", saturated); // 255

    // 使用 overflowing 系列方法返回值和是否溢出
    let (result, overflowed) = max_u8.overflowing_add(1);
    println!("255 overflowing_add 1: {} (overflow: {})", result, overflowed);
}
```

## 🔢 浮点类型

Rust 提供两种浮点类型：`f32`（单精度）和 `f64`（双精度，默认）。

```rust
fn main() {
    // 默认 f64
    let pi = 3.14159265358979;

    // 显式 f32
    let approx_pi: f32 = 3.14;

    println!("f64 pi: {}", pi);
    println!("f32 pi: {}", approx_pi);

    // 基本运算
    let sum = 5.0 + 10.5;
    let difference = 95.5 - 4.3;
    let product = 4.0 * 30.5;
    let quotient = 56.7 / 32.2;
    let remainder = 43.0_f64 % 5.0;

    println!("sum: {}", sum);
    println!("difference: {}", difference);
    println!("product: {}", product);
    println!("quotient: {}", quotient);
    println!("remainder: {}", remainder);
}
```

:::warning
浮点数不能直接用 `==` 进行精确比较，应使用误差范围比较：
```rust
fn main() {
    let a = 0.1 + 0.2;
    let b = 0.3;

    // 不可靠的比较
    println!("0.1 + 0.2 == 0.3? {}", a == b); // false

    // 使用误差范围比较
    let epsilon = f64::EPSILON;
    println!("Approximately equal? {}", (a - b).abs() < epsilon);
}
```
:::

## ✅ 布尔类型

```rust
fn main() {
    let is_active: bool = true;
    let is_deleted = false;

    println!("Active: {}", is_active);
    println!("Deleted: {}", is_deleted);

    // 布尔运算
    let and_result = is_active && !is_deleted;
    let or_result = is_active || is_deleted;

    println!("Active and not deleted: {}", and_result);
    println!("Active or deleted: {}", or_result);

    // 布尔值在条件表达式中使用
    let status = if is_active { "online" } else { "offline" };
    println!("Status: {}", status);
}
```

## 🔤 字符类型

Rust 的 `char` 类型占 4 个字节，表示一个 Unicode 标量值，可以表示中文、emoji 等：

```rust
fn main() {
    let letter = 'A';
    let chinese = '中';
    let emoji = '🦀';
    let heart = '❤';

    println!("letter: {} (size: {} bytes)", letter, std::mem::size_of::<char>());
    println!("chinese: {}", chinese);
    println!("emoji: {}", emoji);
    println!("heart: {}", heart);

    // char 的方法
    println!("'A' is alphabetic: {}", 'A'.is_alphabetic());
    println!("'3' is numeric: {}", '3'.is_numeric());
    println!("'a' to uppercase: {}", 'a'.to_uppercase().next().unwrap());
    println!("' ' is whitespace: {}", ' '.is_whitespace());
}
```

:::tip
注意 `char` 用单引号 `'a'`，字符串用双引号 `"hello"`，两者完全不同。`char` 是单个 Unicode 标量值，而字符串是 UTF-8 编码的字节序列。
:::

## 🔄 类型转换

Rust 不支持隐式类型转换，必须使用 `as` 进行显式转换：

```rust
fn main() {
    let integer: i32 = 42;
    let float: f64 = integer as f64;
    println!("{} as f64 = {}", integer, float);

    let large: f64 = 256.99;
    let truncated: u8 = large as u8;
    println!("{} as u8 = {}", large, truncated); // 截断为 0（溢出时按 u8 最大值截断）

    let character = 'A';
    let ascii_code = character as u32;
    println!("'{}' as u32 = {}", character, ascii_code); // 65

    let code: u8 = 90;
    let letter = code as char;
    println!("{} as char = '{}'", code, letter); // 'Z'
}
```

## 📝 实际应用示例

### 温度转换计算器

```rust
fn celsius_to_fahrenheit(celsius: f64) -> f64 {
    celsius * 9.0 / 5.0 + 32.0
}

fn fahrenheit_to_celsius(fahrenheit: f64) -> f64 {
    (fahrenheit - 32.0) * 5.0 / 9.0
}

fn main() {
    let boiling_celsius = 100.0;
    let boiling_fahrenheit = celsius_to_fahrenheit(boiling_celsius);
    println!("{}°C = {:.1}°F", boiling_celsius, boiling_fahrenheit);

    let body_temp_f = 98.6;
    let body_temp_c = fahrenheit_to_celsius(body_temp_f);
    println!("{:.1}°F = {:.1}°C", body_temp_f, body_temp_c);

    let freezing = 32.0;
    let freezing_c = fahrenheit_to_celsius(freezing);
    println!("{:.1}°F = {:.1}°C", freezing, freezing_c);
}
```
