# 不可变绑定与可变绑定

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

在 Rust 中，变量通过 `let` 关键字声明，默认是**不可变的**（immutable）。如果需要修改变量的值，必须显式使用 `let mut` 声明为可变绑定。这种设计是 Rust 安全性哲学的重要组成部分——鼓励开发者默认使用不可变数据，只有在确实需要修改时才声明可变。

## 🎯 不可变绑定（let）

### 基本用法

```rust
fn main() {
    let name = "Rust";
    let year = 2015;
    let pi = 3.14159;

    println!("Language: {}", name);
    println!("First released: {}", year);
    println!("Pi: {}", pi);
}
```

### 不可变意味着什么

不可变绑定一旦赋值后就不能再修改：

```rust
fn main() {
    let language = "Rust";
    println!("Language: {}", language);

    // 下面这行代码会导致编译错误：
    // language = "Go";
    // 错误信息：cannot assign twice to immutable variable `language`
}
```

### 不可变的好处

- **安全性**：防止意外修改数据，减少 Bug
- **并发友好**：不可变数据天然线程安全
- **可读性**：阅读代码时可以确信变量值不会被改变
- **编译器优化**：编译器可以对不可变数据做更多优化

## 🔄 可变绑定（let mut）

当确实需要修改变量的值时，使用 `let mut`：

```rust
fn main() {
    let mut counter = 0;
    println!("Initial: {}", counter);

    counter += 1;
    println!("After increment: {}", counter);

    counter += 1;
    println!("After another increment: {}", counter);

    let mut message = String::from("Hello");
    println!("Before: {}", message);

    message.push_str(", World!");
    println!("After: {}", message);
}
```

### 何时使用 mut

```rust
fn main() {
    // 需要累加 —— 使用 mut
    let mut total = 0;
    for i in 1..=5 {
        total += i;
    }
    println!("Sum of 1 to 5: {}", total);

    // 不需要修改 —— 不使用 mut
    let result = total * 2;
    println!("Double: {}", result);
}
```

## 🔗 变量绑定的本质

Rust 中 `let` 本质上是**模式匹配绑定**，而不仅仅是变量声明：

```rust
fn main() {
    // 基本绑定
    let x = 5;
    println!("x = {}", x);

    // 解构元组
    let (a, b, c) = (1, 2.0, "three");
    println!("a = {}, b = {}, c = {}", a, b, c);

    // 解构元组并标注类型
    let (width, height): (u32, u32) = (1920, 1080);
    println!("Resolution: {}x{}", width, height);

    // 忽略部分值
    let (first, _, third) = (10, 20, 30);
    println!("first = {}, third = {}", first, third);
}
```

## 📝 实际应用示例

### 构建用户信息

```rust
fn main() {
    // 不可变数据：用户 ID 一旦确定就不会变
    let user_id = 42;

    // 可变数据：用户名可以被修改
    let mut username = String::from("alice");
    println!("User #{}: {}", user_id, username);

    // 修改用户名
    username = String::from("alice_updated");
    println!("User #{}: {}", user_id, username);

    // 可变的计数器
    let mut login_count = 0;
    login_count += 1;
    login_count += 1;
    println!("User #{} logged in {} times", user_id, login_count);
}
```

### 交换两个变量的值

```rust
fn main() {
    let mut a = 10;
    let mut b = 20;
    println!("Before swap: a = {}, b = {}", a, b);

    let temp = a;
    a = b;
    b = temp;
    println!("After swap: a = {}, b = {}", a, b);
}
```
