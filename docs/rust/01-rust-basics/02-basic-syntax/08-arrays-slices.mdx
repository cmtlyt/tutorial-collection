# 数组与切片

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

数组（Array）是 Rust 中固定长度的同类型元素集合，存储在栈上。切片（Slice）是对数组或其他连续内存区域的引用视图，长度在运行时确定。数组适合存储已知数量的同类型数据，而切片提供了灵活访问数组部分元素的能力。

## 🎯 数组（Array）

### 创建数组

```rust
fn main() {
    // 类型自动推断
    let numbers = [1, 2, 3, 4, 5];
    println!("numbers: {:?}", numbers);

    // 显式标注类型和长度
    let scores: [i32; 5] = [90, 85, 92, 88, 95];
    println!("scores: {:?}", scores);

    // 使用重复值初始化
    let zeros = [0; 10]; // 10 个 0
    println!("zeros: {:?}", zeros);

    let filled = [true; 3];
    println!("filled: {:?}", filled);
}
```

### 访问数组元素

```rust
fn main() {
    let days = ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"];

    // 通过索引访问
    let first = days[0];
    let last = days[6];
    println!("First: {}, Last: {}", first, last);

    // 获取数组长度
    println!("Length: {}", days.len());

    // 安全访问（返回 Option）
    match days.get(7) {
        Some(day) => println!("Day: {}", day),
        None => println!("Index out of bounds"),
    }
}
```

### 遍历数组

```rust
fn main() {
    let prices = [19.99, 29.99, 39.99, 49.99];

    // for 循环遍历
    for price in &prices {
        println!("Price: ${:.2}", price);
    }

    // 带索引遍历
    for (index, price) in prices.iter().enumerate() {
        println!("Item {}: ${:.2}", index + 1, price);
    }
}
```

### 可变数组

```rust
fn main() {
    let mut grades = [0; 5];
    println!("Initial: {:?}", grades);

    grades[0] = 85;
    grades[1] = 92;
    grades[2] = 78;
    grades[3] = 95;
    grades[4] = 88;
    println!("Updated: {:?}", grades);
}
```

## 🔍 切片（Slice）

切片是对数组（或其他连续内存）的引用，类型写作 `&[T]`：

### 创建切片

```rust
fn main() {
    let numbers = [10, 20, 30, 40, 50, 60];

    // 完整切片
    let all: &[i32] = &numbers;
    println!("All: {:?}", all);

    // 范围切片
    let first_three = &numbers[0..3];
    println!("First three: {:?}", first_three);

    let middle = &numbers[2..5];
    println!("Middle: {:?}", middle);

    // 省略起始或结束
    let from_start = &numbers[..3]; // [10, 20, 30]
    let to_end = &numbers[3..];     // [40, 50, 60]
    let full = &numbers[..];        // 全部

    println!("From start: {:?}", from_start);
    println!("To end: {:?}", to_end);
    println!("Full: {:?}", full);
}
```

### 切片作为函数参数

切片是函数接收数组参数的推荐方式，因为它不关心底层数据的具体长度：

```rust
fn sum(values: &[i32]) -> i32 {
    let mut total = 0;
    for &value in values {
        total += value;
    }
    total
}

fn average(values: &[f64]) -> f64 {
    if values.is_empty() {
        return 0.0;
    }
    let total: f64 = values.iter().sum();
    total / values.len() as f64
}

fn main() {
    let array = [1, 2, 3, 4, 5];
    println!("Sum of array: {}", sum(&array));
    println!("Sum of slice: {}", sum(&array[1..4]));

    let grades = [85.5, 92.0, 78.5, 95.0, 88.0];
    println!("Average: {:.1}", average(&grades));
}
```

### 可变切片

```rust
fn double_values(values: &mut [i32]) {
    for value in values.iter_mut() {
        *value *= 2;
    }
}

fn main() {
    let mut numbers = [1, 2, 3, 4, 5];
    println!("Before: {:?}", numbers);

    double_values(&mut numbers[1..4]);
    println!("After doubling [1..4]: {:?}", numbers);
}
```

### 切片的常用方法

```rust
fn main() {
    let data = [5, 3, 8, 1, 9, 2, 7];

    println!("Length: {}", data.len());
    println!("Is empty: {}", data.is_empty());
    println!("Contains 8: {}", data.contains(&8));
    println!("First: {:?}", data.first());
    println!("Last: {:?}", data.last());

    // 排序（需要可变）
    let mut sortable = [5, 3, 8, 1, 9, 2, 7];
    sortable.sort();
    println!("Sorted: {:?}", sortable);

    // 分块
    let chunks: Vec<&[i32]> = data.chunks(3).collect();
    println!("Chunks of 3: {:?}", chunks);

    // 窗口
    let windows: Vec<&[i32]> = data.windows(3).collect();
    println!("Windows of 3: {:?}", windows);
}
```

## 📝 实际应用示例

### 查找最大值和索引

```rust
fn find_max_with_index(values: &[i32]) -> Option<(usize, i32)> {
    if values.is_empty() {
        return None;
    }

    let mut max_index = 0;
    let mut max_value = values[0];

    for (index, &value) in values.iter().enumerate() {
        if value > max_value {
            max_value = value;
            max_index = index;
        }
    }

    Some((max_index, max_value))
}

fn main() {
    let scores = [72, 95, 88, 67, 91, 83];

    match find_max_with_index(&scores) {
        Some((index, value)) => {
            println!("Max score: {} at index {}", value, index);
        }
        None => println!("No scores available"),
    }
}
```
