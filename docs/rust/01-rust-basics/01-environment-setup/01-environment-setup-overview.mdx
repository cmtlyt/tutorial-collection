## 🔑 核心概念

### Rust 工具链
Rust 通过 rustup 管理工具链，包括编译器（rustc）、包管理器（Cargo）、格式化工具（rustfmt）和代码检查工具（clippy）。这套工具链为 Rust 开发提供了完整的支持。

### Cargo：Rust 的构建系统与包管理器
Cargo 是 Rust 的官方构建工具和包管理器，负责：
1. **项目创建**：`cargo new` / `cargo init`
2. **编译构建**：`cargo build` / `cargo run`
3. **依赖管理**：通过 Cargo.toml 声明和管理依赖
4. **测试运行**：`cargo test`
5. **包发布**：`cargo publish`
