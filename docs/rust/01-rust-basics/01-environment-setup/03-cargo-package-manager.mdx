# Cargo 包管理器

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

Cargo 是 Rust 的官方构建系统和包管理器。它负责项目的创建、编译构建、依赖管理、测试运行和包发布等工作。Cargo 是 Rust 生态系统的核心基础设施，几乎所有 Rust 项目都通过 Cargo 来管理。

## 🎯 创建项目

### 使用 cargo new

```bash
# 创建二进制项目（可执行程序）
cargo new my-project
# 创建的目录结构：
# my-project/
# ├── Cargo.toml
# └── src/
#     └── main.rs

# 创建库项目
cargo new my-library --lib
# 创建的目录结构：
# my-library/
# ├── Cargo.toml
# └── src/
#     └── lib.rs
```

### 使用 cargo init

在已有目录中初始化 Cargo 项目：

```bash
mkdir my-project && cd my-project
cargo init          # 默认创建二进制项目
cargo init --lib    # 创建库项目
```

### 默认生成的文件

二进制项目的 `src/main.rs`：

```rust
fn main() {
    println!("Hello, world!");
}
```

库项目的 `src/lib.rs`：

```rust
pub fn add(left: u64, right: u64) -> u64 {
    left + right
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn it_works() {
        let result = add(2, 2);
        assert_eq!(result, 4);
    }
}
```

## 🔨 构建与运行

### 常用命令

```bash
# 编译项目（debug 模式）
cargo build

# 编译并运行
cargo run

# 仅检查代码是否能编译（比 build 更快）
cargo check

# 以 release 模式编译（启用优化）
cargo build --release

# 以 release 模式编译并运行
cargo run --release
```

### debug 与 release 的区别

| 特性 | debug | release |
|------|-------|---------|
| 编译速度 | 快 | 慢 |
| 运行速度 | 慢 | 快 |
| 文件大小 | 大 | 小 |
| 调试信息 | 包含 | 不包含 |
| 优化级别 | 0 | 3 |
| 输出目录 | `target/debug/` | `target/release/` |

### 传递命令行参数

```bash
# 向程序传递参数
cargo run -- arg1 arg2

# 示例
cargo run -- --name "Rust"
```

## 📦 依赖管理

### 添加依赖

在 `Cargo.toml` 的 `[dependencies]` 节中声明依赖：

```toml
[dependencies]
serde = "1.0"
serde_json = "1.0"
tokio = { version = "1", features = ["full"] }
```

或使用 `cargo add` 命令：

```bash
# 添加最新版本
cargo add serde

# 添加指定版本
cargo add serde@1.0.200

# 添加带 features 的依赖
cargo add tokio --features full

# 添加开发依赖
cargo add --dev assert_cmd
```

### 版本号语法

Cargo 使用语义化版本（SemVer）：

```toml
[dependencies]
# 精确版本
exact-crate = "=1.2.3"

# 兼容版本（默认行为，等价于 ^1.2.3）
compat-crate = "1.2.3"    # 允许 >=1.2.3, <2.0.0

# 波浪号版本
tilde-crate = "~1.2.3"    # 允许 >=1.2.3, <1.3.0

# 通配符版本
wildcard-crate = "1.2.*"  # 允许 >=1.2.0, <1.3.0
```

### 更新依赖

```bash
# 更新所有依赖到兼容的最新版本
cargo update

# 更新指定依赖
cargo update serde

# 查看可更新的依赖
cargo outdated  # 需安装 cargo-outdated
```

## 🧪 测试

```bash
# 运行所有测试
cargo test

# 运行指定测试
cargo test test_name

# 运行指定模块的测试
cargo test module_name::

# 显示测试中的 println! 输出
cargo test -- --nocapture

# 运行文档测试
cargo test --doc

# 仅编译测试，不运行
cargo test --no-run
```

## 📝 实际应用示例

### 创建一个完整的小项目

```bash
# 创建项目
cargo new greeting-app
cd greeting-app
```

编辑 `src/main.rs`：

```rust
use std::io;

fn greet(name: &str) -> String {
    format!("Hello, {}! Welcome to Rust.", name)
}

fn main() {
    println!("What is your name?");
    let mut name = String::new();
    io::stdin()
        .read_line(&mut name)
        .expect("Failed to read input");
    let name = name.trim();
    println!("{}", greet(name));
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_greet() {
        assert_eq!(greet("World"), "Hello, World! Welcome to Rust.");
    }
}
```

```bash
# 检查编译
cargo check

# 运行测试
cargo test

# 运行程序
cargo run
```
