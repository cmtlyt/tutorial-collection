## 📚 概念介绍

良好的 IDE 配置可以显著提升 Rust 开发效率。本节主要介绍 VS Code + rust-analyzer 的配置方案，这是目前 Rust 社区最主流的开发环境组合。同时也会简要介绍其他 IDE 的选择。

## 🎯 VS Code + rust-analyzer

### 安装 rust-analyzer

rust-analyzer 是 Rust 官方推荐的语言服务器（LSP），提供代码补全、跳转定义、重构等功能。

**方式一：通过 VS Code 扩展市场安装（推荐）**

在 VS Code 扩展面板中搜索 `rust-analyzer` 并安装。

**方式二：通过 rustup 安装**

```bash
rustup component add rust-analyzer
```

### 推荐的 VS Code 扩展

| 扩展 | 说明 |
|------|------|
| rust-analyzer | Rust 语言服务器，核心必装 |
| Even Better TOML | TOML 文件语法高亮和验证 |
| CodeLLDB | Rust 调试支持 |
| Error Lens | 内联显示错误和警告 |
| crates | Cargo.toml 依赖版本提示 |

### VS Code 配置

在项目根目录创建 `.vscode/settings.json`：

```json
{
  "rust-analyzer.check.command": "clippy",
  "rust-analyzer.cargo.features": "all",
  "rust-analyzer.inlayHints.typeHints.enable": true,
  "rust-analyzer.inlayHints.parameterHints.enable": true,
  "rust-analyzer.inlayHints.chainingHints.enable": true,
  "rust-analyzer.procMacro.enable": true,
  "editor.formatOnSave": true,
  "[rust]": {
    "editor.defaultFormatter": "rust-lang.rust-analyzer",
    "editor.tabSize": 4
  }
}
```

### rust-analyzer 常用功能

#### 1. 代码补全与类型提示

rust-analyzer 提供智能代码补全，包括：
- 方法和字段补全
- 导入建议
- 代码片段（snippet）
- 内联类型提示（inlay hints）

#### 2. 代码导航

- **Go to Definition**：`F12` 或 `Ctrl+Click` 跳转到定义
- **Go to Implementation**：`Ctrl+F12` 跳转到实现
- **Find All References**：`Shift+F12` 查找所有引用
- **Go to Symbol**：`Ctrl+Shift+O` 查看文件符号

#### 3. 重构

- **Rename**：`F2` 重命名符号
- **Extract Function**：提取函数
- **Extract Variable**：提取变量
- **Inline**：内联变量或函数

#### 4. 代码操作（Code Actions）

按 `Ctrl+.`（macOS 为 `Cmd+.`）可以触发快速操作：
- 自动导入缺失的模块
- 填充 match 分支
- 生成 impl 块
- 添加缺失的 trait 方法

### 调试配置

在 `.vscode/launch.json` 中配置调试：

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "lldb",
      "request": "launch",
      "name": "Debug executable",
      "cargo": {
        "args": ["build", "--bin=my-project", "--package=my-project"],
        "filter": {
          "name": "my-project",
          "kind": "bin"
        }

      "args": [],

      "cwd": "${workspaceFolder}"
    }
  ]
}
```

## 🔧 其他 IDE 选择

### JetBrains RustRover

RustRover 是 JetBrains 专门为 Rust 开发打造的 IDE：
- 内置 Rust 支持，无需额外插件
- 强大的代码分析和重构功能
- 集成调试器和性能分析器
- 对大型项目支持更好

### Neovim

使用 Neovim + rust-analyzer LSP：

```lua
-- 在 Neovim 中配置 rust-analyzer（使用 nvim-lspconfig）
require('lspconfig').rust_analyzer.setup({
  settings = {
    ['rust-analyzer'] = {
      check = {
        command = 'clippy',
      },
    },
  },
})
```

### Helix

Helix 编辑器内置 LSP 支持，安装 rust-analyzer 后开箱即用：

```bash
# 安装 rust-analyzer 后直接打开 Rust 文件即可
hx src/main.rs
```

## 📝 实际应用示例

### 完整的 VS Code 项目配置

```bash
# 创建项目并配置 VS Code
cargo new my-rust-project
cd my-rust-project
mkdir .vscode
```

创建 `.vscode/settings.json`：

```json
{
  "rust-analyzer.check.command": "clippy",
  "rust-analyzer.cargo.features": "all",
  "editor.formatOnSave": true,
  "[rust]": {
    "editor.defaultFormatter": "rust-lang.rust-analyzer",
    "editor.tabSize": 4
  }
}
```

创建 `rustfmt.toml`：

```toml
max_width = 100
use_field_init_shorthand = true
imports_granularity = "Module"
```

这样项目就拥有了完整的开发环境配置，包括代码补全、自动格式化和 clippy 检查。
