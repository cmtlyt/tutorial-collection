# rustup 安装与管理

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

rustup 是 Rust 官方提供的工具链安装器和版本管理工具。它负责安装和管理 Rust 编译器（rustc）、标准库、Cargo 以及其他相关工具。通过 rustup，你可以轻松在 stable、beta、nightly 之间切换，管理多个编译目标，保持工具链的更新。

## 🎯 安装 rustup

### macOS / Linux

在终端中执行以下命令即可完成安装：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

安装脚本会提示你选择安装选项，默认选项（选择 1）适合大多数场景：

```
1) Proceed with standard installation (default - just press enter)
2) Customize installation
3) Cancel installation
```

安装完成后，需要配置环境变量。安装脚本会自动向 shell 配置文件中添加路径，重新打开终端或手动加载即可：

```bash
source "$HOME/.cargo/env"
```

### Windows

在 Windows 上安装 Rust，需要先下载并运行 [rustup-init.exe](https://rustup.rs/)。安装程序会引导你完成安装流程。

:::tip
Windows 用户还需要安装 [Visual Studio C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)，Rust 编译器依赖其中的链接器和系统库。
:::

### 验证安装

安装完成后，运行以下命令验证：

```bash
rustc --version
# 输出示例：rustc 1.82.0 (f6e511eec 2024-10-15)

cargo --version
# 输出示例：cargo 1.82.0 (8f40fc59f 2024-08-21)

rustup --version
# 输出示例：rustup 1.27.1 (54dd3d00f 2024-04-24)
```

## 🔧 工具链管理

### 查看已安装的工具链

```bash
rustup toolchain list
# 输出示例：
# stable-aarch64-apple-darwin (default)
# nightly-aarch64-apple-darwin
```

### 安装特定工具链

Rust 提供三个发布通道：

- **stable**：稳定版，每 6 周发布一次，推荐日常开发使用
- **beta**：预览版，即将成为下一个 stable 的版本
- **nightly**：每日构建版，包含最新实验性功能

```bash
# 安装 nightly 工具链
rustup toolchain install nightly

# 安装特定版本
rustup toolchain install 1.80.0

# 安装指定日期的 nightly
rustup toolchain install nightly-2024-10-01
```

### 设置默认工具链

```bash
# 设置全局默认工具链
rustup default stable

# 设置项目级工具链（在项目根目录执行）
rustup override set nightly
```

项目级设置也可以通过在项目根目录创建 `rust-toolchain.toml` 文件来实现：

```toml
[toolchain]
channel = "1.82.0"
components = ["rustfmt", "clippy"]
```

### 临时使用特定工具链

```bash
# 使用 nightly 运行单次编译
rustup run nightly rustc --version

# 或使用 + 语法（Cargo 快捷方式）
cargo +nightly build
```

## 🎯 组件管理

rustup 管理的组件包括编译器、标准库、文档和附加工具：

```bash
# 查看已安装的组件
rustup component list --installed

# 添加组件
rustup component add rustfmt        # 代码格式化
rustup component add clippy         # 代码检查
rustup component add rust-src       # 标准库源码（IDE 需要）
rustup component add rust-analyzer  # 语言服务器

# 移除组件
rustup component remove rust-docs
```

### 常用组件说明

| 组件 | 说明 |
|------|------|
| `rustc` | Rust 编译器（默认安装） |
| `cargo` | 包管理器和构建工具（默认安装） |
| `rustfmt` | 代码格式化工具 |
| `clippy` | 代码静态分析和 lint 工具 |
| `rust-src` | 标准库源码，供 IDE 分析使用 |
| `rust-analyzer` | 官方语言服务器 |
| `rust-docs` | 离线文档 |

## 🌐 交叉编译目标

rustup 支持为不同平台添加编译目标：

```bash
# 查看可用目标
rustup target list

# 查看已安装目标
rustup target list --installed

# 添加 WebAssembly 目标
rustup target add wasm32-unknown-unknown

# 添加 Linux musl 目标（用于静态链接）
rustup target add x86_64-unknown-linux-musl

# 使用指定目标编译
cargo build --target wasm32-unknown-unknown
```

## 🔄 更新与维护

```bash
# 更新所有已安装的工具链
rustup update

# 仅更新 stable
rustup update stable

# 查看更新信息
rustup check

# 卸载 Rust 和 rustup
rustup self uninstall
```

## 📝 实际应用示例

### 多项目工具链管理

假设你有两个项目，一个使用 stable，另一个需要 nightly 特性：

```bash
# 项目 A：使用 stable（默认即可）
cd project-a
rustc --version
# 输出：rustc 1.82.0

# 项目 B：需要 nightly
cd project-b
rustup override set nightly
rustc --version
# 输出：rustc 1.84.0-nightly
```

或者在项目 B 的根目录创建 `rust-toolchain.toml`：

```toml
[toolchain]
channel = "nightly"
components = ["rustfmt", "clippy", "rust-analyzer"]
```

这样任何人克隆项目后，rustup 会自动安装并使用指定的工具链。
