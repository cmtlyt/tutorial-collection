# rustfmt 与 clippy

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

rustfmt 和 clippy 是 Rust 官方提供的两个代码质量工具。rustfmt 负责自动格式化代码，确保团队代码风格一致；clippy 则是一个强大的 lint 工具，能够检测代码中的潜在问题并提供改进建议。这两个工具是 Rust 开发中不可或缺的组成部分。

## 🎨 rustfmt：代码格式化

### 基本使用

```bash
# 格式化当前项目的所有文件
cargo fmt

# 检查格式是否正确（不修改文件，适合 CI）
cargo fmt -- --check

# 格式化单个文件
rustfmt src/main.rs

# 查看格式化差异
cargo fmt -- --check --diff
```

### 配置 rustfmt

在项目根目录创建 `rustfmt.toml` 或 `.rustfmt.toml` 文件：

```toml
# 最大行宽（默认 100）
max_width = 100

# 使用 Tab 还是空格
hard_tabs = false

# 缩进宽度（默认 4）
tab_spaces = 4

# 每行链式调用的缩进
chain_indent = "Block"

# 函数参数换行策略
fn_params_layout = "Tall"

# 使用字段初始化简写
use_field_init_shorthand = true

# imports 分组策略
imports_granularity = "Module"

# 重排 imports
reorder_imports = true

# 重排 modules
reorder_modules = true
```

### 格式化前后对比

格式化前：

```rust
fn main(){let x=5;let y=10;
if x>3{println!("x is greater than 3");
}else{println!("x is not greater than 3");}
let result=x+y;println!("result: {}",result);}
```

格式化后：

```rust
fn main() {
    let x = 5;
    let y = 10;
    if x > 3 {
        println!("x is greater than 3");
    } else {
        println!("x is not greater than 3");
    }
    let result = x + y;
    println!("result: {}", result);
}
```

### 跳过格式化

对于不希望被格式化的代码块，可以使用 `#[rustfmt::skip]` 属性：

```rust
// 跳过单个函数
#[rustfmt::skip]
fn hand_formatted_matrix() -> [[i32; 3]; 3] {
    [
        [1,  0,  0],
        [0,  1,  0],
        [0,  0,  1],
    ]
}

fn main() {
    let matrix = hand_formatted_matrix();
    println!("{:?}", matrix);
}
```

## 🔍 clippy：代码检查

### 基本使用

```bash
# 运行 clippy 检查
cargo clippy

# 对所有目标运行检查（包括测试、示例等）
cargo clippy --all-targets

# 将所有警告视为错误（适合 CI）
cargo clippy -- -D warnings

# 自动修复 clippy 建议
cargo clippy --fix

# 允许修改有未提交更改的文件
cargo clippy --fix --allow-dirty
```

### Lint 级别

clippy 的 lint 分为以下级别：

| 级别 | 说明 | 默认行为 |
|------|------|----------|
| `allow` | 允许，不显示任何提示 | 忽略 |
| `warn` | 警告，显示提示但不阻止编译 | 提示 |
| `deny` | 拒绝，产生编译错误 | 报错 |
| `forbid` | 禁止，与 deny 类似但不可被覆盖 | 报错 |

### 常见 clippy 建议

#### 1. 使用更简洁的写法

clippy 提示：

```rust
// clippy 会建议改进的代码
fn example_before() {
    let numbers = vec![1, 2, 3, 4, 5];

    // clippy: manual implementation of Iterator::map
    let mut doubled = Vec::new();
    for number in &numbers {
        doubled.push(number * 2);
    }

    println!("{:?}", doubled);
}

// clippy 建议的改进版本
fn example_after() {
    let numbers = vec![1, 2, 3, 4, 5];
    let doubled: Vec<i32> = numbers.iter().map(|number| number * 2).collect();
    println!("{:?}", doubled);
}

fn main() {
    example_before();
    example_after();
}
```

#### 2. 避免不必要的克隆

```rust
fn process(data: &str) {
    println!("Processing: {}", data);
}

fn main() {
    let text = String::from("hello");

    // clippy 警告：不需要 clone，直接用引用即可
    // process(&text.clone());

    // 改进：直接传引用
    process(&text);
}
```

#### 3. 使用 if let 替代 match

```rust
fn main() {
    let optional_value: Option<i32> = Some(42);

    // clippy 建议使用 if let
    // match optional_value {
    //     Some(value) => println!("Got: {}", value),
    //     None => {},
    // }

    // 改进版本
    if let Some(value) = optional_value {
        println!("Got: {}", value);
    }
}
```

### 配置 clippy

在项目根目录创建 `clippy.toml` 或 `.clippy.toml`：

```toml
# 函数过长的阈值（默认 25 行）
too-many-lines-threshold = 50

# 函数参数过多的阈值（默认 7 个）
too-many-arguments-threshold = 10

# 认知复杂度阈值（默认 25）
cognitive-complexity-threshold = 30

# 类型复杂度阈值（默认 250）
type-complexity-threshold = 300
```

也可以在代码中通过属性控制 lint 行为：

```rust
// 在文件级别允许特定 lint
#![allow(clippy::too_many_arguments)]

// 在函数级别允许特定 lint
#[allow(clippy::needless_return)]
fn explicit_return() -> i32 {
    return 42;
}

fn main() {
    println!("{}", explicit_return());
}
```

## 📝 实际应用示例

### CI/CD 集成

在 GitHub Actions 中集成 rustfmt 和 clippy 检查：

```yaml
# .github/workflows/rust-quality.yml
name: Code Quality

on: [push, pull_request]

jobs:
  fmt:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
        with:
          components: rustfmt
      - run: cargo fmt -- --check

  clippy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
        with:
          components: clippy
      - run: cargo clippy --all-targets -- -D warnings
```

### 项目开发工作流

```bash
# 开发流程建议：编写代码后依次执行
cargo fmt           # 1. 格式化代码
cargo clippy        # 2. 检查代码质量
cargo test          # 3. 运行测试
cargo build         # 4. 编译构建
```
