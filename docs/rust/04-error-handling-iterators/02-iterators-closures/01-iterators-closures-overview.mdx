## 📚 章节介绍

迭代器是 Rust 中处理序列数据的核心抽象，结合闭包可以实现强大的函数式编程风格。本章节将讲解迭代器模式、适配器链以及 Rust 的零成本抽象理念。

## 🔑 核心概念

### 惰性求值
Rust 的迭代器是惰性的，适配器方法（如 map、filter）不会立即执行计算，只有在调用消费适配器（如 collect、sum）时才会真正遍历数据。

### 零成本抽象
迭代器链在编译后会被优化为等价的手写循环代码，没有额外的运行时开销。这就是 Rust "零成本抽象"理念的体现。
