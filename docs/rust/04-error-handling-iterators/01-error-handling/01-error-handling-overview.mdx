# 错误处理 - 总览

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 章节介绍

Rust 的错误处理体系是其安全性设计的重要组成部分。本章节将全面讲解 Rust 的错误处理机制，从基础的 panic! 和 Result 到自定义错误类型和第三方错误处理库。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 区分不可恢复错误（panic!）和可恢复错误（Result）
- 熟练使用 ? 运算符进行错误传播
- 定义自定义错误类型并实现 Error trait
- 使用 thiserror 和 anyhow 等生态库简化错误处理

## 📖 章节结构

### 第一部分：基础错误处理
- panic! 与不可恢复错误
- Result 与可恢复错误
- ? 运算符
- unwrap / expect 的使用场景

### 第二部分：自定义错误
- 实现 std::error::Error trait
- From trait 实现错误转换
- 错误链（Error Chain）

### 第三部分：错误处理生态
- thiserror（库错误定义）
- anyhow（应用级错误处理）
- miette（诊断友好错误）
- color-eyre（彩色错误报告）

## 🔑 核心概念

### 两种错误策略
- **库代码**：使用 `Result<T, E>` 返回具体的错误类型，让调用者决定如何处理。推荐使用 thiserror 定义错误枚举
- **应用代码**：关注错误的上下文和可读性，推荐使用 anyhow 简化错误处理

### ? 运算符
`?` 是 Rust 错误处理的核心语法糖，它会在错误时提前返回，在成功时解包值，同时自动调用 From trait 进行错误类型转换。
