# cargo-deny 依赖策略

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

[cargo-deny](https://github.com/EmbarkStudios/cargo-deny) 是一个全面的依赖策略管理工具，整合了许可证检查、漏洞扫描、禁用依赖和重复依赖检测等功能。相比 cargo-audit 只做安全审计，cargo-deny 提供了更全面的依赖治理能力。

## 🎯 安装与使用

### 基本用法

```bash
# 安装 cargo-deny
cargo install cargo-deny

# 初始化配置文件
cargo deny init

# 运行所有检查
cargo deny check

# 仅运行许可证检查
cargo deny check licenses

# 仅运行漏洞检查
cargo deny check advisories

# 检查禁用的 crate
cargo deny check bans

# 检查依赖来源
cargo deny check sources
```

## 🔄 配置文件 `deny.toml`

### 许可证检查

```toml
[licenses]
# 允许的许可证列表
allow = [
    "MIT",
    "Apache-2.0",
    "BSD-2-Clause",
    "BSD-3-Clause",
    "ISC",
    "Unicode-DFS-2016",
]

# 拒绝的许可证
deny = [
    "GPL-2.0",
    "GPL-3.0",
    "AGPL-3.0",
]

# 对未在允许列表中的许可证的默认处理
unlicensed = "deny"

# 置信度阈值（0.0 - 1.0）
confidence-threshold = 0.8

# 对特定 crate 的许可证例外
[[licenses.exceptions]]
allow = ["OpenSSL"]
name = "ring"
```

### 漏洞检查

```toml
[advisories]
# 漏洞数据库路径
db-path = "~/.cargo/advisory-db"
db-urls = ["https://github.com/rustsec/advisory-db"]

# 忽略特定漏洞
ignore = [
    # "RUSTSEC-2024-0001",
]

# 检测 yanked 版本
yanked = "warn"
```

### 禁用依赖

```toml
[bans]
# 允许多个版本共存的策略
multiple-versions = "warn"

# 高亮哪个依赖导致了多版本
highlight = "all"

# 禁止的 crate
deny = [
    # 旧的 HTTP 库，团队已迁移到 reqwest
    { name = "hyper", wrappers = ["reqwest"] },
]

# 跳过特定版本的重复检查
skip = [
    # 允许 syn 1.x 和 2.x 共存（很多 proc-macro 库还在用 1.x）
    { name = "syn", version = "=1" },
]

# 跳过特定 crate 的重复检查（包括传递依赖）
skip-tree = [
    # old-crate 及其所有传递依赖都跳过重复版本检查
    # { name = "old-crate", version = "=0.5" },
]
```

### 依赖来源

```toml
[sources]
# 不允许从这些来源引入依赖
unknown-registry = "deny"
unknown-git = "deny"

# 允许的注册中心
allow-registry = ["https://github.com/rust-lang/crates.io-index"]

# 允许的 git 来源
allow-git = []

# 允许来源覆盖
[sources.allow-org]
# 允许 GitHub 特定组织的 git 依赖
github = ["my-org"]
```

## 📊 输出示例

### 许可证检查失败

```
error[L003]: crate-with-gpl v0.1.0 is licensed under GPL-3.0-only,
which is not in the allow list
```

### 重复依赖警告

```
warning[B003]: found 2 duplicate entries for crate 'syn'
  ├── syn 1.0.109 (/path/to/Cargo.lock)
  │   └── used by: serde_derive v1.0.200
  └── syn 2.0.48 (/path/to/Cargo.lock)
      └── used by: tokio-macros v2.2.0
```

  run: cargo deny check
