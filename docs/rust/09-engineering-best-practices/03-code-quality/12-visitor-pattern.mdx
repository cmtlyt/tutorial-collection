# 访问者模式

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

访问者模式（Visitor Pattern）允许你在不修改已有数据结构的前提下，为其添加新的操作。在 Rust 中，由于枚举和模式匹配的强大能力，访问者模式的实现比面向对象语言更加简洁。它特别适用于编译器、解释器、序列化器等需要对树形结构进行多种遍历操作的场景。

## 🎯 基本访问者模式

### 使用 Trait 定义 Visitor

```rust
/// 算术表达式的 AST 节点
#[derive(Debug)]
enum Expression {
    Number(f64),
    Add(Box<Expression>, Box<Expression>),
    Multiply(Box<Expression>, Box<Expression>),
    Negate(Box<Expression>),
}

/// 访问者 Trait：定义对每种节点类型的操作
trait ExpressionVisitor {
    type Output;

    fn visit_number(&mut self, value: f64) -> Self::Output;
    fn visit_add(&mut self, left: &Expression, right: &Expression) -> Self::Output;
    fn visit_multiply(&mut self, left: &Expression, right: &Expression) -> Self::Output;
    fn visit_negate(&mut self, inner: &Expression) -> Self::Output;
}

impl Expression {
    /// 接受一个访问者
    fn accept<V: ExpressionVisitor>(&self, visitor: &mut V) -> V::Output {
        match self {
            Expression::Number(value) => visitor.visit_number(*value),
            Expression::Add(left, right) => visitor.visit_add(left, right),
            Expression::Multiply(left, right) => visitor.visit_multiply(left, right),
            Expression::Negate(inner) => visitor.visit_negate(inner),
        }
    }
}

// --- Visitor 1：计算表达式的值 ---

struct Evaluator;

impl ExpressionVisitor for Evaluator {
    type Output = f64;

    fn visit_number(&mut self, value: f64) -> f64 {
        value
    }

    fn visit_add(&mut self, left: &Expression, right: &Expression) -> f64 {
        let left_value = left.accept(self);
        let right_value = right.accept(self);
        left_value + right_value
    }

    fn visit_multiply(&mut self, left: &Expression, right: &Expression) -> f64 {
        let left_value = left.accept(self);
        let right_value = right.accept(self);
        left_value * right_value
    }

    fn visit_negate(&mut self, inner: &Expression) -> f64 {
        -inner.accept(self)
    }
}

// --- Visitor 2：打印表达式 ---

struct Printer;

impl ExpressionVisitor for Printer {
    type Output = String;

    fn visit_number(&mut self, value: f64) -> String {
        format!("{value}")
    }

    fn visit_add(&mut self, left: &Expression, right: &Expression) -> String {
        let left_str = left.accept(self);
        let right_str = right.accept(self);
        format!("({left_str} + {right_str})")
    }

    fn visit_multiply(&mut self, left: &Expression, right: &Expression) -> String {
        let left_str = left.accept(self);
        let right_str = right.accept(self);
        format!("({left_str} * {right_str})")
    }

    fn visit_negate(&mut self, inner: &Expression) -> String {
        let inner_str = inner.accept(self);
        format!("(-{inner_str})")
    }
}

fn main() {
    // 构建表达式：(3 + 4) * (-2)
    let expression = Expression::Multiply(
        Box::new(Expression::Add(
            Box::new(Expression::Number(3.0)),
            Box::new(Expression::Number(4.0)),
        )),
        Box::new(Expression::Negate(Box::new(Expression::Number(2.0)))),
    );

    let mut evaluator = Evaluator;
    let result = expression.accept(&mut evaluator);
    println!("计算结果：{result}"); // -14

    let mut printer = Printer;
    let formatted = expression.accept(&mut printer);
    println!("表达式：{formatted}"); // ((3 + 4) * (-2))
}
```

## 🔄 使用枚举 + match 的简化方式

在 Rust 中，枚举天然支持模式匹配，很多场景下不需要完整的访问者 Trait，直接用递归函数即可：

```rust
#[derive(Debug)]
enum HtmlNode {
    Text(String),
    Element {
        tag: String,
        children: Vec<HtmlNode>,
    },
    Comment(String),
}

/// 渲染 HTML
fn render_html(node: &HtmlNode, indent: usize) -> String {
    let prefix = " ".repeat(indent);
    match node {
        HtmlNode::Text(content) => format!("{prefix}{content}"),
        HtmlNode::Element { tag, children } => {
            let mut result = format!("{prefix}<{tag}>");
            if !children.is_empty() {
                result.push('\n');
                for child in children {
                    result.push_str(&render_html(child, indent + 2));
                    result.push('\n');
                }
                result.push_str(&format!("{prefix}</{tag}>"));
            } else {
                result.push_str(&format!("</{tag}>"));
            }
            result
        }
        HtmlNode::Comment(text) => format!("{prefix}<!-- {text} -->"),
    }
}

/// 统计文本节点数量
fn count_text_nodes(node: &HtmlNode) -> usize {
    match node {
        HtmlNode::Text(_) => 1,
        HtmlNode::Element { children, .. } => {
            children.iter().map(count_text_nodes).sum()
        }
        HtmlNode::Comment(_) => 0,
    }
}

/// 提取所有文本内容
fn extract_text(node: &HtmlNode) -> String {
    match node {
        HtmlNode::Text(content) => content.clone(),
        HtmlNode::Element { children, .. } => {
            children
                .iter()
                .map(extract_text)
                .collect::<Vec<_>>()
                .join(" ")
        }
        HtmlNode::Comment(_) => String::new(),
    }
}

fn main() {
    let document = HtmlNode::Element {
        tag: "div".to_string(),
        children: vec![
            HtmlNode::Comment("标题区域".to_string()),
            HtmlNode::Element {
                tag: "h1".to_string(),
                children: vec![HtmlNode::Text("Hello".to_string())],
            },
            HtmlNode::Element {
                tag: "p".to_string(),
                children: vec![
                    HtmlNode::Text("Welcome to".to_string()),
                    HtmlNode::Element {
                        tag: "strong".to_string(),
                        children: vec![HtmlNode::Text("Rust".to_string())],
                    },
                ],
            },
        ],
    };

    println!("{}", render_html(&document, 0));
    println!("文本节点数量：{}", count_text_nodes(&document));
    println!("所有文本：{}", extract_text(&document));
}
```

## 📊 何时使用访问者模式

| 场景 | 推荐方式 |
|------|----------|
| 数据结构稳定，操作经常新增 | Visitor Trait |
| 操作稳定，数据变体可能新增 | 枚举 + match |
| 简单遍历 | 直接递归函数 |
| 编译器/解释器的 AST 处理 | Visitor Trait |
