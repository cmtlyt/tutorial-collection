# 测试 - 总览

> **版本**：v1.0

## 📚 章节介绍

Rust 拥有内置的测试框架，无需第三方依赖即可编写和运行测试。本章节将全面讲解单元测试、集成测试以及属性测试和模糊测试等高级测试技术。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 编写单元测试并组织测试模块
- 创建集成测试验证模块间协作
- 使用 proptest 进行属性测试
- 使用 cargo-fuzz 进行模糊测试
- 编写文档测试保证示例代码的正确性
- 测量测试覆盖率

## 🔑 核心概念

### Rust 的测试哲学
Rust 将测试作为一等公民：
1. **单元测试**：与源代码放在同一文件中，通过 `#[cfg(test)]` 条件编译
2. **集成测试**：放在 tests 目录，作为外部使用者测试公共 API
3. **文档测试**：文档注释中的代码示例会被自动编译和运行

### 属性测试
属性测试（Property-based Testing）通过自动生成大量随机输入来验证代码的通用属性，能发现手写测试用例难以覆盖的边界情况。
