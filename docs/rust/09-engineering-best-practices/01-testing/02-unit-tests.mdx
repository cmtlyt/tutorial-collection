# 单元测试

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

单元测试是 Rust 中最基本的测试形式。Rust 的测试框架是语言内置的，通过 `#[test]` 属性标记测试函数，使用 `cargo test` 运行测试。单元测试通常与被测代码放在同一个文件中，通过 `#[cfg(test)]` 条件编译确保测试代码不会出现在生产构建中。

## 🎯 编写第一个单元测试

### `#[test]` 属性

在函数上添加 `#[test]` 属性即可将其标记为测试函数：

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_add_positive_numbers() {
        let result = add(2, 3);
        assert_eq!(result, 5);
    }

    #[test]
    fn test_add_negative_numbers() {
        let result = add(-1, -3);
        assert_eq!(result, -4);
    }

    #[test]
    fn test_add_mixed_numbers() {
        let result = add(-1, 5);
        assert_eq!(result, 4);
    }
}
```

运行方式：

```bash
cargo test
```

### 测试函数的规则

- 测试函数不接受参数，也不返回值（或返回 `Result<(), E>`）
- 测试函数在独立线程中运行
- 测试函数 panic 即为失败，正常返回即为通过

## 🔄 测试的返回值

### 使用 `Result<T, E>` 返回值

测试函数可以返回 `Result`，这样就能使用 `?` 操作符简化错误处理：

```rust
use std::num::ParseIntError;

fn parse_and_double(input: &str) -> Result<i32, ParseIntError> {
    let parsed = input.parse::<i32>()?;
    Ok(parsed * 2)
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_parse_and_double_valid() -> Result<(), ParseIntError> {
        let result = parse_and_double("21")?;
        assert_eq!(result, 42);
        Ok(())
    }

    #[test]
    fn test_parse_and_double_zero() -> Result<(), ParseIntError> {
        let result = parse_and_double("0")?;
        assert_eq!(result, 0);
        Ok(())
    }
}
```

:::tip
当返回 `Result` 时，测试在 `Err` 时失败，在 `Ok` 时通过。这种方式特别适合测试可能返回错误的函数。
:::

## 🎯 测试应该 panic 的场景

### `#[should_panic]` 属性

当你期望代码在某些条件下 panic 时，使用 `#[should_panic]` 标记测试：

```rust
struct Temperature {
    degrees: f64,
}

impl Temperature {
    fn new(degrees: f64) -> Self {
        if degrees < -273.15 {
            panic!("温度不能低于绝对零度：{degrees}°C");
        }
        Temperature { degrees }
    }

    fn to_fahrenheit(&self) -> f64 {
        self.degrees * 9.0 / 5.0 + 32.0
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_valid_temperature() {
        let temp = Temperature::new(100.0);
        assert_eq!(temp.to_fahrenheit(), 212.0);
    }

    #[test]
    #[should_panic]
    fn test_below_absolute_zero_panics() {
        Temperature::new(-300.0);
    }

    #[test]
    #[should_panic(expected = "温度不能低于绝对零度")]
    fn test_panic_message_contains_expected_text() {
        Temperature::new(-500.0);
    }
}
```

:::warning
`#[should_panic(expected = "...")]` 会检查 panic 消息是否**包含**指定的字符串，而不是精确匹配。这有助于在 panic 消息变更时保持测试的稳定性。
:::

## ⚙️ 控制测试运行

### 运行特定测试

```bash
# 运行名称包含 "temperature" 的测试
cargo test temperature

# 运行某个模块的所有测试
cargo test tests::test_valid

# 运行完全匹配的测试
cargo test --exact tests::test_valid_temperature
```

### `#[ignore]` 跳过耗时测试

```rust
#[cfg(test)]
mod tests {
    #[test]
    fn test_quick_operation() {
        assert_eq!(2 + 2, 4);
    }

    #[test]
    #[ignore = "此测试需要网络连接，CI 中运行"]
    fn test_slow_network_operation() {
        // 模拟一个耗时操作
        std::thread::sleep(std::time::Duration::from_secs(5));
        assert!(true);
    }
}
```

```bash
# 只运行被忽略的测试
cargo test -- --ignored

# 运行所有测试（包括被忽略的）
cargo test -- --include-ignored
```

### 控制测试输出

```bash
# 显示测试中的 println! 输出（默认情况下成功测试的输出会被捕获）
cargo test -- --nocapture

# 按顺序运行测试（默认并行）
cargo test -- --test-threads=1
```

## 📝 实际应用示例

### 综合示例：一个简单的购物车

```rust
#[derive(Debug, Clone)]
struct CartItem {
    name: String,
    price: f64,
    quantity: u32,
}

struct ShoppingCart {
    items: Vec<CartItem>,
}

impl ShoppingCart {
    fn new() -> Self {
        ShoppingCart { items: Vec::new() }
    }

    fn add_item(&mut self, name: &str, price: f64, quantity: u32) {
        if price < 0.0 {
            panic!("价格不能为负数");
        }
        if quantity == 0 {
            panic!("数量不能为零");
        }
        if let Some(item) = self.items.iter_mut().find(|item| item.name == name) {
            item.quantity += quantity;
        } else {
            self.items.push(CartItem {
                name: name.to_string(),
                price,
                quantity,
            });
        }
    }

    fn total(&self) -> f64 {
        self.items
            .iter()
            .map(|item| item.price * item.quantity as f64)
            .sum()
    }

    fn item_count(&self) -> usize {
        self.items.iter().map(|item| item.quantity as usize).sum()
    }

    fn remove_item(&mut self, name: &str) -> bool {
        let original_length = self.items.len();
        self.items.retain(|item| item.name != name);
        self.items.len() < original_length
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_new_cart_is_empty() {
        let cart = ShoppingCart::new();
        assert_eq!(cart.total(), 0.0);
        assert_eq!(cart.item_count(), 0);
    }

    #[test]
    fn test_add_single_item() {
        let mut cart = ShoppingCart::new();
        cart.add_item("苹果", 3.5, 2);
        assert_eq!(cart.total(), 7.0);
        assert_eq!(cart.item_count(), 2);
    }

    #[test]
    fn test_add_duplicate_item_increases_quantity() {
        let mut cart = ShoppingCart::new();
        cart.add_item("苹果", 3.5, 2);
        cart.add_item("苹果", 3.5, 3);
        assert_eq!(cart.item_count(), 5);
        assert_eq!(cart.total(), 17.5);
    }

    #[test]
    fn test_remove_existing_item() {
        let mut cart = ShoppingCart::new();
        cart.add_item("苹果", 3.5, 2);
        cart.add_item("香蕉", 2.0, 1);
        assert!(cart.remove_item("苹果"));
        assert_eq!(cart.total(), 2.0);
    }

    #[test]
    fn test_remove_nonexistent_item_returns_false() {
        let mut cart = ShoppingCart::new();
        cart.add_item("苹果", 3.5, 2);
        assert!(!cart.remove_item("橙子"));
    }

    #[test]
    #[should_panic(expected = "价格不能为负数")]
    fn test_negative_price_panics() {
        let mut cart = ShoppingCart::new();
        cart.add_item("苹果", -1.0, 1);
    }

    #[test]
    #[should_panic(expected = "数量不能为零")]
    fn test_zero_quantity_panics() {
        let mut cart = ShoppingCart::new();
        cart.add_item("苹果", 3.5, 0);
    }
}
```
