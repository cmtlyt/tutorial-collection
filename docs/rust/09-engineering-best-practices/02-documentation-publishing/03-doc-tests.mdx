# 文档测试

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

文档测试是 Rust 文档系统的核心优势：文档注释中的代码示例会被 `cargo test` 自动编译和执行。本节从文档发布的角度讲解如何编写高质量的文档测试，使文档既是使用说明也是可靠的测试用例。

:::tip
本节侧重于文档发布场景下的文档测试最佳实践。关于文档测试的基础语法，请参阅[测试章节的文档测试](../01-testing/11-doc-tests)。
:::

## 🎯 编写高质量的文档测试

### 文档测试的双重作用

文档测试同时扮演两个角色：
1. **用户文档**：教会使用者如何使用你的 API
2. **回归测试**：确保示例代码永远可以编译和运行

```rust
/// 合并两个已排序的切片为一个新的有序 Vec。
///
/// 两个输入切片必须已排序（升序），否则结果未定义。
///
/// # 示例
///
/// 合并两个有序数组：
///
/// ```
/// use my_lib::merge_sorted;
///
/// let left = vec![1, 3, 5];
/// let right = vec![2, 4, 6];
/// let merged = merge_sorted(&left, &right);
/// assert_eq!(merged, vec![1, 2, 3, 4, 5, 6]);
/// ```
///
/// 处理包含重复元素的情况：
///
/// ```
/// use my_lib::merge_sorted;
///
/// let left = vec![1, 2, 3];
/// let right = vec![2, 3, 4];
/// let merged = merge_sorted(&left, &right);
/// assert_eq!(merged, vec![1, 2, 2, 3, 3, 4]);
/// ```
///
/// 一个切片为空时直接返回另一个：
///
/// ```
/// use my_lib::merge_sorted;
///
/// let data = vec![1, 2, 3];
/// let empty: Vec<i32> = vec![];
/// assert_eq!(merge_sorted(&data, &empty), vec![1, 2, 3]);
/// assert_eq!(merge_sorted(&empty, &data), vec![1, 2, 3]);
/// ```
pub fn merge_sorted(left: &[i32], right: &[i32]) -> Vec<i32> {
    let mut result = Vec::with_capacity(left.len() + right.len());
    let mut left_index = 0;
    let mut right_index = 0;

    while left_index < left.len() && right_index < right.len() {
        if left[left_index] <= right[right_index] {
            result.push(left[left_index]);
            left_index += 1;
        } else {
            result.push(right[right_index]);
            right_index += 1;
        }
    }

    result.extend_from_slice(&left[left_index..]);
    result.extend_from_slice(&right[right_index..]);
    result
}
```

## 🔄 使用隐藏行简化展示

### `#` 前缀隐藏 setup 代码

用户不需要看到的 setup 代码可以用 `# ` 隐藏：

```rust
/// 配置解析器，支持多种格式。
///
/// # 示例
///
/// ```
/// # use std::collections::HashMap;
/// use my_lib::parse_config;
///
/// let input = "host=localhost\nport=8080";
/// let config = parse_config(input);
/// assert_eq!(config.get("host"), Some(&"localhost".to_string()));
/// assert_eq!(config.get("port"), Some(&"8080".to_string()));
/// ```
pub fn parse_config(input: &str) -> std::collections::HashMap<String, String> {
    input
        .lines()
        .filter_map(|line| {
            let parts: Vec<&str> = line.splitn(2, '=').collect();
            if parts.len() == 2 {
                Some((parts[0].trim().to_string(), parts[1].trim().to_string()))
            } else {
                None
            }
        })
        .collect()
}
```

## 🎯 错误处理场景

### 展示正常路径和错误路径

高质量的文档应该同时展示成功和失败的场景：

```rust
/// 解析 "HH:MM" 格式的时间字符串。
///
/// # 示例
///
/// 正常解析：
///
/// ```
/// use my_lib::parse_time;
///
/// let (hours, minutes) = parse_time("14:30").unwrap();
/// assert_eq!(hours, 14);
/// assert_eq!(minutes, 30);
/// ```
///
/// 无效格式返回错误：
///
/// ```
/// use my_lib::parse_time;
///
/// assert!(parse_time("invalid").is_err());
/// assert!(parse_time("25:00").is_err());
/// assert!(parse_time("12:60").is_err());
/// ```
pub fn parse_time(input: &str) -> Result<(u32, u32), String> {
    let parts: Vec<&str> = input.split(':').collect();
    if parts.len() != 2 {
        return Err(format!("无效的时间格式：{input}"));
    }

    let hours: u32 = parts[0]
        .parse()
        .map_err(|_| format!("无效的小时数：{}", parts[0]))?;
    let minutes: u32 = parts[1]
        .parse()
        .map_err(|_| format!("无效的分钟数：{}", parts[1]))?;

    if hours > 23 {
        return Err(format!("小时数超出范围（0-23）：{hours}"));
    }
    if minutes > 59 {
        return Err(format!("分钟数超出范围（0-59）：{minutes}"));
    }

    Ok((hours, minutes))
}
```

## 📊 特殊标注的使用场景

| 标注 | 编译 | 运行 | 适用场景 |
|------|------|------|----------|
| （无标注） | ✅ | ✅ | 正常的可运行示例 |
| `no_run` | ✅ | ❌ | 需要网络/文件系统的示例 |
| `compile_fail` | ✅（期望失败） | ❌ | 展示编译错误的示例 |
| `ignore` | ❌ | ❌ | 伪代码或需要特殊环境的示例 |

```rust
/// 连接到远程服务器。
///
/// # 示例
///
/// ```no_run
/// use my_lib::connect;
///
/// let connection = connect("192.168.1.1", 8080).unwrap();
/// println!("已连接到服务器");
/// ```
pub fn connect(host: &str, port: u16) -> Result<String, String> {
    Ok(format!("Connected to {host}:{port}"))
}

/// 这个函数要求参数实现 Send trait。
///
/// 以下代码将无法编译，因为 `Rc` 不是 `Send`：
///
/// ```compile_fail
/// use std::rc::Rc;
/// use my_lib::send_to_thread;
///
/// let value = Rc::new(42);
/// send_to_thread(value); // 编译错误：Rc 不是 Send
/// ```
pub fn send_to_thread<T: Send + 'static>(value: T) {
    std::thread::spawn(move || {
        drop(value);
    });
}
```
