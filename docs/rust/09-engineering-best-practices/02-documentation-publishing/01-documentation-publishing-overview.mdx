## 🔑 核心概念

### rustdoc：文档即代码
Rust 的文档注释（`///` 和 `//!`）支持 Markdown 语法，其中的代码块会被自动编译和测试，确保文档始终与代码同步。

### 语义化版本
Rust 生态遵循语义化版本（SemVer）规范：
- **主版本号**：不兼容的 API 变更
- **次版本号**：向后兼容的功能新增
- **修订号**：向后兼容的问题修复
