# 元组结构体

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

元组结构体（Tuple Struct）是一种介于普通结构体和元组之间的类型。它拥有结构体的名称（赋予类型语义），但字段没有名称，只通过位置索引访问。元组结构体非常适合用于 **Newtype 模式**——为已有类型创建语义不同的包装类型。

## 🎯 基本定义与使用

### 定义与实例化

```rust
struct Color(u8, u8, u8);
struct Point3D(f64, f64, f64);

fn main() {
    let red = Color(255, 0, 0);
    let origin = Point3D(0.0, 0.0, 0.0);

    // 通过索引访问字段
    println!("R={}, G={}, B={}", red.0, red.1, red.2);
    println!("x={}, y={}, z={}", origin.0, origin.1, origin.2);
}
```

### 解构元组结构体

```rust
struct Point(f64, f64);

fn main() {
    let point = Point(3.0, 4.0);

    // 解构赋值
    let Point(x, y) = point;
    println!("x={}, y={}", x, y);

    // 在函数参数中解构
    let distance = calculate_distance(Point(3.0, 4.0));
    println!("到原点的距离: {:.2}", distance);
}

fn calculate_distance(Point(x, y): Point) -> f64 {
    (x * x + y * y).sqrt()
}
```

## 🎯 Newtype 模式

元组结构体最重要的应用场景是 Newtype 模式——用一个新类型包装已有类型，在编译期区分不同语义：

```rust
struct Meters(f64);
struct Kilometers(f64);
struct Seconds(f64);

fn calculate_speed(distance: Kilometers, time: Seconds) -> f64 {
    distance.0 / time.0
}

fn main() {
    let distance = Kilometers(120.0);
    let time = Seconds(3600.0);
    let speed = calculate_speed(distance, time);
    println!("速度: {:.2} km/s", speed);

    // 编译错误：类型不匹配，防止误用
    // let wrong_distance = Meters(120.0);
    // let speed = calculate_speed(wrong_distance, time);
}
```

:::tip 为什么用 Newtype
即使 `Meters` 和 `Kilometers` 内部都是 `f64`，编译器也会将它们视为**完全不同的类型**。这可以在编译期捕获单位混淆等错误，比如著名的火星气候轨道飞行器事故就是因为单位混淆导致的。
:::

## 🎯 单字段元组结构体

单字段的元组结构体是 Newtype 模式的典型用法：

```rust
#[derive(Debug, Clone, PartialEq)]
struct UserId(u64);

#[derive(Debug, Clone, PartialEq)]
struct OrderId(u64);

fn find_user_orders(user_id: &UserId) -> Vec<OrderId> {
    // 模拟查询
    vec![OrderId(1001), OrderId(1002)]
}

fn main() {
    let user = UserId(42);
    let orders = find_user_orders(&user);
    println!("用户 {:?} 的订单: {:?}", user, orders);

    // 编译错误：UserId 和 OrderId 是不同类型
    // let wrong: UserId = OrderId(1);
}
```

## 📝 实际应用示例

### 类型安全的验证包装

```rust
#[derive(Debug)]
struct Email(String);

#[derive(Debug)]
struct ValidationError(String);

fn validate_email(input: &str) -> Result<Email, ValidationError> {
    if input.contains('@') && input.contains('.') {
        Ok(Email(input.to_string()))
    } else {
        Err(ValidationError(format!("无效的邮箱地址: {}", input)))
    }
}

fn send_welcome_email(email: &Email) {
    println!("向 {} 发送欢迎邮件", email.0);
}

fn main() {
    match validate_email("alice@example.com") {
        Ok(email) => {
            send_welcome_email(&email);
        }
        Err(error) => {
            println!("验证失败: {}", error.0);
        }
    }

    match validate_email("invalid-email") {
        Ok(email) => {
            send_welcome_email(&email);
        }
        Err(error) => {
            println!("验证失败: {}", error.0);
        }
    }
}
```
