# 命名字段结构体

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

命名字段结构体（Named Field Struct）是 Rust 中最常用的结构体形式，每个字段都有明确的名称和类型。它类似于其他语言中的 class 或 record，用于将相关数据组合成一个有意义的整体。

## 🎯 基本定义与实例化

### 定义结构体

使用 `struct` 关键字定义命名字段结构体，每个字段由 `名称: 类型` 组成：

```rust
struct User {
    username: String,
    email: String,
    age: u32,
    active: bool,
}

fn main() {
    let user = User {
        username: String::from("alice"),
        email: String::from("alice@example.com"),
        age: 28,
        active: true,
    };

    println!("用户名: {}", user.username);
    println!("邮箱: {}", user.email);
    println!("年龄: {}", user.age);
    println!("活跃: {}", user.active);
}
```

:::tip 注意
结构体实例化时，**所有字段都必须赋值**，Rust 不允许部分初始化。字段的顺序不需要与定义时一致。
:::

### 可变结构体

Rust 不支持将单个字段标记为可变，整个结构体实例要么可变，要么不可变：

```rust
struct Point {
    x: f64,
    y: f64,
}

fn main() {
    let mut point = Point { x: 1.0, y: 2.0 };
    point.x = 3.0; // 整个实例是 mut 的，所以可以修改任意字段
    println!("Point: ({}, {})", point.x, point.y);
}
```

## 🎯 字段初始化简写

当变量名与字段名相同时，可以使用简写语法：

```rust
struct Config {
    host: String,
    port: u16,
    debug: bool,
}

fn create_config(host: String, port: u16) -> Config {
    Config {
        host,  // 等价于 host: host
        port,  // 等价于 port: port
        debug: false,
    }
}

fn main() {
    let config = create_config(String::from("localhost"), 8080);
    println!("{}:{} (debug={})", config.host, config.port, config.debug);
}
```

## 🎯 结构体更新语法

使用 `..` 语法从已有实例创建新实例，未显式赋值的字段将从源实例中复制或移动：

```rust
struct User {
    username: String,
    email: String,
    age: u32,
    active: bool,
}

fn main() {
    let user1 = User {
        username: String::from("alice"),
        email: String::from("alice@example.com"),
        age: 28,
        active: true,
    };

    // 仅修改 email，其余字段从 user1 获取
    let user2 = User {
        email: String::from("alice_new@example.com"),
        ..user1
    };

    // 注意：user1.username 已被移动到 user2，不能再使用 user1.username
    // 但 age 和 active 是 Copy 类型，user1.age 仍然可用
    println!("user2: {} - {}", user2.username, user2.email);
    println!("user1.age 仍可用: {}", user1.age);
}
```

:::warning 所有权转移
结构体更新语法对非 `Copy` 类型的字段执行的是**移动**操作，而非复制。移动后原实例中对应字段不再可用。
:::

## 🎯 结构体的打印与调试

通过派生 `Debug` trait 来启用格式化输出：

```rust
#[derive(Debug)]
struct Rectangle {
    width: f64,
    height: f64,
}

fn main() {
    let rect = Rectangle {
        width: 30.0,
        height: 50.0,
    };

    println!("矩形: {:?}", rect);
    println!("矩形（美化）: {:#?}", rect);

    // 使用 dbg! 宏进行调试输出（输出到 stderr）
    let rect2 = dbg!(Rectangle {
        width: 10.0,
        height: 20.0,
    });

    println!("面积: {}", rect2.width * rect2.height);
}
```

## 📝 实际应用示例

### 构建一个简单的用户管理系统

```rust
#[derive(Debug)]
struct User {
    id: u64,
    username: String,
    email: String,
    login_count: u32,
    active: bool,
}

fn create_user(id: u64, username: String, email: String) -> User {
    User {
        id,
        username,
        email,
        login_count: 0,
        active: true,
    }
}

fn deactivate_user(user: &User) -> User {
    User {
        active: false,
        username: user.username.clone(),
        email: user.email.clone(),
        ..*user
    }
}

fn main() {
    let user = create_user(
        1,
        String::from("alice"),
        String::from("alice@example.com"),
    );
    println!("新用户: {:#?}", user);

    let inactive_user = deactivate_user(&user);
    println!("停用后: {:#?}", inactive_user);
    println!("原用户仍可用: {}", user.username);
}
```
