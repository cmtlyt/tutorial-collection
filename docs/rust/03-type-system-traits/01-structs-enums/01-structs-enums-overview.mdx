> **版本**：v1.0

## 📚 章节介绍

结构体和枚举是 Rust 类型系统的基础构建块。本章节将讲解各种结构体类型、枚举变体、方法定义，以及 Option 和 Result 这两个最重要的枚举类型。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 定义和使用各种结构体类型
- 通过 impl 块为结构体定义方法和关联函数
- 创建带数据的枚举变体
- 熟练使用 Option 和 Result 进行安全编程
- 掌握模式匹配和解构

## 🔑 核心概念

### Rust 的枚举：代数数据类型
Rust 的枚举不仅仅是简单的整数标签，每个变体都可以携带不同类型和数量的数据，这使其成为一种强大的代数数据类型（ADT），能够精确表达业务逻辑中的各种状态。

### Option 与 Result：消灭空指针
Rust 没有 null 值，取而代之的是 `Option<T>`（值可能存在或不存在）和 `Result<T, E>`（操作可能成功或失败），这在类型层面强制开发者处理所有可能的情况。
