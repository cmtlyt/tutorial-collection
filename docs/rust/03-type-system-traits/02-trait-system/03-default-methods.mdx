# 默认方法实现

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

Trait 中的方法可以提供**默认实现**（default implementation）。实现该 Trait 的类型可以选择使用默认实现，也可以覆盖（override）它。默认方法让 Trait 的使用者只需实现必要的核心方法，而其他方法可以自动基于核心方法推导出来。

## 🎯 基本默认方法

```rust
trait Greeting {
    fn name(&self) -> &str;

    // 默认方法：可以直接使用，也可以被覆盖
    fn greet(&self) -> String {
        format!("你好，我是 {}", self.name())
    }

    fn farewell(&self) -> String {
        format!("再见！—— {}", self.name())
    }
}

struct Person {
    name: String,
}

struct Robot {
    model: String,
}

// Person 使用默认的 greet 和 farewell
impl Greeting for Person {
    fn name(&self) -> &str {
        &self.name
    }
}

// Robot 覆盖了默认的 greet，但保留默认的 farewell
impl Greeting for Robot {
    fn name(&self) -> &str {
        &self.model
    }

    fn greet(&self) -> String {
        format!("嘟嘟嘟...我是机器人 {}，已启动", self.name())
    }
}

fn main() {
    let person = Person {
        name: String::from("Alice"),
    };
    println!("{}", person.greet());
    println!("{}", person.farewell());

    let robot = Robot {
        model: String::from("RX-78"),
    };
    println!("{}", robot.greet());
    println!("{}", robot.farewell());
}
```

## 🎯 默认方法调用其他方法

默认方法可以调用同一 Trait 中的其他方法，包括没有默认实现的方法：

```rust
trait Logger {
    // 必须实现的核心方法
    fn write(&self, message: &str);
    fn log_level(&self) -> &str;

    // 默认方法，基于核心方法构建
    fn info(&self, message: &str) {
        if self.should_log("INFO") {
            self.write(&format!("[INFO] {}", message));
        }
    }

    fn warn(&self, message: &str) {
        if self.should_log("WARN") {
            self.write(&format!("[WARN] {}", message));
        }
    }

    fn error(&self, message: &str) {
        if self.should_log("ERROR") {
            self.write(&format!("[ERROR] {}", message));
        }
    }

    fn should_log(&self, level: &str) -> bool {
        let priority = |l: &str| match l {
            "ERROR" => 3,
            "WARN" => 2,
            "INFO" => 1,
            _ => 0,
        };
        priority(level) >= priority(self.log_level())
    }
}

struct ConsoleLogger {
    min_level: String,
}

// 只需实现两个核心方法，其余自动获得
impl Logger for ConsoleLogger {
    fn write(&self, message: &str) {
        println!("{}", message);
    }

    fn log_level(&self) -> &str {
        &self.min_level
    }
}

fn main() {
    let logger = ConsoleLogger {
        min_level: String::from("WARN"),
    };

    logger.info("这条不会显示");
    logger.warn("这是警告");
    logger.error("这是错误");
}
```

## 🎯 部分覆盖

实现者可以选择覆盖部分默认方法，保留其余的：

```rust
trait Formatter {
    fn format_header(&self, title: &str) -> String {
        format!("=== {} ===", title)
    }

    fn format_body(&self, content: &str) -> String {
        content.to_string()
    }

    fn format_footer(&self) -> String {
        String::from("---")
    }

    fn format_document(&self, title: &str, content: &str) -> String {
        format!(
            "{}\n{}\n{}",
            self.format_header(title),
            self.format_body(content),
            self.format_footer()
        )
    }
}

struct MarkdownFormatter;

impl Formatter for MarkdownFormatter {
    // 只覆盖 header 和 footer 的格式
    fn format_header(&self, title: &str) -> String {
        format!("# {}", title)
    }

    fn format_footer(&self) -> String {
        String::from("---\n*Generated by MarkdownFormatter*")
    }
    // format_body 和 format_document 使用默认实现
}

struct PlainFormatter;

// 全部使用默认实现
impl Formatter for PlainFormatter {}

fn main() {
    let markdown = MarkdownFormatter;
    println!("{}", markdown.format_document("Rust 教程", "Rust 是一门系统编程语言。"));
    println!();

    let plain = PlainFormatter;
    println!("{}", plain.format_document("Rust 教程", "Rust 是一门系统编程语言。"));
}
```

## 📝 实际应用示例

### 可配置的序列化 Trait

```rust
trait Serialize {
    fn field_names(&self) -> Vec<&str>;
    fn field_values(&self) -> Vec<String>;

    fn to_csv(&self) -> String {
        self.field_values().join(",")
    }

    fn to_csv_with_header(&self) -> String {
        format!("{}\n{}", self.field_names().join(","), self.to_csv())
    }

    fn to_key_value(&self) -> String {
        self.field_names()
            .iter()
            .zip(self.field_values().iter())
            .map(|(name, value)| format!("{}={}", name, value))
            .collect::<Vec<_>>()
            .join("; ")
    }
}

struct Product {
    name: String,
    price: f64,
    quantity: u32,
}

impl Serialize for Product {
    fn field_names(&self) -> Vec<&str> {
        vec!["name", "price", "quantity"]
    }

    fn field_values(&self) -> Vec<String> {
        vec![
            self.name.clone(),
            format!("{:.2}", self.price),
            self.quantity.to_string(),
        ]
    }
}

fn main() {
    let product = Product {
        name: String::from("Rust Book"),
        price: 39.99,
        quantity: 100,
    };

    println!("CSV:");
    println!("{}", product.to_csv_with_header());
    println!();
    println!("Key-Value:");
    println!("{}", product.to_key_value());
}
```
