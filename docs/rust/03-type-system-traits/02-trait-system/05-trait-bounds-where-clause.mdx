# Trait bound 与 where 子句

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

Trait bound 是 Rust 中约束泛型参数的方式，确保泛型类型具有你所需要的行为。当 Trait bound 变得复杂时，`where` 子句提供了更清晰的书写方式。

## 🎯 Trait bound 语法

### 基本写法

在泛型参数后使用 `:` 指定 Trait bound：

```rust
use std::fmt::Display;

// Trait bound 写法
fn print_value<T: Display>(value: &T) {
    println!("值: {}", value);
}

// 等价的 impl Trait 写法
fn print_value_alt(value: &impl Display) {
    println!("值: {}", value);
}

fn largest<T: PartialOrd>(list: &[T]) -> &T {
    let mut largest = &list[0];
    for item in &list[1..] {
        if item > largest {
            largest = item;
        }
    }
    largest
}

fn main() {
    print_value(&42);
    print_value_alt(&"hello");

    let numbers = vec![34, 50, 25, 100, 65];
    println!("最大值: {}", largest(&numbers));

    let chars = vec!['y', 'm', 'a', 'q'];
    println!("最大字符: {}", largest(&chars));
}
```

### 多个 Trait bound

使用 `+` 组合多个 Trait bound：

```rust
use std::fmt::{Debug, Display};

fn print_info<T: Display + Debug>(value: &T) {
    println!("Display: {}", value);
    println!("Debug: {:?}", value);
}

fn compare_and_display<T: PartialOrd + Display>(a: &T, b: &T) {
    if a > b {
        println!("{} 大于 {}", a, b);
    } else if a < b {
        println!("{} 小于 {}", a, b);
    } else {
        println!("{} 等于 {}", a, b);
    }
}

fn main() {
    print_info(&42);
    compare_and_display(&10, &20);
    compare_and_display(&"apple", &"banana");
}
```

## 🎯 where 子句

当 Trait bound 较多或较复杂时，`where` 子句将约束移至函数签名末尾，提升可读性：

```rust
use std::fmt::{Debug, Display};

// 不使用 where：签名很长
fn process_pair_inline<T: Display + Clone, U: Debug + Default>(first: &T, second: &U) -> String {
    format!("{} - {:?}", first, second)
}

// 使用 where：更清晰
fn process_pair<T, U>(first: &T, second: &U) -> String
where
    T: Display + Clone,
    U: Debug + Default,
{
    format!("{} - {:?}", first, second)
}

fn main() {
    let result1 = process_pair_inline(&"hello", &42);
    let result2 = process_pair(&"hello", &42);
    println!("{}", result1);
    println!("{}", result2);
}
```

### 在结构体和 impl 块中使用

```rust
use std::fmt::Display;

struct Wrapper<T>
where
    T: Display + Clone,
{
    value: T,
}

impl<T> Wrapper<T>
where
    T: Display + Clone,
{
    fn new(value: T) -> Self {
        Wrapper { value }
    }

    fn show(&self) {
        println!("Wrapper 包含: {}", self.value);
    }

    fn duplicate(&self) -> Wrapper<T> {
        Wrapper {
            value: self.value.clone(),
        }
    }
}

fn main() {
    let wrapper = Wrapper::new(String::from("Hello"));
    wrapper.show();

    let cloned = wrapper.duplicate();
    cloned.show();
}
```

## 🎯 使用 Trait bound 选择性实现方法

可以根据泛型参数满足的 Trait bound 来有选择地实现方法：

```rust
use std::fmt::Display;

struct Pair<T> {
    first: T,
    second: T,
}

// 所有 Pair<T> 都有 new 方法
impl<T> Pair<T> {
    fn new(first: T, second: T) -> Self {
        Pair { first, second }
    }
}

// 只有 T 实现了 Display + PartialOrd 的 Pair<T> 才有 compare_and_display 方法
impl<T: Display + PartialOrd> Pair<T> {
    fn compare_and_display(&self) {
        if self.first >= self.second {
            println!("较大值: {}", self.first);
        } else {
            println!("较大值: {}", self.second);
        }
    }
}

fn main() {
    let pair_numbers = Pair::new(10, 20);
    pair_numbers.compare_and_display();

    let pair_strings = Pair::new(String::from("apple"), String::from("banana"));
    pair_strings.compare_and_display();

    // Pair<Vec<i32>> 没有 compare_and_display 方法（Vec 没实现 Display）
    let _pair_vecs = Pair::new(vec![1], vec![2]);
    // _pair_vecs.compare_and_display(); // 编译错误
}
```

## 📝 实际应用示例

### 泛型缓存

```rust
use std::collections::HashMap;
use std::fmt::Display;
use std::hash::Hash;

struct Cache<K, V>
where
    K: Eq + Hash + Display,
    V: Clone,
{
    store: HashMap<K, V>,
    max_size: usize,
}

impl<K, V> Cache<K, V>
where
    K: Eq + Hash + Display,
    V: Clone,
{
    fn new(max_size: usize) -> Self {
        Cache {
            store: HashMap::new(),
            max_size,
        }
    }

    fn get(&self, key: &K) -> Option<V> {
        self.store.get(key).cloned()
    }

    fn insert(&mut self, key: K, value: V) -> bool {
        if self.store.len() >= self.max_size && !self.store.contains_key(&key) {
            println!("缓存已满，无法插入键 '{}'", key);
            return false;
        }
        self.store.insert(key, value);
        true
    }

    fn size(&self) -> usize {
        self.store.len()
    }
}

fn main() {
    let mut cache: Cache<String, i32> = Cache::new(3);

    cache.insert(String::from("a"), 1);
    cache.insert(String::from("b"), 2);
    cache.insert(String::from("c"), 3);
    println!("缓存大小: {}", cache.size());

    cache.insert(String::from("d"), 4); // 缓存已满

    if let Some(value) = cache.get(&String::from("a")) {
        println!("a = {}", value);
    }
}
```
