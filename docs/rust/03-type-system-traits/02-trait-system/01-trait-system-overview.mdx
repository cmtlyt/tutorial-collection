# Trait 系统 - 总览

> **版本**：v1.0

## 📚 章节介绍

Trait 是 Rust 实现多态和代码复用的核心机制，类似于其他语言中的接口。本章节将全面讲解 Trait 的定义、实现、常用标准 Trait 以及高级特性。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 定义和实现自定义 Trait
- 使用 Trait bound 和 where 子句约束泛型
- 掌握常用标准 Trait 的用法和实现
- 理解关联类型和运算符重载
- 区分动态分发和静态分发

## 🔑 核心概念

### 静态分发 vs 动态分发
- **静态分发（impl Trait / 泛型）**：编译期单态化，零运行时开销，但会增加编译产物大小
- **动态分发（dyn Trait）**：运行期通过虚表（vtable）分发，有少量运行时开销，但更灵活

### 孤儿规则
你只能在以下两种情况之一下为类型实现 Trait：
1. Trait 是在当前 crate 中定义的
2. 类型是在当前 crate 中定义的

这条规则确保了 Trait 实现的全局一致性。
