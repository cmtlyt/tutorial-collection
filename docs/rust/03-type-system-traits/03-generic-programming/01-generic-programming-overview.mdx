## 🔑 核心概念

### 单态化：零成本抽象
Rust 的泛型在编译时通过单态化展开为具体类型的代码，这意味着泛型不会引入任何运行时开销，但可能增加编译时间和产物大小。

### PhantomData
PhantomData 用于在类型中引入"幽灵"类型参数，告诉编译器该类型逻辑上与某个类型相关，即使实际上不持有该类型的值。常用于 FFI 和高级类型设计。
