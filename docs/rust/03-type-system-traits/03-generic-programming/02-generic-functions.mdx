# 泛型函数

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

泛型函数允许你编写适用于多种类型的通用代码，而不必为每种类型重复编写逻辑。Rust 通过在函数签名中使用类型参数（如 `<T>`）来实现泛型，编译器会在编译期为实际使用的每种类型生成特化版本。

## 🎯 基本泛型函数

### 定义与调用

```rust
fn first<T>(list: &[T]) -> Option<&T> {
    list.first()
}

fn last<T>(list: &[T]) -> Option<&T> {
    list.last()
}

fn main() {
    let numbers = vec![1, 2, 3, 4, 5];
    let words = vec!["hello", "world"];

    // 编译器自动推断类型参数
    println!("第一个数字: {:?}", first(&numbers));
    println!("最后一个单词: {:?}", last(&words));

    // 也可以显式指定类型（turbofish 语法）
    println!("第一个: {:?}", first::<i32>(&numbers));
}
```

### 多个类型参数

```rust
fn zip_pair<A, B>(first: A, second: B) -> (A, B) {
    (first, second)
}

fn swap<T>(pair: (T, T)) -> (T, T) {
    (pair.1, pair.0)
}

fn main() {
    let pair = zip_pair(42, "hello");
    println!("配对: {:?}", pair);

    let swapped = swap((1, 2));
    println!("交换: {:?}", swapped);

    let swapped_str = swap(("first", "second"));
    println!("交换: {:?}", swapped_str);
}
```

## 🎯 带 Trait 约束的泛型函数

没有约束的泛型参数几乎什么都做不了（不能比较、打印、计算等）。通过 Trait bound 赋予泛型行为能力：

```rust
use std::fmt::Display;

fn print_labeled<T: Display>(label: &str, value: &T) {
    println!("{}: {}", label, value);
}

fn largest<T: PartialOrd>(list: &[T]) -> &T {
    let mut largest = &list[0];
    for item in &list[1..] {
        if item > largest {
            largest = item;
        }
    }
    largest
}

fn find_first<T: PartialEq>(list: &[T], target: &T) -> Option<usize> {
    list.iter().position(|item| item == target)
}

fn main() {
    print_labeled("年龄", &28);
    print_labeled("名字", &"Alice");

    let numbers = vec![34, 50, 25, 100, 65];
    println!("最大数字: {}", largest(&numbers));

    let words = vec!["cherry", "apple", "banana"];
    println!("最大单词: {}", largest(&words));

    let data = vec![10, 20, 30, 40];
    println!("30 的位置: {:?}", find_first(&data, &30));
    println!("99 的位置: {:?}", find_first(&data, &99));
}
```

## 🎯 泛型返回值

```rust
fn create_default<T: Default>() -> T {
    T::default()
}

fn repeat_value<T: Clone>(value: &T, count: usize) -> Vec<T> {
    vec![value.clone(); count]
}

fn main() {
    let number: i32 = create_default();
    let text: String = create_default();
    let flag: bool = create_default();
    println!("默认 i32: {}", number);
    println!("默认 String: '{}'", text);
    println!("默认 bool: {}", flag);

    let repeated = repeat_value(&"hello", 3);
    println!("重复: {:?}", repeated);
}
```

## 📝 实际应用示例

### 泛型最小/最大值查找器

```rust
use std::fmt::Display;

fn min_max<T: PartialOrd + Display>(list: &[T]) -> Option<(&T, &T)> {
    if list.is_empty() {
        return None;
    }

    let mut min = &list[0];
    let mut max = &list[0];

    for item in &list[1..] {
        if item < min {
            min = item;
        }
        if item > max {
            max = item;
        }
    }

    Some((min, max))
}

fn print_stats<T: PartialOrd + Display>(label: &str, data: &[T]) {
    match min_max(data) {
        Some((min, max)) => {
            println!("{}: 最小={}, 最大={}, 共{}个元素", label, min, max, data.len());
        }
        None => println!("{}: 空数据", label),
    }
}

fn main() {
    let scores = vec![85, 92, 78, 96, 88, 73];
    print_stats("成绩", &scores);

    let temperatures = vec![36.5, 37.2, 35.8, 38.1, 36.9];
    print_stats("体温", &temperatures);

    let names = vec!["Charlie", "Alice", "Bob", "Diana"];
    print_stats("姓名", &names);
}
```
