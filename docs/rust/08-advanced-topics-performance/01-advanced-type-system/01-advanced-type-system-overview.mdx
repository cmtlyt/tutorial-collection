## 📚 章节介绍

Rust 的类型系统远不止基础的泛型和 Trait，它还提供了类型别名、Never 类型、GAT 和类型状态模式等高级特性。本章节将深入探索这些高级类型系统功能。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 理解动态大小类型（DST）和 Sized trait
- 掌握 GAT（泛型关联类型）的定义和应用
- 使用类型状态模式实现编译期状态机
- 运用 Builder 模式和 Typestate 设计

## 🔑 核心概念

### GAT：泛型关联类型
GAT 允许在 Trait 的关联类型中使用泛型参数，极大增强了 Trait 的表达能力。它是实现诸如异步 trait、借用迭代器等高阶抽象的关键特性。

### 类型状态模式
通过在类型参数中编码状态信息，利用编译器在编译期检查状态转换的合法性，将运行时错误转化为编译期错误。
