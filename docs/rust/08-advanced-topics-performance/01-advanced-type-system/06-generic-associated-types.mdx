# 泛型关联类型（GAT）

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

**泛型关联类型（Generic Associated Types, GAT）** 是 Rust 1.65 稳定的一个重要特性，它允许在 Trait 的关联类型中使用泛型参数和生命周期参数。GAT 极大地增强了 Trait 的表达能力，使得许多之前无法表达或需要 workaround 的抽象成为可能。

在 GAT 出现之前，关联类型是"固定的"——它们不能携带额外的泛型参数。GAT 打破了这一限制，使关联类型可以根据不同的参数产生不同的具体类型。

## 🎯 从问题出发

### 没有 GAT 时的困境

```rs
// 假设我们想定义一个通用的"容器"Trait
// 要求 iter() 方法返回一个借用迭代器

// 没有 GAT 时，这个 Trait 无法正确表达
// 因为关联类型 Iter 需要携带生命周期 'a
// 但普通关联类型不支持泛型参数

trait CollectionOld {
    type Item;
    // 无法定义 type Iter<'a>，只能返回固定类型
    // 这意味着我们无法返回一个借用了 self 的迭代器
}

// 只能通过这些 workaround：
// 1. 返回 Box<dyn Iterator>（有性能开销）
// 2. 定义一个单独的 trait 来约束迭代器类型

fn main() {
    println!("GAT 解决了关联类型无法携带泛型参数的问题");
}
```

### GAT 的解决方案

```rs
// 使用 GAT，我们可以优雅地表达这个 Trait
trait Collection {
    type Item;
    type Iter<'a>: Iterator<Item = &'a Self::Item> where Self: 'a;

    fn iter(&self) -> Self::Iter<'_>;
    fn len(&self) -> usize;
    fn is_empty(&self) -> bool {
        self.len() == 0
    }
}

// 为 Vec<T> 实现 Collection
impl<T> Collection for Vec<T> {
    type Item = T;
    type Iter<'a> = std::slice::Iter<'a, T> where T: 'a;

    fn iter(&self) -> Self::Iter<'_> {
        self.as_slice().iter()
    }

    fn len(&self) -> usize {
        Vec::len(self)
    }
}

// 现在可以写泛型函数来处理任何 Collection
fn print_all<C: Collection>(collection: &C)
where
    C::Item: std::fmt::Debug,
{
    print!("[");
    let mut first = true;
    for item in collection.iter() {
        if !first { print!(", "); }
        print!("{:?}", item);
        first = false;
    }
    println!("]");
}

fn main() {
    let numbers = vec![1, 2, 3, 4, 5];
    print!("数字: ");
    print_all(&numbers);

    let names = vec!["Alice".to_string(), "Bob".to_string()];
    print!("名字: ");
    print_all(&names);
}
```

## 🔧 GAT 语法详解

### 定义带生命周期参数的 GAT

```rs
trait LendingIterator {
    type Item<'a> where Self: 'a;

    fn next(&mut self) -> Option<Self::Item<'_>>;
}

// 一个窗口迭代器，每次返回对内部数据的切片引用
struct WindowIter {
    data: Vec<i32>,
    position: usize,
    window_size: usize,
}

impl WindowIter {
    fn new(data: Vec<i32>, window_size: usize) -> Self {
        WindowIter { data, position: 0, window_size }
    }
}

impl LendingIterator for WindowIter {
    type Item<'a> = &'a [i32] where Self: 'a;

    fn next(&mut self) -> Option<Self::Item<'_>> {
        if self.position + self.window_size <= self.data.len() {
            let window = &self.data[self.position..self.position + self.window_size];
            self.position += 1;
            Some(window)
        } else {
            None
        }
    }
}

fn main() {
    let mut iter = WindowIter::new(vec![1, 2, 3, 4, 5], 3);

    while let Some(window) = iter.next() {
        println!("窗口: {:?}", window);
    }
    // 输出:
    // 窗口: [1, 2, 3]
    // 窗口: [2, 3, 4]
    // 窗口: [3, 4, 5]
}
```

### 定义带类型参数的 GAT

```rs
trait Functor {
    type Item;
    type Mapped<U>: Functor;

    fn map<U, F>(self, f: F) -> Self::Mapped<U>
    where
        F: FnMut(Self::Item) -> U;
}

// 为 Option 实现 Functor
impl<T> Functor for Option<T> {
    type Item = T;
    type Mapped<U> = Option<U>;

    fn map<U, F>(self, f: F) -> Option<U>
    where
        F: FnMut(T) -> U,
    {
        Option::map(self, f)
    }
}

// 为 Vec 实现 Functor
impl<T> Functor for Vec<T> {
    type Item = T;
    type Mapped<U> = Vec<U>;

    fn map<U, F>(self, f: F) -> Vec<U>
    where
        F: FnMut(T) -> U,
    {
        self.into_iter().map(f).collect()
    }
}

fn double_all<C: Functor<Item = i32>>(container: C) -> C::Mapped<i32> {
    container.map(|x| x * 2)
}

fn main() {
    let option_val: Option<i32> = Some(21);
    let doubled_option = double_all(option_val);
    println!("Option: {:?}", doubled_option); // Some(42)

    let vec_val = vec![1, 2, 3, 4, 5];
    let doubled_vec = double_all(vec_val);
    println!("Vec: {:?}", doubled_vec); // [2, 4, 6, 8, 10]
}
```

## 📝 实际应用示例

### 数据库查询抽象

```rs
use std::collections::HashMap;

// 使用 GAT 定义一个通用的存储抽象
trait Storage {
    type Item;
    type Ref<'a>: std::ops::Deref<Target = Self::Item> where Self: 'a;
    type Iter<'a>: Iterator<Item = (usize, Self::Ref<'a>)> where Self: 'a;

    fn get(&self, id: usize) -> Option<Self::Ref<'_>>;
    fn iter(&self) -> Self::Iter<'_>;
    fn insert(&mut self, item: Self::Item) -> usize;
}

// 内存存储实现
struct InMemoryStorage<T> {
    data: HashMap<usize, T>,
    next_id: usize,
}

impl<T> InMemoryStorage<T> {
    fn new() -> Self {
        InMemoryStorage {
            data: HashMap::new(),
            next_id: 0,
        }
    }
}

impl<T> Storage for InMemoryStorage<T> {
    type Item = T;
    type Ref<'a> = &'a T where T: 'a;
    type Iter<'a> = std::collections::hash_map::Iter<'a, usize, T> where T: 'a;

    fn get(&self, id: usize) -> Option<&T> {
        self.data.get(&id)
    }

    fn iter(&self) -> Self::Iter<'_> {
        self.data.iter()
    }

    fn insert(&mut self, item: T) -> usize {
        let id = self.next_id;
        self.next_id += 1;
        self.data.insert(id, item);
        id
    }
}

#[derive(Debug)]
struct User {
    name: String,
    email: String,
}

fn main() {
    let mut storage = InMemoryStorage::new();

    let id1 = storage.insert(User {
        name: "Alice".to_string(),
        email: "alice@example.com".to_string(),
    });
    let id2 = storage.insert(User {
        name: "Bob".to_string(),
        email: "bob@example.com".to_string(),
    });

    if let Some(user) = storage.get(id1) {
        println!("用户 {}: {} ({})", id1, user.name, user.email);
    }

    println!("\n所有用户:");
    for (id, user) in storage.iter() {
        println!("  [{}] {:?}", id, user);
    }

    println!("查找 ID {}: {:?}", id2, storage.get(id2).map(|u| &u.name));
}
```

## 🔗 相关概念

- **关联类型**：GAT 是关联类型的泛型扩展
- **生命周期**：GAT 最常见的用法是携带生命周期参数
- **Trait 对象**：含 GAT 的 Trait 在使用 Trait 对象时有限制
- **高阶 Trait bound（HRTB）**：`for<'a>` 语法与 GAT 密切相关
