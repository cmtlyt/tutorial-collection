## 📚 章节介绍

性能是 Rust 的核心卖点之一。本章节将全面讲解 Rust 的性能分析工具、内存优化策略和编译优化技术，帮助你编写高性能的 Rust 代码。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 使用 cargo bench 和 criterion 进行基准测试
- 使用 flamegraph 分析性能瓶颈
- 掌握内存优化策略（减少堆分配、对象池、竞技场分配）
- 了解编译优化选项（LTO、PGO）

## 🔑 核心概念

### 基准测试驱动优化
性能优化必须以数据为基础，而非凭直觉。通过 criterion 进行统计基准测试，可以获得可靠的性能数据，避免误判优化效果。

### 编译优化三板斧
1. **LTO（链接时优化）**：跨 crate 边界进行内联和优化，显著减小产物大小并提升性能
2. **PGO（配置文件引导优化）**：基于运行时性能数据指导编译器优化决策
3. **codegen-units = 1**：减少并行编译单元数量，允许更激进的优化
