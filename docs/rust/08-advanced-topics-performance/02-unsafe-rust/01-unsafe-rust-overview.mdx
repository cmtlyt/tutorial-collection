# Unsafe Rust - 总览

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 章节介绍

Unsafe Rust 允许执行编译器无法验证安全性的操作。本章节将系统讲解 unsafe 的五种超能力、如何在 unsafe 之上构建安全抽象，以及使用 Miri 检测未定义行为。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 理解 unsafe 关键字的五种超能力
- 在 unsafe 代码上构建安全的 API 抽象
- 文档化安全契约和不变量
- 使用 Miri 检测未定义行为

## 📖 章节结构

### 第一部分：unsafe 基础
- unsafe 块与 unsafe fn
- 解引用裸指针
- 调用 unsafe 函数
- 访问可变静态变量
- 实现 unsafe trait

### 第二部分：安全抽象
- 在 unsafe 上构建安全 API
- 不变量维护
- 文档化安全契约
- Miri 工具检测未定义行为

## 🔑 核心概念

### unsafe 的五种超能力
1. 解引用裸指针（*const T / *mut T）
2. 调用 unsafe 函数或方法
3. 访问或修改可变静态变量
4. 实现 unsafe trait
5. 访问 union 的字段

### 安全抽象原则
unsafe 不意味着代码一定不安全，而是告诉编译器"安全性由开发者保证"。最佳实践是将 unsafe 操作封装在安全的 API 内部，对外只暴露安全接口，并通过文档明确标注安全契约。
