# 调用 unsafe 函数

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

调用 unsafe 函数是 unsafe Rust 的五种超能力之一。被标记为 `unsafe` 的函数表示它有一些编译器无法自动验证的**前置条件（preconditions）**，调用者必须保证这些条件成立。最常见的场景包括调用 C 语言函数（FFI）、使用标准库中的 unsafe 方法，以及调用自定义的 unsafe 函数。

## 🎯 标准库中的 unsafe 函数

### 常见的 unsafe 方法

```rs
fn main() {
    // 1. slice::get_unchecked — 跳过边界检查
    let data = [10, 20, 30, 40, 50];
    let value = unsafe { *data.get_unchecked(3) };
    println!("get_unchecked(3): {}", value); // 40

    // 对比安全版本
    let safe_value = data.get(3);
    println!("get(3): {:?}", safe_value); // Some(40)

    // 2. String::from_utf8_unchecked — 跳过 UTF-8 验证
    let bytes = vec![72, 101, 108, 108, 111]; // "Hello" 的 UTF-8 编码
    let text = unsafe { String::from_utf8_unchecked(bytes) };
    println!("from_utf8_unchecked: {}", text);

    // 对比安全版本
    let bytes2 = vec![72, 101, 108, 108, 111];
    let safe_text = String::from_utf8(bytes2).unwrap();
    println!("from_utf8: {}", safe_text);

    // 3. slice::from_raw_parts — 从指针和长度创建切片
    let array = [1, 2, 3, 4, 5];
    let ptr = array.as_ptr();
    let slice = unsafe { std::slice::from_raw_parts(ptr.add(1), 3) };
    println!("from_raw_parts: {:?}", slice); // [2, 3, 4]
}
```

### 性能关键路径中的 unsafe

```rs
fn sum_checked(data: &[i32]) -> i64 {
    let mut total: i64 = 0;
    for i in 0..data.len() {
        total += data[i] as i64; // 每次访问都有边界检查
    }
    total
}

fn sum_unchecked(data: &[i32]) -> i64 {
    let mut total: i64 = 0;
    for i in 0..data.len() {
        // 跳过边界检查：循环条件已保证 i < len
        unsafe {
            total += *data.get_unchecked(i) as i64;
        }
    }
    total
}

fn sum_iterator(data: &[i32]) -> i64 {
    // 推荐方式：迭代器通常已经优化掉了边界检查
    data.iter().map(|&x| x as i64).sum()
}

fn main() {
    let data: Vec<i32> = (1..=100).collect();

    let result1 = sum_checked(&data);
    let result2 = sum_unchecked(&data);
    let result3 = sum_iterator(&data);

    println!("checked:   {}", result1);
    println!("unchecked: {}", result2);
    println!("iterator:  {}", result3);
    assert_eq!(result1, result2);
    assert_eq!(result1, result3);
}
```

## 🔧 FFI：调用 C 函数

### 使用 extern 声明外部函数

```rs
// 声明 C 标准库函数
extern "C" {
    fn abs(input: i32) -> i32;
    fn strlen(s: *const std::os::raw::c_char) -> usize;
    fn memcpy(dest: *mut u8, src: *const u8, n: usize) -> *mut u8;
}

fn main() {
    // 调用 C 的 abs 函数
    let result = unsafe { abs(-42) };
    println!("C abs(-42) = {}", result);

    // 调用 C 的 strlen 函数
    let c_string = b"Hello, C!\0";  // C 字符串以 \0 结尾
    let len = unsafe { strlen(c_string.as_ptr() as *const std::os::raw::c_char) };
    println!("C strlen = {}", len);

    // 调用 C 的 memcpy 函数
    let src = [1u8, 2, 3, 4, 5];
    let mut dest = [0u8; 5];
    unsafe {
        memcpy(dest.as_mut_ptr(), src.as_ptr(), src.len());
    }
    println!("memcpy 结果: {:?}", dest);
}
```

### 使用 CString 进行安全的 FFI

```rs
use std::ffi::{CString, CStr};
use std::os::raw::c_char;

extern "C" {
    fn strlen(s: *const c_char) -> usize;
}

fn safe_strlen(s: &str) -> usize {
    // CString 确保字符串以 null 结尾且不包含内部 null 字节
    let c_string = CString::new(s).expect("字符串包含内部 null 字节");
    unsafe { strlen(c_string.as_ptr()) }
}

fn demonstrate_cstr() {
    // 从 C 指针创建 CStr（借用）
    let bytes = b"Hello from C\0";
    let c_str = unsafe {
        CStr::from_ptr(bytes.as_ptr() as *const c_char)
    };

    // CStr → &str
    let rust_str = c_str.to_str().expect("无效的 UTF-8");
    println!("CStr → &str: {}", rust_str);

    // CStr → String
    let owned = c_str.to_string_lossy().into_owned();
    println!("CStr → String: {}", owned);
}

fn main() {
    println!("安全 strlen(\"Rust\"): {}", safe_strlen("Rust"));
    println!("安全 strlen(\"你好\"): {}", safe_strlen("你好")); // UTF-8 多字节

    demonstrate_cstr();
}
```

## 📝 实际应用示例

### 封装 C 库调用为安全 Rust API

```rs
use std::fmt;

// 模拟一个 C 数学库的 FFI 绑定
mod ffi {
    extern "C" {
        pub fn sqrt(x: f64) -> f64;
        pub fn pow(base: f64, exp: f64) -> f64;
        pub fn log(x: f64) -> f64;
        pub fn floor(x: f64) -> f64;
        pub fn ceil(x: f64) -> f64;
    }
}

// 安全的 Rust 包装器
struct MathLib;

impl MathLib {
    fn sqrt(x: f64) -> Result<f64, String> {
        if x < 0.0 {
            return Err(format!("sqrt: 输入 {} 不能为负数", x));
        }
        Ok(unsafe { ffi::sqrt(x) })
    }

    fn pow(base: f64, exp: f64) -> f64 {
        unsafe { ffi::pow(base, exp) }
    }

    fn ln(x: f64) -> Result<f64, String> {
        if x <= 0.0 {
            return Err(format!("ln: 输入 {} 必须为正数", x));
        }
        Ok(unsafe { ffi::log(x) })
    }

    fn floor(x: f64) -> f64 {
        unsafe { ffi::floor(x) }
    }

    fn ceil(x: f64) -> f64 {
        unsafe { ffi::ceil(x) }
    }
}

struct Stats {
    mean: f64,
    std_dev: f64,
    min: f64,
    max: f64,
}

impl fmt::Display for Stats {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "均值={:.2}, 标准差={:.2}, 最小={:.2}, 最大={:.2}",
               self.mean, self.std_dev, self.min, self.max)
    }
}

fn compute_stats(data: &[f64]) -> Option<Stats> {
    if data.is_empty() {
        return None;
    }

    let n = data.len() as f64;
    let mean = data.iter().sum::<f64>() / n;

    let variance = data.iter()
        .map(|x| MathLib::pow(x - mean, 2.0))
        .sum::<f64>() / n;

    let std_dev = MathLib::sqrt(variance).unwrap_or(0.0);

    let min = data.iter().cloned().fold(f64::INFINITY, f64::min);
    let max = data.iter().cloned().fold(f64::NEG_INFINITY, f64::max);

    Some(Stats { mean, std_dev, min, max })
}

fn main() {
    println!("sqrt(16) = {:?}", MathLib::sqrt(16.0));
    println!("sqrt(-1) = {:?}", MathLib::sqrt(-1.0));
    println!("pow(2, 10) = {}", MathLib::pow(2.0, 10.0));
    println!("ln(e) = {:?}", MathLib::ln(std::f64::consts::E));
    println!("floor(3.7) = {}", MathLib::floor(3.7));
    println!("ceil(3.2) = {}", MathLib::ceil(3.2));

    let data = vec![2.0, 4.0, 4.0, 4.0, 5.0, 5.0, 7.0, 9.0];
    if let Some(stats) = compute_stats(&data) {
        println!("\n统计结果: {}", stats);
    }
}
```
