## 📚 章节介绍

生命周期是 Rust 引用系统的重要组成部分，它确保所有引用在其指向的数据有效期间保持有效。本章节将讲解生命周期标注语法、省略规则以及高级用法。

- 理解生命周期省略规则

## 🔑 核心概念

### 为什么需要生命周期
生命周期帮助 Rust 编译器确保引用始终有效。当编译器无法自动推断引用的有效范围时，就需要开发者显式标注生命周期。

### 生命周期省略规则
编译器通过三条规则自动推断生命周期，使大部分情况下无需手动标注：
1. 每个引用参数都获得独立的生命周期参数
2. 如果只有一个输入生命周期参数，则所有输出引用使用该生命周期
3. 如果有 &self 或 &mut self 参数，则输出引用使用 self 的生命周期
