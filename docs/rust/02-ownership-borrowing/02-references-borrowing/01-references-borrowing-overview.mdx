# 引用与借用 - 总览

> **版本**：v1.0

## 📚 章节介绍

引用与借用是 Rust 所有权系统的延伸，允许你在不获取所有权的情况下访问数据。本章节将讲解借用规则、可变引用与不可变引用的区别，以及切片引用。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 理解不可变引用与可变引用的区别
- 掌握借用规则及其背后的设计动机
- 理解悬垂引用的防护机制
- 熟练使用字符串切片和数组切片

## 🔑 核心概念

### 借用规则
在任意给定时刻，你只能拥有以下两者之一（不能同时拥有）：
1. **一个可变引用**（&mut T）
2. **任意数量的不可变引用**（&T）

这条规则在编译期就能防止数据竞争。

### 切片：安全的部分引用
切片是对集合中连续元素序列的引用，它不拥有数据的所有权，但保证了指向的数据在切片有效期间不会被修改或释放。
