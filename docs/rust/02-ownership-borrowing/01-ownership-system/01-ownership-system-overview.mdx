## 📚 章节介绍

所有权系统是 Rust 最独特、最核心的特性，它使 Rust 能在没有垃圾回收的情况下保证内存安全。本章节将深入讲解所有权规则、移动语义以及栈堆内存管理。

- 理解栈分配与堆分配的区别
- 掌握 Box 智能指针和 Drop trait

## 🔑 核心概念

### 所有权三规则
1. Rust 中每一个值都有一个变量作为它的**所有者**
2. 同一时刻，一个值**有且仅有一个**所有者
3. 当所有者离开作用域时，这个值将被**丢弃**（drop）

### 移动 vs 复制
- **移动（Move）**：默认行为，所有权从一个变量转移到另一个变量，原变量不再可用
- **复制（Copy）**：实现了 Copy trait 的类型（如整数、浮点数）在赋值时会进行按位复制，原变量仍然可用
