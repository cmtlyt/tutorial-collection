# 声明宏 - 总览

> **版本**：v1.0

## 📚 章节介绍

声明宏（macro_rules!）是 Rust 元编程的基础工具，通过模式匹配对代码进行转换和生成。本章节将讲解声明宏的语法、片段说明符、递归宏以及宏的卫生性。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 使用 macro_rules! 定义声明宏
- 掌握宏中的模式匹配和重复语法
- 理解各种片段说明符（expr / ident / ty / tt）
- 编写递归宏
- 理解宏的卫生性机制

## 🔑 核心概念

### 宏 vs 函数
宏在编译期进行代码展开，能做到函数无法做到的事：
1. **可变参数**：宏可以接受任意数量的参数
2. **代码生成**：宏可以生成重复的代码结构
3. **语法扩展**：宏可以创造新的语法形式

### 宏的卫生性
Rust 的声明宏是"部分卫生"的，宏内部定义的变量不会与外部同名变量冲突，但宏可以引用外部的类型和 trait。
