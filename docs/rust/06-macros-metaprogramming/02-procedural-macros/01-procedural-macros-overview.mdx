# 过程宏 - 总览

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 章节介绍

过程宏是 Rust 元编程的高级工具，它以 Rust 代码的形式操作 TokenStream，能实现派生宏、属性宏和函数式宏三种形式的代码生成。

## 🎯 学习目标

完成本章节学习后，你将能够：
- 使用 syn 和 quote 库编写过程宏
- 实现自定义 derive 派生宏
- 创建属性宏修饰函数和结构体
- 编写函数式过程宏
- 理解 TokenStream 的解析与生成

## 📖 章节结构

### 第一部分：派生宏（Derive Macros）
- 自定义 derive
- syn 与 quote 库
- TokenStream 解析与生成

### 第二部分：属性宏（Attribute Macros）
- 自定义属性定义
- 函数/结构体修饰

### 第三部分：函数式宏（Function-like Macros）
- 自定义语法扩展
- 编译期代码生成

## 🔑 核心概念

### 三种过程宏
1. **派生宏（Derive）**：通过 `#[derive(MyMacro)]` 自动为类型生成 trait 实现
2. **属性宏（Attribute）**：通过 `#[my_attribute]` 修饰函数、结构体等条目
3. **函数式宏（Function-like）**：以 `my_macro!(...)` 形式调用，类似声明宏但功能更强

### syn + quote 工具链
- **syn**：将 TokenStream 解析为结构化的语法树（AST）
- **quote**：将 Rust 代码模板转换回 TokenStream
