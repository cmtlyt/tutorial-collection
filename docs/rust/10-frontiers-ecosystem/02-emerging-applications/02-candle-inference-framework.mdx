# candle 推理框架

> **版本**：v1.0  
> **最后更新**：2026-04-23

## 📚 概念介绍

[candle](https://github.com/huggingface/candle) 是 Hugging Face 开源的一个用 Rust 编写的极简机器学习框架。与 Python 生态中的 PyTorch 不同，candle 专注于**轻量级推理**，核心目标是让无服务器（serverless）推理成为可能——无需 Python 运行时、无需庞大的依赖链，只需一个编译好的二进制文件即可运行模型推理。

### 核心特点

- **极简设计**：API 风格类似 PyTorch，学习成本低
- **高性能**：原生 Rust 实现，支持 CPU 和 CUDA GPU
- **零 Python 依赖**：部署时无需 Python 环境
- **safetensors 原生支持**：直接加载 Hugging Face Hub 上的模型
- **多精度支持**：支持 f32、f16、bf16 等数据类型
- **WASM 支持**：可编译为 WebAssembly 在浏览器中运行

### 张量基础操作

```rust
use candle_core::{Device, Tensor, DType};
use anyhow::Result;

fn main() -> Result<()> {
    // 选择设备（CPU 或 CUDA）
    let device = Device::Cpu;

    // 创建张量
    let a = Tensor::new(&[[1.0f32, 2.0], [3.0, 4.0]], &device)?;
    let b = Tensor::new(&[[5.0f32, 6.0], [7.0, 8.0]], &device)?;

    // 基本运算
    let sum = (&a + &b)?;
    let product = a.matmul(&b)?;

    println!("矩阵 A:\n{a}");
    println!("矩阵 B:\n{b}");
    println!("A + B:\n{sum}");
    println!("A × B:\n{product}");

    // 创建随机张量
    let random = Tensor::randn(0f32, 1.0, (3, 4), &device)?;
    println!("随机张量 (3x4):\n{random}");

    // 张量变形
    let reshaped = random.reshape((2, 6))?;
    println!("变形后 (2x6):\n{reshaped}");

    // 类型转换
    let float16 = a.to_dtype(DType::F16)?;
    println!("F16 张量:\n{float16}");

    Ok(())
}
```

### 构建简单神经网络

```rust
use candle_core::{Device, Tensor, DType, Module};
use candle_nn::{Linear, linear, VarBuilder, VarMap};
use anyhow::Result;

struct SimpleClassifier {
    layer1: Linear,
    layer2: Linear,
    output: Linear,
}

impl SimpleClassifier {
    fn new(input_dim: usize, hidden_dim: usize, output_dim: usize, vb: VarBuilder) -> Result<Self> {
        let layer1 = linear(input_dim, hidden_dim, vb.pp("layer1"))?;
        let layer2 = linear(hidden_dim, hidden_dim, vb.pp("layer2"))?;
        let output = linear(hidden_dim, output_dim, vb.pp("output"))?;
        Ok(Self { layer1, layer2, output })
    }

    fn forward(&self, input: &Tensor) -> Result<Tensor> {
        let hidden = self.layer1.forward(input)?.relu()?;
        let hidden = self.layer2.forward(&hidden)?.relu()?;
        let logits = self.output.forward(&hidden)?;
        Ok(logits)
    }
}

fn main() -> Result<()> {
    let device = Device::Cpu;
    let varmap = VarMap::new();
    let vb = VarBuilder::from_varmap(&varmap, DType::F32, &device);

    // 创建模型：输入维度 4，隐藏层 16，输出 3 类
    let model = SimpleClassifier::new(4, 16, 3, vb)?;

    // 模拟输入数据 (batch_size=2, features=4)
    let input = Tensor::randn(0f32, 1.0, (2, 4), &device)?;
    let output = model.forward(&input)?;

    println!("输入形状: {:?}", input.shape());
    println!("输出形状: {:?}", output.shape());
    println!("输出 logits:\n{output}");

    // Softmax 得到概率分布
    let probabilities = candle_nn::ops::softmax(&output, 1)?;
    println!("概率分布:\n{probabilities}");

    Ok(())
}
```

## 🔑 与 PyTorch 的 API 对比

```rust
use candle_core::{Device, Tensor, DType};
use anyhow::Result;

fn api_comparison() -> Result<()> {
    let device = Device::Cpu;

    // PyTorch:  torch.zeros(3, 4)
    // candle:
    let zeros = Tensor::zeros((3, 4), DType::F32, &device)?;

    // PyTorch:  torch.ones(3, 4)
    // candle:
    let ones = Tensor::ones((3, 4), DType::F32, &device)?;

    // PyTorch:  torch.randn(3, 4)
    // candle:
    let random = Tensor::randn(0f32, 1.0, (3, 4), &device)?;

    // PyTorch:  a + b
    // candle:
    let sum = (&zeros + &ones)?;

    // PyTorch:  a.matmul(b)
    // candle:
    let a = Tensor::randn(0f32, 1.0, (2, 3), &device)?;
    let b = Tensor::randn(0f32, 1.0, (3, 4), &device)?;
    let product = a.matmul(&b)?;

    // PyTorch:  x.softmax(dim=-1)
    // candle:
    let logits = Tensor::new(&[[1.0f32, 2.0, 3.0]], &device)?;
    let probs = candle_nn::ops::softmax(&logits, 1)?;

    // PyTorch:  x.reshape(2, 6)
    // candle:
    let reshaped = random.reshape((2, 6))?;

    // PyTorch:  x.to(torch.float16)
    // candle:
    let half = ones.to_dtype(DType::F16)?;

    println!("zeros: {zeros}");
    println!("sum: {sum}");
    println!("product 形状: {:?}", product.shape());
    println!("softmax: {probs}");
    println!("reshaped 形状: {:?}", reshaped.shape());
    println!("half 类型: {:?}", half.dtype());

    Ok(())
}

fn main() -> Result<()> {
    api_comparison()?;
    Ok(())
}
```
