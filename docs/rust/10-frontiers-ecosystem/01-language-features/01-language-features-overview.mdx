## 📚 章节介绍

Rust 通过 Edition 机制持续演进，每隔几年发布新 Edition 引入重要特性。本章节将介绍各 Edition 的关键变化以及正在开发中的实验性特性。

## 🔑 核心概念

### Edition 机制
Rust 的 Edition 机制允许语言在不破坏向后兼容性的前提下引入新特性。不同 Edition 的 crate 可以互相依赖，编译器会自动处理兼容性，开发者可以按自己的节奏升级。

### 关注中的特性
- **async 闭包**：允许闭包内使用 async/await，简化异步编程
- **生成器/协程**：惰性产生值的序列，是 async/await 的底层基础
- **特化**：为更具体的类型提供更优化的 trait 实现
