# Rust 中文社区

> **版本**：v1.0  
> **最后更新**：2026-04-23

## 📚 概念介绍

Rust 中文社区是全球 Rust 社区的重要组成部分。随着 Rust 在国内的快速普及，中文社区已经形成了丰富的学习资源、活跃的讨论氛围和多样的交流平台。从翻译 The Rust Book 到组织线下 Meetup，中文社区为降低 Rust 的学习门槛和推动国内 Rust 生态发展做出了巨大贡献。

### 中文社区的特色

- **翻译项目**：大量核心文档和优质文章被翻译为中文
- **本土化资源**：适合中文读者的教程和书籍
- **活跃讨论**：微信群、知乎、掘金等平台的技术讨论
- **企业实践**：字节跳动、蚂蚁集团、华为等国内企业的 Rust 实践分享

## 📊 常用术语中英对照

| 英文 | 中文 | 说明 |
|------|------|------|
| Ownership | 所有权 | Rust 核心概念 |
| Borrowing | 借用 | 引用的使用 |
| Lifetime | 生命周期 | 引用的有效范围 |
| Trait | 特征/特性 | 类似接口 |
| Pattern Matching | 模式匹配 | match 表达式 |
| Crate | 包/库 | Rust 的编译单元 |
| Closure | 闭包 | 匿名函数 |
| Iterator | 迭代器 | 惰性序列 |
| Smart Pointer | 智能指针 | Box、Rc、Arc 等 |
| Concurrency | 并发 | 多线程/异步 |
