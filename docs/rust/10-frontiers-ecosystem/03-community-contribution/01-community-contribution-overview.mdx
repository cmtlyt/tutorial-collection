## 🔑 核心概念

### Rust RFC 流程
Rust 的重大语言特性和标准库变更都通过 RFC（Request for Comments）流程进行讨论和决策。任何人都可以提交 RFC 提案，经过社区讨论后由核心团队决定是否接受。

### 社区驱动的发展
Rust 是一个由社区驱动的开源项目，通过工作组（Working Groups）和团队（Teams）的形式组织贡献者，涵盖编译器、语言设计、库、工具、文档等多个方向。
