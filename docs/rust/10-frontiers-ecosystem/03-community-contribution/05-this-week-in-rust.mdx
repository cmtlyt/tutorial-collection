# This Week in Rust

> **版本**：v1.0  
> **最后更新**：2026-04-23

## 📚 概念介绍

[This Week in Rust](https://this-week-in-rust.org/)（简称 TWiR）是 Rust 社区最重要的周刊，自 2013 年以来每周发布。它汇集了 Rust 生态中最重要的新闻、精选文章、crate 推荐、RFC 动态和社区活动，是跟进 Rust 发展的最佳方式之一。TWiR 本身也是开源项目，任何人都可以投稿。

### TWiR 的价值

- **信息聚合**：一站式了解 Rust 生态的最新动态
- **质量筛选**：经过编辑团队筛选的高质量内容
- **社区连接**：发现有趣的项目、文章和活动
- **投稿机会**：你的文章和项目有机会被全球 Rust 开发者看到

## 🔑 如何向 TWiR 投稿

### 投稿流程

```
投稿步骤
1. 访问 TWiR 的 GitHub 仓库：
   https://github.com/rust-lang/this-week-in-rust

2. 找到下一期的 draft PR 或 issue

3. 在对应分类下提交你的链接：
   - 文章链接 → "Observations/Thoughts" 或 "Rust Walkthroughs"
   - 项目更新 → "Project/Tooling Updates"
   - 活动信息 → "Upcoming Events"
   - crate 推荐 → "Crate of the Week"

4. 也可以通过以下方式提交：
   - 在 GitHub Issue 中留言
   - 通过表单提交：https://this-week-in-rust.org/submit
   - 在 Rust Zulip 的 #thisweek 频道提交

5. 编辑团队会在发布前审阅并决定是否收录
```

```rust

    println!("=== TWiR 投稿建议 ===\n");

    println!("✅ 容易被收录的内容:");
    println!("  - 原创的深度技术文章");
    println!("  - 实际项目中使用 Rust 的经验分享");
    println!("  - 新发布的 Rust 项目/crate");
    println!("  - 详细的教程和指南");
    println!("  - 性能对比和基准测试");

    println!("  - 内容过短或缺乏深度\n");

    println!("  - 确保文章质量（校对、代码可运行）");
    println!("  - 选择合适的分类");
}

    describe_submission_tips();
```
