# React Server Components

> **版本**：v1.0  
> **最后更新**：2026-04-22

## 📚 概念介绍

React Server Components (RSC) 是 React 生态系统的重大变革，它允许组件在服务器上渲染，从而显著减少客户端 JavaScript 包大小，提升性能。RSC 与传统的客户端组件不同，它们可以直接访问服务器资源，如数据库、文件系统等，同时保持 React 的组件化开发体验。

## 🎯 服务端组件基础

服务端组件默认在服务器上渲染，不会发送到客户端，这大大减少了 JavaScript 包的大小。

### 基础服务端组件

```js
import { db } from './db'

async function BlogPostList() {
  const posts = await db.query('SELECT * FROM posts ORDER BY created_at DESC LIMIT 10')
  
  return (
    <div>
      <h1>最新博客文章</h1>
      <div>
        {posts.map(post => (
          <article key={post.id} style={{ marginBottom: '24px', padding: '16px', border: '1px solid #ddd', borderRadius: '8px' }}>
            <h2>{post.title}</h2>
            <p>{post.excerpt}</p>
            <small>{new Date(post.created_at).toLocaleDateString()}</small>
          </article>
        ))}
      </div>
    </div>
  )
}

export default BlogPostList
```

## 🎯 客户端组件

客户端组件是传统的 React 组件，它们在浏览器中运行，可以处理用户交互和状态管理。

### 基础客户端组件

```js
'use client'

import { useState } from 'react'

function LikeButton({ initialLikes = 0 }) {
  const [likes, setLikes] = useState(initialLikes)
  const [isLiked, setIsLiked] = useState(false)
  
  const handleLike = () => {
    if (isLiked) {
      setLikes(prev => prev - 1)
      setIsLiked(false)
    } else {
      setLikes(prev => prev + 1)
      setIsLiked(true)
    }
  }
  
  return (
    <button 
      onClick={handleLike}
      style={{
        padding: '8px 16px',
        background: isLiked ? '#ff6b6b' : '#fff',
        color: isLiked ? '#fff' : '#333',
        border: '1px solid #ddd',
        borderRadius: '4px',
        cursor: 'pointer',
        display: 'flex',
        alignItems: 'center',
        gap: '8px'
      }}
    >
      <span>{isLiked ? '❤️' : '🤍'}</span>
      <span>{likes}</span>
    </button>
  )
}

export default LikeButton
```

### 交互式客户端组件

```js
'use client'

import { useState } from 'react'

function CommentForm({ postId }) {
  const [comment, setComment] = useState('')
  const [isSubmitting, setIsSubmitting] = useState(false)
  const [submittedComments, setSubmittedComments] = useState([])
  
  const handleSubmit = async (e) => {
    e.preventDefault()
    
    if (!comment.trim()) return
    
    setIsSubmitting(true)
    
    await new Promise(resolve => setTimeout(resolve, 1000))
    
    setSubmittedComments(prev => [...prev, {
      id: Date.now(),
      text: comment,
      timestamp: new Date().toISOString()
    }])
    
    setComment('')
    setIsSubmitting(false)
  }
  
  return (
    <div style={{ marginTop: '16px' }}>
      <h3>发表评论</h3>
      
      <form onSubmit={handleSubmit}>
        <textarea
          value={comment}
          onChange={(e) => setComment(e.target.value)}
          placeholder="写下你的评论..."
          rows={4}
          style={{
            width: '100%',
            padding: '8px',
            border: '1px solid #ddd',
            borderRadius: '4px',
            marginBottom: '8px',
            resize: 'vertical'
          }}
        />
        
        <button
          type="submit"
          disabled={isSubmitting || !comment.trim()}
          style={{
            padding: '8px 16px',
            background: isSubmitting ? '#ccc' : '#007bff',
            color: '#fff',
            border: 'none',
            borderRadius: '4px',
            cursor: isSubmitting ? 'not-allowed' : 'pointer'
          }}
        >
          {isSubmitting ? '提交中...' : '提交评论'}
        </button>
      </form>
      
      {submittedComments.length > 0 && (
        <div style={{ marginTop: '16px' }}>
          <h4>已提交的评论：</h4>
          {submittedComments.map(c => (
            <div key={c.id} style={{ 
              padding: '8px', 
              background: '#f9f9f9', 
              borderRadius: '4px',
              marginBottom: '8px'
            }}>
              <p>{c.text}</p>
              <small>{new Date(c.timestamp).toLocaleTimeString()}</small>
            </div>
          ))}
        </div>
      )}
    </div>
  )
}

export default CommentForm
```

## 🎯 Server Actions

Server Actions 允许你在客户端组件中调用服务端函数，实现表单提交、数据更新等操作。

### 基础 Server Action

```js
'use server'

import { db } from './db'

async function createPost(formData) {
  const title = formData.get('title')
  const content = formData.get('content')
  const author = formData.get('author')
  
  if (!title || !content) {
    return { error: '标题和内容不能为空' }
  }
  
  const newPost = {
    id: Date.now(),
    title,
    content,
    author: author || '匿名用户',
    created_at: new Date().toISOString(),
    likes: 0
  }
  
  await db.query('INSERT INTO posts ...', newPost)
  
  return { success: true, post: newPost }
}

export { createPost }
```

## 🎯 Suspense 与数据加载

Suspense 在服务端组件中用于处理异步数据加载，提供更好的用户体验。

### Suspense 边界

```js
import { Suspense } from 'react'

async function PostList() {
  const posts = await fetchPosts()
  
  return (
    <div>
      {posts.map(post => (
        <article key={post.id} style={{ marginBottom: '16px', padding: '12px', border: '1px solid #ddd' }}>
          <h3>{post.title}</h3>
          <p>{post.excerpt}</p>
        </article>
      ))}
    </div>
  )
}

async function Sidebar() {
  const categories = await fetchCategories()
  
  return (
    <aside>
      <h3>分类</h3>
      <ul>
        {categories.map(cat => (
          <li key={cat.id}>{cat.name}</li>
        ))}
      </ul>
    </aside>
  )
}

function BlogPage() {
  return (
    <div style={{ display: 'flex', gap: '20px' }}>
      <main style={{ flex: 1 }}>
        <Suspense fallback={<div>加载文章中...</div>}>
          <PostList />
        </Suspense>
      </main>
      
      <aside style={{ width: '250px' }}>
        <Suspense fallback={<div>加载分类中...</div>}>
          <Sidebar />
        </Suspense>
      </aside>
    </div>
  )
}

export default BlogPage
```
