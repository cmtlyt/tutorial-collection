> **版本**：v1.0

## 📚 概念介绍

JSX（JavaScript XML）是 React 的核心特性之一，它允许我们在 JavaScript 中编写类似 HTML 的语法。JSX 不是必需的，但它让 React 组件更加直观和易于理解。本章节将详细介绍 JSX 的语法和特性。

## 🎯 JSX 基本语法

### JSX 是什么

JSX 是 JavaScript 的语法扩展，它看起来像 HTML，但实际上是 JavaScript：

```jsx
// JSX 语法
const element = <h1>Hello, World!</h1>;

// 编译后的 JavaScript（使用 React.createElement）
const element = React.createElement('h1', null, 'Hello, World!');
```

### JSX 规则

```jsx
// 1. 必须有一个根元素
// ✅ 正确
<div>
  <h1>Title</h1>
  <p>Content</p>
</div>

// ✅ 使用 Fragment 避免额外的 div
<>
  <h1>Title</h1>
  <p>Content</p>
</>

// ❌ 错误 - 多个根元素
<h1>Title</h1>
<p>Content</p>

// 2. 所有标签必须闭合
// ✅ 正确
<img src="image.jpg" alt="Image" />
<input type="text" />
<br />
<hr />

// ❌ 错误 - 未闭合
<img src="image.jpg" alt="Image">
<input type="text">

// 3. 使用 className 而不是 class
// ✅ 正确
<div className="container">
  <p className="text">Hello</p>
</div>

// ❌ 错误
<div class="container">
  <p class="text">Hello</p>
</div>

// 4. 使用 htmlFor 而不是 for
// ✅ 正确
<label htmlFor="email">Email:</label>
<input id="email" type="email" />

// ❌ 错误
<label for="email">Email:</label>
<input id="email" type="email" />

// 5. 属性使用驼峰命名
// ✅ 正确
<div onClick={handleClick} onMouseEnter={handleHover} />

// ❌ 错误
<div onclick={handleClick} onmouseenter={handleHover} />
```

## 🎯 表达式嵌入

### 在 JSX 中使用 JavaScript 表达式

```jsx
import React from 'react';

function Greeting({ name, age }) {
  const currentTime = new Date().toLocaleTimeString();
  
  return (
    <div>
      {/* 单行表达式 */}
      <h1>Hello, {name}!</h1>
      
      {/* 计算表达式 */}
      <p>You are {age} years old</p>
      <p>Next year you will be {age + 1}</p>
      
      {/* 调用函数 */}
      <p>Current time: {currentTime}</p>
      <p>Uppercase name: {name.toUpperCase()}</p>
      
      {/* 三元运算符 */}
      <p>
        {age >= 18 ? 'You are an adult' : 'You are a minor'}
      </p>
      
      {/* 逻辑与运算符 */}
      {age >= 18 && <p>You can vote!</p>}
      
      {/* 逻辑或运算符 */}
      <p>{name || 'Anonymous'}</p>
      
      {/* 数组方法 */}
      <p>Reversed name: {name.split('').reverse().join('')}</p>
    </div>
  );
}

export default Greeting;
```

### 属性中的表达式

```jsx
import React from 'react';

function Button({ text, isPrimary, size }) {
  const baseClass = 'btn';
  const sizeClass = size === 'large' ? 'btn-lg' : 'btn-sm';
  const variantClass = isPrimary ? 'btn-primary' : 'btn-secondary';
  
  return (
    <button
      className={`${baseClass} ${sizeClass} ${variantClass}`}
      disabled={!isPrimary}
      style={{ fontSize: size === 'large' ? '18px' : '14px' }}
    >
      {text}
    </button>
  );
}

// 使用示例
function App() {
  return (
    <div>
      <Button text="Primary Button" isPrimary={true} size="large" />
      <Button text="Secondary Button" isPrimary={false} size="small" />
    </div>
  );
}

export default App;
```

### 提前返回

```jsx
import React from 'react';

function UserProfile({ user, loading, error }) {
  // 加载状态
  if (loading) {
    return <div>Loading...</div>;
  }
  
  // 错误状态
  if (error) {
    return <div>Error: {error.message}</div>;
  }
  
  // 用户不存在
  if (!user) {
    return <div>User not found</div>;
  }
  
  // 正常渲染
  return (
    <div className="user-profile">
      <h2>{user.name}</h2>
      <p>Email: {user.email}</p>
      <p>Age: {user.age}</p>
    </div>
  );
}

export default UserProfile;
```

### 使用变量存储 JSX

```jsx
import React from 'react';

function StatusMessage({ status }) {
  let message;
  
  if (status === 'success') {
    message = <p style={{ color: 'green' }}>Operation successful!</p>;
  } else if (status === 'error') {
    message = <p style={{ color: 'red' }}>Operation failed!</p>;
  } else if (status === 'warning') {
    message = <p style={{ color: 'orange' }}>Warning!</p>;
  } else {
    message = <p>Unknown status</p>;
  }
  
  return (
    <div>
      <h1>Status</h1>
      {message}
    </div>
  );
}

export default StatusMessage;
```

### 为什么 Key 很重要

```jsx
import React, { useState } from 'react';

function TodoApp() {
  const [todos, setTodos] = useState([
    { id: 1, text: 'Learn React', completed: false },
    { id: 2, text: 'Build a project', completed: false },
    { id: 3, text: 'Write documentation', completed: false }
  ]);
  
  const addTodo = (text) => {
    const newTodo = {
      id: Date.now(),
      text,
      completed: false
    };
    setTodos([...todos, newTodo]);
  };
  
  const toggleTodo = (id) => {
    setTodos(todos.map(todo =>
      todo.id === id ? { ...todo, completed: !todo.completed } : todo
    ));
  };
  
  const deleteTodo = (id) => {
    setTodos(todos.filter(todo => todo.id !== id));
  };
  
  return (
    <div>
      <h1>Todo List</h1>
      
      <form onSubmit={(e) => {
        e.preventDefault();
        const input = e.target.elements.todo;
        if (input.value.trim()) {
          addTodo(input.value.trim());
          input.value = '';
        }
      }}>
        <input name="todo" type="text" placeholder="Add a new todo" />
        <button type="submit">Add</button>
      </form>
      
      <ul>
        {todos.map(todo => (
          <li key={todo.id}>
            <input
              type="checkbox"
              checked={todo.completed}
              onChange={() => toggleTodo(todo.id)}
            />
            <span style={{ textDecoration: todo.completed ? 'line-through' : 'none' }}>
              {todo.text}
            </span>
            <button onClick={() => deleteTodo(todo.id)}>
              Delete
            </button>
          </li>
        ))}
      </ul>
    </div>
  );
}

export default TodoApp;
```

### 展开运算符传递属性

```jsx
import React from 'react';

function Input({ type, placeholder, value, onChange }) {
  return (
    <input
      type={type}
      placeholder={placeholder}
      value={value}
      onChange={onChange}
    />
  );
}

function App() {
  const [email, setEmail] = React.useState('');
  const [password, setPassword] = React.useState('');
  
  const emailProps = {
    type: 'email',
    placeholder: 'Enter your email',
    value: email,
    onChange: (e) => setEmail(e.target.value)
  };
  
  const passwordProps = {
    type: 'password',
    placeholder: 'Enter your password',
    value: password,
    onChange: (e) => setPassword(e.target.value)
  };
  
  return (
    <form>
      <Input {...emailProps} />
      <Input {...passwordProps} />
    </form>
  );
}

export default App;
```

## 🎯 React 19 新 JSX Transform（必须启用）

### 新 JSX Transform 的优势

React 19 引入了新的 JSX Transform，它带来了以下改进：

1. **无需导入 React**：不再需要在文件顶部导入 React
2. **自动转换**：JSX 自动转换为 `jsx()` 函数调用
3. **更好的性能**：减少了包体积
4. **更快的编译**：编译速度提升

### 旧版 vs 新版对比

```jsx
// ❌ 旧版 - 需要导入 React
import React from 'react';

function App() {
  return <div>Hello, World!</div>;
}

// ✅ 新版 - 无需导入 React
function App() {
  return <div>Hello, World!</div>;
}
```

### 编译后的代码

```jsx
// 旧版编译结果
import React from 'react';

function App() {
  return React.createElement('div', null, 'Hello, World!');
}

// 新版编译结果
import { jsx as _jsx } from 'react/jsx-runtime';

function App() {
  return _jsx('div', {
    children: 'Hello, World!'
  });
}
```

### 配置要求

确保你的构建工具配置了新的 JSX Transform：

**Babel 配置：**
```json
{
  "presets": [
    [
      "@babel/preset-react",
      {
        "runtime": "automatic"
      }
    ]
  ]
}
```

**Vite 配置：**
Vite 默认使用新的 JSX Transform，无需额外配置。

**Next.js 配置：**
Next.js 13+ 默认使用新的 JSX Transform。

## 📝 实际应用示例

### 综合示例：产品卡片组件

```jsx
import React, { useState } from 'react';

function ProductCard({ product, onAddToCart }) {
  const [isHovered, setIsHovered] = useState(false);
  
  return (
    <div
      className={`product-card ${isHovered ? 'hovered' : ''}`}
      onMouseEnter={() => setIsHovered(true)}
      onMouseLeave={() => setIsHovered(false)}
    >
      <div className="product-image">
        <img src={product.image} alt={product.name} />
        {product.discount > 0 && (
          <span className="discount-badge">
            -{product.discount}%
          </span>
        )}
      </div>
      
      <div className="product-info">
        <h3>{product.name}</h3>
        <p className="category">{product.category}</p>
        
        <div className="price">
          {product.discount > 0 ? (
            <>
              <span className="original-price">
                ${product.originalPrice}
              </span>
              <span className="discounted-price">
                ${product.price}
              </span>
            </>
          ) : (
            <span className="regular-price">
              ${product.price}
            </span>
          )}
        </div>
        
        <div className="rating">
          {'★'.repeat(Math.floor(product.rating))}
          {'☆'.repeat(5 - Math.floor(product.rating))}
          <span>({product.reviewCount})</span>
        </div>
        
        <div className="stock">
          {product.inStock ? (
            <span className="in-stock">In Stock</span>
          ) : (
            <span className="out-of-stock">Out of Stock</span>
          )}
        </div>
        
        <button
          className="add-to-cart"
          onClick={() => onAddToCart(product)}
          disabled={!product.inStock}
        >
          {product.inStock ? 'Add to Cart' : 'Out of Stock'}
        </button>
      </div>
    </div>
  );
}

function ProductList({ products, onAddToCart }) {
  return (
    <div className="product-list">
      {products.map(product => (
        <ProductCard
          key={product.id}
          product={product}
          onAddToCart={onAddToCart}
        />
      ))}
    </div>
  );
}

// 使用示例
const products = [
  {
    id: 1,
    name: 'Wireless Headphones',
    category: 'Electronics',
    price: 149.99,
    originalPrice: 199.99,
    discount: 25,
    rating: 4.5,
    reviewCount: 128,
    inStock: true,
    image: '/headphones.jpg'
  },
  {
    id: 2,
    name: 'Smart Watch',
    category: 'Electronics',
    price: 299.99,
    originalPrice: 299.99,
    discount: 0,
    rating: 4.8,
    reviewCount: 256,
    inStock: true,
    image: '/watch.jpg'
  },
  {
    id: 3,
    name: 'Bluetooth Speaker',
    category: 'Electronics',
    price: 79.99,
    originalPrice: 99.99,
    discount: 20,
    rating: 4.2,
    reviewCount: 89,
    inStock: false,
    image: '/speaker.jpg'
  }
];

function App() {
  const [cart, setCart] = useState([]);
  
  const handleAddToCart = (product) => {
    setCart([...cart, product]);
    alert(`${product.name} added to cart!`);
  };
  
  return (
    <div className="app">
      <header>
        <h1>Online Store</h1>
        <nav>Cart: {cart.length} items</nav>
      </header>
      
      <main>
        <ProductList
          products={products}
          onAddToCart={handleAddToCart}
        />
      </main>
    </div>
  );
}

export default App;
```
