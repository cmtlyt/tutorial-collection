## 🔑 核心概念

### Core Web Vitals
Google 的核心性能指标，用于衡量用户体验：
- **LCP（Largest Contentful Paint）**：最大内容绘制，衡量加载性能
- **FID（First Input Delay）**：首次输入延迟，衡量交互性
- **CLS（Cumulative Layout Shift）**：累积布局偏移，衡量视觉稳定性

### 性能监控的重要性
性能监控是优化用户体验的关键：
- **发现问题**：及早发现性能瓶颈
- **量化改进**：用数据驱动优化决策
- **持续优化**：持续跟踪性能指标
- **用户体验**：提供流畅的用户体验

### React 19.2 Performance Tracks
React 19.2 引入了强大的性能追踪功能：
- **Scheduler 轨道**：可视化调度器工作
- **Components 轨道**：组件渲染性能分析
- **Server 轨道**：服务端组件性能追踪
- **Chrome DevTools 集成**：与 DevTools 无缝集成

## 📊 性能指标详解

### LCP（Largest Contentful Paint）
- **目标**：< 2.5 秒
- **衡量**：页面最大内容元素的加载时间
- **优化**：优化图片、延迟加载、预加载关键资源

### FID（First Input Delay）
- **目标**：< 100 毫秒
- **衡量**：用户首次交互到浏览器响应的时间
- **优化**：减少 JavaScript 执行时间、优化主线程

### CLS（Cumulative Layout Shift）
- **目标**：< 0.1
- **衡量**：页面布局的稳定性
- **优化**：为图片和视频预留空间、避免动态插入内容

## 🛠️ 实践建议

### 性能优化策略
1. **首屏加载优化**
   - 代码分割和懒加载
   - 预加载关键资源
   - 优化图片和字体
   - 使用 CDN

2. **运行时性能优化**
   - 避免不必要的渲染
   - 使用 React.memo、useMemo、useCallback
   - 虚拟化长列表
   - 优化状态更新

3. **网络优化**
   - 使用 HTTP/2
   - 启用压缩（Gzip、Brotli）
   - 优化缓存策略
   - 减少请求次数

### React 19.2 Performance Tracks 使用
```jsx
import { Profiler } from 'react';

function onRenderCallback(
  id,
  phase,
  actualDuration,
  baseDuration,
  startTime,
  commitTime
) {
  console.log({
    id,
    phase,
    actualDuration,
    baseDuration,
    startTime,
    commitTime
  });
}

<Profiler id="App" onRender={onRenderCallback}>
  <App />
</Profiler>
```

## 🎯 重点提示

### 性能优化优先级
1. **首屏加载**：用户首次访问的体验最重要
2. **交互响应**：确保快速响应用户操作
3. **视觉稳定**：避免布局跳动
4. **持续监控**：持续跟踪性能指标

### React 19.2 性能追踪
- **仅在开发和 profiling 构建中启用**：生产环境不会启用
- **性能影响**：profiling 仪表化会增加额外开销
- **Chrome DevTools 集成**：与 DevTools 无缝集成
- **细粒度分析**：提供详细的性能数据

### 性能监控工具
- **Lighthouse**：综合性能评估
- **Chrome DevTools**：详细的性能分析
- **React DevTools Profiler**：React 组件性能分析
- **WebPageTest**：真实的网络环境测试
