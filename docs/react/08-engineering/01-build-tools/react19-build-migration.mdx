# React 19 构建迁移指南

> **版本**: v1.0  
> **最后更新**: 2026-04-22

## 📚 概念介绍

React 19 引入了重要的构建要求变化，包括新 JSX Transform 的强制使用、UMD 构建的移除以及对 ESM 的全面支持。本指南将帮助你从 React 18 平滑迁移到 React 19，并确保构建配置符合新版本的要求。

## 🛠️ 升级步骤

### 步骤 1：更新 React 依赖

```bash
# 升级到 React 19
npm install react@19 react-dom@19

# 如果使用 TypeScript，更新类型定义
npm install -D @types/react@19 @types/react-dom@19

# 更新相关依赖
npm install react-router-dom@latest
npm install @testing-library/react@latest @testing-library/jest-dom@latest
```

### 步骤 2：更新 TypeScript 配置

```json
// tsconfig.json
{
  "compilerOptions": {
    "target": "ES2020",
    "useDefineForClassFields": true,
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "skipLibCheck": true,
    "moduleResolution": "bundler",
    "allowImportingTsExtensions": true,
    "resolveJsonModule": true,
    "isolatedModules": true,
    "noEmit": true,
    "jsx": "react-jsx",
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noFallthroughCasesInSwitch": true
  },
  "include": ["src"],
  "references": [{ "path": "./tsconfig.node.json" }]
}
```

**关键变更**：
- `"jsx": "react-jsx"`：启用新 JSX Transform，这是 React 19 的必需配置
- `"moduleResolution": "bundler"`：使用现代模块解析策略

### 步骤 3：移除 React 导入

React 19 的新 JSX Transform 不再需要手动导入 React：

```jsx
// ❌ 旧写法（React 18）
import React from 'react';

function App() {
  return <div>Hello World</div>;
}

export default App;
```

```jsx
// ✅ 新写法（React 19）
function App() {
  return <div>Hello World</div>;
}

export default App;
```

### 步骤 5：移除废弃 API

React 19 移除了一些废弃的 API，需要更新代码：

```jsx
// ❌ 旧写法（已废弃）
import React, { PropTypes } from 'react';

MyComponent.propTypes = {
  name: PropTypes.string,
  age: PropTypes.number
};

MyComponent.defaultProps = {
  age: 18
};
```

```jsx
// ✅ 新写法
import PropTypes from 'prop-types';

MyComponent.propTypes = {
  name: PropTypes.string,
  age: PropTypes.number
};

MyComponent.defaultProps = {
  age: 18
};
```

## 📝 迁移示例

### 示例 1：迁移函数组件

```jsx
// ❌ 旧写法
import React, { useState, useEffect } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `Count: ${count}`;
  }, [count]);

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
}

export default Counter;
```

```jsx
// ✅ 新写法
import { useState, useEffect } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `Count: ${count}`;
  }, [count]);

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
```

### 示例 2：迁移类组件

```jsx
// ❌ 旧写法
import React, { Component } from 'react';

class Counter extends Component {
  constructor(props) {
    super(props);
    this.state = { count: 0 };
  }

  increment = () => {
    this.setState(prevState => ({ count: prevState.count + 1 }));
  };

  render() {
    return (
      <div>
        <p>Count: {this.state.count}</p>
        <button onClick={this.increment}>Increment</button>
      </div>
    );
  }
}

export default Counter;
```

```jsx
// ✅ 新写法（推荐使用函数组件）
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  const increment = () => {
    setCount(prevCount => prevCount + 1);
  };

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={increment}>Increment</button>
    </div>
  );
}

export default Counter;
```

### 示例 4：迁移 forwardRef

```jsx
// ❌ 旧写法
import React, { forwardRef } from 'react';

const Button = forwardRef((props, ref) => {
  return <button ref={ref} {...props} />;
});

Button.displayName = 'Button';

export default Button;
```

```jsx

import { forwardRef } from 'react';

function Button(props, ref) {
  return <button ref={ref} {...props} />;
}

export default forwardRef(Button);
```

## 🚀 新特性使用

### 使用 React 19 新 Hooks

```jsx
// useActionState 示例
import { useActionState } from 'react';

async function submitForm(prevState, formData) {
  const name = formData.get('name');
  const response = await fetch('/api/submit', {
    method: 'POST',
    body: formData
  });
  return response.json();
}

function ContactForm() {
  const [state, submitAction, isPending] = useActionState(
    submitForm,
    { success: false, message: '' }
  );

  return (
    <form action={submitAction}>
      <input name="name" type="text" required />
      <button type="submit" disabled={isPending}>
        {isPending ? 'Submitting...' : 'Submit'}
      </button>
      {state.success && <p>{state.message}</p>}
    </form>
  );
}

export default ContactForm;
```

```jsx
// useOptimistic 示例
import { useOptimistic, useState } from 'react';

function TodoList({ todos, addTodo }) {
  const [optimisticTodos, addOptimisticTodo] = useOptimistic(
    todos,
    (state, newTodo) => [...state, { ...newTodo, pending: true }]
  );

  const [newTodo, setNewTodo] = useState('');

  async function handleSubmit(e) {
    e.preventDefault();
    addOptimisticTodo({ id: Date.now(), text: newTodo });
    setNewTodo('');
    await addTodo(newTodo);
  }

  return (
    <div>
      <form onSubmit={handleSubmit}>
        <input
          value={newTodo}
          onChange={(e) => setNewTodo(e.target.value)}
          placeholder="Add todo"
        />
        <button type="submit">Add</button>
      </form>
      <ul>
        {optimisticTodos.map(todo => (
          <li key={todo.id}>
            {todo.text}
            {todo.pending && ' (saving...)'}
          </li>
        ))}
      </ul>
    </div>
  );
}

export default TodoList;
```

## 🔍 常见问题解决

### 问题 1：构建失败 - JSX Transform 错误

**错误信息**：
```
React is not defined
```

**解决方案**：
确保 `tsconfig.json` 中设置了 `"jsx": "react-jsx"`，并移除所有 `import React from 'react'`。

### 问题 2：类型错误 - React 类型不匹配

**错误信息**：
```
Type 'ReactElement' is not assignable to type 'ReactNode'
```

**解决方案**：
更新 `@types/react` 和 `@types/react-dom` 到最新版本：

```bash
npm install -D @types/react@19 @types/react-dom@19
```

### 问题 3：测试失败 - React 19 兼容性问题

**错误信息**：
```
React 19 requires the new JSX Transform
```

**解决方案**：
更新测试配置，确保使用新 JSX Transform：

```js
// jest.config.js
module.exports = {
  transform: {
    '^.+\\.(js|jsx|ts|tsx)$': ['babel-jest', {
      presets: [
        ['@babel/preset-react', { runtime: 'automatic' }]
      ]
    }]
  }
};
```

## 🎯 最佳实践

### 1. 渐进式迁移

不要一次性迁移整个项目，建议：

1. 先升级依赖和配置
2. 逐个模块更新代码
3. 充分测试每个模块
4. 最后处理复杂组件

### 2. 使用 Codemods

React 官方提供了 Codemods 工具来自动化迁移：

```bash
# 安装 codemod CLI
npm install -g jscodeshift

# 运行 React 19 codemods
npx react-codemod@latest update-react-imports
```

### 3. 版本控制

使用 Git 跟踪迁移过程：

```bash
# 创建迁移分支
git checkout -b feature/react19-migration

# 提交每个步骤
git add package.json
git commit -m "Update React to version 19"

git add tsconfig.json
git commit -m "Update TypeScript config for React 19"

# 完成后合并到主分支
git checkout main
git merge feature/react19-migration
```

## 🎯 重点提示

### 关键变更
- **新 JSX Transform 必需**: 必须在 `tsconfig.json` 中设置 `"jsx": "react-jsx"`
- **移除 React 导入**: 不再需要 `import React from 'react'`
- **UMD 构建移除**: React 19 不再提供 UMD 构建
- **ESM 优先**: 全面支持 ESM 模块系统

### 迁移要点
- **备份项目**: 迁移前创建备份分支
- **渐进式迁移**: 逐步迁移，充分测试
- **使用 Codemods**: 利用自动化工具加速迁移
- **版本控制**: 使用 Git 跟踪迁移过程

### 兼容性
- **TypeScript 5.0+**: 建议使用 TypeScript 5.0 或更高版本
- **Node.js 18+**: React 19 需要 Node.js 18 或更高版本
- **构建工具更新**: 确保构建工具支持 React 19
