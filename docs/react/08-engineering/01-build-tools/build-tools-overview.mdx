## 🔑 核心概念

### 构建工具的作用
构建工具是现代前端开发的核心基础设施，负责：
- **模块打包**：将分散的模块打包成浏览器可执行的文件
- **代码转换**：将 TypeScript、JSX 等转换为 JavaScript
- **资源优化**：压缩、混淆、tree shaking
- **开发体验**：热模块替换（HMR）、快速启动
- **生产优化**：代码分割、懒加载、缓存策略

### 构建工具演进
```
Webpack (2014) - 功能最全面，生态最成熟
    ↓
Rollup (2015) - 专注于 ESM，tree shaking 优秀
    ↓
esbuild (2020) - Go 语言，编译速度极快
    ↓
Vite (2020) - 基于 esbuild + Rollup，开发体验极佳
    ↓
Rspack (2023) - Rust 语言，兼容 Webpack 配置
    ↓
Turbopack (2023) - Rust 语言，Next.js 团队开发
```

### React 19 构建变化
React 19 引入了重要的构建要求变化：
- **新 JSX Transform 必需**：不再需要手动导入 React
- **UMD 构建移除**：专注于现代 ESM 工作流
- **ESM CDN 支持**：更好的 tree shaking 和包体积优化

## 🛠️ 实践建议

### 工具选择指南
- **新项目**：首选 Vite，开发体验极佳
- **大型项目**：考虑 Webpack 或 Rspack，配置灵活
- **Next.js 项目**：使用 Turbopack
- **Webpack 迁移**：考虑 Rspack，配置兼容性好

### 配置优化要点
1. **代码分割**：合理配置 splitChunks
2. **Tree Shaking**：确保使用 ESM 格式
3. **缓存策略**：配置持久化缓存
4. **资源优化**：图片压缩、字体优化
5. **环境变量**：正确处理环境变量

### React 19 迁移要点
1. **更新 TypeScript 配置**：设置 `"jsx": "react-jsx"`
2. **移除 React 导入**：不再需要 `import React from 'react'`
3. **更新构建工具**：使用支持 React 19 的版本
4. **移除 UMD 依赖**：确保使用 ESM 格式
5. **测试构建结果**：验证所有功能正常

## 🎯 重点提示

### Vite 优势
- **极速启动**：基于 esbuild，冷启动速度快
- **即时 HMR**：模块级别的热替换，开发体验极佳
- **开箱即用**：内置 TypeScript、JSX、CSS 等支持
- **插件生态**：丰富的插件系统

### Webpack 优势
- **功能全面**：最成熟的构建工具，功能最全面
- **生态丰富**：大量的 loader 和 plugin
- **配置灵活**：可以满足各种复杂需求
- **生产优化**：成熟的生产环境优化方案

### React 19 构建关键
- **必须使用新 JSX Transform**：在 `tsconfig.json` 中设置 `"jsx": "react-jsx"`
- **移除 UMD 依赖**：确保使用 ESM 格式的依赖
- **更新构建工具**：使用支持 React 19 的最新版本构建工具
- **验证构建结果**：确保所有功能正常工作
