## 🔑 核心概念

### 前端安全的重要性
前端安全是保护用户数据和隐私的关键：
- **用户数据保护**：防止用户数据泄露
- **隐私保护**：保护用户隐私信息
- **防止攻击**：防范各种网络攻击
- **合规要求**：满足法律法规要求

### 常见安全威胁
1. **XSS（跨站脚本攻击）**：注入恶意脚本
2. **CSRF（跨站请求伪造）**：伪造用户请求
3. **点击劫持**：欺骗用户点击
4. **中间人攻击**：窃取传输数据
5. **依赖漏洞**：第三方库的安全漏洞

### 安全防护策略
- **输入验证**：对所有用户输入进行验证
- **输出编码**：对输出内容进行编码
- **HTTPS 强制**：所有通信使用 HTTPS
- **CSP 配置**：配置严格的内容安全策略
- **依赖管理**：定期更新和审计依赖

## 📊 安全威胁对比

| 威胁类型 | 危害程度 | 防护难度 | 常见场景 |
|----------|----------|----------|----------|
| XSS | 高 | 中 | 评论、表单输入 |
| CSRF | 中 | 低 | 表单提交、API 调用 |
| 点击劫持 | 中 | 中 | 嵌入 iframe |
| 中间人攻击 | 高 | 低 | HTTP 通信 |
| 依赖漏洞 | 高 | 高 | 第三方库 |

## 🛠️ 实践建议

### XSS 防护
```jsx
// 使用 React 的自动转义
function UserInput({ content }) {
  // React 自动转义内容，防止 XSS
  return <div>{content}</div>;
}

// 使用 DOMPurify 清理 HTML
import DOMPurify from 'dompurify';

function SanitizedHTML({ html }) {
  const cleanHTML = DOMPurify.sanitize(html);
  return <div dangerouslySetInnerHTML={{ __html: cleanHTML }} />;
}
```

### CSRF 防护
```jsx
// 使用 CSRF Token
import { getCsrfToken } from './utils/csrf';

function Form() {
  const csrfToken = getCsrfToken();

  const handleSubmit = async (e) => {
    e.preventDefault();
    const formData = new FormData(e.target);
    formData.append('csrf_token', csrfToken);
    
    await fetch('/api/submit', {
      method: 'POST',
      body: formData,
      credentials: 'include'
    });
  };

  return <form onSubmit={handleSubmit}>{/* 表单内容 */}</form>;
}
```

### CSP 配置
```http
Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline' https://cdn.example.com; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:; connect-src 'self' https://api.example.com;
```

## 🎯 重点提示

### 安全最佳实践
- **永远不要信任用户输入**：对所有输入进行验证和清理
- **使用 HTTPS**：所有通信都必须使用 HTTPS
- **最小权限原则**：只授予必要的权限
- **定期更新**：及时更新依赖和修复漏洞
- **安全审计**：定期进行安全审计

### React 安全特性
- **自动转义**：React 自动转义 JSX 中的内容
- **dangerouslySetInnerHTML**：谨慎使用，确保内容安全
- **React 19 改进**：更好的安全性和类型安全

### 依赖安全
- **定期审计**：使用 npm audit、Snyk 等工具
- **自动更新**：使用 Dependabot、Renovate 等工具
- **漏洞监控**：关注安全公告和 CVE 数据库
- **供应链安全**：验证依赖的完整性和可信度
