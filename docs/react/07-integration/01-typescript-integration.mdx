## 📚 概念介绍

TypeScript 为 React 应用提供了强大的类型安全，能够在编译时捕获错误，提高代码质量和开发效率。React 19 对 TypeScript 支持进行了重大改进，包括更严格的类型推断、更好的泛型支持以及移除了许多已废弃的类型。

本节将深入探讨如何在 React 19 中有效使用 TypeScript，包括组件类型定义、Hooks 类型安全、事件处理类型以及 React 19 的最新 TypeScript 变更。

## 🎯 TypeScript 基础

### 类型系统

TypeScript 的类型系统是静态的，这意味着类型检查在编译时进行，而不是运行时。这有助于在开发早期发现错误。

```js
// 基本类型示例
const userName = 'John Doe';
const userAge = 30;
const isAdmin = true;
const userData = null;
const userSkills = ['JavaScript', 'TypeScript', 'React'];

// 对象类型
const user = {
  id: 1,
  name: 'John Doe',
  email: 'john@example.com',
  age: 30,
  isActive: true
};

console.log('User:', user);
console.log('Skills:', userSkills);

// 类型检查示例
function processUserData(userData) {
  if (typeof userData !== 'object' || userData === null) {
    throw new Error('Invalid user data');
  }
  
  return {
    ...userData,
    processedAt: new Date().toISOString()
  };
}

const processedUser = processUserData(user);
console.log('Processed user:', processedUser);
```

### 接口与类型

接口和类型别名是 TypeScript 中定义复杂类型的两种主要方式。

```tsx
// 使用接口定义用户类型
interface InterfaceUser {
  id: number;
  name: string;
  email: string;
  getFullName(): string;
}

const interfaceUser: InterfaceUser = {
  id: 1,
  name: 'John Doe',
  email: 'john@example.com',
  getFullName() {
    return this.name;
  }
};

// 使用类型别名
type UserType = {
  id: number;
  name: string;
  email: string;
  role: 'admin' | 'user' | 'guest';
};

const typeUser: UserType = {
  id: 2,
  name: 'Jane Smith',
  email: 'jane@example.com',
  role: 'admin'
};

console.log('Interface User:', interfaceUser.getFullName());
console.log('Type User:', typeUser);

// 联合类型
type DisplayValue = string | number | boolean;

const displayValue = (value: DisplayValue): string => {
  if (typeof value === 'string') {
    return `String: ${value}`;
  } else if (typeof value === 'number') {
    return `Number: ${value}`;
  }
  return `Other: ${value}`;

console.log(displayValue('Hello'));
console.log(displayValue(42));
console.log(displayValue(true));
```

### 泛型编程

泛型允许我们创建可重用的组件，同时保持类型安全。

```tsx
// 泛型函数
function identity<T>(value: T): T {
  return value;
}

const stringResult: string = identity('Hello TypeScript');
const numberResult: number = identity(42);
const arrayResult: number[] = identity([1, 2, 3]);

console.log('String:', stringResult);
console.log('Number:', numberResult);
console.log('Array:', arrayResult);

// 泛型接口
interface ApiResponse<T> {
  data: T;
  status: 'success' | 'error';
  message: string;
}

interface Product {
  id: number;
  name: string;
}

const dataResponse: ApiResponse<Product> = {
  data: { id: 1, name: 'Product' },
  status: 'success',
  message: 'Data fetched successfully'
};

console.log('Response:', dataResponse);

// 泛型约束
interface HasLength {
  length: number;
}

function logLength<T extends HasLength>(value: T): T {
  console.log(`Length: ${value.length}`);
  return value;
}

logLength('Hello World');
logLength([1, 2, 3, 4, 5]);
```

## 🎯 React + TypeScript

### 组件类型定义

在 React 中，我们可以为组件的 Props 定义类型，确保组件接收正确的数据。

```tsx
// 在实际项目中使用 import React from 'react'
import React from 'react';

// 定义 Props 类型
interface GreetingProps {
  name: string;
  age: number;
  isAdmin: boolean;
}

// 函数组件类型定义
const Greeting: React.FC<GreetingProps> = ({ name, age, isAdmin }) => {
  return (
    <div>
      <h1>Hello, {name}!</h1>
      <p>Age: {age}</p>
      <p>Admin: {isAdmin ? 'Yes' : 'No'}</p>
    </div>
  );
};

// 使用组件
const App: React.FC = () => {
  return (
    <div>
      <Greeting name="John Doe" age={30} isAdmin={false} />
      <Greeting name="Admin User" age={35} isAdmin={true} />
    </div>
  );
};

// Props 验证函数（编译时类型检查）
function validateGreetingProps(props: GreetingProps): string[] {
  const errors: string[] = [];
  
  if (typeof props.name !== 'string' || props.name.trim() === '') {
    errors.push('name must be a non-empty string');
  }
  
  if (typeof props.age !== 'number' || props.age < 0) {
    errors.push('age must be a positive number');
  }
  
  if (typeof props.isAdmin !== 'boolean') {
    errors.push('isAdmin must be a boolean');
  }
  
  return errors;
}

// 测试验证
const validProps: GreetingProps = { name: 'John', age: 30, isAdmin: false };
// const invalidProps: GreetingProps = { name: '', age: -5, isAdmin: 'yes' }; // TypeScript 编译错误

console.log('Valid props errors:', validateGreetingProps(validProps));
```

### Hooks 类型安全

TypeScript 为 React Hooks 提供了完整的类型支持，确保状态和副作用的类型安全。

```tsx
import { useState, useEffect } from 'react';

// 定义用户类型
interface User {
  id: number;
  name: string;
  email: string;
}

// useState 类型示例
const Counter: React.FC = () => {
  const [count, setCount] = useState<number>(0);
  const [user, setUser] = useState<User | null>(null);

  const increment = () => {
    setCount(prevCount => prevCount + 1);
  };

  const loadUser = () => {
    setUser({
      id: 1,
      name: 'John Doe',
      email: 'john@example.com'
    });
  };

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={increment}>Increment</button>
      <button onClick={loadUser}>Load User</button>
      {user && (
        <div>
          <p>User: {user.name}</p>
          <p>Email: {user.email}</p>
        </div>
      )}
    </div>
  );
};

// useEffect 类型示例
interface Data {
  id: number;
  title: string;
  content: string;
}

const DataFetcher: React.FC = () => {
  const [data, setData] = useState<Data | null>(null);
  const [loading, setLoading] = useState<boolean>(true);
  const [error, setError] = useState<string | null>(null);

  const fetchData = async (): Promise<void> => {
    try {
      setLoading(true);
      // 模拟 API 调用
      const mockData: Data = {
        id: 1,
        title: 'Sample Data',
        content: 'This is sample content'
      };
      setData(mockData);
    } catch (err) {
      setError('Failed to fetch data');
    } finally {
      setLoading(false);
    }
  };

  useEffect(() => {
    fetchData();
  }, []);

  return (
    <div>
      <button onClick={fetchData}>Fetch Data</button>
      {loading && <p>Loading...</p>}
      {error && <p>Error: {error}</p>}
      {data && (
        <div>
          <h2>{data.title}</h2>
          <p>{data.content}</p>
        </div>
      )}
    </div>
  );
};
```

### 类型工具与实用类型

TypeScript 提供了许多实用的类型工具，可以帮助我们创建更灵活和可重用的类型。

```tsx
// 定义用户类型
interface User {
  id: number;
  name: string;
  email: string;
  age: number;
}

// Partial 类型 - 使所有属性变为可选
function updateUser(user: User, updates: Partial<User>): User {
  return { ...user, ...updates };
}

const originalUser: User = {
  id: 1,
  name: 'John Doe',
  email: 'john@example.com',
  age: 30
};

const updatedUser: User = updateUser(originalUser, { age: 31 });
console.log('Updated user:', updatedUser);

// Required 类型 - 使所有属性变为必需
interface PartialUser {
  id: number;
  name: string;
  email?: string;
}

const completeUser: Required<PartialUser> = {
  id: 2,
  name: 'Jane Smith',
  email: 'jane@example.com'
};

console.log('Complete user:', completeUser);

// Pick 类型 - 从类型中选择部分属性
type UserSummary = Pick<User, 'id' | 'name'>;

const userSummary: UserSummary = {
  id: 1,
  name: 'John Doe'
};

console.log('User summary:', userSummary);

// Omit 类型 - 从类型中排除部分属性
type CreateUser = Omit<User, 'id'>;

const createUserWithoutId: CreateUser = {
  name: 'New User',
  email: 'newuser@example.com',
  age: 25
};

console.log('User without ID:', createUserWithoutId);

// Record 类型 - 创建对象类型
type UserRole = 'admin' | 'user' | 'guest';
type RoleDescription = Record<UserRole, string>;

const userRoles: RoleDescription = {
  admin: 'Administrator',
  user: 'Regular User',
  guest: 'Guest User'
};

console.log('User roles:', userRoles);

// ReturnType 类型 - 获取函数返回类型
function getUserData(): { id: number; name: string; email: string } {
  return {
    id: 1,
    name: 'John Doe',
    email: 'john@example.com'
  };
}

type UserData = ReturnType<typeof getUserData>;
const userData: UserData = getUserData();
console.log('User data:', userData);
```

```js
// React 19 ref 清理函数

const RefCleanupExample = () => {
  const elementRef = null;

  const setRefWithCleanup = (element) => {
    if (elementRef) {
      // 清理之前的 ref
      console.log('Cleaning up previous ref');
    }

    elementRef = element;

    if (element) {
      // 设置新的 ref
      console.log('Setting new ref:', element);

      // 返回清理函数
      return () => {
        console.log('Ref cleanup function called');
        // 执行清理操作
      };
    }
  };

  return (
    <div>
      <div ref={setRefWithCleanup} style={{ padding: '20px', background: '#f0f0f0' }}>
        This div has a ref with cleanup function
      </div>
    </div>
  );
};

// 使用 ref 清理函数的实际示例
const AutoFocusInput = () => {
  const inputRef = null;
  const timeoutId = null;

  const setRefWithAutoFocus = (element) => {
    // 清理
    if (timeoutId) {
      clearTimeout(timeoutId);
    }

    if (element) {
      // 自动聚焦
      timeoutId = setTimeout(() => {
        element.focus();
        console.log('Input auto-focused');
      }, 100);

      // 返回清理函数
      return () => {
        if (timeoutId) {
          clearTimeout(timeoutId);
        }
        console.log('Input ref cleanup');
      };
    }
  };

  return (
    <div>
      <input
        ref={setRefWithAutoFocus}
        type="text"
        placeholder="This input will auto-focus"
      />
    </div>
  );
};

console.log('Ref cleanup components defined');
```

```tsx
import React from 'react';

// useActionState 类型定义
interface FormState {

const useFormExample: React.FC = () => {

interface Item {
  id: number;
  text: string;
  pending: boolean;

const OptimisticList: React.FC = () => {
  const [items, setItems] = React.useState<Item[]>([
    { id: 1, text: 'Item 1', pending: false }
  ]);

    <div>
      <button onClick={() => addItem('New Item')}>
        Add Optimistic Item
      </button>
      <ul>

          </li>
        ))}
      </ul>
    </div>
  );
};
```

```tsx
import React, { useState, useEffect } from 'react';

// 定义用户类型
interface User {
  id: number;
  name: string;
  email: string;
  role: 'admin' | 'user';
  createdAt?: string;
  updatedAt?: string;
}

// 定义用户数据类型（用于创建/更新）

const UserAPI: UserAPI = {

    return <p>No users found</p>;

          <p>Email: {user.email}</p>

          <div style={{ marginTop: '8px' }}>
            <button onClick={() => onEdit(user)}>Edit</button>
            <button
              style={{ marginLeft: '8px' }}
              onClick={() => onDelete(user.id)}
            >
              Delete
            </button>
          </div>
        </li>
      ))}
    </ul>
  );
};

// UserForm 组件 Props
interface UserFormProps {
  user?: User | null;
  onSubmit: (formData: UserData) => void;
  onCancel: () => void;
}

// 用户表单组件
const UserForm: React.FC<UserFormProps> = ({ user, onSubmit, onCancel }) => {
  const [formData, setFormData] = useState<UserData>(
    user || { name: '', email: '', role: 'user' }
  );

  const handleChange = (field: keyof UserData) => (
    event: React.ChangeEvent<HTMLInputElement | HTMLSelectElement>
  ) => {
    setFormData(prev => ({
      ...prev,
      [field]: event.target.value
    }));
  };

  const handleSubmit = (event: React.FormEvent<HTMLFormElement>): void => {
    event.preventDefault();
    onSubmit(formData);
  };

  return (
    <form
      onSubmit={handleSubmit}
      style={{
        border: '1px solid #ccc',
        padding: '16px',
        borderRadius: '4px'
      }}
    >
      <div style={{ marginBottom: '12px' }}>
        <label style={{ display: 'block', marginBottom: '4px' }}>Name:</label>
        <input
          type="text"
          value={formData.name}
          onChange={handleChange('name')}
          style={{ width: '100%', padding: '8px' }}
        />
      </div>
      <div style={{ marginBottom: '12px' }}>
        <label style={{ display: 'block', marginBottom: '4px' }}>Email:</label>
        <input
          type="email"
          value={formData.email}
          onChange={handleChange('email')}
          style={{ width: '100%', padding: '8px' }}
        />
      </div>
      <div style={{ marginBottom: '12px' }}>
        <label style={{ display: 'block', marginBottom: '4px' }}>Role:</label>
        <select
          value={formData.role}
          onChange={handleChange('role')}
          style={{ width: '100%', padding: '8px' }}
        >
          <option value="user">User</option>
          <option value="admin">Admin</option>
        </select>
      </div>
      <div>
        <button type="submit">Submit</button>
        <button
          type="button"
          style={{ marginLeft: '8px' }}
          onClick={onCancel}
        >
          Cancel
        </button>
      </div>
    </form>
  );
};

// 主应用组件
const UserManagementApp: React.FC = () => {
  const [users, setUsers] = useState<User[]>([]);
  const [loading, setLoading] = useState<boolean>(true);
  const [error, setError] = useState<string | null>(null);
  const [editingUser, setEditingUser] = useState<User | null>(null);
  const [showForm, setShowForm] = useState<boolean>(false);

  const loadUsers = async (): Promise<void> => {
    try {
      setLoading(true);
      const data = await UserAPI.fetchUsers();
      setUsers(data);
    } catch (err) {
      setError('Failed to load users');
    } finally {
      setLoading(false);
    }
  };

  const handleCreateUser = async (userData: UserData): Promise<void> => {
    try {
      const newUser = await UserAPI.createUser(userData);
      setUsers(prev => [...prev, newUser]);
      setShowForm(false);
    } catch (err) {
      setError('Failed to create user');
    }
  };

  const handleUpdateUser = async (userId: number, updates: Partial<UserData>): Promise<void> => {
    try {
      const updatedUser = await UserAPI.updateUser(userId, updates);
      setUsers(prev =>
        prev.map(user => (user.id === userId ? updatedUser : user))
      );
      setEditingUser(null);
    } catch (err) {
      setError('Failed to update user');
    }
  };

  const handleDeleteUser = (userId: number): void => {
    setUsers(prev => prev.filter(user => user.id !== userId));
  };

  const handleEdit = (user: User): void => {
    setEditingUser(user);
    setShowForm(true);
  };

  const handleSubmit = (formData: UserData): void => {
    if (editingUser) {
      handleUpdateUser(editingUser.id, formData);
    } else {
      handleCreateUser(formData);
    }
  };

  useEffect(() => {
    loadUsers();
  }, []);

  return (
    <div style={{ padding: '20px', maxWidth: '800px', margin: '0 auto' }}>
      <h1>User Management</h1>
      {loading && <p>Loading...</p>}
      {error && <p style={{ color: 'red' }}>{error}</p>}
      {!loading && !error && (
        <div>
          <button
            style={{ marginBottom: '16px' }}
            onClick={() => {
              setEditingUser(null);
              setShowForm(true);
            }}
          >
            Add New User
          </button>
          {showForm && (
            <div style={{ marginBottom: '20px' }}>
              <h2>{editingUser ? 'Edit User' : 'Create User'}</h2>
              <UserForm
                user={editingUser}
                onSubmit={handleSubmit}
                onCancel={() => setShowForm(false)}
              />
            </div>
          )}
          <UserList
            users={users}
            onEdit={handleEdit}
            onDelete={handleDeleteUser}
          />
        </div>
      )}
    </div>
  );
};

// 导出组件
export default UserManagementApp;
```
