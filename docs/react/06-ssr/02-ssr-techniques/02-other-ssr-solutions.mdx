## 📚 概念介绍

除了 Next.js，还有许多其他优秀的 SSR 框架，如 Remix、Astro、Gatsby 等。每个框架都有其独特的特点和适用场景。本章节将介绍这些主流的 SSR 方案。

## 🎯 Remix 框架

### Remix 基础

Remix 是一个基于 React Router 的全栈框架，专注于 Web 标准和渐进增强。

```js
// app/routes/products.tsx
import { json, LoaderFunctionArgs } from '@remix-run/node';
import { useLoaderData, Link } from '@remix-run/react';

// 服务器端数据加载
export async function loader({ request }: LoaderFunctionArgs) {
  const url = new URL(request.url);
  const category = url.searchParams.get('category');
  
  const res = await fetch(`https://api.example.com/products?category=${category}`);
  const products = await res.json();
  
  return json(products);
}

export default function ProductsPage() {
  const products = useLoaderData();
  
  return (
    <div>
      <h1>产品列表</h1>
      <ul>
        {products.map((product) => (
          <li key={product.id}>
            <Link to={`/products/${product.id}`}>
              <h2>{product.name}</h2>
              <p>¥{product.price}</p>
            </Link>
          </li>
        ))}
      </ul>
    </div>
  );
}
```

### Remix Actions

```js
// app/routes/products.new.tsx
import { ActionFunctionArgs, redirect } from '@remix-run/node';
import { Form } from '@remix-run/react';

// 服务器端表单处理
export async function action({ request }: ActionFunctionArgs) {
  const formData = await request.formData();
  const name = formData.get('name');
  const price = formData.get('price');
  
  // 创建产品
  const res = await fetch('https://api.example.com/products', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ name, price }),
  });
  
  const newProduct = await res.json();
  
  return redirect(`/products/${newProduct.id}`);
}

export default function NewProductPage() {
  return (
    <div>
      <h1>创建新产品</h1>
      <Form method="post">
        <div>
          <label>产品名称</label>
          <input name="name" type="text" required />
        </div>
        
        <div>
          <label>价格</label>
          <input name="price" type="number" required />
        </div>
        
        <button type="submit">创建</button>
      </Form>
    </div>
  );
}
```

## 🎯 Astro 框架

### Astro 基础

Astro 是一个现代的静态站点生成器，专注于内容网站和性能。

```astro
---
// src/pages/index.astro
const response = await fetch('https://api.example.com/posts');
const posts = await response.json();
---

<html lang="zh-CN">
  <head>
    <title>我的博客</title>
  </head>
  <body>
    <h1>欢迎来到我的博客</h1>
    <ul>
      {posts.map((post) => (
        <li>
          <a href={`/posts/${post.id}`}>
            <h2>{post.title}</h2>
            <p>{post.excerpt}</p>
          </a>
        </li>
      ))}
    </ul>
  </body>
</html>
```

## 🎯 Gatsby 框架

### Gatsby 基础

Gatsby 是一个基于 React 的静态站点生成器，专注于性能和开发者体验。

```js
// gatsby-config.js
module.exports = {
  siteMetadata: {
    title: 'My Gatsby Site',
    description: 'A Gatsby site',
    author: '@username',
  },
  plugins: [
    'gatsby-plugin-image',
    'gatsby-plugin-sharp',
    'gatsby-transformer-sharp',
    'gatsby-source-filesystem',
  ],
};
```

### Gatsby 页面

```js
// src/pages/index.js
import React from 'react';
import { graphql, useStaticQuery } from 'gatsby';

export default function HomePage() {
  const data = useStaticQuery(graphql`
    query {
      allMarkdownRemark {
        edges {
          node {
            frontmatter {
              title
              date
            }
            excerpt
          }
        }
      }
    }
  `);
  
  return (
    <div>
      <h1>博客文章</h1>
      <ul>
        {data.allMarkdownRemark.edges.map((edge) => (
          <li key={edge.node.id}>
            <h2>{edge.node.frontmatter.title}</h2>
            <p>{edge.node.excerpt}</p>
            <time>{edge.node.frontmatter.date}</time>
          </li>
        ))}
      </ul>
    </div>
  );
}
```

### Gatsby 数据源

## 🎯 框架对比

### 性能对比

```js
// 各框架的性能特点

// Next.js
// - 优势：完整的 SSR/SSG/ISR 支持
// - 适用：全栈应用、电商、SaaS
// - 性能：优秀，支持流式渲染

// Remix
// - 优势：渐进增强、Web 标准
// - 适用：传统 Web 应用、表单密集型应用
// - 性能：优秀，优化的数据加载

// Astro
// - 优势：极致性能、零 JS 默认
// - 适用：内容网站、博客、文档
// - 性能：最佳，静态 HTML

// Gatsby
// - 优势：丰富的插件生态、GraphQL
// - 适用：营销网站、博客
// - 性能：优秀，静态站点
```

### 选择建议

```js
// 框架选择指南

function chooseFramework(requirements) {
  const {
    needSSR,
    needAPI,
    contentFocused,
    performanceCritical,
    teamExperience,
  } = requirements;
  
  if (contentFocused && performanceCritical) {
    return 'Astro';
  }
  
  if (needSSR && needAPI) {
    if (teamExperience.includes('React')) {
      return 'Next.js';
    }
    return 'Remix';
  }
  
  if (contentFocused && teamExperience.includes('GraphQL')) {
    return 'Gatsby';
  }
  
  return 'Next.js'; // 默认选择
}

// 使用示例
const framework = chooseFramework({
  needSSR: true,
  needAPI: true,
  contentFocused: false,
  performanceCritical: true,
  teamExperience: ['React'],
});

console.log(`推荐的框架: ${framework}`);
```

## 🔗 相关概念

- **Next.js**: 完整的 React SSR 框架
- **Remix**: 基于 Web 标准的全栈框架
- **Astro**: 内容优先的静态站点生成器
- **Gatsby**: 基于 GraphQL 的静态站点生成器
- **框架选择**: 根据需求选择合适的框架
